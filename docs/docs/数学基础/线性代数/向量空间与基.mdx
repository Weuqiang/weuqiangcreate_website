# 向量空间与基

学完「线性代数入门」和「矩阵与线性方程组」后，你会发现一个反复出现的疑问：为什么有的方程组有唯一解，有的却有无穷多解？为什么三维数据「其实只有两维信息」？答案都藏在**向量空间与基**里。

## 学习目标

- 用自己的话说清什么是向量空间、什么是子空间，并能举出两个非坐标向量的例子。
- 判断一组向量是否线性无关，并能解释「无关」与「张成」的分工。
- 求出一个子空间的基与维数，理解 `rank` 到底在数什么。
- 把同一个向量在不同基下的坐标互相转换。

## 核心直觉

把向量空间想成**一块可以自由行走的场地**：你只有两种交通工具——「沿某个方向走任意远（数乘）」和「先走一段再接着走另一段（加法）」。所谓向量空间，就是任何用这两种动作都走不出去的场地。走不出去这件事叫**封闭性**，它比那 8 条公理更值得记住。

在这块场地上，一组向量有两个独立的评价维度：

- **张成（span）够不够大**：用这组向量能走遍整个场地吗？够大叫「张成整个空间」。
- **有没有冗余**：其中某个向量是否可以由其他向量走出来？没有冗余叫**线性无关**。

**基 = 恰好够用、且一个都不多**。它像地图上的经纬网：既能定位场地上任意一点，又不会给出两套重复的坐标。基里向量的个数是固定的，这个数就是**维数**——它不依赖你选哪组基，是空间自身的性质。

由此看矩阵就清楚了：矩阵 $A$ 的**列空间**是它所有列向量张成的子空间，$\mathrm{rank}(A)$ 就是列空间的维数，也就是「列向量里真正互不冗余的个数」。方程 $A\vec{x}=\vec{b}$ 有解，等价于 $\vec{b}$ 落在列空间这块场地里。

一个向量在基 $B=\{\vec{b}_1,\dots,\vec{b}_n\}$ 下的**坐标** $[\vec{v}]_B$，是指

$$
\vec{v}=c_1\vec{b}_1+\cdots+c_n\vec{b}_n,\qquad [\vec{v}]_B=(c_1,\dots,c_n)^T
$$

关键认知：**向量本身不变，坐标随基而变**。同一支箭，用不同的经纬网去量，读数不同。若把基向量按列拼成矩阵 $B$，则 $\vec{v}=B\,[\vec{v}]_B$，于是 $[\vec{v}]_B=B^{-1}\vec{v}$。

## 最小示例

```python
import numpy as np

# ---- 1. 判断线性无关：秩 == 向量个数 ----
v1 = np.array([1., 0., 1.])
v2 = np.array([0., 1., 1.])
v3 = np.array([1., 1., 2.])          # v3 = v1 + v2，是冗余的
M = np.column_stack([v1, v2, v3])    # 3x3，每列一个向量
print(np.linalg.matrix_rank(M))      # 2 -> 只有 2 个无关方向

# 去掉冗余后 {v1, v2} 就是列空间的一组基，维数 = 2
B = np.column_stack([v1, v2])
print(np.linalg.matrix_rank(B))      # 2 -> 确认无关

# ---- 2. 求坐标：v 在基 {b1, b2} 下的读数 ----
b1 = np.array([1., 1.])
b2 = np.array([1., -1.])             # 一组非标准基
B2 = np.column_stack([b1, b2])
v  = np.array([4., 2.])              # 标准基下的坐标是 (4, 2)

coords = np.linalg.solve(B2, v)      # 解 B2 @ coords = v
print(coords)                        # [3. 1.]  ->  v = 3*b1 + 1*b2

# 验算：换回标准基应还原 v
print(B2 @ coords)                   # [4. 2.]  ✔
```

手算核对第 2 段：$3(1,1)+1(1,-1)=(3+1,\,3-1)=(4,2)$，与代码一致。

## 易错点

- **把「张成」和「线性无关」混为一谈**。向量太多必定能张成，但会有冗余；向量太少必定无关，但张不满。基是这两者的唯一平衡点。
- **以为基是唯一的**。同一个空间有无穷多组基（上例中 $\{(1,1),(1,-1)\}$ 和标准基都行），但维数唯一。
- **含零向量的集合一定线性相关**。因为 $1\cdot\vec{0}$ 就是零向量的非平凡组合，所以任何包含 $\vec{0}$ 的集合都不能作基。
- **子空间必须过原点**。平面 $x+y=1$ 不是子空间（不含 $\vec{0}$、对数乘不封闭）；$x+y=0$ 才是。

## 练习

1. 判断 $\{(1,2,3),(2,4,6),(0,1,1)\}$ 是否线性无关，并给出其张成空间的维数。
   *提示：第二个向量是第一个的 2 倍，秩为 2，维数 = 2。*
2. 设基 $B=\{(2,0),(0,3)\}$，求 $\vec{v}=(6,6)$ 在 $B$ 下的坐标。
   *答案：$(3,2)$，因为 $3(2,0)+2(0,3)=(6,6)$。*
3. 证明：若 $\{\vec{u},\vec{v}\}$ 线性无关，则 $\{\vec{u}+\vec{v},\ \vec{u}-\vec{v}\}$ 也线性无关。
   *提示：设 $a(\vec{u}+\vec{v})+b(\vec{u}-\vec{v})=\vec{0}$，整理成 $(a+b)\vec{u}+(a-b)\vec{v}=\vec{0}$，由无关性得 $a+b=0,\ a-b=0$，故 $a=b=0$。*

## 小结

向量空间是对「加法与数乘封闭」的场地的抽象，子空间是其中同样封闭的一小块。一组向量的价值由两件事衡量：张成够不够大、有没有冗余；两者同时满足就是基，基的个数即维数。矩阵的秩正是其列空间的维数，因此秩决定了方程组解的结构。最后，向量是客观的，坐标是相对于基的读数——理解这一点，后面的特征值分解、SVD、主成分分析都只是在「换一组更好用的基」而已。
