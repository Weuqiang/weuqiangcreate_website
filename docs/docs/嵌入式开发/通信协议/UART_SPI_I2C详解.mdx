## 核心概念

三者是按“省线、高速、通用”不同的折中：UART 简单点对点，SPI 高速全双工，I2C 省引脚多设备。

本章主线：
- UART 异步串口
- SPI 同步高速
- I2C 同步省线
- 选型对照

## 1. UART（异步串口）

- 两根线：TX（发）、RX（收），**交叉连接**。
- 参数：波特率（如 9600/115200）、数据位、停止位、校验位。
- 全双工、点对点，无时钟线（靠双方约定波特率）。

```cpp
Serial.begin(115200);
Serial.println("hello");   // Arduino 的 Serial 就是 UART
```

## 2. SPI（同步、高速）

- 四线：SCK（时钟）、MOSI、MISO、CS（片选）。
- 主从结构，全双工，速度可达数十 MHz。
- 每个从设备一根 CS 线——设备多时引脚占用大。

```cpp
// 伪代码：读 SPI 传感器
digitalWrite(CS, LOW);
SPI.transfer(0x80);              // 发命令
uint8_t data = SPI.transfer(0);  // 收数据
digitalWrite(CS, HIGH);
```

## 3. I2C（同步、省线）

- 两线：SCL（时钟）、SDA（数据），**所有设备共享总线**。
- 每个从机有 7 位地址，主机会寻址。
- 速度较低（标准 100k / 快速 400k），但省引脚，适合挂多个传感器。

```cpp
Wire.beginTransmission(0x48);   // 从机地址
Wire.write(0x00);
Wire.endTransmission();
Wire.requestFrom(0x48, 2);
int val = (Wire.read() << 8) | Wire.read();
```

## 4. 怎么选

| 总线 | 速度 | 连线 | 适用 |
|------|------|------|------|
| UART | 中 | 2 | 调试、GPS、蓝牙模块 |
| SPI | 高 | 4+ | 屏幕、Flash、ADC |
| I2C | 低 | 2 | 多传感器、EEPROM |

> 上拉电阻：I2C 的 SCL/SDA 必须外接上拉（通常 4.7kΩ）到 VCC。

## 示例

一个把三种总线串起来的实用例程：UART 回显、I2C 读温度传感器（地址 0x48）、SPI 读 ADC，覆盖"点对点 / 多设备省线 / 高速全双工"三种拓扑：

```cpp
// 1) UART 回显：收到什么发什么
Serial.begin(115200);
if (Serial.available()) Serial.write(Serial.read());

// 2) I2C 读温度（TI TMP102，地址 0x48，2 字节补码）
Wire.beginTransmission(0x48);
Wire.write(0x00); Wire.endTransmission(false);   // 重复起始条件
Wire.requestFrom(0x48, 2);
int16_t raw = (Wire.read() << 8) | Wire.read();
float temp = raw * 0.0625f;

// 3) SPI 读 ADC（CS 拉低选中，发 0 收数据，用完拉高）
digitalWrite(CS, LOW);
SPI.transfer(0x80); uint16_t adc = SPI.transfer(0) << 8 | SPI.transfer(0);
digitalWrite(CS, HIGH);
```

> I2C 的 SDA/SCL 必须外接 4.7kΩ 上拉；SPI 多从机时每个设备独立 CS，传完立即拉高避免误触发。

## 小结

UART 交叉连接、SPI 管好片选、I2C 必接上拉；速度、线数、拓扑决定选型，三者覆盖绝大多数板级通信。

## 易错点

- **UART 要交叉连接**：A 的 TX 接 B 的 RX，接反了没数据；且两端波特率/电平必须一致。
- **I2C 不能忘上拉**：SDA/SCL 是开漏，没有上拉电阻总线拉不高，通信直接失败。
- **SPI 的 CS 必须管好**：多从机时 CS 没拉低就传，会误触发别的设备；用完及时拉高。
