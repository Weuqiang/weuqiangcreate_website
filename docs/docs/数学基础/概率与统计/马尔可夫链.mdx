# 马尔可夫链

天气预报、输入法联想、PageRank、强化学习的环境模型——它们共享同一个假设：**未来只取决于现在，与如何到达现在无关**。这就是马尔可夫性，也是最简单却最实用的随机过程模型。

## 学习目标

- 用状态转移矩阵描述一个马尔可夫链，并检查其行随机性。
- 计算 $n$ 步转移概率与任意时刻的状态分布。
- 求平稳分布，并解释它与特征值 1 的关系。
- 说明什么条件下链会收敛到唯一平稳分布，以及 PageRank 为何要加阻尼因子。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [概率基础与随机变量](/docs/数学基础/概率与统计/概率基础与随机变量) 中的条件概率。
- 了解矩阵乘法可参考 [线性代数入门](/docs/数学基础/线性代数/线性代数入门)。
- 能接受「下一步只取决于当前」的简化假设。

## 核心概念
**马尔可夫性 = 无记忆性**：

$$
P(X_{n+1}=j\mid X_n=i,X_{n-1},\dots,X_0)=P(X_{n+1}=j\mid X_n=i)
$$

想象在几个房间之间随机走动：下一步去哪，只看你**现在**站在哪个房间，与你之前走过什么路线完全无关。这个假设看似粗糙，却让模型从「需要记录全部历史」简化成「一张固定的转移表」，计算复杂度天差地别。

把转移概率排成矩阵 $P$，其中 $P_{ij}=P(i\to j)$。它有两条必须成立的性质：**每个元素非负**，且**每一行之和为 1**（从任一状态出发，总要去往某处）。这类矩阵叫**行随机矩阵**。

关键运算规则出奇地简洁——**多走一步就是多乘一次矩阵**：

$$
P^{(n)}=P^{n},\qquad \vec\pi_{n}=\vec\pi_{0}P^{n}
$$

其中状态分布 $\vec\pi$ 写成**行向量**。「两步从 $i$ 到 $j$」的概率就是「枚举中转站 $k$，把 $P_{ik}P_{kj}$ 加起来」，这正是矩阵乘法的定义。

**平稳分布** $\vec\pi$ 是走一步后分布不变的那个分布：

$$
\vec\pi P=\vec\pi,\qquad \sum_i\pi_i=1
$$

对照特征值方程可以立刻看出：**$\vec\pi$ 就是 $P$ 对应特征值 $\lambda=1$ 的左特征向量**（归一化后）。行随机矩阵必然有特征值 1，因为全 1 列向量满足 $P\mathbf{1}=\mathbf{1}$。

什么时候一定收敛到唯一的 $\vec\pi$？需要两个条件：

- **不可约**：任意状态都能（经若干步）到达任意状态，图是连通的；
- **非周期**：不存在「必须每 3 步才回来一次」这类固定节律。

满足两者的链称为**遍历的**，此时无论初始分布如何，$\vec\pi_n$ 都收敛到同一个 $\vec\pi$，收敛速度由第二大特征值的模 $|\lambda_2|$ 决定（越小越快）。

**PageRank** 正是这个理论的著名应用：网页是状态，链接是转移，$\vec\pi_i$ 就是网页 $i$ 的重要性。真实网络里存在没有出链的「悬挂节点」和封闭子图，会破坏不可约性，所以要加**阻尼因子** $d=0.85$：

$$
P'=d\,P+(1-d)\frac{1}{N}\mathbf{J}
$$

即「以 15% 概率随机跳到任意页面」，强行让链变得不可约且非周期，唯一平稳分布于是存在。

## 最小示例

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

# 天气模型：状态 0=晴, 1=雨
# 晴天后 90% 仍晴；雨天后 50% 转晴
P = np.array([[0.9, 0.1],
              [0.5, 0.5]])
print("行和:", P.sum(axis=1))       # [1. 1.] ✔ 行随机矩阵

# ---- 1. n 步转移：今天晴，n 天后的分布 ----
pi0 = np.array([1.0, 0.0])          # 行向量：今天 100% 晴
for n in [1, 2, 5, 20, 50]:
    print(f"n={n:>2} 天后: {pi0 @ np.linalg.matrix_power(P, n)}")
# 逐渐稳定到 [0.8333 0.1667]，且与初值无关

# ---- 2. 解线性方程求平稳分布 πP = π ----
# 等价于 (Pᵀ - I)πᵀ = 0，再补上归一化条件 Σπ = 1
A = np.vstack([P.T - np.eye(2), np.ones(2)])
b = np.array([0., 0., 1.])
pi_solve, *_ = np.linalg.lstsq(A, b, rcond=None)
print("\n解方程得平稳分布:", pi_solve)      # [0.8333 0.1667]
# 手算验证: π = (5/6, 1/6)，因为 0.9*(5/6)+0.5*(1/6) = 0.75+0.0833 = 5/6 ✔

# ---- 3. 特征向量法：λ=1 的左特征向量 ----
vals, vecs = np.linalg.eig(P.T)             # 左特征向量 = Pᵀ 的右特征向量
i = np.argmin(np.abs(vals - 1))             # 找 λ=1
pi_eig = np.real(vecs[:, i]); pi_eig /= pi_eig.sum()
print("特征向量法:", pi_eig)                # 同上 ✔
print("第二大特征值 |λ2| =", np.sort(np.abs(vals))[-2])   # 0.4 -> 收敛很快

# ---- 4. 幂迭代（PageRank 的实际算法）----
N = 4
# 4 个网页的链接结构：0->1,2 ; 1->2 ; 2->0 ; 3->2  （3 只出不进）
L = np.array([[0, 1, 1, 0],
              [0, 0, 1, 0],
              [1, 0, 0, 0],
              [0, 0, 1, 0]], dtype=float)
L = L / L.sum(axis=1, keepdims=True)        # 行归一化
d = 0.85
G = d * L + (1 - d) / N                     # 加阻尼，保证不可约非周期

rank = np.ones(N) / N
for _ in range(100):
    rank = rank @ G                         # 幂迭代
print("\nPageRank:", rank, " 和 =", rank.sum())
print("最重要的页面是:", int(np.argmax(rank)))   # 页面 2（被三个页面指向）
```

## 易错点

- **行向量与列向量混用**。本文约定分布是**行向量**、更新为 $\vec\pi P$；很多教材用列向量约定 $P^T\vec\pi$。两者不能混着写，否则结果错位。
- **忘记检查行和为 1**。构造转移矩阵时若某行是全零（悬挂节点），矩阵不再是随机矩阵，迭代会漏掉概率质量。
- **周期链不收敛**。$P=\begin{bmatrix}0&1\\1&0\end{bmatrix}$ 有平稳分布 $(0.5,0.5)$，但从 $(1,0)$ 出发会在两个状态间永远振荡，永不收敛。平稳分布**存在**不等于**收敛到**它。
- **可约链的平稳分布不唯一**。若存在两个互不连通的闭合子集，每个子集都有自己的平稳分布，任意凸组合也是平稳分布。
- **把马尔可夫性当成「无关历史」的普遍真理**。真实系统常有长程依赖，此时应扩充状态（如把「过去两天天气」并成一个状态）来恢复马尔可夫性。

## 练习

1. 已知 $P=\begin{bmatrix}0.7&0.3\\0.4&0.6\end{bmatrix}$，求平稳分布。
   *提示：解 $0.7\pi_1+0.4\pi_2=\pi_1$ 且 $\pi_1+\pi_2=1$，得 $\vec\pi=(4/7,3/7)\approx(0.571,0.429)$。*
2. 某链的第二大特征值模为 0.99，说明收敛速度如何。
   *答案：极慢。误差每步只衰减 1%，约需数百步才能收敛，实践中需要加速技巧或重构状态空间。*
3. 为什么 PageRank 要加阻尼因子 0.85？
   *答案：真实网络存在悬挂节点和「蜘蛛陷阱」（只进不出的封闭子图），会导致链可约、概率质量被吸走。随机跳转让链变为不可约非周期，从而保证唯一平稳分布存在且幂迭代收敛。*

## 小结

马尔可夫链假设未来只依赖当前状态，从而把随机过程压缩成一张转移矩阵。$n$ 步转移就是矩阵的 $n$ 次幂，状态分布的演化是行向量与矩阵的连乘。平稳分布满足 $\vec\pi P=\vec\pi$，即特征值 1 对应的左特征向量；当链不可约且非周期时，任意初始分布都会收敛到它，收敛速度由第二大特征值决定。PageRank 通过阻尼因子人为保证这两个条件，是该理论最成功的工程落地。
