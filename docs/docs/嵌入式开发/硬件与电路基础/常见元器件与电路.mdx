# 常见元器件与电路

做嵌入式少不了和电阻、电容、LED、三极管打交道。本篇列出最常用元件与几个必会电路。

## 1. 电阻、电容、电感

| 元件 | 作用 | 记忆口诀 |
|------|------|----------|
| 电阻 R | 限流、分压 | $V=IR$ |
| 电容 C | 储能、滤波、去耦 | 隔直通交 |
| 电感 L | 阻高频、储能 | 隔交通直 |

LED 限流电阻估算：$R=\frac{V_{CC}-V_{LED}}{I_{LED}}$，如 5V 驱动 2V/10mA 的 LED，取 $R=300\Omega$（常用 330Ω）。

## 2. 三极管作开关

用 MCU 的 3.3V 引脚驱动 5V/大电流的负载（如继电器、电机），常用 NPN 三极管或 MOSFET 作电子开关：

```text
MCU引脚 ──[1kΩ]── B
                 |
                NPN
                 |\
            E ── GND
            C ── 负载 ── VCC
```

`digitalWrite(pin, HIGH)` 导通，负载得电。

## 3. 上拉 / 下拉电阻

按键一端接地、一端接 IO，IO 需**上拉电阻**保证松开时为确定高电平：

```cpp
pinMode(BTN, INPUT_PULLUP);   // MCU 内部已带上拉
```

## 4. 去耦电容

每个 IC 的电源引脚旁放 `0.1µF` 陶瓷电容到地，滤除电源噪声——这是 PCB 上的「标配」。

## 5. 万用表与示波器

- **万用表**：测通断、电压、电流、电阻。
- **示波器**：看信号波形与时序（如 UART 波特率、PWM 占空比）。

> 调试「灯不亮 / 没通信」时，先量电源、再量信号，比瞎改代码高效十倍。

## 易错点

- **漏放去耦电容**：IC 电源脚旁没 0.1µF，电源噪声会导致随机复位/通信错误。
- **上拉电阻搞反**：按键/开漏信号必须上拉到确定电平，否则悬空读数是随机的。
- **三极管当开关要限流基极**：B 极直接接 MCU 引脚不串电阻会烧 IO 或三极管。

## 练习

1. 计算 3.3V 驱动 2.0V/5mA 的 LED 所需限流电阻，并选一个常用标称值。
2. 用 NPN 三极管驱动一个 12V 继电器，画出 MCU→三极管→继电器的连接与续流二极管。
