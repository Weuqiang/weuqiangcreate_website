# 编程外的基础：学习路线图

写代码只是工程的一小部分。本分类补全「不写业务代码但每天都会用、且决定你上限」的底层能力：**计算机科学导论**（建立全局心智模型）、**数据结构与算法**（解决问题的标准工具箱）、**开发工具链**（把代码可靠地变成可交付产物）。

## 推荐学习顺序

```text
计算机科学导论  →  数据结构与算法  →  开发工具链（与前面并行练习）
   （全局地图）      （思维与工具箱）      （工程化落地）
```

- **计算机科学导论** 先看：用最短路径建立「计算、操作系统、网络、数据库、编译」的全局地图，知道每个领域解决什么问题。
- **数据结构与算法** 是核心训练：它训练你把模糊问题拆成可计算步骤，是面试与日常编码的共同底盘。
- **开发工具链** 边用边学：Git / 终端 / Docker / Markdown / YAML 是每天的工具，不必系统学，遇到即用即查。

## 待补充主题（完善清单）

- **计算机科学导论**：图灵机与可计算性、操作系统概念（进程/内存/文件系统）、计算机网络基础（TCP/IP 分层）、数据库概念（关系模型/SQL）、编译原理概览。
- **数据结构与算法**：
  - 线性结构：数组、链表、栈、队列、哈希表。
  - 树与堆：二叉树、二叉搜索树、堆（优先队列）、平衡树、 Trie。
  - 图：表示、遍历（BFS/DFS）、最短路径、最小生成树。
  - 算法范式：排序与查找、递归、分治、动态规划、贪心、回溯、二分。
  - 复杂度：大 O 分析、均摊分析、常见复杂度速查。

## 学习建议

数据结构与算法**不要背代码，要背「什么时候用」**。每学一种结构/算法，先问三件事：它解决哪类问题？时间/空间复杂度多少？和相近的几种怎么选？本分类文章会按「场景 → 结构/算法 → 复杂度 → 实现 → 易错点」的模板展开。
