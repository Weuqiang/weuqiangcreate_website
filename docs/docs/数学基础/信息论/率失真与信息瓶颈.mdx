# 率失真与信息瓶颈

[信息论基础](/docs/数学基础/概率与统计/信息论基础) 的源编码定理回答「**无损**压缩能压多小」（极限是熵 $H(X)$）。但现实中我们接受一点点失真换更高压缩率：照片有噪点、音频丢高频、视频抽帧——人眼人耳并不在乎。率失真理论（Rate–Distortion）回答：**给定可接受的失真上限 $D$，最少需要多少比特/符号？** 这一章先讲清 $R(D)$，再引出它的近亲——信息瓶颈（Information Bottleneck），后者是深度学习表征理论的重要视角。

## 学习目标

- 写出率失真函数 $R(D)$ 的定义，并解释其「在失真约束下最小化互信息」的本质。
- 计算高斯源（MSE 失真）的率失真函数，理解「失真换码率」的折中曲线。
- 了解 Blahut–Arimoto 算法如何数值求解 $R(D)$。
- 理解信息瓶颈的目标 $\max I(T;Y)-\beta I(T;X)$，以及它如何统一「压缩」与「保留任务相关信息」。

- 熟悉 [信息论基础](/docs/数学基础/概率与统计/信息论基础) 的互信息与 KL 散度。
- 信息瓶颈与表示学习有关，可参考 [自监督与对比学习](/docs/人工智能/深度学习/自监督与对比学习)（表征学习的另一视角）。

## 核心概念

### 率失真函数：有损压缩的极限

给定源 $X$ 与失真度量 $d(x,\hat x)\ge 0$（$d=0$ 表示「完美重建」），我们允许用一个**重建符号** $\hat X$ 来近似，平均失真不超过 $D$：

$$
R(D)=\min_{p(\hat x\mid x)\,:\,\mathbb E[d(X,\hat X)]\le D} I(X;\hat X)
$$

直观解释：

- $I(X;\hat X)$ 是「为描述重建值而必须传输的信息量」——这就是**率（Rate）**。
- 约束 $\mathbb E[d]\le D$ 是「允许的失真（Distortion）」。
- $R(D)$ 是在「失真不超过 $D$」前提下，能达到的**最小**传输率。

**典型形状**：$R(D)$ 随 $D$ 增大而单调递减、凸。

- $D=0$（无损）时，对离散源 $R(0)=H(X)$——退化为源编码定理。
- $D\ge D_{\max}$（恰好用「最懒重建」即可满足）时 $R(D)=0$，什么都不用传。
- 中间是平滑的折中曲线：**愿意接受更多失真，就能压得更狠**。

**香农率失真定理**：对 i.i.d. 源，存在码率任意接近 $R(D)$ 的编码方案，使平均失真 $\le D$；任何低于 $R(D)$ 的码率都无法在约束内保证失真。换言之，$R(D)$ 就是有损压缩的**理论天花板**。

### 例子：高斯源 + 均方误差（MSE）

当 $X\sim\mathcal N(0,\sigma^2)$、$d(x,\hat x)=(x-\hat x)^2$ 时，可解析求出：

$$
R(D)=\begin{cases}
\frac12\log_2\frac{\sigma^2}{D}, & 0<D\le \sigma^2\\[4pt]
0, & D>\sigma^2
\end{cases}
$$

这正是「信噪比」视角：每符号只需 $\frac12\log_2(\text{SNR})$ 比特就能把失真压到 $D$。均匀标量量化在高频段近似达到这条曲线。

### Blahut–Arimoto 算法

$R(D)$ 是个带约束的最小化，解析解只在少数分布存在。Blahut–Arimoto 用**交替优化**数值求解：

1. 固定 $p(\hat x)$，更新辅助分布 $q(x\mid \hat x)\propto p(x)\exp\big(\beta\, d(x,\hat x)\big)$（$\beta$ 由 Lagrange 乘子控制失真）。
2. 固定 $q$，更新 $p(\hat x)=\sum_x p(x)q(x\mid\hat x)$。
3. 交替至收敛，互信息即逼近 $R(D)$。

这是「率失真」版的期望最大化（EM），说明优化问题本身有迭代结构。

### 信息瓶颈（Information Bottleneck, IB）

把「源 $X$ → 重建 $\hat X$」换成「输入 $X$ → 压缩表示 $T$ → 相关变量 $Y$」：我们希望 $T$ 尽量**压缩** $X$，又尽量**保留**关于 $Y$ 的信息。Tishby 等提出最大化

$$
\mathcal L=I(T;Y)-\beta\,I(T;X)
$$

- $I(T;X)$ 小 → 表示 $T$ 是 $X$ 的紧致压缩（去冗余）。
- $I(T;Y)$ 大 → $T$ 对任务 $Y$（如类别标签）仍有判别力。
- $\beta$ 平衡两者：大 $\beta$ 偏重压缩，小 $\beta$ 偏重保真。

IB 提供了「深度网络每层在做什么」的一种解释：前向传播像是逐层做 IB——在压缩输入冗余的同时保有预测所需信息。变分下界（如 VIB）让它能用神经网络训练。

## 最小示例

```python
import numpy as np

# ---- 1. 高斯源率失真函数的解析值 ----
def R_gaussian(D, sigma=1.0):
    return 0.5 * np.log2(sigma**2 / D) if 0 < D <= sigma**2 else 0.0

for D in [0.01, 0.1, 0.5, 1.0]:
    print(f"D={D:<4} -> R(D)={R_gaussian(D):.3f} 比特/符号")

# ---- 2. Blahut-Arimoto 求离散源的 R(D)（简化版） ----
def blahut_arimoto(px, d_matrix, beta, iters=200):
    # px: 源分布; d_matrix[i,j]=d(x_i, xhat_j); beta 对应失真权重
    Xn, Xhn = len(px), d_matrix.shape[1]
    # 初始化 q(x|xhat) 均匀
    q = np.ones((Xn, Xhn)) / Xhn
    for _ in range(iters):
        # 更新 p(xhat) = sum_x px * q(x|xhat)
        p_xhat = px @ q
        # 更新 q(x|xhat) ∝ px(x) * exp(-beta * d(x,xhat))
        log_q = np.log(px)[:,None] - beta * d_matrix
        log_q -= log_q.max(axis=0)            # 数值稳定
        q = np.exp(log_q); q /= q.sum(axis=0)
    # 计算平均失真与互信息
    p_joint = px[:,None] * q
    distortion = np.sum(p_joint * d_matrix)
    # I(X;Xhat) = sum p(x,xhat) log [p(x,xhat)/(p(x)p(xhat))]
    p_xhat = p_joint.sum(axis=0)
    with np.errstate(divide='ignore', invalid='ignore'):
        mi = np.nansum(p_joint * np.log2(p_joint / (px[:,None] * p_xhat[None,:])))
    return R := mi, distortion

# 二值源，汉明失真
px = np.array([0.5, 0.5])
d = np.array([[0,1],[1,0]])                  # d(x,xhat)
mi, dist = blahut_arimoto(px, d, beta=10.0)
print(f"\n二值源 BA: I(X;Xhat)={mi:.3f} bit, 平均失真={dist:.3f}")
# 与理论对比：二值源 R(D)=H2(0.5)-H2(D)=1-H2(D)
def H2(p): return -p*np.log2(p)-(1-p)*np.log2(1-p)
print(f"理论 R(D={dist:.3f})={1-H2(dist):.3f} bit")
```

## 易错点

- **把 $R(D)$ 当成「编码器的实际码率」**。$R(D)$ 是**存在性**极限（渐近、大块长度），具体编码器（如 JPEG）通常高于它，但永远不应低于它。
- **混淆失真度量**。$R(D)$ 强烈依赖 $d(\cdot,\cdot)$：MSE、汉明、绝对误差给出的曲线完全不同；比较「压缩率」前必须先固定失真定义。
- **高斯 $R(D)$ 在 $D>\sigma^2$ 直接取 0 的直觉**：此时「永远输出均值 0」的平均 MSE 已是 $\sigma^2$，再大的 $D$ 无额外收益，故率为 0。
- **信息瓶颈里 $\beta$ 的方向**：$\beta$ 大→强压缩（牺牲 $I(T;Y)$），$\beta$ 小→保真优先；写反会导致「越压缩越准」的反直觉结果。
- **IB 与率失真混为一谈**。$R(D)$ 压缩 $X$ 到 $\hat X$ 以逼近 $X$ 自身；IB 压缩 $X$ 到 $T$ 以保留**另一下游变量 $Y$** 的信息，目标函数多了一项 $I(T;Y)$。

## 练习

1. 对二值对称源（$p=0.5$）与汉明失真，证明 $R(D)=1-H_2(D)$（$0\le D\le 0.5$），并画出曲线。
   *提示：用 Blahut–Arimoto 数值结果与上式对照；当 $D=0$ 得 1 比特（即熵），$D=0.5$ 得 0。*
2. 高斯源 $\sigma^2=4$，若要求 $R(D)\le 1$ 比特/符号，最大允许失真 $D$ 是多少？
   *答案：由 $\frac12\log_2(4/D)\le1$ 得 $\log_2(4/D)\le2$ → $4/D\le4$ → $D\ge1$。*
3. 信息瓶颈中若令 $Y=X$（即要保留关于自身的全部信息），目标退化为何？这说明了压缩与保真的张力。
   *提示：退化为 $\max -(\beta-1)I(T;X)$，当 $\beta<1$ 时鼓励 $T$ 完全保留 $X$，与「压缩」矛盾。*

## 小结

率失真函数 $R(D)=\min_{p(\hat x|x),\,\mathbb E[d]\le D} I(X;\hat X)$ 给出了**有损压缩的理论极限**：在失真约束下最小化必须传输的互信息。高斯源+MSE 有简洁闭式 $R(D)=\frac12\log_2(\sigma^2/D)$；一般源可由 Blahut–Arimoto 迭代求解。信息瓶颈把同一思想迁移到表征学习：在压缩输入 $X$（减 $I(T;X)$）与保留任务信息 $Y$（增 $I(T;Y)$）之间用 $\beta$ 权衡。它们与 [信道容量](/docs/数学基础/信息论/信道容量与香农定理) 共享「在约束下优化互信息」的核心范式。
