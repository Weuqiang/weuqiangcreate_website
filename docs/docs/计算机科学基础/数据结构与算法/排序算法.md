# 排序算法

排序是最常被考察、也最实用的算法家族。本文把常见排序按「直觉 → 实现 → 复杂度」串起来，帮你建立选型的肌肉记忆。

## 学习目标

- 口述冒泡/选择/插入/快排/归并各自的核心思想。
- 背下它们的时空复杂度，并解释快排为什么平均更快。
- 能手写快速排序（递归 + 分治）。

## 前置知识

- [数组与链表](../数组与链表) — 排序的输入通常是数组。
- [栈与队列](../栈与队列) — 理解递归与分治的基础。

## 核心概念与对比

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定 | 思想 |
|---|---|---|---|---|---|
| 冒泡排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 | 相邻比较交换 |
| 选择排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 | 每轮选最小放前面 |
| 插入排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 | 像理扑克牌 |
| 快速排序 | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$ | 不稳定 | 分治 + 基准 |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 稳定 | 分治 + 合并 |

> **稳定**指「相等元素排序后相对顺序不变」，对对象排序（如按成绩排，成绩相同保持原序）很重要。

## 最小可运行示例

冒泡排序（教学用，实际少用）：

```python
def bubble(a):
    a = a[:]
    for i in range(len(a)):
        for j in range(len(a)-1-i):
            if a[j] > a[j+1]:
                a[j], a[j+1] = a[j+1], a[j]
    return a
```

快速排序（必须掌握）：

```python
def quicksort(a):
    if len(a) <= 1:
        return a
    pivot = a[len(a)//2]          # 选基准
    left  = [x for x in a if x < pivot]
    mid   = [x for x in a if x == pivot]
    right = [x for x in a if x > pivot]
    return quicksort(left) + mid + quicksort(right)   # 分治合并

print(quicksort([3,1,4,1,5,9,2,6]))   # [1, 1, 2, 3, 4, 5, 6, 9]
```

> 上面是「易懂版」（用列表推导，空间 $O(n)$）。工程实现常用原地 `partition` 把空间压到 $O(\log n)$，但思想一致。

## 怎么选

- 数据量小或基本有序：**插入排序**很快（常数小）。
- 通用默认：**快速排序**（平均最快，且原地版省内存）。
- 需要稳定或最坏有保障：**归并排序**（外部排序、链表排序常用）。
- 几乎别用：冒泡/选择——仅用于教学和理解。

## 易错点

1. **快排最坏 $O(n^2)$**：当数组已排序且总选首尾作基准时退化。随机选基准或三数取中可缓解。
2. **递归深度**：快排递归深度 $O(\log n)$，但最坏 $O(n)$ 会爆栈；超大数组考虑改用堆排序或迭代版。
3. **混淆稳定性**：快排不稳定，若业务要求稳定别乱用。
4. **忘了边界**：递归终止条件 `len(a) <= 1` 必须写，否则死循环。

## 练习

1. 实现原地快排（单数组 + `partition`），并统计比较次数。
2. 用归并排序思想统计数组中的逆序对数量。
3. 给一个「成绩+姓名」列表，按成绩降序、成绩相同按姓名升序稳定排序。

## 小结

排序的本质是「比较 + 移动」，快排和归并用**分治**把 $O(n^2)$ 压到 $O(n\log n)$。记住对比表，面试时先说复杂度再写代码。相关结构见 [哈希表](../哈希表) 与 [树与二叉树](../树与二叉树)。
