## 核心概念

高维数据常有冗余和噪声，降维把它压到低维同时尽量保住结构。PCA 找「方差最大」的正交方向做线性投影，适合去噪和压缩；t-SNE/UMAP 专为可视化设计，保的是「近邻关系」而非全局距离，所以绝不能用它们降维后的坐标做后续建模特征——那会引入假结构。降维是工具不是目的，先想清楚要保什么。

## 为什么要降维

数据常有成百上千个特征，听起来信息丰富，实则带来难题：高维空间里样本彼此疏远（“维度灾难”），训练慢、易过拟合、还画不出来。降维就是**在尽量保留有用信息的前提下，把特征压到更低维**。

常见用途：数据压缩、去噪、可视化、作为其他模型的预处理。

## 三大主力

### PCA（主成分分析）—— 线性

找方差最大的若干正交方向（对协方差矩阵做特征分解），把数据投影上去。

- **可逆**：能从低维近似还原高维，适合压缩 / 去噪。
- **保全局结构**：保留的是“总方差最大”的方向，不刻意保局部近邻。
- 对特征**尺度敏感**：先标准化。

### t-SNE —— 非线性，保局部

把高维近邻关系转成概率分布，在低维重建相似分布。

- 擅长把**聚类结构**画得清清楚楚。
- **不适合**训练后泛化到新样本，也不适合超大样本（复杂度高）。
- `perplexity`（困惑度）是核心超参，需调。

### UMAP —— 非线性，更快更稳

思路和 t-SNE 类似但理论更扎实，通常**更快**、可泛化到新样本、保留更多全局结构。

## 最小可运行示例（scikit-learn）

```python showLineNumbers
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.datasets import load_iris
import matplotlib.pyplot as plt

X, y = load_iris(return_X_y=True)

X_pca = PCA(n_components=2).fit_transform(X)      # 线性降维
X_tsne = TSNE(n_components=2, perplexity=30,
              random_state=0).fit_transform(X)    # 非线性降维

plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y)
plt.title("PCA of iris"); plt.show()
plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y)
plt.title("t-SNE of iris"); plt.show()
```

## 常见误区

- **不先标准化就跑 PCA**：量纲大的特征会霸占主成分，结果失真。
- **把 t-SNE 当确定性的**：它带随机性，要固定 `random_state` 才能复现；且降维结果**不能**直接当特征去训练分类器（易过拟合 / 信息泄漏）。
- **混淆降维与特征选择**：降维是“造新特征”，特征选择是“挑旧特征”，目的不同。
- **只看 2D 图下结论**：高维结构映射到 2D 必然有扭曲，t-SNE 的簇间距不代表真实距离。

## 小结

PCA 保方差、适合预处理；t-SNE/UMAP 保近邻、只适合看图。别把可视化降维的结果当特征喂回模型——那会编造距离关系。
