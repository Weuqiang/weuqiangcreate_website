# 递归与分治

递归是「函数调用自己」的写法，分治是「把大问题拆成同类小问题分别解决再合并」的策略。两者常一起出现：分治几乎总用递归实现。

## 学习目标

- 写出一个正确的递归函数（明确基线条件）。
- 说出分治三步走：分解、解决、合并。
- 识别递归的风险（栈溢出、重复计算）。

## 前置知识

- [栈与队列](../栈与队列) — 递归本质是用调用栈。
- [排序算法](../排序算法) — 快排/归并就是分治。

## 核心概念

### 1. 递归的两要素

- **基线条件（base case）**：最小到不用再拆的情况，必须能直接返回，否则无限递归。
- **递推关系（recursive step）**：把问题缩小一步后调用自己。

### 2. 分治（Divide and Conquer）

1. **分解**：把规模 $n$ 的问题拆成若干规模更小的同类子问题。
2. **解决**：子问题小到直接解（落到基线）。
3. **合并**：把子问题的解组合成原问题的解。

代表：归并排序、快速排序、二分查找。

## 最小可运行示例

递归阶乘：

```python
def fact(n):
    if n <= 1:          # 基线
        return 1
    return n * fact(n - 1)   # 递推
```

带备忘录的斐波那契（消除重复计算，从 $O(2^n)$ 降到 $O(n)$）：

```python
def fib(n, memo=None):
    if memo is None: memo = {}
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]
```

分治：归并排序的「合并」步骤

```python
def merge(left, right):
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    return out + left[i:] + right[j:]
```

## 易错点

1. **忘写基线条件**：导致无限递归直到「递归深度超限」报错。
2. **重复计算**：朴素斐波那契指数级重复，必须用备忘录或迭代。
3. **栈溢出**：递归深度与 $n$ 成正比，超深时改迭代或尾递归（Python 不优化尾递归）。
4. **合并写错**：分治的难点常在「合并」，别只拆不解。

## 练习

1. 用递归实现数组求和与最大子数组和（分治法）。
2. 用备忘录优化「爬楼梯」问题（每次 1 或 2 步，到第 n 阶有多少种走法）。
3. 把递归快排改写成非递归版本，观察是否还需要栈。

## 小结

递归让代码贴近「问题的数学定义」，分治让复杂度从 $O(n^2)$ 降到 $O(n\log n)$。记住「基线 + 递推 + 合并」三步。接下来看 [二分查找](../二分查找)（分治在有序数组上的特例）和 [动态规划入门](../动态规划入门)（分治的进阶，处理重叠子问题）。
