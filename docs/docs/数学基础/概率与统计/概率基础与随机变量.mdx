# 概率基础与随机变量

不确定性无处不在：网络延迟、用户点击、模型预测都是随机的。概率与统计提供了一套描述与推理不确定性的语言。

## 学习目标

学完本章，你应该能够：

- 说清概率的三条公理与非负、归一、可加性。
- 用贝叶斯定理在「已知结果」时反推「原因」概率。
- 区分离散与连续随机变量及其分布。
- 理解期望与方差刻画了分布的「中心」与「散布」。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已了解 [集合逻辑与证明](/docs/数学基础/离散数学/集合逻辑与证明) 中的集合运算。
- 高中排列组合的直观即可。
- 能接受「长期频率趋近概率」的直觉。

## 核心概念

概率论给「不确定性」一套严谨的账本：三条公理（非负、总概率为 1、互斥事件概率可加）让所有计算有据可依。随机变量是把「实验结果」翻译成「数字」的桥梁，于是分布、期望、方差得以统一描述。最反直觉也最有用的是贝叶斯定理——它让你在看到新证据后，反过来更新对原因的相信程度，这正是机器学习里大量推断的思想源头。

本章主线：
- 从概率公理建立不确定性的账本
- 用贝叶斯定理连接原因与证据
- 再用随机变量统一描述分布

## 1. 概率公理

样本空间 $\Omega$ 上，事件 $A$ 的概率满足：

- $0 \le P(A) \le 1$
- $P(\Omega)=1$
- 互斥事件可加：$P(A\cup B)=P(A)+P(B)$

条件概率与乘法公式：

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)}
$$

## 2. 贝叶斯定理

已知「结果」反推「原因」的概率：

$$
P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}
$$

这是 spam 过滤、医学诊断、参数估计的共同骨架。例如：已知某检测对患病者 99% 灵敏、对健康者 95% 特异，若人群患病率 1%，则检测阳性者真正患病的概率只有约 17%——「先验」的影响巨大。

## 3. 随机变量与分布

随机变量把结果映射到数值。两类常见分布：

| 分布 | 场景 | 关键参数 |
|------|------|----------|
| 伯努利 / 二项 | 一次 / 多次成败 | $p$ |
| 正态（高斯） | 自然测量误差 | $\mu,\sigma$ |
| 泊松 | 单位时间事件数 | $\lambda$ |

```python
import numpy as np
# 1000 次掷硬币（p=0.5）的正面次数分布
samples = np.random.binomial(n=10, p=0.5, size=1000)
print(samples.mean())   # ≈ 5
```

## 4. 期望与方差

期望是「长期平均值」，方差衡量离散程度：

$$
\mathbb{E}[X]=\sum_x x\,P(x),\qquad \mathrm{Var}(X)=\mathbb{E}[(X-\mathbb{E}[X])^2]
$$

下一篇将用它们做描述统计与贝叶斯推断。

## 示例

**期望与方差（掷骰子的长期平均）**：设 $X$ 为一次掷六面骰子的点数，等概率 $1/6$：

$$
\mathbb{E}[X]=\frac{1+2+3+4+5+6}{6}=3.5,\qquad
\mathrm{Var}(X)=\mathbb{E}[X^2]-\mathbb{E}[X]^2=\frac{91}{6}-12.25\approx 2.92
$$

**贝叶斯（垃圾邮件）**：设 $P(\text{spam})=0.2$，某词 W 在垃圾邮件中出现概率 $0.8$、正常邮件中 $0.1$，则出现 W 的邮件是垃圾的后验：

$$
P(\text{spam}\mid W)=\frac{0.8\times0.2}{0.8\times0.2+0.1\times0.8}=\frac{0.16}{0.24}\approx 0.667
$$

```python
def bayes(p_h, p_e_given_h, p_e_given_not):
    p_not = 1 - p_h
    p_e = p_e_given_h*p_h + p_e_given_not*p_not
    return p_e_given_h*p_h / p_e
print(round(bayes(0.2, 0.8, 0.1), 3))   # 0.667
```

## 小结

概率公理给不确定性立规矩，贝叶斯定理让你用证据更新信念，随机变量把结果翻译成可计算的分布。它是 [描述统计与贝叶斯推断](/docs/数学基础/概率与统计/描述统计与贝叶斯推断)、[信息论](/docs/数学基础/概率与统计/信息论基础) 与 [大数定律](/docs/数学基础/概率与统计/大数定律与中心极限定理) 的基石，也是现代 [机器学习](/docs/人工智能/大模型与应用/检索增强) 的语言。

## 易错点

- 条件概率 $P(A\mid B)$ 与 $P(B\mid A)$ 方向相反、数值不同；贝叶斯定理正是用来在两者间转换。
- 「独立」与「互斥」不是一回事：独立是 $P(A\cap B)=P(A)P(B)$，互斥是 $A\cap B=\varnothing$；两事件若概率都非零，互斥必不独立。
- 期望的线性性质 $\mathbb{E}[X+Y]=\mathbb{E}[X]+\mathbb{E}[Y]$ 恒成立，但 $\mathbb{E}[XY]=\mathbb{E}[X]\mathbb{E}[Y]$ 只在独立时成立。
