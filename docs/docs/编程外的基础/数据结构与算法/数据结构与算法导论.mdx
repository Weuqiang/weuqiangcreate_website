# 数据结构与算法导论

数据结构是**数据的组织方式**，算法是**操作数据的步骤**。两者共同决定程序"快不快、省不省"。

## 1. 复杂度：衡量好坏的尺子

用大 O 表示法描述随数据规模 $n$ 增长的趋势：

| 复杂度 | 含义 | 例子 |
|--------|------|------|
| $O(1)$ | 常数 | 数组按下标访问 |
| $O(\log n)$ | 对数 | 二分查找 |
| $O(n)$ | 线性 | 遍历数组 |
| $O(n \log n)$ | 线性对数 | 归并/快速排序 |
| $O(n^2)$ | 平方 | 冒泡排序 |

## 2. 核心数据结构

```
数据结构
├─ 线性结构   数组 / 链表 / 栈 / 队列
├─ 树        二叉树 / 堆 / 红黑树 / Trie
├─ 图        邻接表 / 邻接矩阵
└─ 哈希      哈希表（O(1) 查找）
```

## 3. 一个例子：用哈希表去重

```python
def unique(items):
    seen = set()          # 哈希集合，平均 O(1) 插入/查询
    result = []
    for x in items:
        if x not in seen:
            seen.add(x)
            result.append(x)
    return result

print(unique([1, 2, 2, 3, 3, 3]))   # [1, 2, 3]
```

## 4. 学习路线

1. **线性结构**：数组、链表、栈、队列及相互转换。
2. **树与图**：遍历（DFS/BFS）、二叉搜索树、堆。
3. **排序与查找**：快排、归并、二分。
4. **高级算法**：动态规划、贪心、回溯。
