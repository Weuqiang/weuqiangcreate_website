# 世界模型

## 核心概念

### 1. 从「试错」到「想象」

标准 RL 每步都要与真实环境交互，样本昂贵。人却能在脑中推演：「如果我这么做，接下来会怎样」。**世界模型（World Model）** 就是把这种「内部模拟器」学出来：一个对环境的紧凑近似，agent 可在其中**无代价地想象轨迹、规划、再回真实环境执行**。

好处直接：在模型里跑成千上万条轨迹不花真实样本；规划可在隐空间做，速度快；模型还能当**表征学习器**，逼出有用的状态抽象。

### 2. 世界模型的三个组件

一个典型世界模型把交互 $(o_t,a_t,r_t)$（观测、动作、奖励）拆成：

- **表示（Representation）** $z_t = q(z_t\mid o_t)$：把高维观测压缩成紧凑隐状态。
- **动态（Dynamics）** $\hat z_{t+1} \sim p(z_{t+1}\mid z_t,a_t)$：预测下一步隐状态（常是随机的，以建模不确定性）。
- **奖励/终止预测** $\hat r_t = p(r_t\mid z_t)$：预测即时奖励与是否结束。

训练目标是让这套生成模型在给定真实轨迹时似然最大（或重构误差最小），之后行为策略只在「想象轨迹」上用标准 RL（如 Actor-Critic）优化。

### 3. RSSM 与 Dreamer：在想象中训练

**RSSM（Recurrent State-Space Model）** 是世界模型最实用的动态结构，它显式区分**确定性隐状态 $h_t$** 与**随机隐状态 $z_t$**：

$$
h_t = f(h_{t-1}, z_{t-1}, a_{t-1}),\qquad z_t \sim p(z_t\mid h_t, o_t)
$$

确定性部分负责长程记忆，随机部分负责建模观测的不确定性。Dreamer 系列在此基础上：用世界模型**生成多步想象轨迹**，在想象上用 lambda-return /  Actor-Critic 训练策略与价值，再把更新后的策略放回真实环境采集——样本效率比无模型 RL 高出一个数量级。

### 4. JEPA：非生成的预测

生成式世界模型要重构像素，成本高且被迫建模无关细节。JEPA（Joint Embedding Predictive Architecture，如 I-JEPA、V-JEPA）走另一条路：**在表征空间里做预测**——给定上下文块，预测未来/被遮块的**嵌入**而非像素。它只建模「任务相关」的结构，更省算力、更鲁棒，被视为通往通用世界模型的方向之一。

## 示例

用伪代码勾勒 Dreamer 式「想象中训练」的骨架：

```python
# 1) 训练世界模型（真实轨迹上）
for o, a, r in real_buffer:
    z = encoder(o)
    z_next = dynamics(z, a)              # 预测隐状态
    loss = recon(z_next, encoder(next_o)) + reward_pred(z, r)
    loss.backward(); wm_opt.step()

# 2) 在想象轨迹上训练策略（不碰真实环境）
h, z = init_hidden()
for t in range(horizon):
    a = actor(z.detach())               # 策略只看隐状态
    z = dynamics(z, a)                   # 在模型里 rollout
    r_hat = reward_head(z)
    adv = critic(z) - baseline
    policy_loss += -logprob(a) * adv     # Actor-Critic 在想象上更新
actor_opt.step()
```

直觉例子：**机器人学走路**。真实每一步摔倒都费硬件、有损耗；用世界模型先在隐空间里试百万次「抬哪条腿、重心怎么移」，学出稳健策略后只需少量真实微调即可站立行走——这正是样本效率的来源。

## 易错点

- **模型误差累积**：长程想象会放大世界模型的偏差，策略可能在「模型的幻觉」里很优、回真实环境就崩。需限制想象长度、或用模型集成估计不确定性。
- **过度拟合无关细节**：生成式模型若忙着重构背景像素，会挤占容量、学到的表征反而没用。JEPA 类「只预测嵌入」可缓解。
- **奖励欺骗（reward hacking）**：若奖励预测头不准，策略会钻模型漏洞拿高分。真实环境校验不可省。
- **Sim2Real 鸿沟**：纯仿真训的世界模型在真实传感器噪声下失效；需域随机化或真实数据回填。

## 练习

3. 思考：JEPA 不重构像素，它靠什么保证「预测的嵌入」仍包含任务相关信息？

## 小结

世界模型把「在真实环境试错」升级为「先学内部模拟器、再在想象中训练」。RSSM/Dreamer 用确定+随机隐状态在隐空间 rollout，把样本效率提升一个量级；JEPA 则放弃像素重构、只在表征空间预测，更省更稳。它是高效 RL、Sim2Real 与具身智能的共同引擎。
