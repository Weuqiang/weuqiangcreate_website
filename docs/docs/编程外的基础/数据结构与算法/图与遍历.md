# 图与遍历

图（Graph）是比树更一般的层次/网络结构：节点（顶点）之间可以任意相连，不要求有根、也不要求无环。**树是「无环连通图」**，所以图能表达社交网络、地图路由、依赖关系等一切「多对多」关系。

## 学习目标

- 说出邻接表与邻接矩阵两种表示的取舍。
- 手写 DFS 与 BFS，并说清各自适合什么场景。
- 知道最短路径/最小生成树的大致思路。

## 前置知识

- [树与二叉树](../树与二叉树) — 图是树的推广；DFS/BFS 同样适用。
- [栈与队列](../栈与队列) — DFS 用栈（递归即隐式栈），BFS 用队列。

## 核心概念

### 1. 图的表示

- **邻接表**：每个顶点存一个「邻居列表」。空间 $O(V+E)$，适合**稀疏图**（边远少于 $V^2$）。
- **邻接矩阵**：`V×V` 的二维数组 `matrix[u][v]` 表示是否有边。查询 $O(1)$，但空间 $O(V^2)$，适合**稠密图**。

### 2. 两种遍历

| 遍历 | 数据结构 | 顺序 | 典型应用 |
|---|---|---|---|
| DFS（深度优先） | 栈 / 递归 | 一条路走到底再回溯 | 连通分量、拓扑排序、环检测 |
| BFS（广度优先） | 队列 | 一层层扩散 | **最短路（无权）**、层序、迷官最短步 |

两者都需一个 `visited` 集合避免重复访问（图可能有环，不像树天然无环）。

## 最小可运行示例

邻接表 + DFS / BFS：

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'], 'E': ['B'], 'F': ['C'],
}

def dfs(graph, start):
    visited, stack = set(), [start]
    while stack:
        u = stack.pop()
        if u not in visited:
            visited.add(u)
            stack.extend(reversed(graph[u]))   # 保证顺序直观
    return visited

from collections import deque
def bfs(graph, start):
    visited, q = set([start]), deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in visited:
                visited.add(v)
                q.append(v)
    return visited

print(dfs(graph, 'A'))   # {'A','B','C','D','E','F'}
print(bfs(graph, 'A'))   # 同样访问到全部，但按层顺序
```

## 易错点

1. **忘了 `visited`**：图有环，不用 visited 会无限循环。
2. **DFS 用递归爆栈**：极深的图递归会超出递归深度，改显式栈（如上）。
3. **混淆 BFS/DFS 用途**：求「无权图最短路径」必须用 BFS（DFS 不保证最短）；找「是否存在路径/环」两者都行。
4. **表示法选错**：稀疏图用邻接矩阵会浪费大量空间。

## 练习

1. 判断无向图是否连通（从任一点 DFS/BFS 能否访问全部）。
2. 用 BFS 求无权图中两点的最短距离。
3. 检测有向图是否有环（拓扑排序思路）。

## 小结

图的威力在于表达「任意关系」。邻接表省空间、邻接矩阵查得快；DFS 探深度、BFS 探广度。它们是一切图算法（最短路径 Dijkstra、最小生成树、拓扑排序）的底座。回到 [树与二叉树](../树与二叉树) 复习层次结构，或看 [哈希表](../哈希表) 做邻接表的哈希实现。
