# 梯度与方向导数

一元函数的导数只有「向左」「向右」两个方向可走。到了多元世界，方向有无穷多个——**往哪走下降最快？** 梯度就是回答这个问题的工具，也是所有机器学习训练算法的引擎。

## 学习目标

- 计算多元函数的偏导数与梯度向量。
- 用内积公式求任意方向的方向导数，并证明梯度是最陡上升方向。
- 解释梯度与等高线垂直的几何原因。
- 实现最基础的梯度下降，并用数值梯度校验解析梯度是否写对。

## 核心直觉

把二元函数 $f(x,y)$ 想成一片**山地地形**：$(x,y)$ 是地图坐标，$f$ 是海拔。

- **偏导数** $\frac{\partial f}{\partial x}$ 是「只沿正东方向走时的坡度」，$\frac{\partial f}{\partial y}$ 是「只沿正北方向走时的坡度」。它们各自把另一个变量当常数。
- **梯度** 把这些分量组装成一个向量：

$$
\nabla f=\left(\frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y}\right)
$$

- **方向导数** 是沿任意单位方向 $\vec u$ 走时的坡度：

$$
D_{\vec u}f=\nabla f\cdot\vec u=\|\nabla f\|\cos\theta
$$

最后这个式子直接给出两个核心结论：

- $\cos\theta$ 在 $\theta=0$ 时最大，所以**梯度方向就是上升最快的方向**，最大坡度等于 $\|\nabla f\|$；负梯度方向则下降最快。
- $\cos\theta=0$ 即 $\vec u\perp\nabla f$ 时坡度为零——沿这个方向走**海拔不变**，而海拔不变的轨迹正是**等高线**。因此**梯度处处垂直于等高线**。这不是巧合，而是内积为零的直接推论。

由此，梯度下降的更新规则就是自然的：

$$
\vec x_{k+1}=\vec x_k-\eta\,\nabla f(\vec x_k)
$$

学习率 $\eta$ 控制步长：太小则慢，太大则会在陡峭的「山谷」两壁之间反复横跳甚至发散。

多元链式法则是反向传播的数学本体。若 $z=f(u,v)$，而 $u=u(t),v=v(t)$，则

$$
\frac{dz}{dt}=\frac{\partial f}{\partial u}\frac{du}{dt}+\frac{\partial f}{\partial v}\frac{dv}{dt}
$$

「每条路径的贡献相乘，所有路径相加」——神经网络的反向传播就是在计算图上反复套用这一条。

再往上一阶是**Hessian 矩阵**（二阶偏导构成的方阵）。在驻点处（$\nabla f=\vec0$）：Hessian 正定为极小值，负定为极大值，特征值有正有负则是**鞍点**。高维空间中鞍点远多于局部极小，这是深度学习优化的重要事实。

## 最小示例

```python
import numpy as np

# 目标函数：f(x, y) = x^2 + 3y^2   （一个偏椭圆的碗）
def f(p):
    x, y = p
    return x**2 + 3*y**2

# 解析梯度：∇f = (2x, 6y)
def grad(p):
    x, y = p
    return np.array([2*x, 6*y])

# ---- 1. 数值梯度校验（写梯度必做的自检）----
def numerical_grad(fn, p, eps=1e-6):
    g = np.zeros_like(p)
    for i in range(len(p)):
        e = np.zeros_like(p); e[i] = eps
        g[i] = (fn(p + e) - fn(p - e)) / (2 * eps)   # 中心差分，精度 O(eps^2)
    return g

p0 = np.array([1.0, 2.0])
print(grad(p0))                      # [2. 12.]
print(numerical_grad(f, p0))         # [2. 12.]  ✔ 解析梯度写对了

# ---- 2. 方向导数：验证梯度方向坡度最大 ----
g = grad(p0)
for name, u in [("梯度方向", g / np.linalg.norm(g)),
                ("正东方向", np.array([1.0, 0.0])),
                ("等高线切向", np.array([-g[1], g[0]]) / np.linalg.norm(g))]:
    print(f"{name}: 方向导数 = {g @ u:.4f}")
# 梯度方向 = 12.1655 (= ||g||，最大)；正东 = 2.0；等高线切向 ≈ 0.0000 ✔

# ---- 3. 梯度下降 ----
p, eta = np.array([3.0, 2.0]), 0.1
for k in range(41):
    if k % 10 == 0:
        print(f"step {k:2d}: p = {p.round(5)}, f = {f(p):.6f}")
    p = p - eta * grad(p)
# 收敛到 (0, 0)，f -> 0 ✔ 注意 y 方向因曲率更大（系数 3）而收敛更快

# ---- 4. 学习率过大导致发散 ----
p, eta = np.array([3.0, 2.0]), 0.4     # 0.4 > 2/6，y 方向不满足收敛条件
for _ in range(10):
    p = p - eta * grad(p)
print("eta=0.4 结果:", p)              # y 分量剧烈震荡放大
```

手算校验：在 $(1,2)$ 处 $\nabla f=(2\cdot1,\ 6\cdot2)=(2,12)$，$\|\nabla f\|=\sqrt{4+144}=\sqrt{148}\approx12.166$，与程序输出一致。

## 易错点

- **方向向量忘记单位化**。$D_{\vec u}f=\nabla f\cdot\vec u$ 要求 $\|\vec u\|=1$，否则算出的「坡度」会被向量长度虚假放大。
- **把梯度当成「函数图像的切平面法向量」**。$\nabla f$ 是**定义域（输入空间）**中的向量，维度与自变量个数相同，不在三维图像空间里。
- **误以为梯度为零就是极小值**。驻点也可能是极大值或鞍点，需要看 Hessian 的特征值符号。
- **学习率与曲率不匹配**。对 $f=\sum c_i x_i^2$，收敛要求 $\eta<2/\max(2c_i)$。各方向曲率差异大（病态）时，固定学习率必然低效，这正是 Adam 等自适应方法的动机。
- **数值梯度的 `eps` 不是越小越好**。太小会被浮点舍入吞掉，中心差分取 $10^{-5}\sim10^{-6}$ 通常最佳。

## 练习

1. 求 $f(x,y)=x^2y+y^3$ 在点 $(1,2)$ 处的梯度。
   *答案：$\nabla f=(2xy,\ x^2+3y^2)=(4,\ 13)$。*
2. 上题中沿方向 $\vec u=(3,4)/5$ 的方向导数是多少？
   *答案：$(4,13)\cdot(0.6,0.8)=2.4+10.4=12.8$。*
3. 判断 $f(x,y)=x^2-y^2$ 在原点是极大、极小还是鞍点。
   *提示：$\nabla f=(2x,-2y)$ 在原点为零；Hessian $=\mathrm{diag}(2,-2)$ 特征值一正一负，故为鞍点。*

## 小结

偏导数刻画沿坐标轴的变化率，梯度把它们组装成向量。方向导数等于梯度与单位方向向量的内积，由此可知梯度指向最陡上升方向、模长即最大坡度，且始终垂直于等高线。沿负梯度迭代就是梯度下降，其步长必须与函数曲率匹配，否则震荡或发散。多元链式法则是反向传播的本质，而 Hessian 的特征值符号则区分极小值、极大值与鞍点。写解析梯度后务必用中心差分做数值校验。
