# 线性代数入门

线性代数是人工智能、计算机图形学、数据科学的数学基石。它研究**向量、矩阵以及它们之间的线性变换**。

## 1. 向量（Vector）

向量是一组有序数的集合，可理解为空间中的一个点（或带方向的箭头）。

$$
\vec{v} = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}
$$

在编程中，向量通常表示为一维数组：

```python
import numpy as np
v = np.array([1, 2, 3])
print(v + v)        # [2 4 6]  向量加法
print(v * 2)        # [2 4 6]  数乘
print(np.dot(v, v)) # 14       点积（内积）
```

## 2. 矩阵（Matrix）

矩阵是二维的数表，代表一个线性变换。

$$
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}
$$

```python
A = np.array([[1, 2], [3, 4]])
x = np.array([1, 1])
print(A @ x)        # [3 7]   矩阵乘向量
print(A.T)          # 转置
print(np.linalg.inv(A))  # 逆矩阵
```

## 3. 为什么重要

- **机器学习**：模型参数、特征、梯度的本质都是向量/矩阵，训练即大量矩阵运算。
- **降维**：PCA 通过特征值分解把高维数据压缩到低维。
- **图形学**：3D 变换（旋转、缩放、平移）用矩阵表示。

## 易错点

- 矩阵乘法**不满足交换律**：$AB$ 通常不等于 $BA$，甚至维度都可能不匹配。
- 点积 $\vec{a}\cdot\vec{b}$ 得到标量，叉积（三维）得到向量，别混用。
- `@`（matmul）与 `*`（逐元素乘）在 NumPy 里完全不同；`A*A` 不是平方，是逐元素乘积。

## 练习

1. 已知向量 $\vec{u}=(1,2,2)$，求其模长 $\|\vec{u}\|$ 与单位向量。
2. 设 $A=\begin{bmatrix}1&0\\0&2\end{bmatrix}, B=\begin{bmatrix}0&1\\1&0\end{bmatrix}$，计算 $AB$ 与 $BA$，验证 $AB\neq BA$。
