# 微分几何基础

## 核心概念

### 1. 流形：局部像欧氏空间的形状

$d$ 维流形 $M$ 是局部同胚于 $\mathbb{R}^d$ 的拓扑空间，例如球面 $S^2$、环面、旋转矩阵群 $SO(3)$。全局可能弯曲，但每点附近可铺一张「局部坐标卡」。许多约束集合（正交矩阵、正定矩阵、概率单纯形）天然是流形——直接在其中优化，往往比反复投影回欧氏空间更自然。

### 2. 切空间与切向量

在点 $p$ 的切空间 $T_pM$ 是所有「经过 $p$ 的曲线在 $p$ 处的速度」的集合。在嵌入视角下它是 $\mathbb{R}^n$ 的线性子空间；抽象视角下它是「方向导数算子」的空间。梯度在流形上不再是 $\mathbb{R}^n$ 里的普通向量，而是切空间中的元素。

### 3. 黎曼度量

黎曼度量 $g_p$ 给每个切空间 $T_pM$ 一个内积 $\langle\cdot,\cdot\rangle_p$。它定义了：向量长度 $\|v\|=\sqrt{g(v,v)}$、两向量的夹角，以及曲线长度（对 $\sqrt{g(\gamma',\gamma')}$ 积分）。不同度量下「最短路径」不同。

### 4. 测地线：流形上的「直线」

测地线是局部最短、且加速度为零（$\nabla_{\gamma'}\gamma'=0$）的曲线。欧氏空间里是直线，球面上则是大圆。流形优化沿测地线方向移动：黎曼梯度下降先用指数映射 $\operatorname{Exp}_p(v)$ 把切向量映回流形。

### 5. 与机器学习/优化的联系

- **黎曼优化**：在流形约束上做梯度下降（如 SPD 矩阵上的协方差学习、Stiefel 流形上的正交约束）
- **流形上的扩散模型**：把数据生成过程放在数据所在的低维流形上理解（流形 SDE）
- **信息几何**：用黎曼度量（Fisher 信息矩阵）度量和分布之间的距离

## 示例

在球面 $S^2$ 上用黎曼梯度下降求「最远离给定点 $p$」的位置（即其对踵点 $-p$），演示「梯度 → 切空间投影 → 指数映射回流形」的核心三步：

```python
import numpy as np

p = np.array([0.0, 0.0, 1.0])      # 目标点
q = np.array([1.0, 0.0, 0.0])      # 初始点（单位化）
q = q / np.linalg.norm(q)

def riemann_step(q, p, lr=0.6):
    grad = p                                  # 欧氏梯度 ∇f = p
    grad_tan = grad - q * (q @ grad)          # 投影到切空间 T_q S^2
    nrm = np.linalg.norm(grad_tan) + 1e-12
    v = lr * grad_tan / nrm                   # 切向量
    nv = np.linalg.norm(v)
    return q * np.cos(nv) + v * np.sin(nv) / nv   # 指数映射回球面

for _ in range(40):
    q = riemann_step(q, p)
print("收敛到的点（应≈ -p）:", np.round(q, 4))
print("与 -p 的距离:", round(np.linalg.norm(q - (-p)), 6))
```

## 易错点

- **把流形梯度当欧氏向量直接加**：必须先投影到切空间、再用指数映射回流形。
- **忽略度量差异**：不同黎曼度量下长度、角度、测地线都不同，「最近」没有绝对标准。
- **混淆流形维数与嵌入维数**：如 $S^2$ 是 2 维流形，尽管嵌在 $\mathbb{R}^3$。
- **以为所有约束集都是光滑流形**：带角点或不等式活跃约束处只是流形的边界，不可直接套指数映射。

## 小结

微分几何研究弯曲空间上的微积分：流形是局部像欧氏的形状，切空间承载方向与梯度，黎曼度量定义长度与角度，测地线是流形上的「直线」。黎曼优化、流形上的扩散模型与信息几何都把机器学习问题搬到了流形上，是欧氏优化的自然推广。
