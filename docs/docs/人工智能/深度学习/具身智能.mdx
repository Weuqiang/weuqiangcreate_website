# 具身智能

## 学习目标

- 理解「具身」为何是通用智能的关键一环（符号落地、因果交互）

## 核心概念

### 1. 为什么「身体」重要

传统 AI 在文本/图像里「旁观」世界，没有因果交互。具身智能主张：智能体必须**有身体、能行动、能从行动后果中学习**。它解决了两个根本问题：

- **符号落地（symbol grounding）**：「杯子」不只是词向量，而是能抓、会掉、盛水的物理对象。
- **主动因果**：智能体通过「我做→世界变→我再看」建立因果，而非被动接收标注。

这更接近人类与动物的学习：婴儿靠抓握、跌落、行走理解物理，而非读说明书。

### 2. 感知-决策-执行闭环

具身系统是一个闭环：

$$
\text{观测 } o_t \xrightarrow{\text{感知}} \text{状态/表征 } s_t \xrightarrow{\text{决策 } \pi} \text{动作 } a_t \xrightarrow{\text{执行}} \text{环境 } \xrightarrow{} o_{t+1}
$$

- **感知**：视觉（RGB/深度）、 proprioception（本体感受：关节角、力矩）、语言指令；
- **决策**：把多模态观测映成动作，常用 Transformer 骨干 + 策略头；
- **执行**：底层控制器把高层指令转成电机力矩/速度（常是 PID 或学习得到的低层策略）。

### 3. VLA：把大模型接进机器人

**VLA（Vision-Language-Action）模型** 是当前最热路线：用大规模网文/视频预训练的语言-视觉大模型作为「大脑」，再在其上接一个**动作解码头**，直接输出机器人动作（如 RT-1/RT-2、OpenVLA）。它带来的质变：

- **指令跟随**：用自然语言下达「把红块放到蓝盘里」，模型零样本理解；
- **泛化**：互联网规模预训练让它能认没见过的物体/场景；
- **链式推理**：可先「想 steps」再「做动作」，把长程任务拆开。

### 4. Sim2Real 与训练范式组合

真实机器人数据采集贵且慢，于是多在仿真训练、再迁移到真实（Sim2Real）：

- **域随机化**：在仿真里随机化光照、摩擦、质量，逼出对干扰鲁棒的策略；
- **世界模型**：在仿真学内部模拟器，想象中训练、真实少量微调（见[世界模型](/docs/人工智能/深度学习/世界模型)）；
- **模仿学习**：用人类遥操作示范快速起步，配 DAgger 纠偏（见[模仿学习](/docs/人工智能/机器学习/模仿学习与逆强化学习)）；
- **分层控制**：高层定子目标（「靠近门」），低层执行细节（见[分层强化学习](/docs/人工智能/机器学习/分层强化学习与选项)）。

## 示例

用伪代码勾勒一个 VLA 风格的机器人策略前向：

```python
class VLA(nn.Module):
    def forward(self, image, instruction, state):
        vis = vision_encoder(image)              # 视觉令牌
        txt = text_encoder(instruction)          # 语言令牌
        tok = concat([vis, txt, proprio(state)]) # 多模态融合
        feat = transformer(tok)                  # 共享「大脑」
        action = action_head(feat)               # 解码为 6-DoF 动作
        return action

# 部署：闭环执行
while not done:
    a = vla(camera(), "把红块放蓝盘", robot.state())
    robot.step(a)                                # 底层控制器执行
```

直觉例子：**厨房整理**。传统编程要为每个物体写检测+抓取+放置规则，脆弱。VLA 接收一句「把用过的碗放进洗碗机」，自己结合当前视觉判断碗在哪、用哪只手、路径怎么避障——把「感知-语言-动作」端到端打通。

## 易错点

- **Sim2Real 鸿沟被低估**：仿真里完美的策略，遇到真实传感器噪声、关节 backlash、未建模摩擦就失效。域随机化与真实回填缺一不可。
- **开环执行**：只输出单步动作、不回看后果，累积误差让长程任务崩。必须闭环（用最新观测重新决策）。
- **语言与动作错位**：VLA 在未见过的物体/指令上可能「听懂但做错」，需评估而非盲信零样本。
- **安全边界缺失**：真实物理里动作有误会伤人/损物；需碰撞约束、力限幅与急停。

## 练习

1. 列举三个「纯文本 AI 永远学不会、必须具身交互才能懂」的能力，并说明原因。
2. 设计一个缓解 Sim2Real 的域随机化清单（至少 5 项物理/视觉属性）。
3. 思考：把世界模型 + VLA + 分层控制三者组合，各自负责哪一层？画出信息流。

## 小结

具身智能让智能「长在身体里」：通过感知-决策-执行闭环在物理世界中建立因果与符号落地。VLA 把互联网规模预训练的大模型接进机器人，实现自然语言指令跟随与泛化；世界模型、模仿学习与分层控制则解决真实采样的昂贵与安全。它是通向通用智能与机器人落地的核心路径。
