# 计算机科学基础：学习路线图

写代码只是工程的一小部分。本分支补全「不写业务代码但每天都会用、且决定你上限」的底层能力：**计算机科学导论**（建立全局心智模型）、**组成原理 / 操作系统 / 编译原理 / 计算机网络**（四门核心专业课）、**数据结构与算法**（解决问题的标准工具箱）。

## 推荐学习顺序

```text
计算机科学导论 → 组成原理 → 操作系统 → 编译原理 → 计算机网络
   （全局地图）    （硬件怎么算）（资源怎么管）（代码怎么翻译）（数据怎么传）
                              ↘  数据结构与算法（全程并行训练）  ↙
```

- **计算机科学导论** 先看：用最短路径建立全局地图，知道每个领域解决什么问题，避免一头扎进细节。
- **四门核心课** 按硬件 → 系统 → 语言 → 网络的顺序读，每一层都在为上一层隐藏复杂度，顺序读才连得起来。
- **数据结构与算法** 是贯穿全程的核心训练：它训练你把模糊问题拆成可计算步骤，是面试与日常编码的共同底盘。

## 学习建议

数据结构与算法**不要背代码，要背「什么时候用」**。每学一种结构/算法，先问三件事：它解决哪类问题？时间/空间复杂度多少？和相近的几种怎么选？本分类文章会按「场景 → 结构/算法 → 复杂度 → 实现 → 易错点」的模板展开。
