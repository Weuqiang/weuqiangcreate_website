# Rust 语言入门

Rust 是一门**内存安全、无垃圾回收、高性能**的系统级语言，能在编译期消除数据竞争与悬垂指针。

## 学习目标
- 跑通第一个 Rust 程序（`cargo run`）；
- 理解**所有权（ownership）**为何能替代垃圾回收；
- 理解**借用（borrow）**如何在不转移所有权的情况下安全使用值；
- 知道为什么 Rust 值得学、能用在哪些场景。

## 前置知识
- 任意编程语言基础（变量、函数、循环）；
- 想对照内存模型，可看 [C 语言入门](../../../C/0基础语法) 或 [Go 语言入门](../../../Go/语言基础/Go语言入门)。

## 核心概念

### 1. Hello World

```rust
fn main() {
    println!("Hello, Rust!");
}
```

运行：`cargo run`（Cargo 是 Rust 的构建与包管理工具）

### 2. 所有权（Ownership）：Rust 的灵魂

Rust 不用 GC，而是靠**所有权规则**在编译期管理内存：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;              // 所有权转移（move），s1 此后失效
    // println!("{}", s1);   // ❌ 编译错误：value borrowed after move
    println!("{}", s2);      // ✓
}
```

- 每个值有唯一**所有者**。
- 离开作用域时自动释放（无需手动 `free`）。
- 赋值或传参默认是 **move**，避免浅拷贝导致的双重释放。

### 3. 借用与生命周期

```rust
fn len(s: &String) -> usize {  // & 借用，不获取所有权
    s.len()
}
```

- `&T` 不可变借用，`&mut T` 可变借用（同一时刻只能有一个可变借用）。
- 编译器用**生命周期**标注确保引用始终有效。

### 4. 为什么值得学

- **安全**：编译期杜绝空指针、数据竞争、悬垂引用。
- **性能**：零成本抽象，对标 C/C++。
- **适用广**：系统编程、Web 后端（Actix）、嵌入式（no_std）、WASM。

## 最小可运行示例
上面 Hello World 即最小示例。把代码存为 `main.rs`，执行 `cargo run` 即可看到输出。

## 常见误区 / 易错点
- **move 后原变量失效**：`let s2 = s1;` 之后再用 `s1` 会编译报错。需要共享时用 `&s1` 借用，或用 `s1.clone()` 显式复制。
- **忘记 `mut`**：变量默认不可变，`let mut s = ...` 才能修改或 `&mut` 借用。
- **生命周期不是运行时概念**：`'a` 只是给编译器的证明，不会延长任何值的存活时间。

## 练习
1. 写一个函数 `first_word(s: &String) -> &str`，返回第一个空格前的切片（提示：用 `&s[..]`）。
2. 故意在 `let s2 = s1;` 后 `println!("{}", s1)`，观察编译器报什么错，理解 move 语义。

## 小结
所有权让 Rust 在**没有垃圾回收**的前提下保证内存安全：每个值有唯一所有者，离开作用域即释放，赋值默认 move。配合借用，既能零拷贝又能安全共享。
