# 动态规划

动态规划（DP）用"记忆化"把重叠子问题变成高效求解。本篇讲核心思想与套路。

## 1. 核心：最优子结构与重叠子问题

- **重叠子问题**：暴力递归反复算同一子问题 → 用记忆化（缓存）避免；
- **最优子结构**：大问题的最优解含子问题最优解。

## 2. 斐波那契：从递归到 DP

暴力递归 $O(2^n)$，记忆化 $O(n)$：

```python
from functools import lru_cache
@lru_cache(None)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)
```

进一步改成**自底向上**的 DP 表：

```python
def fib_dp(n):
    if n < 2: return n
    dp = [0, 1]
    for i in range(2, n+1):
        dp.append(dp[i-1] + dp[i-2])
    return dp[n]
```

## 3. 0-1 背包

`n` 件物品，容量 `W`，求最大价值：

```python
def knapsack(w, v, W):
    dp = [0] * (W + 1)
    for i in range(len(w)):
        for c in range(W, w[i]-1, -1):   # 倒序，避免重复取
            dp[c] = max(dp[c], dp[c-w[i]] + v[i])
    return dp[W]
```

状态转移：`dp[c] = max(不选, 选)`。

## 4. 解题套路

1. 定义 `dp[i]` 或 `dp[i][j]` 表示什么；
2. 找状态转移方程；
3. 定边界（base case）；
4. 决定遍历顺序（尤其"倒序防重复"）；
5. 空间优化（滚动数组）。

## 5. 常见题型

| 题型 | 例子 |
|------|------|
| 线性 DP | 最长递增子序列（LIS） |
| 区间 DP | 矩阵链乘 |
| 背包 | 0-1 背包、完全背包 |
| 树形 DP | 树上选点 |
| 状压 DP | 旅行商（TSP） |

## 小结

DP = 暴力递归 + 记忆化 + 状态设计。难点在"定义状态"，一旦方程清晰，代码很短。它是算法面试与竞赛的高频考点。
