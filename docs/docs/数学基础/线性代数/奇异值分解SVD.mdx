# 奇异值分解（SVD）

特征值分解只对方阵有效，还要求特征向量够多。奇异值分解（SVD）没有这些限制：**任何**实矩阵——方的、长的、扁的、奇异的——都能分解。它是数值线性代数里最万能的工具。

## 学习目标

- 说清 $A=U\Sigma V^T$ 中三个因子各自的几何角色。
- 从奇异值读出矩阵的秩、条件数与「信息集中程度」。
- 用截断 SVD 做低秩近似，并解释为什么它是最优的。
- 用 SVD 求伪逆，稳定地解病态或非满秩的最小二乘问题。

## 核心直觉

把矩阵 $A$ 看成一个把单位圆（球）映成椭圆（椭球）的操作。SVD 说的是：**任何线性变换都可以拆成「先转一下，再沿坐标轴拉伸，最后再转一下」**。

$$
A = U\Sigma V^{T}
$$

- $V^{T}$：在输入空间里旋转，把「将被拉伸的那些正交方向」对齐到坐标轴；
- $\Sigma$：对角阵，元素 $\sigma_1\ge\sigma_2\ge\cdots\ge0$ 是**奇异值**，就是椭圆各半轴的长度；
- $U$：在输出空间里再旋转，把结果摆到最终姿态。

$U,V$ 都是正交矩阵（列向量两两正交且单位长），只转不变形；所有的「变形」都被隔离到 $\Sigma$ 里。

奇异值告诉你三件事：

- **非零奇异值的个数 = $\mathrm{rank}(A)$**。这是数值上判断秩最可靠的方法（比看行列式稳健得多）。
- **条件数 $\kappa=\sigma_{\max}/\sigma_{\min}$**，衡量解方程时误差被放大的倍数。$\kappa$ 很大就是「病态」。
- **能量分布**。$\|A\|_F^2=\sum\sigma_i^2$，若前几个 $\sigma$ 占了绝大部分平方和，说明这个矩阵「本质上是低秩的」，可以大幅压缩。

把分解写成秩一矩阵之和最能看出压缩的道理：

$$
A=\sum_{i=1}^{r}\sigma_i\,\vec u_i\vec v_i^{T}
$$

只保留前 $k$ 项得到 $A_k$。**Eckart–Young 定理**保证：在所有秩不超过 $k$ 的矩阵中，$A_k$ 与 $A$ 的误差最小。也就是说，截断 SVD 不是一个凑合的近似，而是**理论最优**的近似。PCA、图像压缩、推荐系统的隐语义模型，本质上都是这一句话。

## 最小示例

```python
import numpy as np
np.set_printoptions(precision=3, suppress=True)

# 构造一个「本质低秩 + 微小噪声」的矩阵
rng = np.random.default_rng(0)
base = np.outer([1., 2., 3., 4.], [1., 1., 2.])      # 秩 1
A = base + 0.01 * rng.standard_normal((4, 3))        # 加噪后数值上满秩

U, s, Vt = np.linalg.svd(A, full_matrices=False)
print(s)                       # [13.414  0.021  0.006] -> 能量高度集中在第一个

# ---- 秩与能量占比 ----
print(np.linalg.matrix_rank(A))          # 3（受噪声影响）
print(s[0]**2 / np.sum(s**2))            # ≈ 0.999 -> 第一主成分解释了 99.9%

# ---- 秩 1 截断近似 ----
k = 1
A_k = (U[:, :k] * s[:k]) @ Vt[:k, :]
err = np.linalg.norm(A - A_k) / np.linalg.norm(A)
print(f"相对误差 {err:.4%}")             # ≈ 0.17%，说明压缩几乎无损

# 存储量对比：原始 4*3=12 个数；秩 1 只需 4+3+1=8 个数
# 对 1000x1000 的矩阵取 k=10，压缩比会非常可观

# ---- 用 SVD 求伪逆，解病态最小二乘 ----
b = np.array([1., 2., 3., 4.])
A_pinv = Vt.T @ np.diag(1 / s) @ U.T     # 等价于 np.linalg.pinv(A)
x = A_pinv @ b
print(np.allclose(x, np.linalg.pinv(A) @ b))   # True ✔
```

一个可手算的极简例子：$A=\begin{bmatrix}3&0\\0&2\end{bmatrix}$ 的 SVD 就是 $U=I,\ \Sigma=A,\ V=I$，奇异值 $3,2$——它把单位圆映成半轴 3 和 2 的椭圆，和几何直觉完全吻合。

## 易错点

- **奇异值不是特征值**。$\sigma_i$ 是 $A^TA$ 特征值的**平方根**，恒非负；特征值可以是负数或复数。只有当 $A$ 对称半正定时两者才相等。
- **`full_matrices=True` 会返回大而无用的方阵**。做低秩近似时用 `full_matrices=False`（经济型 SVD），否则维度对不上。
- **numpy 返回的是 `Vt`（即 $V^T$）不是 $V$**。重构时写 `U @ np.diag(s) @ Vt`，多加一次转置就错了。
- **别用 `matrix_rank` 的默认阈值去判断「理论秩」**。有噪声时数值秩往往是满的，应该看奇异值是否出现数量级断崖。
- **求伪逆时不要对接近 0 的 $\sigma$ 直接取倒数**，会放大噪声；`np.linalg.pinv` 自带截断阈值 `rcond`，直接用它更安全。

## 练习

1. 已知 $A$ 的奇异值为 $10,\,1,\,0.001$，求条件数并判断求解 $A\vec x=\vec b$ 是否稳定。
   *答案：$\kappa=10/0.001=10^4$，属于病态，右端项的小扰动会被放大约一万倍。*
2. 一张 $512\times512$ 的灰度图做 SVD 后保留前 50 个奇异值，需要存多少个浮点数？压缩比是多少？
   *提示：$50\times(512+512+1)=51250$，原始 $262144$，约压到 19.6%。*
3. 证明 $\|A\|_F^2=\sum_i\sigma_i^2$。
   *提示：$\|A\|_F^2=\mathrm{tr}(A^TA)$，而 $A^TA=V\Sigma^2V^T$，迹在正交相似变换下不变。*

## 小结

SVD 把任意矩阵拆为「旋转 → 沿轴拉伸 → 旋转」，其中奇异值刻画了每个主方向上的拉伸强度。非零奇异值个数即秩，最大与最小之比即条件数，平方和即 Frobenius 能量。按奇异值从大到小截断可得到理论最优的低秩近似（Eckart–Young），这正是 PCA、图像压缩与推荐系统的共同数学内核。当矩阵非方阵、非满秩或病态时，基于 SVD 的伪逆是最稳健的求解途径。
