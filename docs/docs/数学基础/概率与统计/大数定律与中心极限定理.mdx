# 大数定律与中心极限定理

为什么民意调查抽 1000 人就敢推断全国？为什么身高、测量误差、模型残差都近似正态？这两个问题的答案，就是概率论的两根支柱：**大数定律（LLN）** 和 **中心极限定理（CLT）**。

## 学习目标

- 陈述大数定律，并解释它为什么保证了蒙特卡洛方法与 A/B 测试的有效性。
- 陈述中心极限定理，说明「正态分布无处不在」的根本原因。
- 计算标准误差 $\sigma/\sqrt{n}$，并据此估计所需样本量。
- 区分「总体分布」「样本分布」与「样本均值的抽样分布」三个易混概念。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [概率基础与随机变量](/docs/数学基础/概率与统计/概率基础与随机变量) 中的期望与方差。
- 了解 [描述统计](/docs/数学基础/概率与统计/描述统计与贝叶斯推断) 中的均值。
- 基本的直观即可，无需严格证明。

## 核心概念
**大数定律：样本越多，平均越准。**

$$
\bar X_n=\frac{1}{n}\sum_{i=1}^{n}X_i\ \xrightarrow{\ n\to\infty\ }\ \mu=\mathbb{E}[X]
$$

抛硬币 10 次可能出现 7 次正面，但抛 100 万次，正面比例几乎必然贴着 0.5。LLN 说的是**随机性会被平均掉**——这是一切「用样本估计总体」的合法性来源。

但 LLN 只说了「会收敛」，没说「收敛得多快、误差长什么样」。补上这一块的是 CLT。

**中心极限定理：大量独立随机因素叠加后，其和（或均值）近似正态——无论每个因素本身服从什么分布。**

$$
\bar X_n\ \approx\ \mathcal{N}\!\left(\mu,\ \frac{\sigma^2}{n}\right),
\qquad\text{等价地}\quad
\frac{\bar X_n-\mu}{\sigma/\sqrt n}\ \xrightarrow{\ d\ }\ \mathcal{N}(0,1)
$$

这个定理的震撼之处在于**它不关心原始分布的形状**。骰子点数是均匀分布、硬币是伯努利分布、等待时间是指数分布——只要独立同分布且方差有限，把它们平均起来，形状都会趋向那条钟形曲线。现实中的身高、测量误差之所以近似正态，正是因为它们都是大量微小独立因素叠加的结果。

**标准误差**是 CLT 最实用的产物：

$$
\mathrm{SE}=\frac{\sigma}{\sqrt n}
$$

注意分母是 $\sqrt n$ 而**不是** $n$。这条「平方根律」有极强的现实含义：**想让精度提高 10 倍，样本量要增加 100 倍**。这解释了为什么民调误差长期卡在 ±3% 左右——把它降到 ±1% 的成本是九倍。

由此得到 95% 置信区间的常用近似：

$$
\bar X\pm1.96\cdot\frac{s}{\sqrt n}
$$

## 最小示例

```python
import numpy as np
rng = np.random.default_rng(0)

# ============ 1. 大数定律：掷骰子均值收敛到 3.5 ============
rolls = rng.integers(1, 7, size=1_000_000)
running_mean = np.cumsum(rolls) / np.arange(1, len(rolls) + 1)
for n in [10, 100, 10_000, 1_000_000]:
    print(f"n={n:>9}: 均值={running_mean[n-1]:.4f}  偏差={abs(running_mean[n-1]-3.5):.4f}")
# 偏差稳步缩小，验证 LLN ✔

# ============ 2. 中心极限定理：极端偏态分布也会被"正态化" ============
# 原始分布：指数分布（严重右偏，完全不像正态）
lam = 1.0
mu, sigma = 1/lam, 1/lam          # 指数分布的均值与标准差都是 1/λ

print("\n样本均值的分布形状（偏度 -> 0 表示越来越对称）：")
from statistics import NormalDist
for n in [1, 2, 10, 50]:
    samples = rng.exponential(scale=1/lam, size=(50_000, n)).mean(axis=1)
    skew = ((samples - samples.mean())**3).mean() / samples.std()**3
    se_theory = sigma / np.sqrt(n)
    print(f"  n={n:>2}: 实测标准差={samples.std():.4f}  理论SE={se_theory:.4f}  偏度={skew:.3f}")
# n=1 时偏度 ≈ 2（严重偏态）；n=50 时偏度 ≈ 0.28，已接近正态 ✔
# 实测标准差始终与 σ/√n 吻合 ✔

# ============ 3. 平方根律：精度翻倍需要 4 倍样本 ============
print("\n标准误差随 n 的变化：")
for n in [100, 400, 1600, 6400]:
    print(f"  n={n:>5}: SE={sigma/np.sqrt(n):.5f}")
# n 每变 4 倍，SE 恰好减半 ✔

# ============ 4. 置信区间的覆盖率检验 ============
hit = 0
trials = 10_000
n = 100
for _ in range(trials):
    s = rng.exponential(scale=1/lam, size=n)
    lo = s.mean() - 1.96 * s.std(ddof=1) / np.sqrt(n)
    hi = s.mean() + 1.96 * s.std(ddof=1) / np.sqrt(n)
    hit += (lo <= mu <= hi)
print(f"\n95% 置信区间实际覆盖率: {hit/trials:.2%}")   # ≈ 94%，接近名义值 ✔
```

## 易错点

- **误以为 LLN 会「纠正」历史**（赌徒谬误）。连开 10 次红并不会让下一次开黑的概率变高。均值收敛靠的是**后续样本的稀释**，而不是对既往偏差的补偿。
- **把「样本分布」和「样本均值的抽样分布」搞混**。100 个指数分布样本画直方图仍然是右偏的；变成正态的是**很多组样本的均值**构成的分布。
- **以为 CLT 对任何分布都成立**。柯西分布方差无限，其样本均值永远不会收敛到正态——重尾数据（金融收益、网络延迟）要格外小心。
- **忘记独立性要求**。时间序列、聚类抽样中的样本高度相关，有效样本量远小于 $n$，直接套 $\sigma/\sqrt n$ 会严重低估误差。
- **混淆标准差与标准误差**。$\sigma$ 描述**个体**的离散程度，不随 $n$ 变化；SE 描述**均值估计**的精度，随 $n$ 减小。
- **样本标准差要用 `ddof=1`**。numpy 默认 `ddof=0`（有偏），估计总体方差时应改为 1（贝塞尔校正）。

## 练习

1. 某总体标准差 $\sigma=20$，欲使样本均值的标准误差不超过 1，至少需要多少样本？
   *答案：$20/\sqrt n\le1\Rightarrow n\ge400$。*
2. 掷 100 次公平硬币，正面次数超过 60 的概率大约是多少？
   *提示：$\mu=50,\sigma=\sqrt{100\times0.25}=5$，$z=(60-50)/5=2$，故约 2.3%。*
3. 为什么样本量从 1000 增加到 4000，民调误差只从 ±3% 降到 ±1.5%，而不是降到四分之一？
   *答案：误差按 $1/\sqrt n$ 衰减，$n$ 变 4 倍则误差减半，这就是平方根律的代价。*

## 小结

大数定律保证样本均值随样本量增大而收敛到真实期望，为一切统计推断提供合法性；中心极限定理进一步指出，无论原始分布形状如何，样本均值都近似服从均值为 $\mu$、标准差为 $\sigma/\sqrt n$ 的正态分布。由此得到标准误差与置信区间这两件最常用的工具，也解释了「精度提升 10 倍需样本 100 倍」的平方根律。使用时必须确认独立同分布与方差有限这两个前提，重尾或强相关数据会让结论失效。
