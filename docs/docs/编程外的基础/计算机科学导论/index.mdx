# 计算机科学导论

计算机科学不只是"写程序"，而是研究**计算本身**的学科。理解它的主干，能让你在学具体技术时不迷路。

## 五大支柱

- **组成原理**：程序最终都是 0/1。CPU 通过"取指—译码—执行"循环运行指令，内存按地址存取。
- **操作系统**：硬件与应用的"中间商"——用进程/线程抽象 CPU、虚拟内存抽象 RAM、文件系统抽象磁盘。
- **计算机网络**：数据被切成包，按 TCP/IP 分层逐层封装与拆解，核心是"分层"与"可靠传输"。
- **编译原理**：源代码 → 词法 → 语法 → 语义 → 中间代码 → 优化 → 目标代码。

## 为什么程序员要懂这些

- 写出**更快**的代码（懂缓存、懂系统调用开销）；
- 定位**诡异 bug**（并发、内存、字节序）；
- 做**技术选型**时有底层依据。

> 理解抽象层是关键：电路 → 微指令 → 汇编 → 高级语言，每一层都在隐藏下层的复杂。
