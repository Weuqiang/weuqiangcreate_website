# 凸优化基础

## 学习目标

- 用「线段在集合内」的直觉理解凸集，用「弦在图像下方」理解凸函数
- 掌握凸函数的二阶判据（Hessian 半正定），并理解「凸问题的局部最优即全局最优」
- 说清一个优化问题的三要素：变量、目标、约束
- 了解拉格朗日乘子、KKT 条件，以及「强对偶」为何能简化带约束的机器学习问题

## 前置知识

- [梯度与方向导数](/docs/数学基础/微积分/梯度与方向导数) —— 本文的下降方向就来自梯度
- [矩阵与线性方程组](/docs/数学基础/线性代数/矩阵与线性方程组) —— 约束常写成 $Ax=b$ 或 $Ax\preceq b$
- [正交投影与最小二乘](/docs/数学基础/线性代数/正交投影与最小二乘) —— 最小二乘是最经典的凸优化

## 核心概念

### 1. 凸集：两点之间的线段仍属于它

集合 $C\subseteq\mathbb{R}^n$ 是凸集，当且仅当对任意 $x,y\in C$ 与任意 $\theta\in[0,1]$：

$$
\theta x + (1-\theta)y \in C
$$

直觉：你站在集合里的任意两点，朝对方走直线，脚下的点都还在集合里。超平面、半空间、球、多面体都是凸的；而「有两个分开山峰的地形投影」就不是凸集。

### 2. 凸函数：函数图像在任何弦的下方

函数 $f:\mathbb{R}^n\to\mathbb{R}$ 是凸函数，当且仅当其定义域是凸集，且对任意 $x,y$ 与 $\theta\in[0,1]$：

$$
f(\theta x+(1-\theta)y) \le \theta f(x) + (1-\theta)f(y)
$$

几何意义：连接图像上两点的弦，始终不低于函数图像；等价地，**切线（支撑超平面）在图像下方**。

一阶判据（可微时）：

$$
f(y) \ge f(x) + \nabla f(x)^\top (y-x) \quad \forall x,y
$$

二阶判据（二阶可微时）：Hessian 半正定，即 $\nabla^2 f(x) \succeq 0$。例如 $f(x)=x^2$ 的 Hessian 是 $2>0$，凸；$f(x)=\sin x$ 的二阶导 $-\sin x$ 可正可负，非凸。

### 3. 凸优化的三要素与「局部即全局」

一个**凸优化问题**满足：目标是凸函数、不等式约束函数也是凸的、等式约束是仿射的。它形如：

$$
\begin{aligned}
\min_{x}\quad & f_0(x) \\
\text{s.t.}\quad & f_i(x)\le 0,\; i=1,\dots,m \\
& h_j(x)=0,\; j=1,\dots,p
\end{aligned}
$$

凸问题最迷人的性质：**任何局部最优解都是全局最优解**。原因是：若存在更低的全局最优点 $x^\star$，凸性保证连接 $x$ 与 $x^\star$ 的线段上函数值都不高于端点连线，那么线段中点附近必有比 $x$ 更低的点，与「局部最优」矛盾。

### 4. 梯度下降为何（通常）收敛

对无约束光滑凸问题 $\min f(x)$，梯度下降迭代：

$$
x_{k+1}=x_k - \eta\,\nabla f(x_k)
$$

当 $f$ 是 $L$-光滑（梯度 Lipschitz 连续）且 $\eta\le 1/L$ 时，步长不会「冲过谷底」，函数值单调下降并收敛到最优点（对强凸问题还有线性收敛率 $O((1-\mu/L)^k)$）。这正是机器学习里成千上万次「算梯度→更新」的理论底气。

### 5. 拉格朗日对偶与 KKT 条件

带约束时，构造拉格朗日量：

$$
\mathcal{L}(x,\lambda,\nu)=f_0(x)+\sum_i \lambda_i f_i(x)+\sum_j \nu_j h_j(x),\quad \lambda_i\ge 0
$$

**KKT 条件**是最优解的充要条件（在凸性 + 约束规范下）：

1. 原始可行：$f_i(x^\star)\le 0,\;h_j(x^\star)=0$
2. 对偶可行：$\lambda_i^\star\ge 0$
3. stationary：$\nabla_x \mathcal{L}=0$
4. 互补松弛：$\lambda_i^\star f_i(x^\star)=0$（约束要么紧、要么乘子为 0）

当**强对偶**成立（如 Slater 条件满足），原问题最优值等于对偶问题最优值，很多 SVM、带正则的问题借此简化。

## 示例

用 numpy 在一个凸二次函数上跑梯度下降，验证「凸问题的局部即全局」：

```python
import numpy as np

# 凸目标 f(x) = 1/2 x^T A x - b^T x，A 正定 => 严格凸
A = np.array([[3.0, 1.0], [1.0, 2.0]])
b = np.array([1.0, 2.0])

def f(x):
    return 0.5 * x @ A @ x - b @ x

def grad(x):
    return A @ x - b

x = np.array([0.0, 0.0])      # 任意起点（凸问题起点不重要）
eta = 0.1
history = [f(x)]
for _ in range(100):
    x = x - eta * grad(x)
    history.append(f(x))

print("最优 x =", x)          # 应接近 A^{-1} b = [0, 1]
print("最终 f =", f(x))
print("单调下降?", all(history[i+1] <= history[i] + 1e-9 for i in range(len(history)-1)))
```

无论起点在哪里（这里只有一个碗状谷），最终都落到同一个全局最优点——非凸问题做不到这一点。

## 易错点

- **把「目标凸」当成「问题凸」**：目标凸但约束非凸（如 $x_1x_2\le 1$ 不是凸约束），整体仍非凸，KKT 不再充要。
- **Hessian 半正定要在每点都成立**：只在某点成立不能断言全局凸，例如 $x^3$ 在负半轴二阶导为负。
- **互补松弛常被忘**：KKT 的第四条 $\lambda_i f_i=0$ 是说「松的约束乘子必为 0」，这是判断哪条约束起作用的关键。
- **梯度下降收敛 ≠ 快速收敛**：凸只保证收敛到全局最优，不保证快；条件数差的 $A$（如 $A=\mathrm{diag}(1,1000)$）会让朴素梯度下降极慢，需动量或预处理。

## 练习

1. 判断 $f(x)=e^x$、$f(x)=x^3$、$f(x)=\|x\|_2$ 是否凸，并说明理由（可用二阶判据）。
2. 写出带 $L_2$ 正则的逻辑回归 $\min_w \sum_i\log(1+e^{-y_i w^\top x_i})+\frac{\lambda}{2}\|w\|^2$ 的梯度，并说明为什么它是凸优化问题。
3. 对问题 $\min x^2$ s.t. $x\ge 1$，写出拉格朗日量并验证 KKT 点。

## 小结

凸优化给机器学习提供了「能收敛、有保证」的理论地基：凸集/凸函数让局部最优等于全局最优，梯度下降在合适步长下单调收敛，KKT 与对偶把带约束问题系统化。它是理解 SVM、岭回归、带正则训练乃至收敛证明的钥匙。
