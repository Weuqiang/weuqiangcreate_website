# 可访问性 a11y

## 学习目标

学完本章，你应该能够：

- 用语义化标签替代「万能 div」
- 在语义不够时用 ARIA 补充角色与状态
- 保证全部功能可用键盘操作
- 检查颜色对比度并支持屏幕阅读器

## 前置知识

在阅读下面的内容前，建议先掌握：

- [HTML 语义化](/docs/软件工程/Web前端/HTML/semantic)
- [DOM 与元素](/docs/软件工程/Web前端/JavaScript/dom/element)

## 核心概念

可访问性（Accessibility，简称 a11y）是让视障、听障、运动障碍或临时受限（强光下看不清、单手操作）的用户也能使用网站。它不仅是「做善事」，更是法律合规与更好体验（如键盘效率、移动端可读）的共性基础。

本章主线：

- 语义化 HTML 优先
- ARIA 补语义
- 键盘可达
- 对比度与屏幕阅读器

## 语义化 HTML 优先

很多「可访问性」不需要额外工作，只要**用对标签**：

```html
<!-- 坏：用 div 拼按钮，屏幕阅读器不知道它是按钮、键盘也难聚焦 -->
<div class="btn" onclick="...">提交</div>

<!-- 好：原生 <button> 自带角色、可聚焦、回车/空格触发 -->
<button type="submit">提交</button>
```

`<nav>`/`<main>`/`<header>`/`<article>` 等 landmarks 帮屏幕阅读器用户快速跳转到区块；`<label for>` 把文字说明绑到输入框；`<table>` 的 `<th scope>` 表达表头关系。优先语义化，能省掉大量 ARIA。

## ARIA：语义不够时补充

当原生语义不足（如自定义组件），用 ARIA 声明**角色、属性、状态**：

```html
<div role="tablist">
  <button role="tab" aria-selected="true" aria-controls="panel-1">概览</button>
</div>
<div role="tabpanel" id="panel-1">...</div>
```

- `role`：这是什么控件（tab、dialog、slider…）
- `aria-selected`/`aria-expanded`：当前状态
- `aria-label`：给无文字的图标按钮加可读名

警告：**ARIA 不能替代语义**。能用原生 `<button>` 就别写 `role="button"`，错误的 ARIA 比没有更糟。

## 键盘可达

所有人（不只残障用户）都该能**只用键盘**完成操作：

- 所有交互元素可 `Tab` 聚焦、可回车/空格触发
- 焦点顺序符合视觉顺序
- 模态框打开时**焦点陷阱**（Tab 不出框）、关闭后焦点回到触发元素
- 可见的 `:focus-visible` 焦点环，别用 `outline: none` 去掉后不补

```css
:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
```

## 对比度与屏幕阅读器

- **对比度**：正文文本与背景对比度至少 4.5:1（WCAG AA），大字 3:1。灰色小字常见踩雷。
- **屏幕阅读器**：用 `alt` 描述图片内容（装饰图用空 `alt=""`）；用 `aria-live` 让动态更新（如「已保存」提示）被朗读；标题层级 `<h1>`→`<h2>` 有秩序，方便导航。
- **不依赖颜色 alone**：用颜色+文字/图标双重表达（如错误不仅标红，还写「必填」）。

## 易错点

1. **`outline: none` 后不补焦点样式**：键盘用户彻底看不见焦点在哪。
2. **装饰图没标 `alt=""`**：屏幕阅读器逐张念文件名，吵且无用。
3. **自定义控件只做样式不做键盘**：鼠标能点、键盘进不去，等于不可用。
4. **滥用 ARIA 覆盖原生语义**：`role="button"` 套在 `<a>` 上反而误导。

## 小结

a11y 的优先级是「语义化 HTML → 不够才 ARIA → 保证键盘可达 → 管好对比度与朗读」。多数可用性来自用对标签，而非堆 ARIA。做好 a11y，残障用户得益，所有用户的效率与体验也同步提升。

## 练习

1. 把一个用 `div+onclick` 做的「按钮」改成原生 `<button>`，对比键盘可达性。
2. 用键盘（只 Tab/回车）完整走一遍你某个页面的核心流程，记录卡住的地方。
3. 用对比度检查工具测页面正文配色，找出不达 4.5:1 的组合并修正。
