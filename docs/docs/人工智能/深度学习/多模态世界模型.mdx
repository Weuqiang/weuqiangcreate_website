# 多模态世界模型

[世界模型](/docs/人工智能/深度学习/世界模型)告诉我们：与其在像素里硬学控制，不如先在**压缩的潜空间**里学会「预测下一步会发生什么」，再在想象中规划。本页把这一想法推进到**多模态**——让模型同时消费并预测视觉、语言、动作、甚至音频等多路信号，从而成为可交互、可生成的「模拟器」。

## 学习目标

- 理解多模态世界模型相对单模态世界模型新增的能力与难点。
- 掌握两类代表路线：视频预测式世界模型，与交互式/可控世界模型（如 Genie、DreamerV3）。
- 认识 JEPA 这类「非生成式」世界模型如何用隐式预测规避逐像素重建。
- 看清当前多模态世界模型在一致性、物理合理性与可扩展性上的局限。

## 核心概念

### 从单模态到多模态

经典世界模型（Dreamer 系列）多在**单一观测模态**（如游戏帧、机器人 proprioception）上工作。多模态世界模型要求：

- **多路输入对齐**：文本指令、视觉观测、动作命令进入同一个潜空间，彼此可互相条件化。
- **多路预测**：给定「指令 + 当前画面 + 动作」，预测「下一帧画面 + 可能伴随的语言/状态描述」。
- **跨模态生成**：用文本生成视频、用视频反推描述、用动作驱动场景演化。

形式上，模型学习一个潜动态 $z_{t+1} = f_\theta(z_t, a_t, c_t)$，其中 $c_t$ 是文本/语音等上下文条件；解码器 $g_\phi$ 则从 $z$ 重建「任意模态」的观测。

### 路线一：视频预测作为世界模型

把「未来帧生成」本身当作世界模型。代表方法用扩散或自回归 Transformer 做**条件视频预测**：

- 输入：首帧 + 文本 prompt（+ 可选动作序列）。
- 输出：一段视觉上连贯、且服从指令/物理约束的视频。

这类模型在「想象」上很强（能生成逼真的未来），但缺陷是**并不显式建模动作-结果因果**，更像「会动的画」而非「可交互的模拟器」——你很难精确指定「向右走三步」并看到确定后果。

### 路线二：交互式、可控世界模型

目标是「可玩、可控」：

- **Genie（DeepMind, 2024）**：从无标注互联网视频里**自动推断动作空间**，训练出一个「给定一帧 + 一个想象的动作，就生成下一帧」的生成式交互环境。它不需要真实动作标签，就能让人用键盘「玩」生成出来的世界——是多模态世界模型走向「可交互模拟器」的关键一步。
- **DreamerV3**：在潜空间做「想象-规划」，并证明能在《Minecraft》等复杂环境中从零学会收集钻石；其表示天然融合视觉与奖励信号，可视为多模态（视觉 + 价值 + 动作）的世界模型。
- 这类路线强在**动作与未来强绑定**，适合机器人仿真、游戏生成、具身智能训练数据扩充。

### 路线三：非生成式 —— JEPA

LeCun 提出的 JEPA（Joint Embedding Predictive Architecture）主张：**不要重建像素，只预测 Embedding**。能量模型在潜空间里拉近「当前观测的表示」与「未来观测的表示」，规避了逐像素生成的高成本与模糊问题。多模态 JEPA（如图像-文本-视频联合）能在不生成图像的前提下，学到「下一帧应该长什么样」的语义级预测，更适合作为**规划与理解的底座**而非「视频生成器」。

## 示例

一个文本条件视频预测的最小流程（示意，基于扩散式视频模型）：

```text
输入：
  帧0    : 一张海滩照片
  指令 c : "镜头向左平移，出现一艘帆船"
  动作 a : [pan_left, pan_left, appear_sailboat]   # 可选，交互式场景

模型内部：
  z0   = enc(帧0)                      # 视觉编码进潜空间
  z1   = world_model(z0, a1, c)        # 预测下一潜状态（含文本条件）
  z2   = world_model(z1, a2, c)
  ...
输出：
  帧1' = dec(z1)  → 画面开始左移
  帧2' = dec(z2)  → 帆船浮现
```

关键点在于：文本 `c` 与动作 `a` 都进入同一个 `world_model`，模型在潜空间里把「语言语义」「动作后果」「视觉演化」绑在一起学。若换成交互式 Genie 路线，则 `a` 不一定来自标注，而是模型从视频统计里自己「发明」的离散动作码。

## 易错点

- **把视频生成当成世界模型**：能生成连贯视频 ≠ 理解动作-结果因果；缺乏显式动作绑定的模型不可控、不可规划。
- **长期一致性崩溃**：自回归预测误差会累积，几十帧后物体身份/几何漂移；这是当前多模态世界模型部署的最大瓶颈之一。
- **物理合理性靠「像」不靠「对」**：扩散生成追求像素逼真，可能产出反物理但好看的运动；用于仿真训练时要额外校验。
- **模态不对齐**：文本指令与视觉语义若没对齐好，模型会「各说各话」，预测出的画面与指令脱节。

## 练习

1. 比较「视频预测式世界模型」与「Genie 式交互式世界模型」在「能否指定动作并看到确定后果」上的差异，各举一应用。
2. 为什么 JEPA「不重建像素」反而可能更适合做规划？它放弃了什么能力？
3. 如果你要用多模态世界模型给机器人生成训练数据，你会担心哪两类失效？如何检测？

## 小结

多模态世界模型把「在潜空间预测未来」推广到跨视觉、语言、动作等多路信号，目标是成为可交互、可生成的模拟器。三条互补路线：视频预测式（强在想象、弱在可控）、交互式可控式（Genie/DreamerV3，强在动作-结果绑定）、以及非生成式的 JEPA（在 Embedding 空间预测，适合作为规划底座）。当前共同瓶颈是长期一致性、物理合理性与模态对齐；它们既是具身智能与游戏生成的有力工具，也仍需在「可控因果」上继续突破。
