# 性能工程

「能跑」和「跑得快、扛得住」是两回事。性能工程不是上线前的临时调参，而是一套**先度量、再定位、后优化**的纪律：用正确的指标看清瓶颈，用剖析工具找到热点，再做有的放矢的改造。它与 [可观测性](/docs/软件工程/工程实践/可观测性) 互补——可观测性发现「慢了」，性能工程回答「为什么慢、怎么改」。
