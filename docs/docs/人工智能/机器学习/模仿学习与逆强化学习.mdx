# 模仿学习与逆强化学习

## 学习目标

- 理解为何奖励稀疏/难设计时，模仿比 RL 更划算
- 掌握行为克隆（BC）及其分布偏移缺陷与 DAgger 修复
- 理解逆强化学习（IRL）的「专家最优」假设与最大熵框架
- 认识 GAIL：用 GAN 思路把 IRL 与策略学习端到端打通

## 核心概念

### 1. 从「试错」到「示范」

标准 RL 需要奖励函数 $r(s,a)$ 与大量试错。但很多任务（自动驾驶、机器人抓取）**奖励极难手写**，且随机探索代价高昂甚至危险。模仿学习（Imitation Learning, IL）转向另一条路：由专家 $\pi_E$ 提供一批状态-动作对 $\mathcal{D}=\{(s,a)\}$，直接学一个策略 $\pi_\theta\approx\pi_E$。

### 2. 行为克隆（Behavioral Cloning, BC）

BC 把 IL 退化为监督学习：把专家示范当成「输入状态、标签动作」的数据集，最小化

$$
\min_\theta\; \mathbb{E}_{(s,a)\sim\mathcal{D}}\big[-\log \pi_\theta(a\mid s)\big]
$$

简单、便宜、能立刻用。但它有两个致命弱点：

- **分布偏移（covariate shift）**：策略一旦偏离专家轨迹，会进入专家从未示范过的状态，误差累积、越偏越远（「复合误差」）。
- **多模态歧义**：同一状态可能有多种合理动作，BC 用 MSE/交叉熵求平均会得到「哪样都不对的模糊动作」。

### 3. DAgger：让专家在线纠错

DAgger（Dataset Aggregation）修复分布偏移：训练中不只用手工示范，而是**让当前策略 $\pi_\theta$ 去采状态，再请专家在这些状态上补标动作**，把数据分布拉回到策略实际会遇到的状态上：

$$
\mathcal{D} \leftarrow \mathcal{D}\cup\{(s,\pi_E(s))\mid s\sim\pi_\theta\}
$$

代价是需要专家（或专家策略）在线可用，但能显著缓解复合误差。

### 3. 逆强化学习（IRL）：反推奖励

BC 学的是「专家怎么做」，但没学到「专家为什么这么做」，因此泛化差。IRL 反过来：**从示范中反推奖励函数 $r$**，使得在该奖励下专家轨迹是最优的，再用 RL 优化这个 $r$ 得到策略。核心假设是「专家在最大化某未知奖励」。

最大熵 IRL 给出优雅框架：在所有能解释专家的行为中，选「最不确定/最均匀」的那个奖励：

$$
P(\tau\mid r) = \frac{1}{Z(r)}\exp\Big(R(\tau)\Big),\quad R(\tau)=\sum_{(s,a)\in\tau} r(s,a)
$$

通过梯度上升最大化专家轨迹的似然来学 $r$。问题是每一步都要解一次 RL 内层优化，昂贵。

### 4. GAIL：把 IRL 变成对抗博弈

GAIL（Generative Adversarial Imitation Learning）用 GAN 思路绕过昂贵的 IRL 内层循环：判别器 $D$ 区分「agent 轨迹」与「专家轨迹」，生成器（策略）$\pi$ 试图骗过 $D$。其等价目标近似最大熵 IRL：

$$
\min_\pi \max_D\; \mathbb{E}_\pi[\log D(s,a)] + \mathbb{E}_E[\log(1-D(s,a))] - \lambda H(\pi)
$$

判别器学到的「好坏边界」隐式定义了奖励，策略端直接策略梯度优化，端到端可训、无需手写奖励。

## 示例

用伪代码对比 BC 与 GAIL 的训练骨架：

```python
# 行为克隆：纯监督
for s, a in expert_dataset:
    loss = cross_entropy(policy(s), a)
    loss.backward(); opt.step()

# GAIL：对抗式
for rollout in collect(policy):            # agent 采轨迹
    for (s, a) in rollout + expert_dataset:
        d = discriminator(s, a)            # 1=专家, 0=agent
        d_loss = bce(d, label)             # 判别器学区分
    reward = -log(1 - discriminator(s, a)) # 判别输出当作隐式奖励
    ppo_update(policy, reward)             # 策略端用 RL 优化
```

直觉例子：**自动驾驶跟车**。手写「安全车距奖励」极难调参；用 GAIL，只需给一段人类驾驶记录，判别器会隐式学会「平稳加速、礼貌让行」等人类偏好，策略据此优化即得自然驾驶。

## 易错点

- **BC 直接上线**：忽视分布偏移，初始小错在长轨迹上复利放大，导致「开头还行、越走越偏」。至少配 DAgger 或加恢复机制。
- **专家数据有偏**：若示范只覆盖任务的一部分（如晴天驾驶），学出的策略在未见分布上脆弱。IL 的上限就是专家覆盖的分布。
- **IRL 非辨识性**：能解释同一批示范的奖励函数不唯一（可加任意势函数），需用最大熵或结构先验约束。
- **GAIL 训练不稳定**：判别器过强会让策略梯度消失，需平衡判别器与策略的学习率、加梯度惩罚。

## 练习

1. 在 CartPole 上分别用 BC 和 DAgger 训练，比较策略偏离初始分布后的恢复能力。
2. 推导最大熵 IRL 中奖励梯度 $\nabla_r \log P(\tau\mid r)$ 的形式，说明它为何等于「专家特征期望 $-$ 当前策略特征期望」。
3. 思考：GAIL 的隐式奖励与真实奖励在测试新环境时，泛化差异来自哪里？

## 小结

模仿学习把「奖励设计 + 海量试错」替换成「专家示范 + 监督/对抗学习」，在奖励难定、探索昂贵的任务上性价比极高。BC 简单但有分布偏移，DAgger 在线纠偏；IRL 反推奖励更泛化但贵，GAIL 用对抗把二者端到端打通。它是机器人操作、自动驾驶与 NPC 行为生成的常用起点。
