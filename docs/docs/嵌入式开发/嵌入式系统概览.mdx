# 嵌入式系统概览

嵌入式系统是以**专用计算机**为核心、嵌入到设备内部、完成特定任务的系统。小到智能手环，大到汽车 ECU，都是嵌入式系统。

## 1. 与通用计算机的区别

| 维度 | 通用计算机 | 嵌入式系统 |
|------|-----------|-----------|
| 目标 | 通用计算 | 专用功能 |
| 资源 | 大（GB 内存、TB 存储） | 小（KB~MB 级） |
| 实时性 | 一般不要求 | 常要求硬/软实时 |
| 交互 | 键盘鼠标屏幕 | 传感器 + 执行器 |

## 2. 核心组成

```
[传感器] → [MCU/MPU] → [执行器]
              ↑
           [外设: UART/SPI/I2C]
              ↑
           [电源 / 时钟]
```

- **MCU（微控制器）**：把 CPU、内存、外设集成在一颗芯片，适合低成本控制（如 STM32、Arduino）。
- **MPU（微处理器）**：性能更强，常跑 Linux（如树莓派、i.MX6）。
- **RTOS**：实时操作系统，调度确定性高（FreeRTOS、RT-Thread）。

## 3. 一个最小例子（Arduino）

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);
  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
}
```

## 4. 学习路线

1. **硬件与电路基础**：电压、电流、电阻、基本数字电路。
2. **单片机 MCU**：Arduino 入门，再进阶 STM32 与 HAL 库。
3. **RTOS 与固件**：FreeRTOS 任务调度、中断、低功耗。
4. **通信协议**：UART、SPI、I2C、CAN。

> 本篇为「嵌入式开发」的入口，下面四块（MCU / 硬件电路 / 通信协议 / RTOS）会逐一展开。

## 易错点

- **MCU ≠ MPU**：MCU 片内集成内存外设、跑裸机或 RTOS；MPU 跑 Linux、需外置 RAM/存储，二者定位不同。
- **"实时"不是"快"**：实时指**确定性时延**（deadline 内必响应），不是单纯高吞吐。
- **资源极度受限**：KB 级内存里每字节都要算计，不能照搬 PC 上的编程习惯。
