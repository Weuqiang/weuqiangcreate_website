# 人工智能：学习路线图

AI 是一条「先懂模型、再堆深度、最后落地应用」的递进线。本分类分三条主线：**机器学习**（经典统计学习）、**深度学习**（神经网络）、**大模型(LLM)与应用**（把模型变成产品）。建议按「机器学习 → 深度学习 → 大模型」的顺序打地基，再横向补应用。

## 推荐学习顺序

```text
机器学习（基础范式） → 深度学习（表示学习） → 大模型与应用（工程落地）
   分类/回归/聚类          CNN/RNN/Transformer        Agent/RAG/微调/部署
```

- **机器学习** 先学：它教你「数据 → 特征 → 模型 → 评估」的完整闭环，是后面一切的基础。
- **深度学习** 再学：当特征难手工设计时，用神经网络自动学表示（CNN 看图、RNN/Transformer 看序列）。
- **大模型与应用** 最后：在预训练模型之上做检索增强(RAG)、微调、Agent 与本地部署，直接对接工程。

## 学习建议

AI 不靠背公式，靠「跑通一个最小例子 + 看懂损失为什么下降」。每篇尽量配可运行代码片段与直觉图解；遇到「为什么有效」，优先建立几何/信息论直觉，再回头补严格推导。
