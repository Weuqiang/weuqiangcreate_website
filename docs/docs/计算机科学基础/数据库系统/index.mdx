# 数据库系统

几乎所有需要「记住数据」的应用背后都有数据库。本主题从**逻辑模型**（怎么用表与 SQL 表达数据）讲到**物理实现**（数据怎么落盘、怎么被快速找到），再到**查询怎么被执行得更快**，最后落到**正确性保证**（事务并发与崩溃恢复）——这是理解 Postgres、MySQL、以及各类存储引擎的主线。

## 本主题内容

- [关系模型与 SQL](/docs/计算机科学基础/数据库系统/关系模型与SQL) —— 关系、键、关系代数与 SQL、范式与规范化
- [存储引擎与索引](/docs/计算机科学基础/数据库系统/存储引擎与索引) —— 页式存储、B+ 树与 LSM 树、哈希索引与缓冲池
- [查询处理与优化](/docs/计算机科学基础/数据库系统/查询处理与优化) —— 执行算子、连接算法、基于代价的优化器
- [事务并发与恢复](/docs/计算机科学基础/数据库系统/事务并发与恢复) —— ACID、隔离级别、锁与 MVCC、WAL 与 ARIES 恢复
