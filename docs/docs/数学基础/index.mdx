# 数学基础：学习路线图

数学是计算机科学与人工智能的底层语言。本分类把程序员最常用、也最容易被劝退的数学，拆成四条彼此独立又互相支撑的线，按「先直观、后严格，先工具、后证明」的顺序组织，让你**一看就懂、知道为何而学、知道学到哪**。

> 学习建议：不要从定义开始死记，而是带着「这个工具能解决什么工程问题」去学。每条线都先读「入门/直觉」篇，再读「计算/应用」篇，最后回到本路线图对照「待补充」清单查漏。

## 推荐学习顺序

```text
① 线性代数  →  ② 微积分  →  ③ 概率与统计  →  ④ 离散数学
   （数据表示）  （变化与累积）  （不确定性与推断）  （结构与逻辑）
```

- **线性代数** 优先：AI、图形、数据处理的几乎一切都以「向量 / 矩阵」为单元。
- **微积分** 次之：理解「变化率、最优、累积」，是机器学习优化的直觉来源。
- **概率与统计** 再次：处理不确定性、做推断与评估，是 ML/数据科学的主轴。
- **离散数学** 最后或并行：图、逻辑、组合，是算法与理论计算机的骨架。

## 待补充主题（完善清单）

- **线性代数**：向量空间与基、特征值 / 特征向量、奇异值分解（SVD）、正交投影与最小二乘、矩阵分解（QR / LU）。
- **微积分**：泰勒展开、常微分方程初步、梯度与方向导数、多重积分应用。
- **概率与统计**：假设检验、大数定律与中心极限定理、马尔可夫链、信息论基础（熵 / KL 散度）。
- **离散数学**：递归与生成函数、布尔代数、自动机与形式语言、复杂度初步。
