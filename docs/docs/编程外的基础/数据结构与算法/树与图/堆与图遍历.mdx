# 堆与图遍历

堆是特殊的完全二叉树，图是更一般的网络。本篇讲优先队列（堆）与图的 DFS/BFS。

## 1. 堆（Heap）

- **大顶堆**：父 ≥ 子；**小顶堆**：父 ≤ 子；
- 用数组存完全二叉树，父 i 的左右子在 2i+1、2i+2；
- 插入/删除（调整） $O(\log n)$，取最值 $O(1)$。

```python
import heapq
h = []
heapq.heappush(h, 3)
heapq.heappush(h, 1)
heapq.heappop(h)     # 1（最小）
```

应用：优先队列、堆排序、Top-K、Dijkstra 最短路。

## 2. 图的基本表示

```
节点集合 V + 边集合 E
```

- **邻接矩阵**：`adj[u][v]`，查边 $O(1)$，占 $O(V^2)$；
- **邻接表**：每个节点挂邻居列表，省空间，遍历邻居快。

## 3. 深度优先（DFS）

一条路走到底，再回溯：

```python
def dfs(u, adj, seen):
    seen.add(u)
    for v in adj[u]:
        if v not in seen:
            dfs(v, adj, seen)
```

用栈（或递归）实现，适合找路径、连通分量、拓扑排序。

## 4. 广度优先（BFS）

逐层扩散，用队列：

```python
from collections import deque
def bfs(s, adj):
    q, seen = deque([s]), {s}
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in seen:
                seen.add(v); q.append(v)
```

BFS 首次到达即最短路径（边权相等时），适合最短路、社交网络扩散。

## 5. 对比

| | DFS | BFS |
|---|------|-----|
| 结构 | 栈/递归 | 队列 |
| 空间 | $O(\text{深度})$ | $O(\text{宽度})$ |
| 最短路径 | 不保证 | 保证（无权） |

## 小结

堆让"取极值"高效，图遍历是网络问题的通用解法。两者结合（如优先队列 BFS）能解最短路等经典问题。下一站：[排序与查找](../../排序与查找/排序算法)。
