# 假设检验

改版按钮后转化率从 10% 涨到 11%——这是真的变好了，还是随机波动？假设检验就是回答这类问题的标准流程，也是 A/B 测试、药物试验、质量控制的共同框架。

## 学习目标

- 正确设立原假设 $H_0$ 与备择假设 $H_1$，理解为什么要「假设无效」。
- 说出 p 值的**准确**定义，并避开最常见的三种误读。
- 区分第一类错误与第二类错误，理解 $\alpha$、$\beta$ 与功效的权衡。
- 用 numpy 完成一次双样本比例检验（A/B 测试），并做样本量估算。

## 核心直觉

假设检验是**统计版的反证法**：

1. 先假设「没有效果」（原假设 $H_0$）；
2. 在这个假设下，计算「观测到当前数据或更极端数据」的概率，这就是 **p 值**；
3. 如果这个概率小到离谱（小于显著性水平 $\alpha$，通常 0.05），说明假设与数据矛盾，于是**拒绝** $H_0$。

法庭类比很贴切：$H_0$ 是「被告无罪」（默认立场），数据是证据，$\alpha$ 是定罪门槛。**证据不足只能「无法定罪」，不等于「证明清白」**——这正是「不能接受 $H_0$，只能不拒绝 $H_0$」的原因。

**p 值的准确定义**：在 $H_0$ 为真的前提下，得到当前这么极端或更极端结果的概率。

$$
p=P(\text{数据至少这么极端}\mid H_0\ \text{为真})
$$

请特别注意条件的方向：p 值是 $P(\text{数据}\mid H_0)$，**不是** $P(H_0\mid\text{数据})$。把两者搞反，是统计学里最普遍的错误。

**两类错误**必须成对理解：

| | $H_0$ 实际为真 | $H_0$ 实际为假 |
|---|---|---|
| **拒绝 $H_0$** | 第一类错误（假阳性）概率 $\alpha$ | 正确 ✔ 功效 $1-\beta$ |
| **不拒绝 $H_0$** | 正确 ✔ | 第二类错误（假阴性）概率 $\beta$ |

- $\alpha$ 是「把无效当有效」——冤枉好人、上线了没用的功能。
- $\beta$ 是「把有效当无效」——放走真凶、错过了真实改进。
- **两者此消彼长**：把 $\alpha$ 从 0.05 收紧到 0.01 会降低误报，但也更容易漏掉真实效应。唯一能同时改善两者的办法是**增加样本量**。

**检验统计量**的通用形式是「信号 / 噪声」：

$$
z=\frac{\text{观测差异}-\text{假设差异}}{\text{标准误差}}
$$

差异越大、噪声越小、样本越多，$z$ 就越大，p 值就越小。

## 最小示例

**场景**：A 组 1000 人转化 100 人（10.0%），B 组 1000 人转化 125 人（12.5%）。B 真的更好吗？

```python
import numpy as np
from statistics import NormalDist

n_a, x_a = 1000, 100      # 对照组
n_b, x_b = 1000, 125      # 实验组
p_a, p_b = x_a / n_a, x_b / n_b

# ---- 双比例 z 检验 ----
# H0: p_a == p_b   H1: p_a != p_b（双侧）
p_pool = (x_a + x_b) / (n_a + n_b)                       # H0 下的合并比例
se = np.sqrt(p_pool * (1 - p_pool) * (1/n_a + 1/n_b))    # 标准误差
z = (p_b - p_a) / se
p_value = 2 * (1 - NormalDist().cdf(abs(z)))             # 双侧

print(f"A={p_a:.3%}  B={p_b:.3%}  提升={p_b-p_a:+.2%}")
print(f"z = {z:.4f},  p = {p_value:.4f}")
print("结论:", "拒绝 H0，差异显著" if p_value < 0.05 else "证据不足，不拒绝 H0")
# z ≈ 1.7691, p ≈ 0.0769 -> 在 α=0.05 下【不显著】，别急着上线！

# ---- 差异的 95% 置信区间（比 p 值信息量更大）----
se_diff = np.sqrt(p_a*(1-p_a)/n_a + p_b*(1-p_b)/n_b)
lo, hi = (p_b - p_a) - 1.96*se_diff, (p_b - p_a) + 1.96*se_diff
print(f"提升的 95% CI: [{lo:+.2%}, {hi:+.2%}]")   # 区间包含 0，与不显著一致 ✔

# ---- 模拟验证：H0 为真时，p 值应均匀分布，且约 5% 落在 0.05 以下 ----
rng = np.random.default_rng(1)
false_pos = 0
for _ in range(20_000):
    a = rng.binomial(1000, 0.10); b = rng.binomial(1000, 0.10)   # 两组真实相同
    pp = (a + b) / 2000
    s = np.sqrt(pp*(1-pp)*(2/1000))
    zz = (b/1000 - a/1000) / s
    false_pos += 2*(1 - NormalDist().cdf(abs(zz))) < 0.05
print(f"\nH0 为真时的误报率: {false_pos/20_000:.2%}")   # ≈ 5% ✔ 正是 α 的定义

# ---- 样本量估算：想以 80% 功效检出 10%->12.5% ----
z_a, z_b = 1.96, 0.84          # α=0.05 双侧, 功效 80%
p1, p2 = 0.10, 0.125
n_need = ((z_a + z_b)**2 * (p1*(1-p1) + p2*(1-p2))) / (p2 - p1)**2
print(f"每组所需样本量 ≈ {int(np.ceil(n_need))}")   # ≈ 2501 -> 当前 1000 人不够！
```

这个例子的教育意义很强：**2.5 个百分点看起来很诱人，但 1000 人的样本量根本不足以证实它**。

## 易错点

- **把 p 值当成「$H_0$ 为真的概率」**。p = 0.03 不代表「原假设只有 3% 可能成立」，它只说「若 $H_0$ 成立，出现这种数据的概率是 3%」。
- **把「不显著」当成「无差异」**。样本不足时真实效应也测不出来。正确表述是「现有证据不足以支持有差异」。
- **p-hacking / 多重比较**。同时测 20 个指标，即使全都无效，平均也会有 1 个「显著」。多重检验需要 Bonferroni 或 FDR 校正。
- **偷看数据、见好就收**。持续监测并在 p 首次跌破 0.05 时停止实验，会让实际误报率远高于 5%。要么预先定好样本量，要么使用序贯检验方法。
- **只看显著性、不看效应量**。样本量足够大时，0.01% 的无意义提升也能显著。务必同时报告置信区间和实际业务影响。
- **忽视检验的前提假设**。z 检验依赖 CLT，小样本或极低转化率时应改用 Fisher 精确检验。

## 练习

1. 某检验得到 p = 0.02，在 $\alpha=0.05$ 下如何决策？在 $\alpha=0.01$ 下呢？
   *答案：前者拒绝 $H_0$；后者不拒绝。这说明结论依赖于事先设定的门槛，$\alpha$ 必须在看数据前定好。*
2. 把 $\alpha$ 从 0.05 调到 0.01，第二类错误率会如何变化？
   *答案：$\beta$ 上升、功效下降。要同时压低两类错误，只能加大样本量。*
3. 上面的 A/B 测试若每组扩到 3000 人且比例不变，结果会显著吗？
   *提示：SE 缩小 $\sqrt3$ 倍，$z\approx1.769\times\sqrt3\approx3.06$，p ≈ 0.002，显著。*

## 小结

假设检验用反证法把「效果是否真实」变成可量化的决策：先假设无效，再看数据在该假设下有多离奇。p 值是「$H_0$ 为真时观测到这般极端结果的概率」，绝不是「$H_0$ 为真的概率」。决策会犯两类错误，$\alpha$ 与 $\beta$ 相互牵制，只有增大样本量才能同时改善。实践中应在实验前确定样本量与显著性水平，报告结果时同时给出效应量与置信区间，并警惕多重比较和中途偷看数据带来的误报膨胀。
