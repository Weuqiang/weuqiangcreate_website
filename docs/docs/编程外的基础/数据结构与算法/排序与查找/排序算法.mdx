# 排序算法

排序是算法基本功。本篇对比常见排序的思想与复杂度。

## 1. 冒泡 / 插入（简单 $O(n^2)$）

```python
# 插入排序：把当前元素插入已排序部分
def insertion(a):
    for i in range(1, len(a)):
        k = a[i]; j = i - 1
        while j >= 0 and a[j] > k:
            a[j+1] = a[j]; j -= 1
        a[j+1] = k
```

- 冒泡：相邻交换，稳定；
- 插入：对小数据/近似有序快，实际常用作快排/归并的底层优化。

## 2. 归并排序（稳定 $O(n \log n)$）

分治：不断二分，再合并两个有序段。

```python
def merge_sort(a):
    if len(a) <= 1: return a
    mid = len(a)//2
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    return merge(left, right)
```

- 稳定、最坏也是 $O(n \log n)$，但需额外空间；
- 适合链表排序、外部排序。

## 3. 快速排序（平均 $O(n \log n)$）

选 pivot，分区，递归。多数语言内置排序用它（或混合）。

```python
def quick(a):
    if len(a) <= 1: return a
    p = a[len(a)//2]
    return quick([x for x in a if x < p]) + \
           [x for x in a if x == p] + \
           quick([x for x in a if x > p])
```

- 最坏（已序+坏 pivot）$O(n^2)$，工程上随机化/三数取中缓解；
- 原地、缓存友好、常数小。

## 4. 堆排序（ $O(n \log n)$）

建堆 + 反复取最值，原地、不稳定。

## 5. 对比

| 算法 | 平均 | 最坏 | 稳定 | 空间 |
|------|------|------|------|------|
| 插入 | $O(n^2)$ | $O(n^2)$ | 是 | $O(1)$ |
| 归并 | $O(n \log n)$ | $O(n \log n)$ | 是 | $O(n)$ |
| 快排 | $O(n \log n)$ | $O(n^2)$ | 否 | $O(\log n)$ |
| 堆排 | $O(n \log n)$ | $O(n \log n)$ | 否 | $O(1)$ |

> 实际：小数据用插入，通用用快排/ introsort，稳定需求用归并。下一站：[二分与哈希查找](../二分与哈希查找)。
