# 树与二叉树

数组、链表、栈、队列都是「线性的」——一个接一个。树是第一个**层次（非线性）**结构：它像公司的组织架构，有根、有分支、有叶子。二叉树是其中最规整、也最常用的一类。

## 学习目标

- 说清树的基本术语（根、父/子、叶子、深度、高度）。
- 手写二叉树的前序 / 中序 / 后序 / 层序遍历。
- 理解二叉搜索树（BST）的查找为何是 $O(\log n)$（平均）。

## 核心概念

### 1. 树的基本术语

- **根（root）**：最顶端的节点，没有父节点。
- **父/子（parent/child）**：连线上方是父，下方是子。
- **叶子（leaf）**：没有子节点的节点。
- **深度**：从根到该节点的边数；**高度**：从该节点到最远叶子的边数。

### 2. 二叉树

每个节点**最多两个子节点**（左、右）。特殊形态：
- **满/完全二叉树**：节点排布紧凑，适合用数组存（下标 `i` 的左子是 `2i+1`，右子是 `2i+2`）。
- **二叉搜索树（BST）**：左子树所有值 < 根 < 右子树所有值。这个性质让查找、插入、删除都能「每步排除一半」→ 平均 $O(\log n)$。

### 3. 四种遍历

| 遍历 | 顺序 | 典型用途 |
|---|---|---|
| 前序（根左右） | 根 → 左 → 右 | 复制树、表达式树前缀 |
| 中序（左根右） | 左 → 根 → 右 | **BST 中序得到升序** |
| 后序（左右根） | 左 → 右 → 根 | 释放/删除节点、求子树和 |
| 层序 | 一层层从左到右 | BFS，用队列实现 |

## 最小可运行示例

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

# 递归中序遍历（BST 中序 = 升序）
def inorder(node, out=None):
    if out is None: out = []
    if node:
        inorder(node.left, out)
        out.append(node.val)
        inorder(node.right, out)
    return out

# 层序遍历（迭代，用队列）
from collections import deque
def levelorder(root):
    if not root: return []
    q, res = deque([root]), []
    while q:
        node = q.popleft()
        res.append(node.val)
        if node.left:  q.append(node.left)
        if node.right: q.append(node.right)
    return res
```

BST 插入（平均 $O(\log n)$）：

```python
def insert(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = insert(root.left, val)
    elif val > root.val:
        root.right = insert(root.right, val)
    return root   # 相等则不插（去重）
```

## 易错点

1. **遍历顺序记混**：中序是「左根右」，BST 升序全靠它；前/后序的「根」位置不同。
2. **递归终止条件**：遍历/插入忘了 `if not node:` 返回，会 `NoneType` 报错。
3. **BST 退化成链**：若插入有序数据（1,2,3,4…），BST 退化为链表，查找变 $O(n)$。工程上用**平衡树**（AVL / 红黑树）避免。
4. **混淆深度与高度**：深度从根往下数，高度从叶子往上数，根的高度 = 树的高度。
