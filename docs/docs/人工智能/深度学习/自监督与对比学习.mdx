## 核心概念

### 1. 为什么需要自监督

标注数据昂贵且稀缺，无标签数据近乎无限。自监督**从数据自身造监督**：把输入的一部分藏起来让模型预测（如掩码语言模型），或构造「同一张图的不同增强视图」作为正样本对。学会的表示可迁移到下游任务，大幅降低标注依赖。

### 2. 两类自监督

- **生成式**：重构输入（自编码器、MAE 掩码重建像素/词），迫使表示保留细节。
- **判别式（pretext task）**：设计代理任务，如「拼图还原」「旋转预测」「时序排序」。对比学习是其中最强的一支。

### 3. 对比学习：拉近相似、推远相异

核心是把**正样本对**（如同一图的两个增强视图 $x_i,\tilde{x}_i$）在表示空间靠近，把**负样本**（其他图）推远。InfoNCE 损失：

$$
\mathcal{L}= -\log\frac{\exp(\mathrm{sim}(z_i,z_j)/\tau)}{\exp(\mathrm{sim}(z_i,z_j)/\tau)+\sum_{k}\exp(\mathrm{sim}(z_i,z_k)/\tau)}
$$

其中 $\mathrm{sim}$ 常用余弦相似度，$\tau$ 是温度系数（越小越强调难分样本）。分母里的负样本越多，表示质量通常越好。

### 4. 关键方法

- **SimCLR**：大批量 + 强数据增强 + 一个可学习的投影头；靠大 batch 提供充足负样本。
- **MoCo**：维护一个**动量更新的编码器**与**负样本队列**，用小 batch 也能有海量负样本。
- **BYOL / SimSiam**：**不用负样本**，仅靠「在线网络预测目标网络的投影」+ 停止梯度，也能学出好表示，打破了「对比必须靠负例」的认知。

## 示例

用 PyTorch 风格写一段 InfoNCE 损失的直觉实现：

```python
import torch, torch.nn.functional as F

def info_nce(z1, z2, tau=0.1):
    # z1, z2: (B, D) 同一批样本的两个增强视图
    z1 = F.normalize(z1, dim=1)
    z2 = F.normalize(z2, dim=1)
    B = z1.size(0)
    # 正样本对：z1[i] 与 z2[i]；其余为（批内）负样本
    reps = torch.cat([z1, z2], dim=0)            # 2B
    sim = reps @ reps.t() / tau                  # 2B x 2B 相似度
    # 掩掉自身相似（对角线）
    sim = sim - torch.eye(2*B, device=sim.device) * 1e9
    # 标签：z1[i] 的正样本是 z2[i]，z2[i] 的正样本是 z1[i]
    labels = torch.cat([torch.arange(B)+B, torch.arange(B)])
    return F.cross_entropy(sim, labels)

# 伪数据：同一批的两个视图
z1 = torch.randn(32, 128); z2 = torch.randn(32, 128)
loss = info_nce(z1, z2)
print("InfoNCE loss =", round(loss.item(), 3), "（越低表示正样本对已比负样本更近）")
```

温度 $\tau$ 把相似度拉开成概率分布；batch 内其他样本自动充当负例——这正是 SimCLR 需要大 batch 的原因。

## 易错点

- **增强太弱或太强**：弱增强正样本对几乎相同、学不到东西；强到语义被破坏（如裁掉主体），正样本对也不再「同一语义」。需调出「难但仍是同一实例」的增强。
- **负样本不足**：batch 太小或队列太短，对比信号弱、表示塌缩。
- **忘记 L2 归一化**：余弦相似度依赖归一化，未归一化会让尺度支配损失。
- **把 BYOL 当普通对比**：BYOL 不用负样本、靠停止梯度防塌缩，若误加负样本反而可能劣化。

## 练习

1. InfoNCE 的分母里负样本越多越好吗？为什么？
2. 温度系数 $\tau$ 调小会发生什么？调大呢？
3. BYOL 没有负样本为何不塌缩成常数？停止梯度起了什么作用？

## 小结

自监督从数据自身造监督，把无标签数据变成预训练燃料；对比学习用「正样本对拉近、负样本推远」的 InfoNCE 把表示空间结构化，SimCLR/MoCo/BYOL 各显神通。它是现代表征学习与大模型预训练的底层引擎。
