# Java 学习路线图

Java 是一门**面向对象、跨平台**的语言，依托 JVM（Java 虚拟机）实现"一次编写，到处运行"，长期占据企业级后端与安卓生态的主导地位。它用自动垃圾回收管理内存、用强类型与接口保证工程稳健，并通过 Spring 生态覆盖从 Web 到微服务的全栈场景。

## 学习目标

学完本栏目，你应该能够：

- 用 Java 语法与面向对象（OOP）写出结构清晰的类与接口；
- 理解 JVM 内存模型、GC 与类加载，能排查内存溢出与依赖冲突；
- 用线程池、`synchronized`、显式锁与 `java.util.concurrent` 编写并发安全代码；
- 用 Spring Boot 在几分钟内起一个分层清晰的 Web 后端。

## 前置知识

- 若你学过 [C](../C/)，会更容易理解"编译成字节码""引用 vs 指针"；
- 若你学过 [Go](../Go/) 或 [Rust](../Rust/)，可对照三者不同的并发模型与内存哲学。

## 推荐学习路线

1. **语言基础**：先打牢语法、类型与面向对象（[Java 语言入门](./语言基础/Java语言入门)、[面向对象与核心语法](./语言基础/面向对象与核心语法)）；
2. **集合框架**：日常开发最高频的容器（[集合框架](./生态/集合框架)）；
3. **JVM**：内存模型、GC 与类加载，理解性能与调优的底层（[JVM 内存模型与 GC](./JVM/JVM内存模型与GC)、[类加载机制](./JVM/类加载机制)）；
4. **并发**：线程、线程池、锁与 JUC 工具（[线程与线程池](./并发/线程与线程池)、[并发容器与锁](./并发/并发容器与锁)）；
5. **标准库**：日常开发离不开 IO/NIO、反射与注解、函数式 Stream、异常与日期时间（[IO 与 NIO](./语言基础/IO与NIO)、[反射与注解](./语言基础/反射与注解)、[函数式与 Stream](./语言基础/函数式与Stream)、[异常与日期时间](./语言基础/异常与日期时间)）；
6. **生态**：用 Spring Boot 串起 Web 全栈（见下方文档列表）。
