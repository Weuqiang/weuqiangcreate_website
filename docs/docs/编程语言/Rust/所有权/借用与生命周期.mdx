# 借用与生命周期

[Rust 语言入门](../Rust语言入门) 讲了所有权。本篇深入"借用"（borrow）与"生命周期"——在不转移所有权的前提下安全使用值。

## 学习目标
- 区分 `&T`（不可变借用）与 `&mut T`（可变借用）；
- 记住编译期的三条借用规则；
- 理解何时需要显式生命周期标注 `'a`；
- 用切片（slice）避免不必要的拷贝。

## 前置知识
- 先读 [Rust 语言入门](../Rust语言入门) 理解所有权与 move。

## 核心概念

### 1. 不可变借用 `&T`

```rust
fn len(s: &String) -> usize {  // 借用，不获取所有权
    s.len()                     // 只读
}                                // s 离开，原所有者不受影响

let s = String::from("hi");
let n = len(&s);                 // &s 创建不可变借用
println!("{} {}", s, n);         // s 仍可用
```

- `&` 借出不转移所有权，函数结束原主仍在。
- 同一时刻可有**多个**不可变借用。

### 2. 可变借用 `&mut T`

```rust
fn append(s: &mut String) {
    s.push_str("!");
}
let mut s = String::from("hi");
append(&mut s);                  // 可变借用
println!("{}", s);               // hi!
```

- 同一时刻**只能有一个**可变借用，且不可变与可变借用**互斥**。
- 编译器在编译期杜绝数据竞争。

### 3. 借用规则（编译期检查）

1. 要么**多个** `&T`（只读），要么**一个** `&mut T`（可写）；
2. 借用生命周期**不超过**所有者；
3. 不存在"悬垂引用"。

```rust
let r: &i32;
{
    let x = 5;
    r = &x;          // ❌ x 即将离开作用域，借用非法
}
// println!("{}", r);
```

### 4. 生命周期标注

多数情况编译器能自动推断；函数返回引用时需显式标注：

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

- `'a` 表示"返回值生命周期与输入中较短者一致"。
- 标注不延长生命周期，只是向编译器证明安全。

### 5. 切片（slice）

```rust
let s = String::from("hello");
let slice: &str = &s[0..2];      // "he"，借用而不拥有
```

字符串切片 `&str`、数组切片 `&[T]` 都是借用，避免拷贝。

## 常见误区 / 易错点
- **可变与不可变借用互斥**：同一作用域内，要么多个 `&T`，要么一个 `&mut T`，不能混用。
- **借用不能比所有者活得更久**：返回局部变量的引用会编译失败（悬垂引用）；用 `'a` 把"返回值寿命"绑定到输入。
- **`&mut` 不是"可写指针"那么简单**：编译器会在编译期追踪借用，确保没有别名写入竞争。

## 练习
1. 自己实现 `fn longest<'a>(x: &'a str, y: &'a str) -> &'a str`（本篇示例已给，试着不抄写默写出并理解 `'a` 的约束）。
2. 让 `let mut s = String::from("hi"); let r1 = &s; let r2 = &mut s;` 同时存在，观察编译器报什么错，体会互斥规则。

## 小结
借用让 Rust 既**零拷贝**又**内存安全**：编译期静态验证"何时可读/可写/引用有效"。这是 Rust 区别于 C++ 的核心。
