# EMC 基础

EMC（Electromagnetic Compatibility，电磁兼容）管两件事：**你的板子别去骚扰别人（EMI，电磁干扰）**，以及**别人骚扰你时你要扛得住（EMS，抗扰度）**。产品要过认证（CE / FCC / CCC）必须做 EMC 测试，而实验室一次测试动辄数万元——设计阶段没做对，就是反复重打板的无底洞。

## 学习目标

- 理解干扰的三要素模型：**骚扰源 → 耦合路径 → 敏感设备**，以及对应的三种治理手段。
- 知道 EMI 的两条主要路径：传导发射与辐射发射，各自的频段与治理方法。
- 掌握实用的抑制手段：滤波、磁珠、共模电感、TVS、屏蔽、缓启动。
- 会做 ESD（静电放电）与浪涌防护的接口电路设计。
- 建立"从设计第一天就考虑 EMC"的意识，而不是等测试挂了再补救。

## 核心直觉

### 直觉一：三要素模型决定了你只有三种解法

```text
  骚扰源  ──── 耦合路径 ────►  敏感设备
（开关电源、    （走线、空间、      （ADC、复位脚、
  时钟、继电器）  电缆、地线）        无线接收）

三种治理方向：
1. 削弱源      → 降低 dV/dt 和 di/dt（缓启动、串阻、降低时钟沿速率）
2. 切断路径    → 滤波、磁珠、屏蔽、缩小环路面积
3. 加固受体    → TVS、去耦、软件容错（CRC、重试、看门狗）
```

任何 EMC 问题，都要先定位是这三者中的哪一环，再对症下药。**盲目加电容加磁珠，是新手最常见的浪费。**

### 直觉二：环路面积就是天线

一个电流环路的辐射强度大致正比于 `环路面积 × 电流 × 频率²`。所以：

```text
差的布线（大环路）：            好的布线（小环路）：
  ┌──────────────┐               ┌─┐
  │  信号        │               │信│
  │              │               │号│
  └──────────────┘               └─┘
  地（绕远路回来）                 地（紧贴信号线正下方）
  面积大 = 高效天线                面积小 = 辐射极低
```

**这也是为什么"完整地平面"是 EMC 的头号武器**——它天然让每根信号线的回流路径紧贴自己下方，环路面积自动最小化。

### 直觉三：差模与共模

```text
差模干扰：两根线上电流大小相等、方向相反
   ───►───         用 X 电容、差模电感滤
   ◄───────

共模干扰：两根线上电流同向，经寄生电容从大地回流
   ───►───         用 Y 电容、共模电感（磁环）滤
   ───►───
```

**实际产品 EMI 超标，八成是共模问题**，而共模的载体通常是"接出去的那根线缆"——电源线、USB 线、传感器延长线。这就是"线缆是最好的天线"这句话的由来。

### 排查四件套的 EMC 映射

- **电源**：开关电源是板上最强的骚扰源，Buck 的开关环路必须做到最小；输入端加 π 型滤波（共模电感 + X/Y 电容）。
- **时钟**：晶振和高速时钟线是窄带辐射的主要来源，展频（Spread Spectrum）能把尖峰摊平 10dB 以上。
- **复位**：复位脚是最典型的敏感点，一次 ESD 就可能让设备重启。必须就近加 100nF 电容，长走线还要加 TVS。
- **引脚复用**：不用的高速外设别开着，不用的引脚别浮空——浮空引脚既是接收天线也是发射天线。

## 最小可运行例程

**接口防护标准电路（可直接照抄的模板）**

```text
=== USB 接口防护 ===
USB 连接器
  VBUS ──[ 保险丝/PTC ]──┬── 10µF ──┬── 到板内 5V
                          └─ TVS(5.5V) ┘
  D+/D- ─[ 共模电感 90Ω ]─┬── 到 MCU
                           └─ ESD 阵列（低结电容 < 1pF，否则影响信号）
  屏蔽壳 ──[ 1MΩ ∥ 1nF ]── GND    ← 高频接地、直流隔离，避免地环路

=== RS485 / 长线传感器接口 ===
A/B ─[ 10Ω PTC ]─┬─[ TVS 差模 + 共模 ]─┬─ 收发器
                  │                      └─ 120Ω 终端电阻（仅两端）
                  └─ 气体放电管 → 大地（户外场合防雷）

=== 电源入口 ===
DC IN ─[ 保险丝 ]─[ 共模电感 ]─┬─ X电容 100nF ─┬─ Buck 输入
                                 └─ TVS(SMBJ) ──┘
                     Y电容 2.2nF ×2 → 外壳地（抑制共模，容值受漏电流法规限制）
```

**软件侧的 EMC 加固**——硬件做到 90 分，剩下 10 分靠软件容错：

```c
/* 1. 通信层：永远假设数据会被干扰污染 */
typedef struct {
    uint8_t  head;        /* 0xAA 帧头 */
    uint8_t  len;
    uint8_t  payload[64];
    uint16_t crc;         /* CRC16 校验，误码必须能检出 */
} frame_t;

bool frame_verify(const frame_t *f)
{
    if (f->head != 0xAA)          return false;
    if (f->len  > sizeof(f->payload)) return false;   /* 长度也要校验，防越界 */
    return crc16(f->payload, f->len) == f->crc;
}

/* 2. 关键寄存器周期性重写 —— 防止外设配置被 ESD 冲乱 */
void periodic_refresh_config(void)
{
    /* 每秒执行一次：把 GPIO 模式、外设关键寄存器按预期值重新写一遍 */
    HAL_GPIO_Init(GPIOA, &g_saved_gpioa_cfg);
    __HAL_UART_ENABLE(&huart1);
    /* 这招在工业现场非常有效：ESD 打进来改了某个寄存器位，
       下一个周期就被自动修正，避免设备"莫名其妙不工作了"       */
}

/* 3. 关键变量做冗余存储 —— 三取二表决 */
typedef struct { uint32_t v, v_inv, v_copy; } safe_u32_t;

void safe_set(safe_u32_t *s, uint32_t v)
{
    s->v = v; s->v_inv = ~v; s->v_copy = v;
}

bool safe_get(const safe_u32_t *s, uint32_t *out)
{
    if (s->v == s->v_copy && s->v == ~s->v_inv) { *out = s->v; return true; }
    return false;      /* 检测到位翻转，上报故障或重新初始化 */
}

/* 4. ADC 采样避开开关电源噪声：与 PWM 同步，在开关管关断的安静时刻采样 */
void HAL_TIM_PWM_PulseFinishedCallback(TIM_HandleTypeDef *htim)
{
    HAL_ADC_Start_IT(&hadc1);   /* PWM 下降沿后触发采样，避开开关尖峰 */
}
```

## 易错点

- **等测试挂了才想 EMC**：整改成本是设计阶段的十倍以上，而且很多问题（如叠层、器件布局）根本改不了。
- **只加电容不看环路**：一颗 100nF 放错位置毫无用处；先缩小环路面积，再谈滤波。
- **Y 电容随便加大**：Y 电容容值直接决定漏电流，超标会导致安规不过、外壳带电麻手。必须按标准限值选取。
- **TVS 选型只看电压不看结电容**：普通 TVS 的结电容有几百 pF，接在 USB / 高速差分线上会把信号糊掉，必须选低容型。
- **屏蔽罩不接地或只接一点**：形同虚设，甚至变成谐振腔。屏蔽罩要多点接地，间距远小于最高频率的四分之一波长。
- **单板测试通过就交付**：EMC 是整机行为，装进金属外壳、接上线缆后结果可能完全不同。必须整机测试。
- **忽视 ESD 路径**：静电从按键、接口打进去，如果没有低阻抗泄放通道，就会穿过 MCU。防护器件要放在**紧靠连接器**的位置，而不是靠近 MCU。
- **地环路**：设备两端都接大地时形成的大环路会引入工频干扰，光耦或变压器隔离是标准解法。
- **共模电感装反或选错阻抗**：共模电感对差模信号应基本透明，选型时要看在目标频段的共模阻抗曲线。

## 练习

1. 为你的板子画出「骚扰源 / 耦合路径 / 敏感设备」清单，逐条给出对应的抑制措施。
2. 用一台廉价近场探头（可用一段同轴自制）配合频谱仪或 SDR，扫描板上辐射最强的位置，验证是否是开关电源或晶振。
3. 做 ESD 对照实验：用静电枪（或摩擦起电的简易方式）对未加防护和加了 TVS 的两版接口放电，记录设备是否复位。
4. 给一个 RS485 长线接口设计完整防护电路，说明每个器件解决什么问题、为什么放在那个位置。
5. 开启 MCU 的展频时钟功能，对比开启前后时钟谐波峰值的变化。

## 小结

EMC 不是玄学，它有清晰的因果链：**减小环路面积、给回流一条低阻抗的路、在连接器处拦住外来能量、用软件兜住残余误码**。把"完整地平面 + 就近去耦 + 接口防护 + 通信校验"这四件事做到位，绝大多数产品都能一次过测试。记住：EMC 是设计出来的，不是整改出来的。
