# Rust

Rust 是一门**内存安全、无垃圾回收、高性能**的系统级语言，能在编译期消除数据竞争与悬垂指针，被 Stack Overflow 多年评为"最受欢迎语言"。

## 本栏目结构

- **所有权**：所有权、借用与生命周期——Rust 不用 GC 也能保证内存安全的核心机制。
- **类型系统**：枚举（enum）、模式匹配、`Result`/`Option` 与 Trait。
- **系统编程**：错误处理、`async`/线程并发与底层系统实践。

## 推荐学习路线

1. **所有权、借用、生命周期**是最难也最关键的一步，务必吃透；
2. 再学类型系统：`enum` + 模式匹配 + `Result` 构成 Rust 的错误处理范式；
3. 最后进入并发与系统编程，体会"无畏并发"（fearless concurrency）。
