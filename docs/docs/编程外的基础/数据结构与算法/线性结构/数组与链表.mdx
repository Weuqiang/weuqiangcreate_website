# 数组与链表

数组与链表是最基础的**线性结构**，几乎所有高级结构都建立在它们之上。本篇对比两者与常见操作。

## 1. 数组（Array）

- 内存中**连续存放**，长度固定（动态数组可扩容）。
- 按下标访问 $O(1)$，但中间插入/删除需移动元素 $O(n)$。

```python
a = [1, 2, 3]
a[0]            # O(1)
a.insert(1, 9)  # 移动，O(n) → [1, 9, 2, 3]
```

动态数组（Python `list`、Java `ArrayList`）扩容时偶发 $O(n)$，均摊 $O(1)$。

## 2. 链表（Linked List）

- 节点散落内存，每个节点存**数据 + 下一节点指针**；
- 插入/删除只需改指针 $O(1)$，但随机访问需遍历 $O(n)$。

```python
class Node:
    def __init__(self, v):
        self.v = v
        self.next = None

# 头部插入
head = Node(1)
head = Node(0)  # 新节点 .next = 原 head
```

## 3. 对比

| 操作 | 数组 | 链表 |
|------|------|------|
| 按下标访问 | $O(1)$ | $O(n)$ |
| 头部插入 | $O(n)$ | $O(1)$ |
| 尾部插入 | $O(1)^*$ | $O(1)$（有尾指针） |
| 内存 | 连续、缓存友好 | 分散、额外指针开销 |

\* 动态数组扩容时偶发 $O(n)$。

## 4. 变体

- **单向 / 双向链表**：双向多一个前驱指针，可反向遍历；
- **循环链表**：尾连头；
- **跳表（Skip List）**：加多层索引，查找接近 $O(\log n)$，Redis 有序集用。

## 5. 选型直觉

- 读多写少、需要随机访问 → 数组；
- 频繁头插/中间增删 → 链表；
- 实际工程多用动态数组（综合更优、缓存友好）。
