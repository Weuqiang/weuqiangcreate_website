# 多重积分应用

一元积分是「把一条线上的小段加起来」，多重积分则是「把一片面积、一团体积上的小块加起来」。它在工程里的三大用途非常具体：**算总量、算重心、算概率**。

## 学习目标

- 把二重积分写成累次积分，并正确确定积分限。
- 用极坐标换元简化圆形区域上的积分，说清雅可比因子 $r$ 从哪来。
- 用多重积分计算面积、体积、质心与联合概率。
- 用蒙特卡洛方法数值估计高维积分，并理解其误差随样本数的衰减规律。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [积分与多元微积分](/docs/数学基础/微积分/积分与多元微积分) 中的二重/三重积分。
- 知道密度、质心的物理直觉。
- 基本的换元（极坐标、球坐标）概念。

## 核心概念
**积分 = 无穷多个小块的加权求和。** 唯一变化的是「小块」长什么样：

| 积分 | 小块 | 典型用途 |
|------|------|----------|
| $\int f\,dx$ | 小线段 $dx$ | 面积、总量 |
| $\iint f\,dA$ | 小方块 $dx\,dy$ | 体积、质量、二维概率 |
| $\iiint f\,dV$ | 小立方 $dx\,dy\,dz$ | 质量、电荷、三维期望 |

**富比尼定理**告诉我们，二重积分可以拆成两次一元积分（累次积分）：

$$
\iint_D f(x,y)\,dA=\int_{a}^{b}\!\!\left[\int_{g_1(x)}^{g_2(x)} f(x,y)\,dy\right]dx
$$

内层积分固定 $x$、沿 $y$ 切一刀求「切片面积」，外层再把所有切片沿 $x$ 累加。**画出区域 $D$ 再定限**是唯一可靠的做法，硬套公式最容易错。

**换元与雅可比。** 遇到圆形区域，直角坐标的积分限会变成开根号的丑陋表达式。换成极坐标 $x=r\cos\theta,\ y=r\sin\theta$ 后：

$$
dA=dx\,dy=r\,dr\,d\theta
$$

那个多出来的 $r$ 不是背下来的，它是**雅可比行列式**：

$$
J=\left|\frac{\partial(x,y)}{\partial(r,\theta)}\right|
=\begin{vmatrix}\cos\theta & -r\sin\theta\\ \sin\theta & r\cos\theta\end{vmatrix}
=r(\cos^2\theta+\sin^2\theta)=r
$$

几何解释更直白：极坐标网格中的小块是「扇环」，它的两边长分别是 $dr$ 和弧长 $r\,d\theta$，面积自然是 $r\,dr\,d\theta$。**离原点越远，同样的角度张开出的格子越大**，所以要乘 $r$ 加权。

**三大应用。**

- **质量与体积**：密度 $\rho(x,y)$ 在区域上的积分即总质量；$f(x,y)$ 为高度时积分即曲顶柱体体积。
- **质心**：$\bar x=\frac{\iint x\rho\,dA}{\iint \rho\,dA}$，本质是「以质量为权重的平均位置」。
- **概率**：联合密度必须满足归一化 $\iint p(x,y)\,dA=1$；边缘分布是「把另一个变量积掉」$p(x)=\int p(x,y)\,dy$；期望是 $\iint g(x,y)p(x,y)\,dA$。多元统计的公式几乎都是多重积分。

## 最小示例

**手算：极坐标求高斯积分。** 经典技巧——平方后换极坐标：

$$
I^2=\iint_{\mathbb{R}^2}e^{-(x^2+y^2)}dA
=\int_0^{2\pi}\!\!\int_0^{\infty}e^{-r^2}r\,dr\,d\theta
=2\pi\cdot\tfrac12=\pi
$$

故 $I=\int_{-\infty}^{\infty}e^{-x^2}dx=\sqrt{\pi}$。**若没有雅可比的那个 $r$，$e^{-r^2}r\,dr$ 就无法初等积出**，这正是 $r$ 的价值所在。

```python
import numpy as np

# ---- 1. 网格法验证二重积分：∬ over [0,1]x[0,2] of (x + y^2) dA ----
# 手算：∫0^1∫0^2 (x + y²) dy dx = ∫0^1 (2x + 8/3) dx = 1 + 8/3 = 11/3 ≈ 3.6667
n = 2000
x = np.linspace(0, 1, n)
y = np.linspace(0, 2, n)
X, Y = np.meshgrid(x, y, indexing="ij")
Z = X + Y**2
dA = (1 / (n - 1)) * (2 / (n - 1))
print(f"网格法: {Z.sum() * dA:.4f}   理论值: {11/3:.4f}")
# 网格法 3.6710 vs 理论 3.6667：左端点求和有 O(1/n) 的系统偏差，加密网格即收敛 ✔

# ---- 2. 蒙特卡洛估计 π：单位圆面积 ----
rng = np.random.default_rng(42)
for N in [10_000, 1_000_000]:
    pts = rng.uniform(-1, 1, size=(N, 2))
    inside = (pts**2).sum(axis=1) <= 1
    print(f"N={N:>9}: π ≈ {4 * inside.mean():.5f}")
# 误差按 1/sqrt(N) 衰减：样本放大 100 倍，精度只提升约 10 倍

# ---- 3. 质心：半圆盘 x²+y²≤1, y≥0，密度均匀 ----
# 理论值：ȳ = 4/(3π) ≈ 0.4244
N = 2_000_000
p = rng.uniform(-1, 1, size=(N, 2))
m = ((p**2).sum(axis=1) <= 1) & (p[:, 1] >= 0)
print(f"质心 ȳ ≈ {p[m, 1].mean():.4f}   理论 {4/(3*np.pi):.4f}")   # ✔

# ---- 4. 验证二维标准正态密度的归一化 ----
g = np.linspace(-6, 6, 1200)
Xg, Yg = np.meshgrid(g, g)
pdf = np.exp(-(Xg**2 + Yg**2) / 2) / (2 * np.pi)
h = g[1] - g[0]
print(f"∬ p dA = {pdf.sum() * h * h:.6f}")    # ≈ 1.000000 ✔
```

## 易错点

- **换元后忘记乘雅可比行列式**。这是多重积分最高频的错误，极坐标漏掉 $r$、球坐标漏掉 $\rho^2\sin\varphi$ 都会让结果整体错一个量级。
- **积分限写反或写成常数**。内层积分限可以依赖外层变量（如 $y$ 从 $0$ 到 $x$），但外层积分限**必须是常数**，否则结果里还留着变量。
- **交换积分次序时不重新画图**。$\int_0^1\!\int_0^x dy\,dx$ 换序后是 $\int_0^1\!\int_y^1 dx\,dy$，直接对调上下限是错的。
- **误以为网格法在高维也可行**。每维取 100 个点，10 维就是 $10^{20}$ 个格点——这就是「维数灾难」。高维只能用蒙特卡洛，因为它的误差 $O(1/\sqrt{N})$ **与维度无关**。
- **把边缘分布和条件分布搞混**。边缘是「积掉」另一个变量，条件是「除以」边缘密度。

## 练习

1. 计算 $\iint_D (x+y)\,dA$，其中 $D=[0,1]\times[0,1]$。
   *答案：$\int_0^1(x+\tfrac12)dx=\tfrac12+\tfrac12=1$。*
2. 用极坐标计算半径为 $R$ 的圆的面积。
   *提示：$\int_0^{2\pi}\!\int_0^{R} r\,dr\,d\theta=2\pi\cdot\frac{R^2}{2}=\pi R^2$。*
3. 蒙特卡洛估计的误差约为 $O(N^{-1/2})$。若想把误差降到原来的 $1/10$，样本量需增加多少倍？
   *答案：100 倍。这也是为什么实践中更依赖方差缩减技巧而非单纯堆样本。*

## 小结

多重积分把「累加」从一维推广到高维，二重积分通过富比尼定理化为累次积分，关键在于对着区域图正确写出积分限。换元时必须乘上雅可比行列式，极坐标的 $r$ 与球坐标的 $\rho^2\sin\varphi$ 都源于此，其几何含义是小块面积/体积的缩放比。多重积分在工程中直接对应总量、质心与联合概率三类计算。当维度升高时网格法失效，应改用误差与维度无关的蒙特卡洛方法。
