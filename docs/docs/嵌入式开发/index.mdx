# 嵌入式开发

嵌入式系统是以**专用计算机**为核心、嵌入到设备内部完成特定任务的系统。智能手环、家电控制板、汽车 ECU、工业 PLC，背后都是嵌入式开发。

本栏目从「电路 → 单片机 → RTOS → 通信」逐层深入：

- **硬件与电路基础**：电压电流电阻、模拟/数字电路、常用元器件与测量仪器。
- **单片机 MCU**：Arduino 入门，进阶 STM32 与 HAL 库，掌握 GPIO/定时器/中断。
- **RTOS 与固件**：FreeRTOS 任务调度、内存与栈、固件烧录与调试。
- **通信协议**：UART/SPI/I2C、CAN 总线与无线通信。

> 推荐顺序：先懂一点电路，再玩 Arduino 跑通点灯，接着上 STM32 做外设，最后引入 RTOS 与通信协议做完整项目。

## 与通用开发的区别

- 资源受限：内存常以 KB 计，要精打细算。
- 实时性：很多场景要求「在规定时间内响应」。
- 软硬结合：你不仅要写代码，还要读原理图、用示波器。
