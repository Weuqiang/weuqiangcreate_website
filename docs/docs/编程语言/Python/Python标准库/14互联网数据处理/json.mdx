## 核心概念

`json` 在 Python 对象与 JSON 文本间互转：`dumps`/`loads` 处理字符串，`dump`/`load` 处理文件。类型映射关键：dict↔object、list/tuple↔array、str↔string、True/False/None↔true/false/null。JSON 键恒为字符串，非字符串键反序列化会丢失——`loads(dumps(x)) != x` 当 x 的键非字符串时。

## json 模块

`json` 模块提供了 `python -> json` 以及 `json -> python` 两种转换，规则如下：

| JSON      | Python -> | JSON           |
| --------- | --------- | -------------- |
| object    | dict      | object -- 对象 |
| array     | list      | array          |
| string    | str       | string         |
| number (int)   | int       | number         |
| number (real)  | float     | number         |
| true      | True      | true           |
| false     | False     | false          |
| null      | None      | null           |
|           | tuple     | array          |

注意：JSON 中的键永远是 `str` 类型。当一个对象被转化为 JSON 时，字典里所有键都会被强制转为字符串。这造成的结果是字典被转换为 JSON 再转换回来时可能和原来不相等——如果 `x` 具有非字符串的键，则 `loads(dumps(x)) != x`。

`json` 模块还有一些其他参数可以控制编码形式、格式化输出等，不过很少用到。

[json 官方模块文档](https://docs.python.org/zh-cn/3/library/json.html#module-json)

### json.load 与 json.dump

`json.load` 与 `json.dump` 是基于文件的转换。

```python showLineNumbers
import json

data = {
    "name": "Satyam kumar",
    "place": "patna",
    "skills": [
        "Raspberry pi",
        "Machine Learning",
        "Web Development"
    ],
    "email": "xyz@gmail.com",
    "projects": [
        "Python Data Mining",
        "Python Data Science"
    ]
}
with open("data_file.json", "w", encoding="utf-8") as write:
    json.dump(data, write, ensure_ascii=False, indent=2)

with open("data_file.json", "r", encoding="utf-8") as read_content:
    print(json.load(read_content))
```

### json.loads 与 json.dumps

`json.loads` 与 `json.dumps` 是直接基于数据的转换，这里的 `s` 表示 `string`（字符串）。

```python showLineNumbers
import json

# JSON string（多行字符串）
data = """{
    "Name": "Jennifer Smith",
    "Contact Number": 7867567898,
    "Email": "jen123@gmail.com",
    "Hobbies":["Reading", "Sketching", "Horse Riding"]
    }"""

# parse data:
res_p = json.loads(data)
print(type(res_p)) # <class 'dict'>

res_j = json.dumps(res_p, ensure_ascii=False, indent=2)
print(type(res_j)) # <class 'str'>
```

## 易错点（重点）

- **中文被转义**：`dumps` 默认 `ensure_ascii=True`，会把中文变成 `\uXXXX`。要原样输出中文，设 `ensure_ascii=False`（并配合 `open(..., encoding="utf-8")`）。
- **非字符串键会被强转**：`dumps({1: "a"})` 得到 `{"1": "a"}`，再 `loads` 回来键变成字符串 `"1"`，与原 dict 不相等。
- **循环引用直接报错**：默认不检测循环引用，`dumps` 循环嵌套对象会抛 `RecursionError` / `ValueError`；可用 `default=` 自定义序列化函数处理未知类型。
- **数字界限模糊**：JSON 只有一种 number，Python 的 `int` 与 `float` 界限可能丢失（如 `1` 与 `1.0`），超大整数也可能被解析成 float 丢失精度。
- **自定义对象不能直接序列化**：`dumps(datetime.now())` 会报 `TypeError`；需 `default=` 或继承 `JSONEncoder` 处理。
- **缩进与可读性**：调试时用 `indent=2` 更易读；生产接口里通常不要 `indent` 以减小体积。

## 练习

1. 把一段中文 dict 用 `dumps(..., ensure_ascii=False, indent=2)` 输出，对比加与不加 `ensure_ascii` 的差异。
2. 用 `dump` 把一个配置 dict 写入 `config.json`，再 `load` 读回来，验证往返一致。
3. 写一个 `default=` 函数，让 `datetime` 对象能被 `dumps` 成 ISO 字符串。

## 示例

```python
import json

data = {"name": "Alice", "tags": ["a", "b"], "age": 30}

# 对象 -> 字符串
s = json.dumps(data, ensure_ascii=False, indent=2)
print(s)

# 字符串 -> 对象
obj = json.loads(s)
print(obj["name"])

# 文件读写
with open("cfg.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False)
```

## 小结

`json` 是 Python 与 JSON 互转的标准工具：`dumps`/`loads` 处理字符串，`dump`/`load` 处理文件。`ensure_ascii=False` 保留中文可读；类型映射要记牢（dict↔object、tuple↔array、None↔null）。它是配置文件与接口数据交换的首选格式。
