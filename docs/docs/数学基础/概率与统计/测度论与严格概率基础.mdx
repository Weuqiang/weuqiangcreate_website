# 测度论与严格概率基础

## 核心概念

### 1. 为什么需要测度论

黎曼积分要求函数「足够好」（区间上几乎连续）；但概率里常遇到密度不连续、条件期望、随机过程路径（布朗运动处处不可导）等。测度论提供统一框架：用「集合的大小（测度）」定义概率，对离散、连续、奇异（如 Cantor 分布）一视同仁。

### 2. 测度三元组

概率空间 $(\Omega,\mathcal{F},\mathbb{P})$：

- $\Omega$：样本空间（所有可能结果）
- $\mathcal{F}$：σ-代数，$\Omega$ 的若干子集组成的族，对补与可数并封闭（即可赋予概率的「事件」集合）
- $\mathbb{P}$：$\mathcal{F}\to[0,1]$ 的测度，且 $\mathbb{P}(\Omega)=1$

σ-代数之所以「只要求可数并封闭」，是为了让「可数次事件后的概率」仍有意义（概率的连续性）。

### 3. 可测函数与随机变量

随机变量 $X$ 是一个「可测函数」：对任意 Borel 集 $B$，$X^{-1}(B)\in\mathcal{F}$。即它把结果映成可赋概率的集合，从而 $P(X\in B)$ 才有定义。

### 4. 勒贝格积分

黎曼积分按定义域切片，勒贝格积分按函数值切片。对非负函数：

$$
\int f\,d\mu = \int_0^\infty \mu(\{x: f(x)>t\})\,dt
$$

优势：对更多函数可积、与极限交换更友好（单调收敛定理、控制收敛定理），这正是期望 $\mathbb{E}[X]=\int X\,d\mathbb{P}$ 的严格定义。

### 5. 条件期望与 Radon-Nikodym

条件期望 $\mathbb{E}[X\mid\mathcal{G}]$ 是关于子 σ-代数 $\mathcal{G}$ 的**可测随机变量**（而非一个数），满足对任意 $A\in\mathcal{G}$ 有 $\int_A \mathbb{E}[X\mid\mathcal{G}]\,d\mathbb{P}=\int_A X\,d\mathbb{P}$。Radon-Nikodym 定理保证：若 $\nu\ll\mu$，则存在导数 $d\nu/d\mu$ 使 $\nu=\int (d\nu/d\mu)\,d\mu$——这正是「密度」的严格定义（似然比、后验都源于此）。

## 示例

用离散小例子展示「按函数值分层的勒贝格思想」与「条件期望作为可测近似」：

```python
import numpy as np

# X 取 {1,2,3,4} 等概率，Y=X^2。勒贝格式积分 E[Y]=Σ y·P(Y=y)
values, probs = np.array([1, 4, 9, 16]), np.full(4, 0.25)
print("E[Y] (勒贝格/求和视角):", float((values * probs).sum()))

# 条件期望 E[X | X 奇偶]：在「奇偶」这个粗糙 σ-代数下，X 被替成该类的平均
parity = {1: "奇", 2: "偶", 3: "奇", 4: "偶"}
for cls in ["奇", "偶"]:
    xs = [x for x in [1, 2, 3, 4] if parity[x] == cls]
    print(f"E[X | {cls}] =", float(np.mean(xs)))
```

## 易错点

- **把条件期望当成「一个数」**：严格地它是关于某 σ-代数的可测随机变量（一个投影/近似）。
- **以为所有子集都能赋概率**：在不可数空间（如 $\mathbb{R}$）上必须限制到 σ-代数，否则会引出矛盾（Vitali 集）。
- **混淆「几乎处处」与「处处」**：测度论结论多为 a.s.（零测集上可例外）。
- **忘记 Radon-Nikodym 要求绝对连续 $\nu\ll\mu$**：否则「密度」不存在。

## 练习

1. 说明 $[0,1]$ 上的 Cantor 分布没有（相对于 Lebesgue 测度的）密度，但仍是合法概率测度。
2. 用单调收敛定理说明为何 $\mathbb{E}[\sum X_n]=\sum\mathbb{E}[X_n]$ 对非负项成立。
3. 条件期望 $\mathbb{E}[X\mid\mathcal{G}]$ 如何看成「$X$ 在 $\mathcal{G}$-可测函数空间上的正交投影」？

## 小结

测度论把概率建立在「集合的测度」之上：σ-代数划定可赋概率的事件，可测函数定义随机变量，勒贝格积分统一期望的计算，条件期望与 Radon-Nikodym 导数给出严格的条件概率与密度。它是现代概率、随机过程与统计理论的严格地基。
