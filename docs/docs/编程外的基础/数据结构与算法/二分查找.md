# 二分查找

二分查找（Binary Search）是「分治」在**有序**序列上的经典应用：每次拿中间元素和 target 比，能直接扔掉一半。复杂度 $O(\log n)$，比线性扫描快几个数量级。

## 学习目标

- 说清二分查找的前提（必须有序、可随机访问）。
- 写出不越界、不死循环的二分模板。
- 区分「找等于 / 找左边界 / 找右边界」。

## 核心概念

### 1. 前提

- 数据**已排序**（升序最常见）。
- 支持**按下标随机访问**（数组，而非链表）。

### 2. 循环不变量（不掉坑的关键）

维护 `[left, right]` 表示「答案一定在这个闭区间内」。每轮：
- `mid = (left + right) // 2`
- 若 `nums[mid] == target`：找到。
- 若 `nums[mid] < target`：答案在右半，`left = mid + 1`。
- 若 `nums[mid] > target`：答案在左半，`right = mid - 1`。
- 退出条件 `left > right`：没找到。

### 3. 三种常见问法

| 问法 | 找到后怎么做 |
|---|---|
| 是否存在 / 等于 | 直接返回 `mid` |
| 第一个 ≥ target（左边界） | 记录候选，`right = mid - 1` 继续向左 |
| 最后一个 ≤ target（右边界） | 记录候选，`left = mid + 1` 继续向右 |

## 最小可运行示例

基础版（找等于）：

```python
def binary_search(a, target):
    left, right = 0, len(a) - 1
    while left <= right:                 # 闭区间 [left, right]
        mid = (left + right) // 2
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1                            # 未找到
```

左边界版（第一个 ≥ target）：

```python
def lower_bound(a, target):
    left, right, ans = 0, len(a) - 1, len(a)
    while left <= right:
        mid = (left + right) // 2
        if a[mid] >= target:
            ans, right = mid, mid - 1     # 可能是答案，继续向左逼
        else:
            left = mid + 1
    return ans
```

## 易错点

1. **区间与条件不一致**：用 `[left, right]` 闭区间就必须 `while left <= right` 且更新时 `±1`；用 `[left, right)` 半开区间则条件与更新都不同。**二选一并贯穿到底**。
2. **死循环**：`mid` 不更新边界（漏写 `±1`）会导致 `left==right` 时卡死。
3. **整数溢出**：`(left+right)//2` 在 Python 不会溢出，但某些语言要用 `left + (right-left)//2`。
4. **忘了前提**：对未排序数组二分会得到错误结果，毫无意义。

## 练习

1. 在有序数组里找 target 的**出现次数**（用两次 `lower_bound`）。
2. 在「有序但有旋转」的数组里搜索（如 `[4,5,6,1,2,3]`）。
3. 用二分在「非负整数」范围里求 `x` 的整数平方根（不用 `math.sqrt`）。

## 小结

二分查找把 $O(n)$ 降到 $O(\log n)$，前提是**有序 + 随机访问 + 守住循环不变量**。模板记一种并严格执行，别混用区间定义。相关：用二分优化的「在答案空间上二分」技巧，是 [动态规划入门](../动态规划入门) 之外另一类降复杂度利器。
