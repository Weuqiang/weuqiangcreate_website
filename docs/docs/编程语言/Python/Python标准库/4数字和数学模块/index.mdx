title: 数字和数学模块
---

数值计算是编程的基本功。Python 标准库把最常用的数学工具做成了开箱即用的模块：从标量数学（`math`）、随机性（`random`），到可控精度的定点小数（`decimal`）、精确的统计分析（`statistics`）与有理数（`fractions`）。它们不依赖第三方库，是理解 NumPy、PyTorch 等数值栈之前必须打好的地基。

## 本章模块

- [math 与 random](./math-random) — 标量数学函数、常数，以及伪随机采样与洗牌
- [decimal / statistics / fractions](./decimal-statistics-fractions) — 定点精度、描述统计与有理数运算
