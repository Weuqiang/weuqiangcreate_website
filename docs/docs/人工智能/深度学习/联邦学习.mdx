## 核心概念

### 为什么「数据不能集中」

很多高价值数据天然分散且敏感：手机输入法习惯、医院病历、银行交易。法规（GDPR 等）与商业壁垒使「把数据汇总到一台服务器训练」不可行。联邦学习（Federated Learning, FL）的反直觉做法是：**让模型去数据所在的地方，只传模型更新，不传原始数据**。

### 三类联邦

- **横向联邦（Horizontal）**：参与方**特征相同、样本不同**（如不同地区的同一家银行，字段一致、客户不同）。
- **纵向联邦（Vertical）**：参与方**样本重叠、特征不同**（如同一城市的银行与电商，客户重叠但掌握不同维度）。
- **联邦迁移**：参与方数据分布与特征都差异大，借助迁移学习桥接。

### FedAvg：最基础的聚合算法

1. 服务器下发全局模型 $\theta^t$ 给选中的一批客户端。
2. 每个客户端用本地数据做若干步 SGD，得到 $\theta_k^t$。
3. 客户端只上传**权重更新**（或权重），服务器按样本数加权平均聚合：
   $$\theta^{t+1} = \sum_k \frac{n_k}{n} \theta_k^t$$
4. 重复，直到收敛。

关键：**原始数据从未离开设备**，网络上只流动模型参数（通常再经压缩/加密）。

### 三大挑战

| 挑战 | 表现 | 缓解 |
|------|------|------|
| **统计异构（Non-IID）** | 各客户端数据分布不同，朴素平均收敛慢甚至发散 | FedProx（加近端正则）、SCAFFOLD（控制变量校正偏移） |
| **系统异构** | 设备算力/网络不一，常掉线 | 异步聚合、容错选子集、减少通信轮次 |
| **通信效率** | 每轮上传大模型，带宽贵 | 模型压缩（量化/稀疏）、本地多步再上传、仅传差分 |

### 隐私与攻击

「不传原始数据」不等于绝对安全：**梯度/权重可能泄露训练样本**（梯度反演攻击能重建图像）。因此要叠加：

- **差分隐私（DP）**：在上传的更新里加校准噪声，使单条样本「不可区分」。
- **安全聚合（Secure Aggregation）**：服务器只能看到聚合结果、看不到单个客户端的更新（密码学多方计算）。
- **联邦学习与 [安全对齐](/docs/人工智能/大模型与应用/AI安全对齐) 的交集**：既要保护数据隐私，又要防止被投毒/越狱的客户端污染全局模型。

### 个性化联邦学习

全局模型未必适合每个客户端（大家分布不同）。个性化手段：局部微调最后几层、学习个性化头、或混合全局+局部参数，让「共享知识」与「本地适配」共存。

## 示例

FedAvg 的核心聚合（伪代码）：

```python
def federated_averaging(clients, global_model, rounds=20):
    for r in range(rounds):
        chosen = random.sample(clients, k=int(0.1 * len(clients)))  # 每轮只选 10% 设备
        updates = []
        for c in chosen:
            local = c.train(global_model, steps=5)     # 本地多步 SGD，数据不出设备
            updates.append((c.n_samples, local - global_model))  # 只传「差分」
        # 服务器按样本数加权平均，看不到任何原始数据
        total = sum(n for n, _ in updates)
        delta = sum((n / total) * d for n, d in updates)
        global_model = global_model + delta
    return global_model
```

要点：客户端只回传「模型差分」，服务器做加权平均——原始样本始终留在设备端。

## 易错点

- **误以为「不传数据就安全」**：梯度反演能从上传的权重/梯度重建样本，必须叠加 DP 或安全聚合。
- **忽视 Non-IID 导致不收敛**：直接用 FedAvg 在分布差异大的客户端上，可能发散；需 FedProx/SCAFFOLD 之类修正。
- **通信预算失控**：每轮全模型上传在大规模设备上不可行，必须做压缩与本地多步。
- **混淆 FL 与分布式训练**：数据中心内的分布式训练数据本就集中、网络可靠；FL 的难点正是「数据不出域 + 设备不可靠 + 异构」。

## 小结

联邦学习用「**数据不动模型动**」解决数据隐私与孤岛问题：FedAvg 在客户端本地训练、服务器按样本加权平均聚合。真正难点是**统计异构（Non-IID）、系统异构与通信效率**，以及「不传数据≠安全」带来的**隐私加固（DP/安全聚合）**。它与[分布式系统基础](/docs/计算机科学基础/分布式系统/分布式系统基础)的容错通信、[大模型微调](/docs/人工智能/大模型与应用/模型微调)的本地训练、[安全对齐](/docs/人工智能/大模型与应用/AI安全对齐)的隐私约束共同定义了「可信分布式智能」的工程边界。
