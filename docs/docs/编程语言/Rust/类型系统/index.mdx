Rust 的类型系统把许多运行时错误提前到了编译期。本栏目讲枚举（可携带数据的 enum）、模式匹配、泛型与 Trait（接口）。心智模型：用类型把「合法的态」编码进去，非法的状态根本无法编译通过。
