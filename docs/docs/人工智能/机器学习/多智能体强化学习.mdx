# 多智能体强化学习

## 学习目标

- 理解单智能体 RL 在多智能体场景下为何失效（非平稳性、信用分配、维度爆炸）

- 掌握 CTDE（集中训练分散执行）范式与价值分解（VDN / QMIX / QTRAN）
- 认识 MAPPO、自博弈（self-play）与对手建模的基本思路

## 核心概念

### 1. 为什么单智能体 RL 在多智能体下失效

单智能体假设「环境是固定的马尔可夫过程」。一旦引入 $N$ 个智能体，每个 agent 的策略都在变，对某个 agent 而言**环境转移概率随时间漂移**——这破坏了 MDP 的平稳假设，带来三大难题：

- **非平稳性（non-stationarity）**：对手策略变化让同一状态的价值估计反复失效。
- **部分可观测与信用分配（credit assignment）**：在合作任务里，团队拿到一个共享奖励，但「是哪几个 agent 的哪个动作真正促成了它」很难归因。
- **维度与通信**：联合动作空间是各 agent 动作空间的笛卡尔积，$\lvert\mathcal{A}\rvert^N$ 随 $N$ 指数爆炸；agent 之间能否通信、通信是否消耗带宽也是设计变量。

多智能体问题的标准建模是 **Dec-POMDP**（分散部分可观测马尔可夫决策过程）：每个 agent $i$ 有局部观测 $o_i$、局部动作 $a_i$，通过联合策略 $\vec{\pi}=(\pi_1,\dots,\pi_N)$ 最大化团队回报 $\mathbb{E}\big[\sum_t \gamma^t r_t\big]$。

### 2. 三种博弈结构

| 结构 | 奖励关系 | 典型目标 | 代表方法 |
|---|---|---|---|
| 完全合作 | $r_1=\cdots=r_N$（共享） | 团队回报最大 | VDN / QMIX / MAPPO |
| 完全竞争 | 零和 $r_i=-r_j$ | 纳什均衡 | 最小最大、自博弈 |
| 混合（一般和） | 任意 | 纳什均衡 / 社会最优 | PSRO、博弈求解 |

### 3. CTDE：集中训练、分散执行

这是合作 MARL 的工程基石。**训练时**允许访问全局信息（其他 agent 的状态、动作、联合奖励），**执行时**每个 agent 只看自己的局部观测 $o_i$。它兼顾了训练稳定性与部署时的去中心化。

价值分解是 CTDE 下最成功的路线：假设存在**单调**的可加/非线性组合，使联合动作价值可由各 agent 局部价值反推：

$$
Q_{tot}(\mathbf{s},\mathbf{a}) = f_{\text{mix}}\big(Q_1(o_1,a_1),\dots,Q_N(o_N,a_N);\mathbf{s}\big),
\quad \frac{\partial Q_{tot}}{\partial Q_i}\ge 0
$$

- **VDN**：$Q_{tot}=\sum_i Q_i$（线性、最弱但最稳）。
- **QMIX**：用神经网络 $f_{\text{mix}}$ 做非线性但保持单调性（权重非负），能表达超加性（整体大于部分之和的协同）。
- **QTRAN**：放宽单调约束，逼近 IGM（Individual-Global-Max）条件，表达力更强但更难训。

### 4. MAPPO 与策略侧 CTDE

价值分解针对离散动作、值函数路线。若用策略梯度，则对应 **MAPPO**（多智能体 PPO）：每个 agent 一个 actor（只看局部观测），一个集中的 critic（看全局状态）估计优势。它比 QMIX 更易迁移到连续控制，是大模型多智能体编排之外的另一主流。

### 5. 竞争与自博弈

竞争场景下，训练就是在和一个会变强的对手对打。**自博弈（self-play）** 让 agent 与自己历史版本对战，最终收敛到纳什均衡（AlphaGo / AlphaStar 的核心）。但自博弈容易循环或遗忘，现代做法用 **PSRO**（策略空间回应预言）迭代地加入最佳回应，逼近纳什。

## 示例

下面用伪代码勾勒 QMIX 的训练循环骨架，突出「局部 Q + 集中 mixer + 单调约束」：

```python
import torch, torch.nn as nn

# 每个 agent 一个局部 Q 网络（输入局部观测+动作）
agent_q = AgentNet(obs_dim, act_dim)        # 输出 Q_i(o_i, ·)
# 集中 mixer：输入所有 Q_i 与全局状态，输出 Q_tot
mixer = MixNet(state_dim, n_agents)         # 内部权重非负以保证单调性

def train(batch):
    qs = [agent_q(o_i, a_i) for i in range(n)]        # 局部价值
    q_tot = mixer(qs, state)                          # 联合价值（单调组合）
    target = reward + gamma * mixer(target_qs, next_state)
    loss = ((q_tot - target) ** 2).mean()
    loss.backward(); opt.step()
    # 关键：mixer 中保证 ∂Q_tot/∂Q_i ≥ 0（非负权重/绝对值激活）
```

一个直觉例子：**合作导航**——$N$ 个 agent 要各自抵达不同目标点且不碰撞。共享团队奖励（到达数 $-$ 碰撞罚）。QMIX 能让 agent 学会「让路」「绕行」等协同，而独立 DQN（IQL）因无法归因常常卡在碰撞里。

## 易错点

- **把 IQL 当银弹**：独立学习看似简单，但因为非平稳性，训练曲线剧烈震荡、难以复现；合作任务优先上 CTDE。
- **单调性约束被悄悄破坏**：手写的 mixer 若用了无约束全连接，QMIX 的 IGM 保证就失效，出现「局部最优但联合次优」。
- **忽略对手建模**：竞争任务里把对手当环境噪声，容易被策略性对手利用；自博弈需配历史对手池防遗忘。
- **通信未进观测**：若 agent 本应通过通信获取信息却没把消息纳入 $o_i$，集中式 critic 也无法弥补执行时的信息缺口。

## 练习

1. 在 $2\times2$ 矩阵博弈（如匹配硬币）上，手推纯策略与混合策略纳什均衡，体会竞争与合作的差异。
2. 用 IQL 与 QMIX 各跑一个合作网格世界，对比信用分配效果（提示：记录团队奖励方差）。
3. 思考：把 QMIX 的 mixer 改成允许负权重，会对 IGM 条件产生什么后果？

## 小结

多智能体强化学习把「单决策者」升级为「多决策者共存」的世界。它用 CTDE 化解非平稳与部署约束，用价值分解（VDN/QMIX/QTRAN）解决合作信用分配，用 MAPPO 承接连续控制，用自博弈/PSRO 逼近竞争纳什。它是机器人编队、交通调度、游戏 AI 与大模型多智能体系统的共同底座。
