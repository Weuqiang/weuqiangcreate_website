# 随机过程

## 学习目标

- 区分离散/连续时间、离散/连续状态随机过程
- 掌握泊松过程（无记忆到达）与布朗运动（连续路径、鞅、二次变分）
- 理解鞅的「公平游戏」直觉与停时定理
- 了解随机微分方程（SDE）与伊藤积分，并联系扩散模型

## 核心概念

### 1. 随机过程是什么

随机过程是一族随指标变化的随机变量 $\{X_t : t\in T\}$。$T$ 是时间索引（离散如 $t=0,1,2,\dots$ 或连续如 $t\ge 0$），状态空间 $S$ 可离散可连续。马尔可夫链是「离散时间 + 离散状态」的特例；这里关注连续时间的推广。

### 2. 泊松过程（无记忆计数）

计数过程 $N(t)$ 表示到时刻 $t$ 为止发生的事件数。速率为 $\lambda$ 的齐次泊松过程满足：独立增量、$N(t+s)-N(t)\sim\text{Poisson}(\lambda s)$、无记忆。到达间隔是独立同分布的指数变量 $\text{Exp}(\lambda)$。它建模「随机到达」：请求、光子、突变、顾客。

### 3. 布朗运动（Wiener 过程）

$W(0)=0$，路径连续，独立增量 $W(t)-W(s)\sim\mathcal{N}(0,t-s)$。性质：

- $\mathbb{E}[W(t)]=0,\;\operatorname{Var}(W(t))=t$
- **二次变分** $\langle W\rangle_t=t$——这是它与光滑函数的根本区别（光滑函数二次变分趋于 0）
- 它是**鞅**：$\mathbb{E}[W(t)\mid\mathcal{F}_s]=W(s)$

布朗运动是连续时间随机路径的「原子」，也是随机游走的高速极限。

### 4. 鞅

过程 $M_t$ 满足 $\mathbb{E}[|M_t|]<\infty$ 且 $\mathbb{E}[M_t\mid\mathcal{F}_s]=M_s$。直觉是「公平游戏」：给定历史，未来条件期望等于现在。停时定理说：在正则条件下 $\mathbb{E}[M_\tau]=\mathbb{E}[M_0]$。鞅与马尔可夫是正交概念——布朗运动两者都是，但存在是鞅非马尔可夫（反之亦然）的过程。

### 5. 随机微分方程（SDE）与伊藤积分

$$
dX_t = \mu(X_t,t)\,dt + \sigma(X_t,t)\,dW_t
$$

伊藤积分对 $dW$ 积分而非 Riemann 积分——因为 $W$ 不可导、且二次变分非零。**伊藤引理**给出 $f(W_t)$ 的微分多出一个二阶项：

$$
df(W_t)=f'(W_t)dW_t+\frac12 f''(W_t)dt
$$

SDE 是扩散模型（随机采样）、随机优化（SDE 采样器）、金融定价的数学语言。

## 示例

模拟布朗运动路径并验证其二次变分近似等于 $t$；再生成泊松过程的到达序列：

```python
import numpy as np

# 布朗运动路径
np.random.seed(1)
T, n = 1.0, 10000
dt = T / n
dW = np.random.randn(n) * np.sqrt(dt)
W = np.cumsum(dW)
qv = np.sum(dW ** 2)            # 二次变分 ≈ T
print("末时刻 W:", round(W[-1], 4), " 二次变分≈T:", round(qv, 4))

# 泊松到达（指数间隔，速率 3）
arrivals = []
s = 0.0
while s < T:
    s += np.random.exponential(1 / 3.0)
    if s < T:
        arrivals.append(s)
print("泊松到达次数(速率3, T=1):", len(arrivals))
```

## 易错点

- **把布朗运动当可导**：$\frac{dW}{dt}$ 不存在，必须用伊藤微积分。
- **忽略二次变分**：普通链规则会漏掉 $\frac12\sigma^2 f''$ 项。
- **混淆鞅与马尔可夫**：鞅是「条件期望无漂移」，马尔可夫是「未来只依赖现在」，二者不等价。
- **误用泊松无记忆性**：只有到达间隔为指数分布时才无记忆；确定性或均匀间隔不成立。

## 练习

1. 用 $dW^2\approx dt$ 的缩放论证布朗运动的二次变分 $\langle W\rangle_t=t$。
2. 用伊藤引理求 $d(e^{W_t-t/2})$，并说明它为何是一个鞅。
3. 一个系统的到达用泊松过程、服务用指数分布，简述可用连续时间马尔可夫链（CTMC）还是 SDE 来近似其排队长度演化。

## 小结

随机过程把「随机变量」推广为随时间演化的族：泊松过程刻画无记忆计数，布朗运动是最基本的连续随机路径且本身是鞅，SDE（伊藤）描述带噪声的动力学。它们是队列论、金融数学、扩散模型与随机优化的基础语言。
