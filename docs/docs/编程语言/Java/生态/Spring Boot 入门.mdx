# Spring Boot 入门

Spring Boot 让 Java 后端开发"开箱即用"：自动配置、内嵌服务器、起步依赖，几行代码起一个 Web 服务。它是把前面学的语法、集合、并发落到真实工程的入口。

## 学习目标

- 用 Spring Boot 起一个返回 JSON 的最小 Web 服务；
- 理解起步依赖、自动配置与分层架构；
- 用常用注解与 `application.yml` 完成基础配置。

## 前置知识

- 已学完 [并发容器与锁](../../并发/并发容器与锁)（Controller/Service 常运行在线程池中）；
- 后端工程通识见 [软件工程与后端 / 后端通识](../../../../软件工程与后端/后端通识/)。

## 1. 一个最小应用

```java
@SpringBootApplication
@RestController
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
    @GetMapping("/hello")
    public String hello() { return "Hello, Spring!"; }
}
```

- `@SpringBootApplication`：开启自动配置与组件扫描。
- 内嵌 Tomcat，默认端口 8080，无需外部部署。

## 2. 依赖管理（Maven）

```xml
<parent>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-parent</artifactId>
  <version>3.3.0</version>
</parent>
<dependencies>
  <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
  </dependency>
</dependencies>
```

`spring-boot-starter-web` 一个依赖就拉齐了 Web 所需全部库。

## 3. 分层架构

```java
@RestController
@RequestMapping("/users")
public class UserController {
    private final UserService service;          // 构造注入
    public UserController(UserService service) { this.service = service; }

    @GetMapping("/{id}")
    public User get(@PathVariable Long id) { return service.findById(id); }
}
```

典型分层：`Controller`（接收请求）→ `Service`（业务逻辑）→ `Repository`（数据访问）。

## 4. 常用注解

| 注解 | 作用 |
|------|------|
| `@RestController` | 返回 JSON 的控制器 |
| `@Service` / `@Repository` | 标记业务/数据层组件 |
| `@Autowired` / 构造注入 | 依赖注入 |
| `@ConfigurationProperties` | 绑定 `application.yml` 配置 |

## 5. 配置与运行

```yaml
# application.yml
server:
  port: 9000
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/demo
```

运行：`mvn spring-boot:run` 或打包 `java -jar demo.jar`。

## 易错点

- 组件扫描默认只扫 `@SpringBootApplication` 所在包及其子包；把类放错包会 `@Autowired` 失败。
- 构造注入优于字段注入（`@Autowired` 字段），后者不利于测试与不可变。
- `application.yml` 用空格缩进，Tab 与缩进错误会导致配置不生效且无提示。
