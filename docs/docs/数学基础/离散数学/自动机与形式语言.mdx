# 自动机与形式语言

正则表达式为什么匹配不了嵌套括号？编译器为什么要分「词法分析」和「语法分析」两步？这些问题的答案都在自动机理论里——它精确刻画了**不同计算能力的机器分别能识别什么样的语言**。

## 学习目标

- 定义确定性有限自动机（DFA）的五元组，并画出状态转移图。
- 说明 DFA 与 NFA 表达能力等价，但状态数可能指数级差异。
- 判断一个语言是否正则，会用泵引理给出否定证明。
- 说清乔姆斯基层级四层的对应机器，理解正则与上下文无关的分界。

- 基本的字符串与状态直觉。

## 核心概念
**有限自动机 = 只有有限记忆的读带机器。** 它从左到右逐个字符读输入，每读一个就按规则跳到下一个状态，读完后看落在哪：接受状态就「认」，否则就「不认」。

关键限制在「有限」两个字：**机器只能记住自己在哪个状态，不能记数**。状态数是固定的，与输入长度无关。这一条限制决定了它能力的边界。

形式定义是五元组 $M=(Q,\Sigma,\delta,q_0,F)$：状态集、字母表、转移函数、初始状态、接受状态集。

- **DFA**：$\delta:Q\times\Sigma\to Q$，每个状态对每个字符有且仅有一条出边，运行完全确定。
- **NFA**：允许一个字符对应多条出边，还允许 $\varepsilon$ 空转移。它像是「同时沿所有可能路径探索，有一条能到达接受状态就算接受」。

一个也许反直觉的定理：**NFA 与 DFA 表达能力完全相同**。任何 NFA 都能通过**子集构造法**转成 DFA——让 DFA 的一个状态代表 NFA 的一个「状态集合」。代价是状态数最坏会从 $n$ 涨到 $2^n$。所以 NFA 的价值是**写起来简洁**，DFA 的价值是**跑起来快**（每字符 $O(1)$）。正则表达式引擎干的正是这套转换。

**正则语言**就是能被有限自动机识别的语言，它等价于正则表达式能描述的语言。它对并、交、补、连接、闭包运算都封闭。

**它的能力边界在哪？** 考虑 $L=\{a^nb^n\mid n\ge0\}$（$n$ 个 a 后跟同样多的 b）。要识别它，机器必须「记住读了多少个 a」，而 $n$ 可以任意大，有限状态记不下。这就是**泵引理**的直觉：

> 若 $L$ 正则，则存在常数 $p$，使任何长度 $\ge p$ 的串 $s$ 都能拆成 $s=xyz$，满足 $|y|>0$、$|xy|\le p$，且对**所有** $i\ge0$，$xy^iz\in L$。

为什么？因为读长度超过状态数的串时，**鸽巢原理**保证必有某个状态被重复访问，两次访问之间的那段（就是 $y$）形成了一个环，可以任意多绕几圈而机器无从察觉。要证明某语言**不**正则，只需构造一个串让「泵」之后跳出语言即可。

**乔姆斯基层级**给出了完整的能力谱系：

| 层级 | 语言类 | 对应机器 | 额外记忆 | 例子 |
|------|--------|----------|----------|------|
| 3 型 | 正则 | 有限自动机 | 无 | 标识符、数字字面量 |
| 2 型 | 上下文无关 | 下推自动机（栈） | 一个栈 | 嵌套括号、算术表达式 |
| 1 型 | 上下文有关 | 线性有界自动机 | 有限带 | $a^nb^nc^n$ |
| 0 型 | 递归可枚举 | 图灵机 | 无限带 | 一般程序 |

**加一个栈，就跨过了正则的天花板**——这就是编译器用正则做词法分析（切 token）、用上下文无关文法做语法分析（建语法树）的根本原因。

## 最小示例

```python
# ============ 1. DFA：识别「含偶数个 a」的串 ============
# 状态 0 = 已读偶数个 a（接受）；状态 1 = 已读奇数个 a
dfa_even_a = {
    "states": {0, 1},
    "start": 0,
    "accept": {0},
    "delta": {(0, 'a'): 1, (0, 'b'): 0,
              (1, 'a'): 0, (1, 'b'): 1},
}

def run_dfa(m, s):
    q = m["start"]
    for ch in s:
        if (q, ch) not in m["delta"]:
            return False                  # 无定义转移 -> 拒绝
        q = m["delta"][(q, ch)]           # 唯一确定的下一状态
    return q in m["accept"]

for s in ["", "a", "aa", "aba", "abab", "bbb", "aabab"]:
    print(f"{s!r:8} -> {run_dfa(dfa_even_a, s)}  (a 的个数={s.count('a')})")
# ''   True | 'a'   False | 'aa'  True  | 'aba' True
# 'abab' True | 'bbb' True | 'aabab' False        ✔ 与 a 的奇偶性完全一致

# ============ 2. DFA：识别二进制数能被 3 整除 ============
# 状态 = 当前余数。读入 bit b：新余数 = (2*余数 + b) % 3
dfa_div3 = {
    "start": 0,
    "accept": {0},
    "delta": {(r, str(b)): (2 * r + b) % 3 for r in range(3) for b in (0, 1)},
}
for s in ["0", "11", "110", "1001", "1010"]:
    ok = run_dfa(dfa_div3, s)
    print(f"{s} (十进制 {int(s,2):>2}) 能被3整除: {ok}  实际: {int(s,2)%3==0}")
# 全部吻合 ✔ —— 有限状态足以做模运算，因为余数只有 3 种

# ============ 3. 正则做不到的事：括号匹配需要栈 ============
def match_paren(s):
    """下推自动机的最简实现：栈的深度可以无限增长"""
    depth = 0
    for ch in s:
        if ch == '(':
            depth += 1
        elif ch == ')':
            depth -= 1
            if depth < 0:
                return False              # 右括号过早出现
    return depth == 0

for s in ["()", "(())", "(()", "())(", "((()))"]:
    print(f"{s!r:9} -> {match_paren(s)}")
# 注意 depth 是无界计数器；有限自动机无法实现，因此括号语言不是正则的

# ============ 4. 泵引理的直观演示：a^n b^n 不是正则语言 ============
# 反证：设 L 正则，泵长度为 p，取 s = a^p b^p
# 因 |xy| <= p，y 只能全由 a 组成且 |y| > 0
# 那么 xy²z 的 a 比 b 多 -> 不在 L 中 -> 矛盾
p = 4
s = "a" * p + "b" * p
x, y, z = "a" * 1, "a" * 2, "a" * (p - 3) + "b" * p     # 一种合法拆分
pumped = x + y * 2 + z
print(f"\n原串   {s}  (a={s.count('a')}, b={s.count('b')})")
print(f"泵后串 {pumped}  (a={pumped.count('a')}, b={pumped.count('b')}) -> 已不属于 L ✔")
```

## 易错点

- **以为 NFA 比 DFA 更强大**。两者识别的语言类完全相同，差别只在状态数与描述简洁度，不在能力。
- **拿正则表达式解析嵌套结构**。用正则匹配 HTML 标签、嵌套括号、JSON 是经典误用——这些语言不是正则的，必须用带栈的解析器。
- **混淆编程语言的「正则表达式」与理论上的正则语言**。PCRE 支持反向引用、前瞻断言，其表达能力已**超出**正则语言，代价是最坏情况指数级回溯（ReDoS 漏洞的成因）。
- **用泵引理证明某语言「是」正则的**。泵引理只是必要条件，满足它不代表正则；它只能用于**反证不正则**。
- **DFA 遗漏转移**。DFA 要求转移函数是全函数，实践中常需补一个「死状态」吸收所有非法输入，否则实现会崩。
- **把「有限状态」理解成「状态很少」**。状态数可以很大（如上百万），关键在于它是**常数**、不随输入长度增长。

## 练习

1. 画出识别「以 01 结尾的二进制串」的 DFA。
   *提示：三个状态——「刚读到 0」「刚读到 01（接受）」「其他」，共 3 个状态即可。*
2. 证明 $\{ww\mid w\in\{a,b\}^*\}$ 不是正则语言。
   *提示：取 $s=a^pba^pb$，由 $|xy|\le p$ 知 $y$ 全为 a，泵后前后两半的 a 个数不再相等，故不在语言中。*
3. 为什么编译器要把词法分析和语法分析分开？
   *答案：词法（标识符、数字、关键字）是正则的，用 DFA 扫描效率最高（每字符 $O(1)$）；语法（嵌套表达式、代码块）是上下文无关的，必须用带栈的下推自动机。分层可让每层用最合适、最高效的工具。*

## 小结

有限自动机是只有有限记忆的读带机器，它识别的语言恰为正则语言，与正则表达式等价。NFA 通过子集构造可转为 DFA，两者能力相同但状态数可能相差指数级。有限状态无法完成无界计数，因此 $a^nb^n$ 这类语言不正则，泵引理正是把这一直觉形式化为可用的反证工具。给机器加一个栈就得到下推自动机，能力跃升到上下文无关语言，可处理嵌套结构；再往上是线性有界自动机与图灵机。这套层级直接解释了编译器为何要分词法与语法两个阶段。
