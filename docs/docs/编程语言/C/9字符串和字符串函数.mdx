## 核心概念

C 没有真正的字符串类型，字符串就是「以空字符 `\0` 结尾的 `char` 数组」。这个约定决定了所有字符串函数都靠扫描 `\0` 判定边界——一旦越界或忘了结尾符，就会读穿内存。

本章主线：
- 字符串的本质：以 `\0` 结尾的字符数组
- 字符串字面量 vs 字符数组
- `string.h` 常用函数
- 缓冲区溢出与安全函数

## 字符串的本质

C 语言**没有字符串类型**。字符串就是**以空字符 `\0` 结尾的 `char` 数组**。结尾的 `\0`（值为 0）告诉函数“字符串到此为止”，否则 `strlen`、`printf("%s")` 会一直往后读，直到碰巧遇到 0，造成严重越界。

```c
char s1[] = "abc";        // 编译器自动补 '\0' → 实际存了 4 个字节：a b c \0
char s2[4] = {'a','b','c','\0'};   // 等价写法，必须自己放 '\0'
char s3[3] = {'a','b','c'};        // 错误：缺少 '\0'，不是合法字符串
```

:::caution
字符串字面量（如 `"abc"`）是**只读**的，存放在常量区。不要写 `char *p = "abc"; p[0] = 'x';` —— 行为未定义（通常段错误）。
:::

## 表示字符串和字符串 I/O

### 输出

- `puts(str)`：输出到换行，自动补 `\n`。
- `printf("%s", str)`：不补换行，可用 `%5s`、`%-10s` 控制宽度。

### 输入（重点：别用 gets）

- `gets(str)`：**已废弃**！不检查缓冲区大小，极易缓冲区溢出，永远别用。
- `fgets(str, n, stdin)`：最多读 `n-1` 个字符，会**把换行符 `\n` 也读进来**，并在末尾补 `\0`。安全首选。
- `scanf("%s", str)`：遇空白停止，不读空格；同样不防溢出（除非 `scanf("%9s", str)`，限制宽度 = 数组大小 - 1）。

```c
char name[20];
fgets(name, sizeof(name), stdin);     // 输入 "Tom\n" → name = "Tom\n\0"
name[strcspn(name, "\n")] = '\0';     // 手动去掉换行符，常用技巧
printf("Hello, %s\n", name);
```

## 字符串函数（string.h）

| 函数 | 作用 | 注意 |
|------|------|------|
| `strlen(s)` | 返回字符数（**不含** `\0`） | 不是数组长度 |
| `strcpy(dest, src)` | 把 src 拷到 dest | dest 必须够大，且不重叠 |
| `strncpy(dest, src, n)` | 最多拷 n 个 | **可能不会补 `\0`**，要小心 |
| `strcat(dest, src)` | 把 src 拼到 dest 末尾 | dest 剩余空间要够 |
| `strncat(dest, src, n)` | 最多拼 n 个 | 较安全，会补 `\0` |
| `strcmp(a, b)` | 比较字典序 | 返回负数 / 0 / 正数，不是布尔值 0/1 |
| `strchr(s, c)` | 找字符 c 首次出现 | 返回指针或 NULL |
| `strstr(hay, needle)` | 找子串 | 返回指针或 NULL |

```c
#include <string.h>
#include <stdio.h>

int main(void) {
    char a[20] = "Hello";
    char b[] = "World";
    strcat(a, " ");
    strcat(a, b);                 // a = "Hello World"
    printf("%zu\n", strlen(a));   // 11
    printf("%d\n", strcmp("apple", "apply"));  // 负数（'e' < 'y'）
    printf("%s\n", strstr(a, "World"));         // "World"
    return 0;
}
```

:::info
`strlen` 返回 `size_t`（无符号）。用 `%zu` 打印；别写 `strlen(a) - strlen(b) < 0` 这类无符号相减的坑。
:::

## 手搓核心函数（理解原理）

```c
#include <stddef.h>

// 自己实现 strlen
size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p) p++;
    return (size_t)(p - s);
}

// 自己实现 strcpy（返回 dest，方便链式）
char *my_strcpy(char *dest, const char *src) {
    char *p = dest;
    while ((*p++ = *src++) != '\0')  // 拷贝包括结尾的 '\0'
        ;
    return dest;
}
```

## 字符串排序

字符串数组本质是**指针数组** `char *arr[]`，排序时交换的是指针（不搬动字符串本身）：

```c
#include <string.h>
#include <stdio.h>

int main(void) {
    char *fruits[] = {"banana", "apple", "cherry"};
    int n = 3;
    // 简单冒泡，按字典序
    for (int i = 0; i < n - 1; i++)
        for (int j = i + 1; j < n; j++)
            if (strcmp(fruits[i], fruits[j]) > 0) {
                char *t = fruits[i]; fruits[i] = fruits[j]; fruits[j] = t;
            }
    for (int i = 0; i < n; i++) printf("%s\n", fruits[i]);
    return 0;
}
```

## ctype.h 字符函数

处理单个字符的分类 / 转换，受当前 locale 影响：

- `isalpha(c)` / `isdigit(c)` / `isalnum(c)` / `isspace(c)`：判断类别。
- `tolower(c)` / `toupper(c)`：大小写转换。

```c
#include <ctype.h>
char c = 'A';
if (isalpha(c)) putchar(tolower(c));   // 输出 a
```

## 命令行参数

`main` 的两个参数就是字符串：

```c
int main(int argc, char *argv[]) {
    // argc = 参数个数（程序名算第 0 个）
    // argv[0] = 程序名, argv[1..] = 用户输入的参数
    for (int i = 0; i < argc; i++)
        printf("argv[%d] = %s\n", i, argv[i]);
    return 0;
}
```

## 把字符串转换为数字

- `atoi("123")` / `atof("3.14")`：简单但不报错（非法输入返回 0）。
- `strtol` / `strtod`：更强，能报告“停在哪”、检测溢出，正式程序首选。
- `sscanf`：从字符串按格式解析。

```c
#include <stdlib.h>
#include <stdio.h>

int main(void) {
    char *s = "1024";
    int x = atoi(s);                       // 1024
    char *end;
    long y = strtol(s, &end, 10);          // 10 进制；end 指向 '\0'
    printf("%d %ld\n", x, y);
    return 0;
}
```

## 常见误区

- **忘记留 `\0` 的空间**：`char buf[3]; strcpy(buf, "abc");` 会溢出（需要 4 字节）。
- **`strcmp` 当布尔用**：`if (strcmp(a,b))` 表示“不相等”，`if (!strcmp(a,b))` 才是相等。
- **`fgets` 留了 `\n`**：比较或输出前记得处理换行符。
- **`strncpy` 不一定补 `\0`**：目标不够长时不会加结尾，后续当字符串用会越界；用完手动 `dest[n-1]='\0'` 更稳。
- **用 `gets`**：任何情况下都别用。

## 小结

本章揭示 C 字符串的真相：它只是带结尾符的字符数组。由此带来了 `strcpy` 这类「不检查边界」的危险函数，以及 `strncpy` 等带长度限制的救场方案。处理字符串永远要警惕缓冲区。

## 示例

下面这段程序演示带容量限制的安全拼接、`strstr` 定位子串后用指针相减求下标、`strcmp` 的三态返回值，以及 `fgets` 配 `strcspn` 去掉行尾换行的标准输入套路。

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

/* 就地转大写：注意先转成 unsigned char 再传给 toupper */
void to_upper(char *s) {
    for (; *s != '\0'; s++)
        *s = (char)toupper((unsigned char)*s);
}

/* 安全拼接：始终保证 dst 以 '\0' 结尾，绝不越界 */
void safe_append(char *dst, size_t cap, const char *src) {
    size_t used = strlen(dst);
    if (used + 1 >= cap) return;          /* 已经没有可写空间 */
    strncat(dst, src, cap - used - 1);
}

int main(void) {
    char line[32] = "hello";

    safe_append(line, sizeof(line), ", world");
    printf("[%s] len=%zu\n", line, strlen(line));   /* [hello, world] len=12 */

    to_upper(line);
    printf("[%s]\n", line);                         /* [HELLO, WORLD] */

    char *pos = strstr(line, "WORLD");
    if (pos != NULL)
        printf("found at index %td\n", pos - line); /* found at index 7 */

    /* strcmp 返回负数/0/正数，不是布尔值 */
    printf("cmp = %d\n", strcmp("apple", "apply") < 0 ? -1 : 1);

    char buf[16];
    if (fgets(buf, sizeof(buf), stdin) != NULL) {
        buf[strcspn(buf, "\n")] = '\0';   /* 去掉 fgets 带回来的换行符 */
        printf("you typed [%s]\n", buf);
    }
    return 0;
}
```

## 易错点

- 把 `sizeof` 当成字符串长度：`char s[64] = "hi";` 中 `sizeof(s)` 是 64（数组容量），`strlen(s)` 才是 2；而 `s` 一旦作为参数传进函数退化成 `char *`，`sizeof` 又变成指针大小 4 或 8。
- 修改字符串字面量：`char *p = "abc"; p[0] = 'A';` 是未定义行为（字面量在只读段），要能修改就必须写成 `char p[] = "abc";`。
- 把 `strcmp` 当布尔用：相等时它返回 0，所以 `if (strcmp(a, b))` 判断的其实是「不相等」，写反后整个逻辑颠倒。
- `strncpy` 在截断时不补结尾符：源串长度大于等于 n 时目标没有 `\0`，后续按字符串使用会一路读到越界；稳妥做法是复制后手动补 `dst[n-1] = '\0';`。
- `strcat` 只管从目标已有内容之后接着写，不检查容量：目标数组必须预留「原有长度 + 追加长度 + 1」的空间，否则溢出会破坏栈上相邻变量。
- 直接把 `char` 传给 `toupper` / `isalpha`：`char` 是否带符号由实现决定，遇到非 ASCII 字节会传入负值触发未定义行为，应先转成 `unsigned char`。
