# 嵌入式开发：学习路线图

嵌入式是把「软件」装进「带芯片的硬件」里，让它真实世界交互。本分类覆盖从「什么是嵌入式」到「能独立做一块板子」的完整链路：**系统概览 → 单片机(MCU) → RTOS 与固件 → 硬件与电路 → 通信协议**。

## 推荐学习顺序

```text
嵌入式系统概览 → 单片机MCU(Arduino→STM32) → 硬件与电路基础 → 通信协议 → RTOS与固件
   （建立全景）      （先跑起来）            （懂电路才不翻车）  （让设备能对话）  （跑多任务）
```

- 先读**嵌入式系统概览**，建立「芯片 / 外设 / 固件 / 上位机」的全景。
- 用 **Arduino** 快速跑通「写代码 → 烧录 → 灯亮」，建立手感；再上 **STM32 + HAL 库** 进入工业级。
- 同步补**硬件与电路基础**，否则调板子时看不懂原理图。
- **通信协议** 是设备互联的通用语（UART/SPI/I2C/CAN/无线）。
- 最后用 **RTOS** 管理多任务、用固件调试工具排错。

## 学习建议

嵌入式**最忌只看不焊**。每篇都尽量配「最小可运行例程 + 实物现象」，建议边读边在开发板上复现；遇到玄学 bug，优先回到「电源 → 时钟 → 复位 → 引脚复用」四件套排查。
