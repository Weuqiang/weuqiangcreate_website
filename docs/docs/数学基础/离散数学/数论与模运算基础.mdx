# 数论与模运算基础

## 学习目标

- 用「钟表算术」理解同余 $a\equiv b\pmod m$ 与模加减乘
- 掌握模逆的存在条件（与模互素）与扩展欧几里得求逆
- 用费马小定理 / 欧拉定理快速算大指数取模（如 $2^{100}\bmod 7$）
- 看懂 RSA 公钥体制为什么「加密容易、破解难」

## 核心概念

### 1. 同余：钟表算术

$a\equiv b\pmod m$ 表示 $m\mid(a-b)$，即 $a,b$ 除以 $m$ 余数相同。模运算下加减乘都可「先模后算」：

$$
(a+b)\bmod m = \big((a\bmod m)+(b\bmod m)\big)\bmod m
$$

且 $(a\cdot b)\bmod m = ((a\bmod m)(b\bmod m))\bmod m$。**但除法不能直接模**——要用模逆。

### 2. 模逆与扩展欧几里得

模逆 $a^{-1}\bmod m$ 是满足 $a\cdot a^{-1}\equiv 1\pmod m$ 的数。它**存在当且仅当 $\gcd(a,m)=1$**（互素）。用扩展欧几里得算法同时求 $\gcd$ 与系数 $x,y$ 使 $ax+my=\gcd(a,m)$；当 $\gcd=1$ 时 $x\bmod m$ 即为逆。

### 3. 费马小定理与欧拉定理

- **费马小定理**：若 $p$ 为素数且 $\gcd(a,p)=1$，则 $a^{p-1}\equiv 1\pmod p$。
- **欧拉定理**（$p$ 推广到合数）：若 $\gcd(a,m)=1$，则 $a^{\varphi(m)}\equiv 1\pmod m$，其中 $\varphi(m)$ 是欧拉函数（小于 $m$ 且与 $m$ 互素的个数）。

推论：求大指数取模可先对指数取模 $\varphi(m)$：
$a^k\bmod m = a^{k\bmod\varphi(m)}\bmod m$（在 $\gcd(a,m)=1$ 时）。

### 4. RSA 的「难」从哪来

RSA 选两大素数 $p,q$，令 $n=pq$，$\varphi(n)=(p-1)(q-1)$，选 $e$ 使 $\gcd(e,\varphi(n))=1$，再求 $d=e^{-1}\bmod\varphi(n)$。公钥 $(e,n)$ 加密 $c=m^e\bmod n$，私钥 $d$ 解密 $m=c^d\bmod n$（由欧拉定理保证可逆）。**破解需要由 $n$ 分解出 $p,q$**——大数分解在经典计算机上无高效算法，这是其安全性来源。

## 示例

扩展欧几里得求模逆 + 用费马小定理算大指数：

```python
def egcd(a, b):
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = egcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)

def modinv(a, m):
    g, x, _ = egcd(a, m)
    if g != 1:
        raise ValueError("逆不存在")
    return x % m

# 1) 求 17 在模 3120 下的逆（模拟 RSA 里 d = e^{-1} mod φ(n)）
print("17^{-1} mod 3120 =", modinv(17, 3120))

# 2) 费马小定理：2^100 mod 7。因 7 是素数，2^6 ≡ 1 (mod 7)
#    100 = 6*16 + 4 => 2^100 ≡ 2^4 = 16 ≡ 2 (mod 7)
def pow_mod(a, k, m):
    res = 1
    a %= m
    while k:
        if k & 1:
            res = (res * a) % m
        a = (a * a) % m
        k >>= 1
    return res

print("2^100 mod 7 =", pow_mod(2, 100, 7), "（应等于 2）")
```

`pow_mod` 用「快速幂」把 $O(k)$ 次乘法降到 $O(\log k)$，否则 $2^{100}$ 直接算会溢出——密码学里指数动辄上千位，快速幂是必需品。

## 易错点

- **在模运算里直接做除法**：没有逆就除不了；要先确认互素并求出模逆。
- **费马/欧拉定理要求 $\gcd(a,m)=1$**：若 $a,m$ 不互素，不能直接用 $a^{\varphi(m)}\equiv1$。例如 $2$ 与 $4$ 不互素，$2^{\varphi(4)}=2^2=4\not\equiv1\pmod4$。
- **模逆不存在却硬算**：$\gcd\neq1$ 时 `modinv` 必须报错，否则得到的是错值。
- **把 RSA 安全等同于「大素数难找」**：素数很好找（素性测试快）；难的是**大合数分解**，别混淆。

## 练习

1. 用扩展欧几里得求 $31^{-1}\bmod 60$，并验证。
2. 不用大数计算，用费马小定理求 $3^{201}\bmod 11$。
3. 简述为什么 RSA 中知道 $n$ 和 $e$ 却很难得到 $d$（除非能分解 $n$）。

## 小结

同余把算术搬上「钟表」；模逆在互素时存在、由扩展欧几里得求得；费马/欧拉定理把大指数取模化简为对小指数运算，是 RSA 与各类密码协议的数学引擎。理解这几样，就握住了哈希、签名、密钥交换背后的数论钥匙。
