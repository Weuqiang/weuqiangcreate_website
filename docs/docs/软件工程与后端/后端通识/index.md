# 后端通识：学习路线图

「后端」不是某门编程语言的专利，而是一组**与语言无关的服务端通用能力**。无论你用 Python、Java 还是 Go，下面这些主题都会出现：怎么把服务跑起来（Web 服务器）、怎么设计对外接口（API）、怎么验证接口正确（测试）、数据存哪里（数据库）、怎么从数据里挖价值（分析）、怎么用代码操控浏览器（自动化）。

## 推荐学习顺序

```text
接口开发（先懂 API 是什么）
   → 数据库（数据怎么存）
   → Nginx（服务怎么暴露到公网）
   → 接口测试（怎么证明它是对的）
   → 数据分析 / 网页自动化（按项目需要的进阶玩法）
```

- **接口开发** 先学：理解请求 / 响应、REST 风格、FastAPI / Django 等框架，是后端一切的入口。
- **数据库** 并行学：关系模型与 SQL 是持久化的底座。
- **Nginx** 再学：把本地服务变成可达的生产服务，理解反向代理与静态托管。
- **接口测试 / 数据分析 / 网页自动化** 按业务需要补。

## 学习建议

后端学习的秘诀是**先跑通一个最小服务，再逐步加层**：先用 FastAPI 起一个能返回 JSON 的接口，再接数据库，再套 Nginx，最后写测试。每一层都不要停留在"看懂"，要亲手动手改配置、造数据、故意触发错误看日志。
