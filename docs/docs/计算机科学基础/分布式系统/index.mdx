# 分布式系统

单机不够用时，我们把计算分散到多台机器。但「多机协作」引入了单机不存在的麻烦：**部分机器会随时失败、网络会丢包延迟、时钟不会完全同步**。分布式系统研究如何在这些不可靠之上，构建出「看起来可靠」的服务。
