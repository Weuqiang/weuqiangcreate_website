# 正交投影与最小二乘

现实中的数据几乎从不严丝合缝地落在一条直线上。方程组 $A\vec x=\vec b$ 常常**无解**——但我们仍想要一个「最接近」的答案。最小二乘给出的正是这个答案，而它的几何本质就是**正交投影**。

## 学习目标

- 用内积计算一个向量在另一向量／子空间上的正交投影。
- 从「残差最短」出发推导正规方程 $A^TA\hat{x}=A^T\vec b$。
- 解释投影矩阵 $P$ 的两条性质：幂等与对称，并说明其含义。
- 用 numpy 对照正规方程、`lstsq`、`pinv` 三种解法，理解各自的稳定性差异。

## 核心直觉

太阳当头照，一根斜插在地上的棍子会在地面留下影子。**影子就是棍子在地面这个子空间上的正交投影**，而棍子与影子之间的差（那段竖直线段）就是**残差**。为什么影子是地面上离棍尖最近的点？因为任何其他点连到棍尖的线段都是斜边，而斜边永远比直角边长。

这就是最小二乘的全部几何内容：

- $A$ 的列空间 $\mathrm{Col}(A)$ 是「地面」，它包含了 $A\vec x$ 能取到的所有向量；
- $\vec b$ 是「棍尖」，通常不在地面上（所以方程无解）；
- 最优解 $\hat x$ 满足 $A\hat x=\mathrm{proj}_{\mathrm{Col}(A)}\vec b$，即影子；
- 残差 $\vec r=\vec b-A\hat x$ **垂直于整个列空间**。

把「垂直于列空间」写成公式，就直接得到正规方程：

$$
A^{T}(\vec b-A\hat x)=\vec 0\quad\Longrightarrow\quad A^{T}A\,\hat x=A^{T}\vec b
$$

若 $A$ 列满秩，$A^TA$ 可逆，于是

$$
\hat x=(A^{T}A)^{-1}A^{T}\vec b,\qquad
P=A(A^{T}A)^{-1}A^{T}
$$

$P$ 就是**投影矩阵**，满足两条一眼可验的性质：

- **幂等** $P^2=P$：影子再投一次还是它自己；
- **对称** $P^{T}=P$：正交投影特有的性质（斜投影不满足）。

最简单的一维情形值得记牢：向量 $\vec b$ 在方向 $\vec a$ 上的投影是

$$
\mathrm{proj}_{\vec a}\vec b=\frac{\vec a\cdot\vec b}{\vec a\cdot\vec a}\,\vec a
$$

分子是「重合程度」，分母是「归一化」。多维情形只是把它矩阵化。

## 最小示例

给三个点 $(1,2),(2,2.5),(3,4)$ 拟合直线 $y=kx+c$。设计矩阵

$$
A=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix},\quad
\vec b=\begin{bmatrix}2\\2.5\\4\end{bmatrix},\quad
\hat x=\begin{bmatrix}c\\k\end{bmatrix}
$$

手算：$A^TA=\begin{bmatrix}3&6\\6&14\end{bmatrix}$，$A^T\vec b=\begin{bmatrix}8.5\\19\end{bmatrix}$。由 $3c+6k=8.5$、$6c+14k=19$ 解得 $k=1$，$c=5/6\approx0.833$。

```python
import numpy as np
np.set_printoptions(precision=4, suppress=True)

A = np.array([[1., 1.],
              [1., 2.],
              [1., 3.]])
b = np.array([2., 2.5, 4.])

# 解法 1：正规方程（教学清晰，数值最差）
x1 = np.linalg.solve(A.T @ A, A.T @ b)

# 解法 2：lstsq（内部走 SVD，工程首选）
x2, *_ = np.linalg.lstsq(A, b, rcond=None)

# 解法 3：伪逆
x3 = np.linalg.pinv(A) @ b

print(x1, x2, x3)          # 三者一致 ≈ [0.8333 1.    ]  即 c=5/6, k=1

# ---- 验证残差与列空间正交 ----
r = b - A @ x1
print(A.T @ r)             # ≈ [0. 0.]  ✔ 残差垂直于每一列

# ---- 验证投影矩阵的幂等与对称 ----
P = A @ np.linalg.inv(A.T @ A) @ A.T
print(np.allclose(P @ P, P))     # True  幂等 ✔
print(np.allclose(P.T, P))       # True  对称 ✔
print(np.allclose(P @ b, A @ x1))# True  Pb 就是影子 ✔
```

## 易错点

- **误以为「无解」就是算错了**。超定方程组无解是常态，最小二乘求的是最优近似，不是精确解。
- **直接对 $A^TA$ 求逆**。$A^TA$ 的条件数是 $A$ 的**平方**，病态问题会被急剧放大。生产代码用 `lstsq` 或 QR 分解，别手写正规方程。
- **列相关时 $A^TA$ 奇异**。特征高度共线（比如同时放入「身高厘米」和「身高米」）会让解不唯一，`pinv` 会返回范数最小的那个解。
- **忘记加截距列**。设计矩阵不含全 1 列时，拟合的直线被强制过原点，结果会明显偏差。
- **最小二乘对离群点极其敏感**，因为误差被平方了。异常点多时应考虑 Huber 损失等稳健方法。

## 练习

1. 求 $\vec b=(3,4)$ 在 $\vec a=(1,0)$ 上的正交投影与残差。
   *答案：投影 $(3,0)$，残差 $(0,4)$，两者内积为 0 ✔。*
2. 用正规方程为点 $(0,1),(1,3),(2,5)$ 拟合直线，并说明为什么残差恰好为零。
   *提示：三点严格共线于 $y=2x+1$，$\vec b$ 本就在列空间内，投影即自身。*
3. 证明投影矩阵 $P=A(A^TA)^{-1}A^T$ 满足 $P^2=P$。
   *提示：展开 $P^2$，中间的 $A^TA$ 与 $(A^TA)^{-1}$ 相消。*

## 小结

正交投影是「在子空间里找离目标最近的点」，其判据是残差垂直于该子空间。把这一条件写成 $A^T\vec r=\vec 0$ 就得到正规方程，其解即最小二乘解，对应的投影矩阵幂等且对称。线性回归本质上就是把观测向量投影到特征张成的列空间上。虽然正规方程推导清晰，但它会把条件数平方，实际计算应优先使用基于 QR 或 SVD 的 `lstsq`／`pinv`。
