# 计算机科学概览

计算机科学不只是"写程序"，而是研究**计算本身**的学科。理解它的主干，能让你在学具体技术时不迷路。

## 1. 五大支柱

```
计算机科学
├─ 计算机组成原理   如何用电信号算数、存数据
├─ 操作系统         如何管理 CPU / 内存 / 设备
├─ 计算机网络       机器之间如何通信
├─ 编译原理         高级语言如何变成机器码
└─ 数据结构与算法   如何高效组织与处理数据
```

## 2. 组成原理（一句话）

程序最终都是 0/1。CPU 通过**取指—译码—执行**循环运行指令，内存按地址存取。理解"抽象层"是关键：电路 → 微指令 → 汇编 → 高级语言。

## 3. 操作系统（一句话）

OS 是硬件与应用的"中间商"：用**进程/线程**抽象 CPU，用**虚拟内存**抽象 RAM，用**文件系统**抽象磁盘。

## 4. 计算机网络（一句话）

数据被切成包，按 TCP/IP 分层从应用到网卡逐层封装，对面再逐层拆开。记住"分层"与"可靠传输"两个核心。

## 5. 编译原理（一句话）

源代码 → 词法分析 → 语法分析 → 语义分析 → 中间代码 → 优化 → 目标代码。现代 JIT 还会在运行时编译。

## 6. 为什么程序员要懂这些

- 写出**更快**的代码（懂缓存、懂系统调用开销）
- 定位**诡异 bug**（并发、内存、字节序）
- 做**技术选型**时有底层依据
