# 熵率与微分熵

入门篇 [信息论基础](/docs/数学基础/概率与统计/信息论基础) 的熵只针对**单个离散随机变量**。但真实世界里数据是序列（文本、时间序列、视频帧），也是连续的（传感器读数、高斯噪声）。本章把熵推广到这两种情形：**熵率**描述随机过程的「每秒不确定性」，**微分熵**描述连续分布的不确定性，并引出 Fisher 信息这一统计推断的核心量。

## 学习目标

- 计算随机过程（尤其平稳马尔可夫链）的熵率。
- 理解微分熵与离散熵的关键差异：可正可负、尺度敏感、无「码长」解释。
- 用联合/条件微分熵定义连续互信息，并解释它在机器学习中的角色。
- 掌握 Fisher 信息的定义，以及它与克拉美-罗下界（估计精度的极限）的关系。

## 前置知识

- 已掌握 [信息论基础](/docs/数学基础/概率与统计/信息论基础) 的离散熵、KL 散度与互信息。
- 了解 [马尔可夫链](/docs/数学基础/概率与统计/马尔可夫链) 的平稳分布。
- 连续情形需要 [概率与随机变量](/docs/数学基础/概率与统计/概率基础与随机变量) 中的概率密度函数概念。

## 核心概念

### 熵率：随机过程的「长期平均不确定性」

对随机过程 $X_1,X_2,\dots$，熵率定义为每符号平均不确定性的极限：

$$
H(\mathcal X)=\lim_{n\to\infty}\frac{1}{n}H(X_1,X_2,\dots,X_n)
$$

- 若序列 **i.i.d.**，则 $H(\mathcal X)=H(X)$，退化为单变量熵。
- 若序列**平稳**，由于熵随长度次可加，极限存在，且可写成 $H(\mathcal X)=\lim_{n\to\infty}H(X_n\mid X_1^{n-1})$。
- 对**平稳马尔可夫链**（转移矩阵 $P$、平稳分布 $\pi$），给定过去只需看上一步：

$$
H(\mathcal X)=\sum_i \pi_i\,H(P_{i\cdot})=-\sum_{i,j}\pi_i P_{ij}\log P_{ij}
$$

这正是「状态 $i$ 出现的概率 × 从 $i$ 出发的下一步熵」的加权平均。若链完全确定性（每状态只到一个后继），熵率为 0；若每步都像公平硬币，熵率为 1 比特/步。

### 微分熵：连续变量的熵

连续随机变量 $X\sim f(x)$ 的微分熵：

$$
h(X)=-\int f(x)\log f(x)\,dx
$$

它与离散熵**形似但本质不同**，务必注意三点差异：

1. **可正可负**：离散熵恒非负，但微分熵可负。例如均匀分布于 $[0,a]$ 时 $h(X)=\log a$；当 $a<1$（区间长度小于 1）时即为负——因为「在小于单位长度上定位」所需的连续精度本就超过一个比特。
2. **尺度敏感**：$h(aX)=h(X)+\log|a|$。离散熵没有这个性质（重排不变），而连续熵随坐标伸缩变化——这正说明它**不是**纯粹「信息量」，而依赖度量。
3. **无「码长下界」解释**：香农源编码定理只对离散成立；连续必带失真（见 [率失真](/docs/数学基础/信息论/率失真与信息瓶颈)）。

**最大微分熵**（给定约束下最「不确定」的分布）：
- 方差固定为 $\sigma^2$ 时，高斯分布最大：$h(X)\le \frac12\log(2\pi e\sigma^2)$。
- 支撑在 $[a,b]$ 时，均匀分布最大：$h(X)\le \log(b-a)$。

### 连续互信息与 KL 散度

把离散公式里的求和换成积分即可推广：

$$
I(X;Y)=h(X)+h(Y)-h(X,Y)=D_{KL}\big(p(x,y)\parallel p(x)p(y)\big)
$$

注意 $I(X;Y)\ge 0$ 仍成立（非负性来自 KL 散度），且连续互信息**有**「减少不确定性」的解释。在深度学习中，互信息常用于衡量表示 $Z$ 保留了输入 $X$ 多少关于任务 $Y$ 的信息（信息瓶颈，见下一篇）。

### Fisher 信息：参数能多「准」地被估计

对含参数 $\theta$ 的分布族 $p(x;\theta)$，Fisher 信息

$$
\mathcal I(\theta)=\mathbb E\!\left[\left(\frac{\partial}{\partial\theta}\log p(X;\theta)\right)^2\right]
=-\mathbb E\!\left[\frac{\partial^2}{\partial\theta^2}\log p(X;\theta)\right]
$$

它衡量「对数似然对 $\theta$ 有多敏感」，即样本携带着多少关于 $\theta$ 的信息。由**克拉美-罗下界**：任何无偏估计 $\hat\theta$ 都满足

$$
\operatorname{Var}(\hat\theta)\ge \frac{1}{\mathcal I(\theta)}
$$

也就是说，Fisher 信息越大，参数能被估计得越精确——它是统计推断的「理论精度天花板」。

## 最小示例

```python
import numpy as np

# ---- 1. 马尔可夫链的熵率 ----
P = np.array([[0.9, 0.1],          # 状态0: 90% 留, 10% 跳
              [0.5, 0.5]])          # 状态1: 各 50%
# 平稳分布 π 满足 πP = π, π0+π1=1
# π0*0.9+π1*0.5 = π0 -> 0.1π0 = 0.5π1 -> π0=5π1 -> π=(5/6,1/6)
pi = np.array([5/6, 1/6])
H_rate = -np.sum(pi[:,None] * P * np.log2(P + 1e-12))   # 用 2 为底
print(f"马尔可夫链熵率 = {H_rate:.4f} 比特/步")         # ≈ 0.6095

# ---- 2. 微分熵：高斯 vs 均匀 ----
def h_gaussian(sigma):    # 自然对数，单位 nat
    return 0.5 * np.log(2*np.pi*np.e*sigma**2)
def h_uniform(a, b):
    return np.log(b - a)
print(f"N(0,1) 微分熵 = {h_gaussian(1):.4f} nat")        # ≈ 1.4189
print(f"U(0,0.5) 微分熵 = {h_uniform(0,0.5):.4f} nat")  # ≈ -0.6931 (为负！)

# ---- 3. 尺度敏感：h(2X) = h(X) + log 2 ----
print(f"h(2X) - h(X) = {h_gaussian(2)-h_gaussian(1):.6f}  (应 = log 2)")

# ---- 4. Fisher 信息：N(μ,1) 对 μ ----
# 对 N(μ,σ²=1)，I(μ) = 1/σ² = 1；CRLB: Var(μ_hat) ≥ 1
I_mu = 1.0
print(f"N(μ,1) 的 Fisher 信息 I(μ) = {I_mu:.2f}，CRLB 方差下界 = {1/I_mu:.2f}")
# 样本均值 x̄ 的方差 = 1/n，n≥1 时满足下界（n=1 时取等）
```

## 易错点

- **把微分熵当成「信息量」并与离散熵直接比较**。微分熵可负、随尺度变化，没有「平均码长」含义；要比较连续分布的不确定性，应使用相对熵或考虑微分熵差。
- **忽略分布族的支撑集就谈「最大熵」**。最大微分熵高度依赖约束（方差固定 → 高斯；支撑固定 → 均匀），约束不同结论完全不同。
- **混淆熵率与逐符号熵**。`H(X)`（单符号）通常远大于熵率（长程相关性被「摊薄」后每符号的平均），时间序列建模里务必用熵率。
- **Fisher 信息用错公式**：二阶形式带负号 $-\mathbb E[\partial^2 \ell/\partial\theta^2]$，一阶形式带平方期望；两者等价但数值实现时后者对噪声更敏感。
- **以为 $I(X;Y)=0$ 一定独立**。连续情形仍成立（由 KL 非负），但若用样本估计互信息，小样本会估出伪相关，需做显著性检验。

## 练习

1. 一个两状态马尔可夫链转移矩阵为 $[[0.7,0.3],[0.3,0.7]]$，求其平稳分布与熵率。
   *提示：对称链平稳分布为 $(0.5,0.5)$，熵率 $=H_2(0.3)\approx0.881$ 比特/步。*
2. 证明 $h(aX)=h(X)+\log|a|$，并说明为什么这意味微分熵不是坐标不变的。
3. 对 $X\sim \text{Uniform}[0,\theta]$，写出 $\theta$ 的 Fisher 信息，并指出用样本最大值估计 $\theta$ 时为何不能套用「无偏 + CRLB」的常规结论。
   *提示：最大值是「有偏且有界」的估计，CRLB 针对无偏估计，且支撑依赖 $\theta$ 时常规 CRLB 推导需小心。*

## 小结

熵率把离散熵推广到随机过程，平稳马尔可夫链的熵率等于「平稳分布加权平均的逐步转移熵」；微分熵把熵推广到连续变量，但失去非负性与码长解释，且对坐标尺度敏感。连续互信息仍由 KL 散度定义并保留非负性，是表示学习的常用度量；Fisher 信息刻画参数可估计精度，经克拉美-罗下界给出任何无偏估计的方差天花板。三者共同构成通往 [率失真](/docs/数学基础/信息论/率失真与信息瓶颈) 与 [信道容量](/docs/数学基础/信息论/信道容量与香农定理) 的工具基础。
