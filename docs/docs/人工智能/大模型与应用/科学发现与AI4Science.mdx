## 核心概念

### 为什么科学是 AI 的「硬骨头」

相比互联网文本，科学数据有三大不同：

1. **极度稀缺且昂贵**：一个蛋白质实验、一次材料合成要数周与高额成本，远不够喂饱黑盒大模型。
2. **强约束的物理规律**：生成的结果必须满足能量最低、电荷守恒、对称性等，不能随意「 hallucinate」。
3. **可证伪要求高**：科学结论要可重复、可解释，而端到端神经网络常是「黑箱」。

因此科学 AI 往往走「**物理先验 + 数据驱动**」的混合路线，而不是纯数据拟合。

### 角色一：结构预测（从序列到三维）

最著名的突破是 **AlphaFold2/3**：输入氨基酸序列，直接预测蛋白质三维结构与分子间相互作用（蛋白质-配体、蛋白质-核酸）。它把结构生物学从「数年实验」压缩到「数秒计算」，是 AI 改变基础科学的标志性事件。

后续 **AlphaFold3** 进一步统一了多种生物分子复合物预测，把「结合构象」也纳入同一框架。

### 角色二：生成式设计（从需求到分子）

预测是「理解已有」，设计是「创造新物」：

- **RFdiffusion / ProteinMPNN**：用扩散模型「画」出满足功能约束的新蛋白质骨架，再设计氨基酸序列，已实现酶、结合蛋白的全新设计。
- **GNoME（Graph Networks for Materials Exploration）**：用图神经网络在已知材料空间外预测稳定晶体结构，一次性发现数十万种候选新材料。

这类方法把「材料/分子发现」从试错式实验变成「在生成空间中搜索 + 少量实验验证」。

### 角色三：加速仿真与替代模型（surrogate）

许多科学问题本质是求解偏微分方程（流体、气候、量子多体）。神经求解器/替代模型用神经网络逼近昂贵的数值仿真：

- **神经算子（如 Fourier Neural Operator）**：学习从输入场到输出场的映射，推理比传统求解器快几个数量级。
- **分子动力学加速**：用学习到的势能面替代第一性原理计算，在保持精度的前提下提速。
- **气候/湍流降阶模型**：在粗网格上校正误差。

### 角色四：科学推理（LLM 进实验室）

大模型本身也能参与科学工作流：读文献、提假设、写仿真代码、解读实验结果。但它**不是真理来源**——需要把它的输出接到可验证的实验/仿真闭环里（见 [AI 安全对齐](/docs/人工智能/大模型与应用/AI安全对齐) 关于「幻觉」的风险）。

## 示例

用伪代码勾勒「生成-筛选-验证」的材料发现闭环：

```python
# 1. 生成候选结构（图生成模型）
candidates = graph_generator.sample(n=10000, constraints={"formula": "ABO3"})

# 2. 替代模型快速筛选稳定性（GNoME 式能量预测）
energies = surrogate_energy_model.predict(candidates)
stable = [c for c, e in zip(candidates, energies) if e < threshold]

# 3. 仅对少量稳定候选做昂贵的第一性原理验证
verified = [dft_relax(c) for c in stable[:50]]   # 真实仿真，数量可控

# 4. 把验证结果回灌，迭代生成器
graph_generator.finetune(on=verified)
```

要点：**用便宜的模型筛掉 99%，只把真正有希望的送进昂贵实验**——这是 AI4Science 性价比的核心。

## 易错点

- **把预测当真理**：AlphaFold 对「无序区」和结构新颖区的置信度低，盲目信任会出错；要看 pLDDT 等置信指标。
- **忽视物理约束**：纯扩散生成的分子可能化学上不成立（价键错误、能量爆炸），必须加有效性校验（validity check）。
- **数据泄露**：用训练集里的分子做「发现」并声称新颖，是常见评审被毙原因；要严查重叠。
- **可解释性缺口**：黑箱预测难以被科学家采信，需配套注意力/归因或物理可解释的旁路。

## 小结

AI4Science 是 2024–2026 增长最快的 AI 落地方向之一，覆盖**结构预测（AlphaFold）、生成设计（RFdiffusion/GNoME）、加速仿真（神经算子）、科学推理（LLM）** 四条主线。它的方法论与 [大模型应用](/docs/人工智能/大模型与应用/) 一脉相承，但更强调**物理先验、数据稀缺下的泛化与可证伪性**。它也是 [合成数据](/docs/人工智能/大模型与应用/合成数据与数据工程) 思路在科学域的延伸——用仿真生成训练样本。
