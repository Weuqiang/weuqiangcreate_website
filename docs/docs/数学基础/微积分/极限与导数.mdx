# 极限与导数

微积分研究「变化」：导数描述瞬时变化率，积分描述累积量。本篇先建立极限与导数的直观，下一篇再讲积分。

- 解释导数的几何意义（切线斜率）与物理意义（瞬时速度）。
- 写出常见导数公式，并理解链式法则的角色。
- 说清为什么梯度下降要用导数（沿最陡下降方向走）。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 能接受「无限逼近但不到达」的想法——可参考 [Python 画图](/docs/编程语言/Python/0基础语法) 把函数画出来观察趋势。
- 知道斜率是直线的倾斜程度。

## 核心概念

极限回答「当输入越来越接近某点时，输出趋近于什么」；导数则是把这个问题钉在「两个点无限靠近」的瞬间，得到曲线在该点的瞬时变化率（切线斜率）。它是整个微积分的引擎：有了导数，就能判断函数上升还是下降、最快在哪、极值在哪。导数不为零的方向就是变化最剧烈的方向，这正是机器学习里梯度下降的依据。

本章主线：
- 先用逼近的直觉理解极限
- 再把极限推到「两点无限近」得到导数
- 最后看导数如何驱动优化与建模

## 1. 极限：逼近的思想

极限描述「当 $x$ 无限接近 $a$ 时，$f(x)$ 趋向的值」。这句话里有两个容易被忽略的要点：

- **「趋向」不等于「等于」**。$x$ 可以无限靠近 $a$ 却不必取到 $a$；函数在 $a$ 处甚至可以没有定义（如 $\frac{\sin x}{x}$ 在 $0$ 处无定义），极限照样存在。极限关心的是**趋势**，不是那个点本身。
- **必须左右一致**。只有从左侧与从右侧逼近得到同一个值，极限才存在。左右不一致的典型是符号函数 $\operatorname{sgn}(x)$ 在 $0$ 处：左极限 $-1$、右极限 $+1$，所以 $\lim_{x\to 0}\operatorname{sgn}(x)$ 不存在。

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1
$$

直观理解：当 $x$ 越来越小，$\sin x$ 与 $x$ 几乎相等。

**ε-δ 直觉**（把「无限逼近」说精确）：无论你给定多小的误差带 $\varepsilon>0$，总能找到一个邻域半径 $\delta>0$，使得只要 $0<|x-a|<\delta$，就有 $|f(x)-L|<\varepsilon$。也就是说，把 $x$ 限制得足够靠近 $a$，$f(x)$ 就被死死压在 $L$ 的 $\varepsilon$ 范围内——这正是「任意逼近」的严格说法。

## 2. 导数：变化率

导数 $f'(x)$ 是函数在某点的瞬时斜率，定义为差商的极限：

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}
$$

**可导比连续更强**：可导必然连续，但连续不一定可导——$|x|$ 在 $0$ 处连续，却因左右斜率不一致（左 $-1$、右 $+1$）而不可导。判定一点可导，等价于要求「左导数」与「右导数」存在且相等；任一不存在或不等，导数就不存在（尖点、折点即此类）。

常见导数：

| 函数 | 导数 |
|------|------|
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sin x$ | $\cos x$ |

## 3. 为什么重要：梯度下降

机器学习的核心优化算法**梯度下降**，就是对损失函数 $L(\theta)$ 求梯度 $\nabla L$，沿反方向更新参数：

$$
\theta \leftarrow \theta - \eta \nabla L(\theta)
$$

其中 $\eta$ 是学习率。导数告诉我们「往哪走能让损失下降最快」。

```python
import numpy as np
# 最小化 f(x) = x^2，解析梯度为 2x
x = 5.0
lr = 0.1
for _ in range(50):
    x = x - lr * 2 * x
print(x)   # 趋近于 0
```

## 4. 链式法则

复合函数 $(f \circ g)(x)$ 的导数：

$$
\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)
$$

反向传播（神经网络训练）正是链式法则的层层套用。

## 示例

**用定义求导**：求 $f(x)=x^3$ 在 $x=2$ 处的导数，按定义展开差商：

$$
f'(2)=\lim_{h\to 0}\frac{(2+h)^3-8}{h}
=\lim_{h\to 0}\frac{8+12h+6h^2+h^3-8}{h}
=\lim_{h\to 0}(12+6h+h^2)=12
$$

与幂法则 $(x^3)'=3x^2$ 在 $x=2$ 得 $12$ 一致。**链式法则**：$\frac{d}{dx}\sin(x^2)=\cos(x^2)\cdot 2x$。

**数值导数**（用差商逼近，验证解析结果）：

```python
def f(x): return x**3
def num_deriv(f, x, h=1e-6):
    return (f(x+h) - f(x-h)) / (2*h)
print(num_deriv(f, 2))   # ≈ 12.0000000002
```

## 小结

极限是「无限逼近」，导数是「无限逼近下的瞬时变化率」，二者把「变化」这件事量化。它不仅是物理与几何的语言，更是 [梯度与方向导数](/docs/数学基础/微积分/梯度与方向导数) 与 [泰勒展开](/docs/数学基础/微积分/泰勒展开) 的基石，也是现代 [机器学习优化](/docs/人工智能/大模型与应用/检索增强) 的数学底座。

## 易错点

- 导数存在要求函数在该点**连续且左右导数相等**；尖点（如 $|x|$ 在 0 处）不可导。
- 链式法则别漏层：$\frac{d}{dx}f(g(x))=f'(g(x))\cdot g'(x)$，常有人忘记乘 $g'(x)$。
- 「导数大」不代表「函数值大」，导数只描述局部变化快慢。
