# Java 语言入门

Java 是一门**面向对象、跨平台**的语言：源码编译成字节码（`.class`），由各平台的 JVM 解释或 JIT 执行，因此"一次编写，到处运行"。

## 学习目标

- 跑通第一个 Java 程序，理解"源码 → 字节码 → JVM 执行"；
- 说清 JVM 跨平台、自动内存管理、强类型面向对象三大特性；
- 写出类、继承、多态的最小示例。

## 前置知识

- 了解 [C 语言基础](../../../C/) 有助于对比"指针 vs 引用""手动内存 vs GC"；
- 已学过 [Go](../../../Go/) 的话，可对照两者"如何管理内存与并发"。

## 核心概念

Java 是静态强类型、面向对象语言，源代码编译为字节码后在 JVM 上运行，因此“一次编写、到处运行”。类型分两类：基本类型（`int`/`double`/`boolean` 等，存值）与引用类型（对象/数组，存引用）。一切代码都写在类里，`public static void main(String[] args)` 是程序入口。

本章主线：
- JVM 与跨平台：字节码 vs 机器码
- 基本类型与引用类型
- 变量、运算符与数组
- 类与 main 入口

## 1. Hello World

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

编译运行：

```bash
javac Main.java   # 生成 Main.class 字节码
java Main         # JVM 执行字节码
```

> 类名必须与文件名一致（`Main.java` 里只能是 `public class Main`），这是很多新手第一次报错的原因。

## 2. 核心特性

- **JVM 跨平台**：源码编译成字节码，由各平台 JVM 解释/JIT 执行，屏蔽操作系统差异。
- **自动内存管理**：垃圾回收（GC）自动回收不再使用的对象，开发者不用手动 `free`。
- **强类型 + 面向对象**：变量必须声明类型；一切皆类（除基本类型外），单继承 + 接口多实现。

## 3. 面向对象三要素

```java
class Animal {
    void speak() { System.out.println("..."); }
}
class Dog extends Animal {        // 继承
    @Override
    void speak() { System.out.println("Woof"); }  // 多态
}
```

- **封装**：用 `private` 隐藏内部细节，通过 `getter/setter` 暴露受控访问。
- **继承**：`extends` 复用父类能力，构造器不会被子类继承（需用 `super()` 调用）。
- **多态**：父类引用指向子类对象，运行时调用实际类型的方法（动态绑定）。

## 4. 并发与生态

- 并发：`Thread`、`Runnable`、线程池 `ExecutorService`、`synchronized` 与 `java.util.concurrent`。
- 生态：Spring（Web/企业级）、Maven/Gradle（构建）、JUnit（测试）。

## 小结

Java 靠 JVM 实现跨平台，类型静态强类型；代码都在类中，`main` 是入口。理解“值类型 vs 引用类型”是后续学对象、GC 的基石。

## 易错点

- 比较字符串/包装类型用 `equals`，不要用 `==`（`==` 比的是引用而非值）。
- `main` 方法签名必须固定为 `public static void main(String[] args)`，少一个修饰符都跑不起来。
- 数组长度是 `arr.length`（属性），而 `String` 长度是 `s.length()`（方法），别混。
