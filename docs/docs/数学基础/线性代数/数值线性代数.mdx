# 数值线性代数

## 核心概念

### 1. 为什么需要数值线性代数

直接法（高斯消元/LU、QR、SVD）对小到中等规模在浮点误差内「精确」，但代价是 $O(n^3)$ 且需要稠密存储。一旦矩阵来自 PDE 离散、图、或深层网络的 Hessian 近似，规模可达百万维且**高度稀疏**——此时存储整个矩阵或做 $O(n^3)$ 分解都不现实。迭代法从一个初始猜测出发「逐步逼近」，只需反复做矩阵-向量乘（对稀疏阵极廉价），更适合这类问题。

### 2. 条件数：问题本身有多「脆」

解 $Ax=b$，若 $A$ 或 $b$ 有微小扰动，解的相对误差放大约 $\kappa(A)\cdot\varepsilon_{\text{machine}}$。谱条件数

$$
\kappa_2(A)=\|A\|_2\|A^{-1}\|_2=\frac{\sigma_{\max}}{\sigma_{\min}}
$$

（$A$ 奇异时 $\kappa=\infty$）。$\kappa$ 大 ⇒ 病态：答案对输入极度敏感，**再好的算法也救不回**。典型例子是 Hilbert 矩阵 $H_{ij}=1/(i+j-1)$，$\kappa$ 随 $n$ 指数增长。

### 3. Krylov 子空间：低维里找最优解

从初值 $x_0$ 与残差 $r_0=b-Ax_0$ 出发，构造 Krylov 子空间

$$
\mathcal{K}_m(A,r_0)=\operatorname{span}\{r_0,Ar_0,\dots,A^{m-1}r_0\}
$$

迭代法在越来越大（但始终低维）的 $\mathcal{K}_m$ 中搜索近似解，**从不显式分解或存储 $A$**，只依赖矩阵-向量乘 $Av$。这是它能扩展到超大规模的关键。

### 4. 共轭梯度法（CG）

针对**对称正定（SPD）**系统。CG 沿互相 $A$-正交（共轭）的方向下降，$m$ 步内在 $\mathcal{K}_m$ 中达到精确解（理想算术下）。收敛速率约

$$
\|e_k\|\lesssim 2\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k
$$

即约 $O(\sqrt{\kappa})$ 步，远快于朴素 $O(\kappa)$。适合大规模稀疏 SPD（最小二乘法方程、图 Laplacian）。

### 5. GMRES 与一般系统

对非对称系统，GMRES 在 $\mathcal{K}_m$ 中**最小化残差范数** $\|b-Ax_m\|$。它需要保存一组正交基，内存随 $m$ 增长，实践中常用「重启版」（restarted GMRES）控制开销。对称不定则用 MINRES。

### 6. 稳定性的典型陷阱

- **先求逆再乘**：`inv(A) @ b` 误差大、慢，应直接解 $Ax=b$；
- **近奇异矩阵**：$\kappa$ 爆炸，任何方法都难；
- **裸迭代不收敛**：高 $\kappa$ 下 CG/GMRES 极慢，必须上**预条件（preconditioner）**；
- **忽略问题尺度**：残差阈值应结合 $b$ 的量级，而非固定绝对小值。

## 示例

用 scipy 构造病态 Hilbert 矩阵，比较直接解法与 CG 的误差表现，并展示条件数随维度飙升：

```python
import numpy as np
from scipy.sparse.linalg import cg

def hilbert(n):
    i = np.arange(1, n + 1)
    return 1.0 / (i[:, None] + i[None, :] - 1)

for n in [4, 8, 12]:
    A = hilbert(n)
    x_true = np.ones(n)
    b = A @ x_true
    kappa = np.linalg.cond(A)
    x_direct = np.linalg.solve(A, b)          # 直接法
    x_cg, info = cg(A, b, rtol=1e-12)         # CG（A 对称正定）
    print(f"n={n:2d} κ={kappa:.2e} "
          f"直接法误差={np.linalg.norm(x_direct - x_true):.2e} "
          f"CG误差={np.linalg.norm(x_cg - x_true):.2e} info={info}")
```

观察 $\kappa$ 随 $n$ 指数增长，直接法误差迅速恶化；CG 对 SPD 有效，但同样受 $\kappa$ 限制——此时需要预条件（如不完全 Cholesky）才能真正收敛。

## 易错点

- **对非对称系统用 CG**：CG 仅保证 SPD 收敛，非对称须用 GMRES / MINRES 等。
- **用 `np.linalg.inv(A) @ b` 代替 `solve`**：数值更差、更慢，且无必要。
- **忽略预条件**：裸迭代在病态时可能根本不收敛到所需精度。
- **把迭代法当「不精确就放大容差」**：应监控相对残差 $\|r\|/\|b\|$，并结合问题物理尺度设阈值。

## 练习

1. 简述为何 SPD 系统下 CG 能在 $n$ 步内（理想算术）达到精确解，而一般系统需要 GMRES。
2. 三对角矩阵（如 1D 离散 Laplacian）用 LU 与用 CG 的复杂度各是多少？为何稀疏迭代更优？
3. 若预条件子 $P\approx A$ 满足 $\kappa(P^{-1}A)\ll\kappa(A)$，说明这会如何改善 CG 收敛，并讨论构造 $P$ 的代价。

## 小结

数值线性代数研究「如何在有限精度与大规模下解线性代数问题」：条件数量化问题的病态程度，Krylov 子空间方法（CG/GMRES）以反复矩阵-向量乘换取存储与计算的可扩展性，预条件是决定实际收敛速度的关键。它是科学计算、图算法与深度学习二阶优化的数学底座。
