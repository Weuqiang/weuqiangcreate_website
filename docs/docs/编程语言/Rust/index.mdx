# Rust

Rust 是一门**内存安全、无垃圾回收、高性能**的系统级语言，能在编译期消除数据竞争与悬垂指针，被 Stack Overflow 多年评为"最受欢迎语言"。

## 学习目标
学完本栏目你将能够：
- 用**所有权 / 借用 / 生命周期**解释 Rust 为何无需 GC 也能保证内存安全；
- 用 `enum` + 模式匹配 + `Result`/`Option` 写出显式、无异常的错误处理；
- 用泛型与 Trait 实现零成本抽象与代码复用；
- 用线程 / `async` 编写"无畏并发"（fearless concurrency）程序。

## 前置知识
- 建议先有任意一门编程语言的经验（变量、函数、循环）；
- 想对照学习的同学可看 [Go 语言入门](../Go/语言基础/Go语言入门) 或 [C 语言入门](../C/0基础语法)。

## 本栏目结构（知识地图）
- **所有权**：所有权、借用与生命周期——Rust 不用 GC 也能保证内存安全的核心机制。
- **类型系统**：枚举（enum）、模式匹配、`Result`/`Option` 与 Trait。
- **系统编程**：错误处理、`async`/线程并发与底层系统实践。

## 推荐学习路线
1. **所有权、借用、生命周期**是最难也最关键的一步，务必吃透；
2. 再学类型系统：`enum` + 模式匹配 + `Result` 构成 Rust 的错误处理范式；
3. 最后进入并发与系统编程，体会"无畏并发"。
