# Go

Go（Golang）由 Google 设计，以**简洁语法、原生并发、极快编译**著称，是云原生与后端服务的首选语言之一（Docker、Kubernetes 皆用 Go 编写）。

## 本栏目结构

- **语言基础**：包、变量、函数、结构体、接口、切片（slice）与映射（map）。
- **并发模型**：轻量协程 `goroutine`、通信 `channel`、`select` 与 `sync` 原语。
- **工程实践**：模块（`go mod`）、测试、HTTP 服务与项目结构。

## 推荐学习路线

1. 用一两天过完语法基础，重点掌握切片与映射；
2. 并发是 Go 的灵魂——理解"通过通信共享内存"；
3. 用标准库 `net/http` 写一个真实服务，体会"单二进制部署"的爽感。
