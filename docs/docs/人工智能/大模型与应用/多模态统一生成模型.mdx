## 核心概念

### 为什么要「统一」

早期多模态系统是**分而治之**的：用 CLIP 做图文检索、用 Stable Diffusion 做文生图、用 Whisper 做语音识别。每个任务一个专家模型，接口、词表、训练流程都不互通。

「统一生成模型」的目标是**一个模型、一套参数，完成任意模态到任意模态的生成**（any-to-any）：文本 → 图、图 → 文、文本+图 → 图、文本 → 音频……这种范式带来三点收益：

1. **知识共享**：模态间互补的信号在同一表征空间里互相强化。
2. **组合泛化**：能处理训练时未见过的「模态组合」输入。
3. **简化部署**：一个权重服务替代一堆微服务。

> 关键区分：**多模态理解**（判断、检索、描述）与**多模态生成**（produce 像素/波形）是两件事。统一模型要同时拿下二者，难度显著更高。

### 范式一：把一切 token 化（自回归统一）

代表：Chameleon、Emu、Janus、Show-o（部分）。核心思路是**为每种模态设计离散 tokenizer**：

- 图像用视觉 tokenizer（如 VQ-GAN、ViT-VQGAN）编码成图像 token 序列；
- 音频用神经音频 codec（如 EnCodec）编码成音频 token；
- 文本本就是 token。

之后所有模态拼成一个**统一 token 序列**，由一个 Transformer 自回归预测下一个 token（`next-token prediction`）。生成图像就是「生成一串图像 token，再解码回像素」。

```
[文本token] [图像token] [图像token] ... → Transformer → [下一token（文或图）]
```

这种范式的优势是架构极简、天然支持交错生成；代价是**图像 token 数量巨大**（一张图可能上千 token），自回归逐 token 生成慢，且离散量化会损失高频细节。

### 范式二：扩散 + 自回归混合（Transfusion）

代表：Transfusion、Show-o、EMU-3 路线变体。思路是**在同一个 Transformer 里混合两种损失**：

- 文本 token 走标准的自回归交叉熵损失；
- 图像「块（patch）」走扩散的噪声回归损失（预测加到 patch 上的噪声）。

模型在统一架构下同时学会「按顺序生成语言」和「去噪生成图像」。相比纯离散 token 化，它避免了图像过度量化、生成质量更高，且不必为图像单独维护一套 VQ 词表。

### 模态表征鸿沟与冲突

统一训练最棘手的不是工程，而是**模态间的竞争**：

- **表征尺度不一致**：文本的语义密度远高于图像 patch，模型容易「偏重」某一模态。
- **交错生成中的模态切换**：何时该输出文字、何时该输出图像 token，需要明确的控制符（special token）与对齐监督。
- **数据稀缺**：成对的「文本+图像+音频」高质量交错数据远少于单模态数据。

实践中常用「两阶段」缓解：先分别预训练各模态编码器/解码器，再联合微调统一头部，避免从零硬训。

## 示例

下面用伪代码勾勒「统一 token 序列」的拼接与训练目标，帮助建立直觉：

```python
# 假设 image_tokenizer 把图编码成 ids，text_tokenizer 处理文字
# 一条多模态样本 = 文本片段与图像片段交错
sample = [
    ("text",  "请描述这张图并画一张猫坐在窗边"),
    ("image", cat_photo),          # 真实图像
    ("text",  "这是一只猫，下面是同风格的再创作："),
    ("image", generated_cat),      # 待生成图像（训练时为真值）
]

# 编码为统一序列
seq = []
for modality, payload in sample:
    if modality == "text":
        seq += text_tok(payload)            # 文本 token
    else:
        seq += [IMG_START] + img_tok(payload) + [IMG_END]  # 图像 token 块

# 训练：文本位置用 CE，图像位置用扩散噪声回归
loss = ar_loss(seq_text_positions) + diffusion_loss(seq_image_positions)
```

注意：推理时图像段是**未知**的，模型要逐步自回归生成 `IMG_START` 后的图像 token，再用图像解码器还原成图——这正是「统一」的体现。

## 易错点

- **把「统一」等同于「一个 CLIP」**：CLIP 只能对齐/检索，不能生成像素，不属于统一生成模型。
- **忽视 tokenizer 质量**：图像/音频离散化的码本越大越保真，但越大越难训练，需在码本大小与重建质量间权衡。
- **交错数据不足导致模态塌缩**：若训练数据以纯文本为主，图像生成能力会被「挤掉」，需要刻意配比与课程式训练。
- **混淆范式**：自回归统一生成慢但支持任意交错；扩散混合质量高但实现复杂，选型要看延迟与质量优先级。

## 练习

## 小结

统一多模态生成是 2024–2026 年的活跃前沿：它试图用一套参数打通任意模态的生成，主流走「token 化一切」或「扩散+自回归混合」两条路线。真正的难点不在网络结构，而在**模态表征鸿沟、交错控制与数据稀缺**。它补齐了 [多模态应用](/docs/人工智能/大模型与应用/多模态应用) 只做理解、[多模态世界模型](/docs/人工智能/深度学习/多模态世界模型) 只做预测之外的「生成」拼图。
