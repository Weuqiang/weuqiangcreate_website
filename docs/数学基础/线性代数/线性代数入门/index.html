线性代数入门

线性代数是人工智能、计算机图形学、数据科学的数学基石。它研究向量、矩阵以及它们之间的线性变换。

1. 向量（Vector）​

向量是一组有序数的集合，可理解为空间中的一个点（或带方向的箭头）。

v⃗=[123]\vec{v} = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}v=​123​​

在编程中，向量通常表示为一维数组：

import numpy as np
v = np.array([1, 2, 3])
print(v + v)        # [2 4 6]  向量加法
print(v * 2)        # [2 4 6]  数乘
print(np.dot(v, v)) # 14       点积（内积）

2. 矩阵（Matrix）​

矩阵是二维的数表，代表一个线性变换。

A=[1234]A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}A=[13​24​] 
A = np.array([[1, 2], [3, 4]])
x = np.array([1, 1])
print(A @ x)        # [3 7]   矩阵乘向量
print(A.T)          # 转置
print(np.linalg.inv(A))  # 逆矩阵

3. 为什么重要​

  • 机器学习：模型参数、特征、梯度的本质都是向量/矩阵，训练即大量矩阵运算。
  • 降维：PCA 通过特征值分解把高维数据压缩到低维。
  • 图形学：3D 变换（旋转、缩放、平移）用矩阵表示。
