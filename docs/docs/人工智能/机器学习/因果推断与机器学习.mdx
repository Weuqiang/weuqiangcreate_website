# 因果推断与机器学习

## 核心概念

### 1. 相关不等于因果

$P(y\mid x)$ 的关联可能由混杂 $Z$ 同时影响 $X,Y$ 造成。辛普森悖论：分组与汇总趋势相反。预测模型用关联即可，但**干预 / 决策**必须因果。

### 2. 因果图与 do-算子

有向无环图（DAG）编码变量间因果。$do(X=x)$ 表示「干预」把 $X$ 强制设为 $x$（切断其原有父节点），不同于条件 $P(Y\mid X=x)$。do-演算在有向图下可识别某些因果效应。

### 3. 后门与前门

- **后门准则**：若变量集 $Z$ 阻断 $X\to Y$ 的所有后门路径（不含指向 $X$ 的因果路径），则调整 $Z$ 可识别因果效应：

$$
P(Y\mid do(X))=\sum_z P(Y\mid X,Z=z)\,P(Z=z)
$$

- **前门准则**：当存在未观测混杂无法直接后门调整时，若 $X\to M\to Y$ 且 $M$ 阻断，可经中介 $M$ 识别。

### 4. 工具变量与因果发现

工具变量 $Z$ 只经 $X$ 影响 $Y$，用于估计受混杂污染的处理效应。因果发现：从观测数据恢复 DAG（PC、NOTEARS 等），与 ML 结合做分布外泛化（不变预测）。

## 示例

后门调整的数值示意：在混杂 $Z$ 下计算「$do(X)$ 的效果」：

```python
import numpy as np
np.random.seed(0)
z = np.random.binomial(1, 0.5, 1000)
x = (z + np.random.randn(1000)) > 0.5
y = 2 * x + 3 * z + np.random.randn(1000)        # 真实因果效应 X→Y = 2
naive = np.cov(x, y)[0, 1] / np.std(x) ** 2       # 朴素相关（被 z 混淆，偏高）
adj = np.mean([np.cov(x[z == zi], y[z == zi])[0, 1] / np.std(x[z == zi]) ** 2
               for zi in [0, 1]])                  # 后门调整
print("朴素相关估计:", round(float(naive), 3),
      " 后门调整后:", round(float(adj), 3), " (真值 2)")
```

## 易错点

- **把「控制变量」当成万能**：控制中介或碰撞节点会引入偏差（对撞偏差）。
- **用关联模型做干预预测**（如「提价会增销量」因历史相关）。
- **忽略工具变量的排他性假设**。
- **把因果发现结果当真 DAG**：观测数据常只识别到等价类。

因果推断把「关联」推进到「干预与反事实」：因果图与 do-算子形式化因果，后门 / 前门准则给出可识别条件，工具变量处理未观测混杂。它与机器学习的结合（不变预测、因果发现、反事实公平性）正成为分布外泛化与可信 AI 的关键。
