# 常微分方程初步

物理定律、人口模型、电路方程、学习率衰减——它们描述的往往不是「量本身是多少」，而是「量变化得多快」。**常微分方程（ODE）就是从变化率反推函数的工具**，也是微积分最具实用价值的出口。

## 学习目标

- 识别 ODE 的阶数，并区分通解与特解。
- 用分离变量法求解 $y'=ky$ 一类方程，写出指数增长／衰减模型。
- 用积分因子法求解一阶线性方程 $y'+p(x)y=q(x)$。
- 用欧拉法数值求解 ODE，并与解析解对比理解步长与误差的关系。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [极限与导数](/docs/数学基础/微积分/极限与导数) 中的导数与基本求导。
- 了解「变化率」的物理直觉（速度、增长）。
- 会用 [Python](/docs/编程语言/Python/0基础语法) 画简单曲线更好。

## 核心概念
微分方程给出的是一张**方向场**：平面上每一点都插着一根小箭头，箭头斜率由 $y'=f(x,y)$ 决定。求解 ODE，就是**在这片箭头森林里顺着方向走出一条曲线**。

由此可以立刻理解两件事：

- **通解是一族曲线**。从不同起点出发会走出不同轨迹，这就是解里那个任意常数 $C$。
- **初值条件挑出唯一一条**。给定 $y(x_0)=y_0$ 就是指定了出发点，于是得到**特解**。

最重要的一个方程是

$$
\frac{dy}{dx}=ky
$$

它的意思是「变化速度正比于当前的量」。解为 $y=Ce^{kx}$。$k>0$ 是指数增长（复利、病毒传播早期、细菌繁殖），$k<0$ 是指数衰减（放射性衰变、RC 电路放电、学习率指数衰减）。**指数函数之所以在自然界无处不在，就是因为它是这个最简单反馈方程的解。**

**解法一：分离变量。** 若能写成 $\frac{dy}{dx}=g(x)h(y)$，就把同名变量挪到同一侧再两边积分：

$$
\int\frac{dy}{h(y)}=\int g(x)\,dx
$$

以 $y'=ky$ 为例：$\int\frac{dy}{y}=\int k\,dx\Rightarrow \ln|y|=kx+C_1\Rightarrow y=Ce^{kx}$。

**解法二：积分因子（一阶线性方程）。** 对

$$
y'+p(x)y=q(x)
$$

两边乘以 $\mu(x)=e^{\int p\,dx}$。妙处在于左边恰好变成一个乘积的导数：

$$
(\mu y)'=\mu q\quad\Longrightarrow\quad y=\frac{1}{\mu}\left(\int \mu q\,dx+C\right)
$$

**牛顿冷却定律**是它的经典应用：$T'=-k(T-T_{\text{env}})$，解为 $T=T_{\text{env}}+(T_0-T_{\text{env}})e^{-kt}$——温差按指数衰减，物体渐近趋向环境温度。

**数值解法。** 绝大多数 ODE 没有初等解析解，只能数值求解。最朴素的是**欧拉法**：直接用切线往前走一小步

$$
y_{n+1}=y_n+h\,f(x_n,y_n)
$$

它本质上就是一阶泰勒展开截断，全局误差为 $O(h)$。工程中更常用四阶龙格–库塔（RK4），误差 $O(h^4)$，同样步长下精度高出好几个数量级。

## 最小示例

```python
import numpy as np

# 求解 y' = -2y, y(0) = 1，解析解 y = e^(-2x)
def f(x, y):
    return -2 * y

def exact(x):
    return np.exp(-2 * x)

def euler(f, y0, x_end, h):
    """一阶欧拉法：沿切线小步前进"""
    xs = np.arange(0, x_end + h/2, h)
    ys = np.zeros_like(xs)
    ys[0] = y0
    for n in range(len(xs) - 1):
        ys[n+1] = ys[n] + h * f(xs[n], ys[n])      # 核心一行
    return xs, ys

def rk4(f, y0, x_end, h):
    """四阶龙格-库塔：一步内探四次斜率再加权平均"""
    xs = np.arange(0, x_end + h/2, h)
    ys = np.zeros_like(xs)
    ys[0] = y0
    for n in range(len(xs) - 1):
        x, y = xs[n], ys[n]
        k1 = f(x, y)
        k2 = f(x + h/2, y + h/2 * k1)
        k3 = f(x + h/2, y + h/2 * k2)
        k4 = f(x + h,   y + h * k3)
        ys[n+1] = y + h/6 * (k1 + 2*k2 + 2*k3 + k4)
    return xs, ys

# ---- 步长减半，欧拉法误差也大致减半（O(h)）----
print("欧拉法在 x=1 处的误差：")
for h in [0.2, 0.1, 0.05, 0.025]:
    xs, ys = euler(f, 1.0, 1.0, h)
    print(f"  h={h:<6} 误差={abs(ys[-1] - exact(1.0)):.6f}")

print("\nRK4 在 x=1 处的误差：")
for h in [0.2, 0.1, 0.05]:
    xs, ys = rk4(f, 1.0, 1.0, h)
    print(f"  h={h:<6} 误差={abs(ys[-1] - exact(1.0)):.3e}")
# 欧拉法步长减半、误差也减半（O(h)）；RK4 步长减半、误差降约 16 倍（O(h⁴)）
# RK4 用 h=0.2 的误差（8.1e-05）已比欧拉法 h=0.025（6.8e-03）好约 85 倍

# ---- 牛顿冷却：90°C 的水放在 20°C 房间，k=0.1 ----
def cooling(t, T):
    return -0.1 * (T - 20)

ts, Ts = rk4(cooling, 90.0, 60.0, 0.1)
for t in [0, 10, 30, 60]:
    i = int(t / 0.1)
    analytic = 20 + 70 * np.exp(-0.1 * t)
    print(f"t={t:>2} min: 数值={Ts[i]:.4f}°C, 解析={analytic:.4f}°C")
# 两者完全吻合 ✔ 温度从 90°C 渐近趋向 20°C
```

手算校验：$T(10)=20+70e^{-1}=20+70\times0.3679=45.75$，与输出一致。

## 易错点

- **分离变量时丢掉常数解**。$y'=ky$ 除以 $y$ 时默认了 $y\neq0$，而 $y\equiv0$ 也是一个解。带绝对值的 $\ln|y|$ 在合并常数时也要小心符号。
- **通解与特解混用**。没代入初值就交卷，答案里留着未定的 $C$，等于没解完。
- **积分因子忘记乘到右端**。$\mu$ 必须乘在方程**两边**，只乘左边是常见笔误。
- **欧拉法用大步长解「刚性」方程会爆炸**。对 $y'=-100y$，显式欧拉要求 $h<2/100$，否则数值解会震荡发散——不是程序错了，是方法不适用，应改用隐式方法。
- **误以为数值方法可以无限减小步长**。步长过小时舍入误差累积会反过来占主导，总误差存在最优步长。

## 练习

1. 求解 $y'=3y$，$y(0)=2$。
   *答案：$y=2e^{3x}$。*
2. 某放射性物质半衰期为 5 年，写出其衰变方程并求衰变常数 $k$。
   *提示：$\tfrac12=e^{-5k}\Rightarrow k=\ln 2/5\approx0.1386\ \text{年}^{-1}$。*
3. 用积分因子解 $y'+y=x$。
   *提示：$\mu=e^{x}$，$(e^x y)'=xe^x$，积分得 $e^xy=(x-1)e^x+C$，故 $y=x-1+Ce^{-x}$。*

## 小结

常微分方程描述的是变化率与量之间的关系，其解是一族曲线，初值条件从中挑出唯一一条。最基本的 $y'=ky$ 给出指数增长与衰减，解释了自然界中指数律的普遍性。可分离变量法与积分因子法覆盖了大部分一阶方程的解析求解需求。当解析解不存在时，用欧拉法（误差 $O(h)$）或 RK4（误差 $O(h^4)$）数值推进，但必须注意步长与方程刚性的匹配，否则数值解会失稳。
