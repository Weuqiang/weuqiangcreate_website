# 栈与队列

栈和队列是受访问限制的线性结构，规则简单却极其常用。本篇讲原理与典型应用。

## 1. 栈（Stack）：LIFO

**后进先出**（Last In First Out），只在一端操作：

```python
stack = []
stack.append(1)      # 入栈 push
stack.append(2)
top = stack.pop()    # 出栈 pop → 2
```

操作：$O(1)$。

典型应用：

- 函数调用栈（递归、局部变量）；
- 撤销（Undo）；
- 括号匹配、表达式求值（后缀表达式）；
- 深度优先搜索（DFS）。

括号匹配：

```python
def match(s):
    st = []
    for c in s:
        if c in "([{": st.append(c)
        elif c in ")]}" and (not st or "([{".index(st.pop()) != ")]}".index(c)):
            return False
    return not st
```

## 2. 队列（Queue）：FIFO

**先进先出**（First In First Out），一端进一端出：

```python
from collections import deque
q = deque()
q.append(1)          # 入队
q.append(2)
front = q.popleft()  # 出队 → 1
```

`deque`（双端队列）两端操作都是 $O(1)$，比 `list.pop(0)` 的 $O(n)$ 优。

典型应用：

- 任务调度、消息队列；
- 广度优先搜索（BFS）；
- 缓冲区、打印机队列。

## 3. 双端队列与优先队列

- **双端队列（deque）**：两端都能进出；
- **优先队列（堆实现）**：出队总是最小/最大元素，见 [堆与图遍历](../../树与图/堆与图遍历)。

## 4. 对比

| 结构 | 顺序 | 出口 | 典型用途 |
|------|------|------|----------|
| 栈 | LIFO | 同端 | 调用栈、撤销 |
| 队列 | FIFO | 异端 | 调度、BFS |

## 小结

栈"后进先出"、队列"先进先出"，限制带来了确定性。它们几乎是算法与系统的通用零件。
