## tempfile 模块

程序运行时常常需要一块"用完即弃"的磁盘空间：下载的缓存、上传文件的中间落盘、原子写入（先写临时文件再 rename 覆盖）等。`tempfile` 模块帮你做对三件事：**唯一的名字**（避免冲突）、**合理的权限**（默认仅当前用户可读）、**自动清理**（进程退出或上下文结束时删除）。

### NamedTemporaryFile：最常用

返回一个已打开的文件对象，上下文结束（或对象被回收）时自动删除：

```python showLineNumbers
import tempfile

with tempfile.NamedTemporaryFile(
    mode="w+t",        # 文本读写；默认 "w+b" 二进制
    suffix=".txt",     # 文件名后缀，方便识别
    prefix="myapp_",   # 文件名前缀
    delete=True,       # 退出时删除（默认 True）
) as f:
    f.write("hello temp")
    f.seek(0)
    print(f.read())    # hello temp
    print(f.name)      # 形如 /tmp/myapp_xxxx.txt
# 离开 with 块后文件已被自动删除
```

### mkstemp：返回 (fd, path)，手动管理

当你需要把"文件路径"交给别的库或进程时，用 `mkstemp` 拿到文件描述符和路径：

```python showLineNumbers
import tempfile, os

fd, path = tempfile.mkstemp(suffix=".log")
try:
    # 必须用 os.fdopen 把 fd 包成文件对象，或 os.write(fd, ...)
    with os.fdopen(fd, "w") as f:
        f.write("some log")
    # 其它代码也可以按 path 打开同一文件
finally:
    os.remove(path)    # 手动清理
```

### TemporaryDirectory：临时目录

需要一次性写多个文件时，建一个临时目录最方便，整个目录及内容一起删除：

```python showLineNumbers
import tempfile, os

with tempfile.TemporaryDirectory() as d:
    cfg = os.path.join(d, "config.json")
    with open(cfg, "w") as f:
        f.write('{"ok": true}')
    print("临时目录:", d)
# d 及其内部文件全部被删除
```

### SpooledTemporaryFile：先内存后落盘

数据小的时候放在内存（更快），超过 `max_size` 才自动写入磁盘，对调用方透明：

```python showLineNumbers
import tempfile

with tempfile.SpooledTemporaryFile(max_size=1_000_000) as f:
    f.write(b"some bytes")
    f.seek(0)
    print(f.read())
```

## 易错点

- **Windows 上 `NamedTemporaryFile` 文件被占用**：在 `with` 块内，其它进程（甚至你自己再次 `open(path)`）可能无法打开同一文件。需要跨进程共享时设 `delete=False`，并在 `finally` 里手动 `os.remove`。
- **`mkstemp` 返回的是低级 fd**：不要既持有 fd 又 `open(path)` 同一文件，容易出错；统一用 `os.fdopen(fd, ...)` 接管。
- **`delete=False` 必须自己清理**：否则临时文件会一直留在系统临时目录，时间久了堆积垃圾。
- **默认目录在系统 temp**（如 Linux `/tmp`）：注意磁盘空间与权限，容器环境可能空间很小。
- **临时文件不是秘密保险箱**：`/tmp` 默认权限较严，但同机其他用户若有权限仍可能读到；敏感数据考虑加密或限制 `dir` 到私有目录。
