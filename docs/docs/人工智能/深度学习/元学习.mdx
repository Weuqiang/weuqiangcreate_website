# 元学习

- 理解「学学习过程本身」与一般训练的区别

## 核心概念

### 1. 从「学一个任务」到「学怎么学」

数据充足时，深度学习表现惊人；但每个新任务都从零训、又慢又费数据。**元学习（Meta-Learning，「学会学习」）** 的野心是：在**一批相关任务** $\{\mathcal{T}_i\}$ 上训练，提炼出一个「初始化 / 度量 / 记忆」，使得面对**全新任务**时，只用极少样本（几张图、几次交互）就能快速适应。

它把优化对象从「模型参数」提升到「学习算法本身」。

### 2. 基于梯度：MAML 与「好初始化」

**MAML（Model-Agnostic Meta-Learning）** 是最具代表性的方法。它寻找一个**对任务变化敏感的参数 $\theta$**，使得每个任务只需一步（或几步）梯度更新就表现良好：

$$
\theta' = \theta - \alpha \nabla_\theta \mathcal{L}_{\mathcal{T}_i}(\theta),\qquad
\min_\theta\; \sum_i \mathcal{L}_{\mathcal{T}_i}(\theta')
$$

外层更新显式经过内层更新，产生**二阶梯度**（通过对 $\theta'$ 再求 $\nabla_\theta$ 实现）。直观：普通初始化是「随便起点」，MAML 初始化是「站在所有任务下坡的交汇处」，新任务一推就滑向最优。

为省二阶开销，FOMAML（丢 outer 二阶）、Reptile（直接把多任务更新后参数往回拉）等近似被广泛使用。

### 3. 基于度量：让同类「天然靠近」

另一条路不直接优化初始化，而是学一个**嵌入空间**，使同类样本距离近、异类远，再用近邻分类做少样本：

- **孪生网络（Siamese）**：用共享编码器把样本映成向量，比较距离判断同类；
- **原型网络（Prototypical）**：每个类用支撑集样本的均值作「原型」，查询样本归到最近原型；
- **匹配网络**：用注意力做带上下文的近邻。

这类方法在 few-shot 分类上简单有效，且无需内层梯度循环。

### 4. 记忆增强与黑盒适应

- **记忆增强**：模型带外部记忆（如 LSTM/神经图灵机风格），把「见过的任务」存进去，遇到新任务读记忆快速适配。
- **黑盒/上下文适应**：不更新权重，而是把少量支撑样本放进输入上下文，让模型「现学现用」——**大模型的小样本/上下文学习（in-context learning）** 本质上就是一种元学习：预训练已把「从示例中归纳」的能力烧进了参数。

## 示例

用伪代码勾勒 MAML 的两层更新（内层任务适应 + 外层元更新）：

```python
for task in batch_of_tasks:
    # 内层：在该任务上用当前 theta 走一步
    theta_i = theta - alpha * grad(L_task(theta, support_set))
    # 外层：以适应后的 theta_i 在查询集上的损失更新元参数
    meta_loss += L_task(theta_i, query_set)

theta = theta - beta * grad(meta_loss)      # 二阶：梯度穿过内层更新
```

直觉例子：**少样本图像分类**。给 5 个新类别、每类 1 张图（5-way 1-shot），从头训的 CNN 必过拟合；MAML 预训练出的初始化，靠这 1 张图一步更新就能区分五类——因为它学到的是「如何快速校准分类边界」，而非某个具体分类器。

## 易错点

- **任务分布太窄**：元学习学到的是「适应训练任务分布的先验」。若测试任务离训练任务族太远，适应失效——「学会学习」不等于「学会一切」。
- **内层步数/学习率敏感**：MAML 对 $\alpha$ 和 inner-step 极敏感，太大一步跑飞、太小没适应；需仔细调。
- **二阶开销与近似偏差**：完整 MAML 的二阶反向传播贵；FOMAML/Reptile 快但引入了偏差，某些任务上略逊。
- **少样本评估泄漏**：few-shot 的支撑/查询划分若与预训练数据重叠，指标虚高。要严控任务划分。

## 练习

1. 用一句话区分「迁移学习」与「元学习」：前者改什么、后者改什么？
2. 推导 MAML 外层梯度 $\nabla_\theta \mathcal{L}(\theta')$ 中出现的二阶项 $\frac{\partial \theta'}{\partial \theta}$，说明为何它编码了「初始化敏感度」。
3. 思考：大模型的上下文学习为何可视为元学习？它与 MAML 的「显式适应」有何本质不同？

## 小结

元学习把训练目标从「学好一个任务」抬升到「学好如何快速学新任务」。MAML 学一个对任务敏感的初始化，度量学习学一个「同类相近」的嵌入，记忆增强与上下文学习则把适应外置或隐式化。它是少样本学习、持续适应与高效 RL 的通用底座。
