# 数据结构与算法

数据结构是**数据的组织方式**，算法是**操作数据的步骤**。两者共同决定程序"快不快、省不省"。

## 复杂度：衡量好坏的尺子

用大 O 表示法描述随数据规模 $n$ 增长的趋势：

| 复杂度 | 含义 | 例子 |
|--------|------|------|
| $O(1)$ | 常数 | 数组按下标访问 |
| $O(\log n)$ | 对数 | 二分查找 |
| $O(n)$ | 线性 | 遍历数组 |
| $O(n \log n)$ | 线性对数 | 归并/快速排序 |
| $O(n^2)$ | 平方 | 冒泡排序 |

## 学习建议

按「线性结构 → 哈希/排序 → 树与图 → 高级算法」的顺序推进。每篇都先建立直觉再看代码，重点不是背实现，而是**判断场景该用哪个结构、复杂度是多少**。
