## 学习目标

学完本章，你应该能够：

- 掌握 Markdown 标题、列表、链接、代码块、表格等基础语法
- 会用 MDX 扩展写选项卡、提示框、数学公式、Mermaid 图与思维导图

在阅读下面的内容前，建议先掌握：

## 核心概念

Markdown 用极少的符号约定换取了「纯文本即排版」的能力：源码本身可读，渲染后又是规范的富文本。它的价值不在语法多强大，而在于版本可控（纯文本可以 diff、可以 Git 管理）与平台无关。MDX 则在 Markdown 之上允许嵌入组件，让文档可以带交互——代价是花括号与尖括号会被当作 JSX 解析，写散文时必须转义。

本章主线：
- 基础语法：标题、列表、强调、链接、代码
- 结构化：表格、脚注、折叠块
- 多媒体：图片、音视频嵌入
- MDX 扩展：选项卡、提示框、公式、Mermaid、思维导图

## 拓展

### MDX

MDX 允许高度自定义样式，例如像<HoverText text="鼠标悬浮展示" explanation="将需要说明的内容嵌入。这使得编写包含组件的长篇内容变得非常有趣。"/>。

也可以加载第三方思维导图组件，用于系统展示框架：

<MarkmapHooks initialMarkdown={`
# 断舍离核心
## 理念
### 不是扔东西
- 重点是改变观念
### 目标
- 获得更自由的生活
## 实践
### 清理
- 决定物品去留
### 收纳
- 1进1出原则
`} />

### 高亮提示

不同颜色的高亮提示：

这是行内<Highlight color="r">危险提醒</Highlight>、<Highlight>警示提醒</Highlight>、<Highlight color="g">建议提醒</Highlight>、<Highlight color="b">信息提醒</Highlight>。

:::danger
用于危险操作的警告。例如 `rm -rf /` 会删除所有文件。
:::

:::warning
用于警示操作的警告。例如 C语言中`5/2` 结果是 `2` 而不是 `2.5`。
:::

:::tip
这是块级的建议提醒。例如 Python 中 type 有另外一个截然不同的用法，它是一个元类，用于创建类。
:::

:::info
这是块级的信息提醒。例如 技术演进的历史背景，辅助读者理解技术原理。
:::

:::note
这是块级的注解提醒。例如 福柯的《规训与惩罚》不仅是对现代社会的批判，也是对权力运作机制的深刻反思。其主要著作有：《规训与惩罚》、《疯癫与文明》、《性史》、《知识考古学》。

主要用在读书笔记中，类似注脚。
:::

### mermaid绘图

支持横向与纵向绘图，支持颜色定义。

```mermaid
graph TD;
    classDef green fill:#9f6,stroke:#333,stroke-width:2px;
    classDef red fill:#f96,stroke:#333,stroke-width:2px;
    A-->|Yes|B;
    A-->|No|C;
    C-->|Yes|F;
    C-->|No|G;
    class A,B green;
    class C,F,G red;
```

```mermaid
graph LR
DSL(断舍离)
DSL --> DSL1(概念)
DSL --> DSL2(实践)

DSL1 --> DSL1_1(非扔东西)
DSL1_1 --> DSL1_1_1(观念转变)
DSL1 --> DSL1_2(目标)
DSL1_2 --> DSL1_2_1(生活自由)

DSL2 --> DSL2_1(清理)
DSL2_1 --> DSL2_1_1(决定去留)
DSL2 --> DSL2_2(收纳)
DSL2_2 --> DSL2_2_1(1进1出)
```

## 小结

Markdown 让写作回到纯文本，MDX 让文档具备交互。日常够用的语法不超过十条，把它们练熟，再按需查扩展写法即可。

## 练习

1. 同一段内容分别用 Markdown 和富文本编辑器写，用 Git diff 对比二者的可维护性差异。
