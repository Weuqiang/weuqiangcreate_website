## 核心概念

### 从有限维走向无限维

线性代数研究有限维向量空间 $R^n$。但机器学习里常见的「向量」其实是**函数**：$f(x)$ 可看作某个无限维空间里的点。直接套有限维结论会出问题：无限维空间的「基」可能不可数，极限操作不一定落在原空间内。因此需要逐层加结构：

```
向量空间 → 赋范空间(有长度) → 内积空间(有角度) → 希尔伯特空间(完备的内积空间)
          ↑度量空间(有距离)
```

- **度量空间**：定义了距离 $d(x,y)$，能谈「接近」。
- **赋范空间**：定义了范数 $\lVert x\rVert$（长度），距离可由范数诱导 $d(x,y)=\lVert x-y\rVert$。
- **内积空间**：定义了内积 $\langle x,y\rangle$，从而有角度与正交。
- **巴拿赫空间**：完备的赋范空间（所有柯西序列都收敛到空间内的点）。
- **希尔伯特空间**：完备的内积空间——这是泛函分析的主角。

> 完备性至关重要：不完备空间中，一个收敛的优化序列可能「极限不在空间里」，导致算法「看起来收敛实则无解」。

### 希尔伯特空间的核心

希尔伯特空间 $H$ 保留了有限维 Euclidean 空间最友好的性质：

- **正交与投影**：给定闭子空间 $M$，任意 $x\in H$ 可唯一分解为 $x = P_M x + (x-P_M x)$，其中 $P_M x\in M$ 是正交投影。这正是线性回归、PCA 的几何本质（见 [线性代数中的正交投影](/docs/数学基础/线性代数/正交投影与最小二乘)）。
- **正交基**：存在一组正交基，元素可用「坐标」（傅里叶系数）展开。区别在于，无限维空间的基可能是不可数的（如 $L^2$ 空间用三角函数/小波基）。
- **Riesz 表示定理**：希尔伯特空间上的连续线性泛函，都可以表示为某个内积——这是「对偶空间」可亲的核心保证。

### 有界线性算子

有限维里「线性映射 = 矩阵」。无限维里线性映射叫**算子** $T:H\to H$。关键概念：

- **有界算子**：存在常数 $C$ 使 $\lVert Tx\rVert \le C\lVert x\rVert$。有界等价于连续——这是算子「行为良好」的门槛。
- **算子范数**：$\lVert T\rVert = \sup_{\lVert x\rVert=1}\lVert Tx\rVert$。
- **伴随算子** $T^*$：满足 $\langle Tx,y\rangle=\langle x,T^*y\rangle$，是矩阵转置/共轭在实数/复数 Hilbert 空间的推广。

### 再生核希尔伯特空间（RKHS）——与 ML 的接口

RKHS 是「能用核函数描述」的特殊 Hilbert 空间。给定核函数 $k(x,y)$，存在一个 Hilbert 空间，其中**点赋值是有界线性泛函**，从而有「再生性质」：

$$f(x) = \langle f, k(\cdot, x)\rangle_H$$

直观意义：空间中每个函数 $f$ 在 $x$ 处的值，等于它与「以 $x$ 为中心的核函数」的内积。这带来两大威力：

1. **核技巧**：把输入映射到一个高维（甚至无限维）特征空间 $\phi(x)$，且**不必显式计算 $\phi$**，只需算核 $k(x,y)=\langle\phi(x),\phi(y)\rangle$。SVM、核 PCA、[高斯过程](/docs/数学基础/概率与统计/高斯过程与贝叶斯优化) 都建立在此之上。
2. **代表定理（Representer Theorem）**：正则化经验风险的最小解，必可写成训练样本的核组合 $f(x)=\sum_i \alpha_i k(x_i,x)$。这意味着无限维优化被约简成有限维 $\alpha$ 的优化。

## 示例

用核岭回归（RKHS 上的代表定理实例）体会「无限维 → 有限维」：

```python
import numpy as np

def rbf_kernel(X, Y, gamma=1.0):
    # k(x,y) = exp(-gamma ||x-y||^2)，无需显式特征 phi
    X2 = np.sum(X**2, 1)[:, None]
    Y2 = np.sum(Y**2, 1)[None, :]
    return np.exp(-gamma * (X2 + Y2 - 2 * X @ Y.T))

X = np.array([[0.], [1.], [2.]])      # 训练输入（1维，但核可隐式映射到无限维）
y = np.array([0.0, 0.8, 0.1])
lam = 1e-2
K = rbf_kernel(X, X)
alpha = np.linalg.solve(K + lam * np.eye(len(X)), y)   # 代表定理：解只在样本核组合中

def predict(x_new):
    k_new = rbf_kernel(x_new, X)
    return k_new @ alpha                                 # f(x)=sum alpha_i k(x_i,x)

print(predict(np.array([[1.5]])))      # 在未见点上的预测
```

要点：`alpha` 只依赖训练样本的核矩阵 $K$，尽管模型实际活在无限维 RKHS 里——代表定理把问题「压回」有限维。

## 易错点

- **忽视完备性**：在没验证完备的空间里做极限/优化，结论可能不落在空间内；希尔伯特/巴拿赫空间的好处正是完备。
- **把无限维基当有限维用**：不可数基下「张成」要用闭包与收敛意义，不能简单说「有限个基向量」。
- **混淆 RKHS 与一般 Hilbert 空间**：并非所有 Hilbert 空间都是 RKHS；RKHS 额外要求「点赋值是连续的」，这才有再生性质。
- **滥用核技巧**：核矩阵 $K$ 的存储与求解是 $O(n^2)/O(n^3)$，样本大时需近似（随机特征、Nystrom）。

## 练习

3. 给定 RBF 核，说明「我们从未显式构造 $\phi(x)$」却能在高维空间做线性分离，这依赖 RKHS 的哪条性质？

## 小结

泛函分析把线性代数推广到函数空间，核心是**希尔伯特空间**（完备内积空间）与**有界线性算子**。它给机器学习提供了关键接口：**RKHS 与核技巧**让非线性问题在隐式高维空间里用线性方法处理，代表定理进一步把无限维优化压成样本核组合的有限维问题——这正是 SVM、核方法与[高斯过程](/docs/数学基础/概率与统计/高斯过程与贝叶斯优化)的数学底座，也与[函数空间上的随机优化](/docs/数学基础/微积分/随机优化与收敛理论)一脉相承。
