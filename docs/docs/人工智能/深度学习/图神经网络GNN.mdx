# 图神经网络（GNN）

## 学习目标

- 说清为什么图数据（非欧、无序、可变大小）让 CNN/RNN 失效
- 掌握消息传递（message passing）范式：聚合邻居 → 更新节点表示
- 理解 GCN、GAT 与 GraphSAGE 的区别（均值/注意力/采样邻居）
- 知道 GNN 的典型任务：节点分类、链接预测、图分类

## 核心概念

### 1. 图数据的特殊性

图像是规则网格（像素有固定邻域），序列是线性顺序——CNN/RNN 依赖这种**归纳偏置**。图没有固定邻域大小、节点无自然顺序、整图大小可变，且具对称性（节点重排不改变语义）。直接用 MLP 会丢失拓扑，GNN 正是为拓扑而生。

### 2. 消息传递：GNN 的统一范式

核心思想：每个节点先**聚合邻居的消息**，再**更新自己的表示**。第 $l$ 层：

$$
h_v^{(l)} = \mathrm{UPDATE}\Big(h_v^{(l-1)},\; \mathrm{AGG}\big(\{h_u^{(l-1)} : u\in\mathcal{N}(v)\}\big)\Big)
$$

多叠几层，节点表示就「看到了」越来越远的邻居（类似 CNN 的感受野）。这是 GCN、GAT、GraphSAGE 的共同骨架。

### 3. 三种经典变体

- **GCN**：聚合用「对称归一化的邻居均值」，$H^{(l)}=\sigma\big(\hat{D}^{-1/2}\hat{A}\hat{D}^{-1/2}H^{(l-1)}W^{(l)}\big)$。简单高效，但每个邻居权重相同。
- **GAT**：用**注意力**给邻居加权，$\alpha_{vu}=\mathrm{softmax}_u\big(\mathrm{LeakyReLU}(a^\top[Wh_v\|Wh_u])\big)$，重要邻居贡献更大。
- **GraphSAGE**：不取全邻居，而是**采样**固定数邻居再聚合，能扩展到巨图，且支持归纳（inductive）到未见过的节点。

### 4. 任务与读出

- **节点级**：节点分类（如论文引用网络里的论文主题）、回归
- **边级**：链接预测（推荐里「用户-商品」是否会连边）
- **图级**：整图分类（分子是否有毒），用一个**读出（readout）**函数（如对所有节点表示求和/最大池化）得到图表示

## 示例

用一层聚合直观看「节点表示如何吸收邻居信息」：

```python
import numpy as np

# 一个 4 节点小图（无向），邻接用集合表示
adj = {0: [1, 2], 1: [0, 2], 2: [0, 1, 3], 3: [2]}
H = {0: np.array([1.0, 0.0]), 1: np.array([0.0, 1.0]),
     2: np.array([1.0, 1.0]), 3: np.array([0.0, 0.0])}

def gcn_layer(H, adj, W):
    newH = {}
    for v in H:
        # 对称归一化均值：自己+邻居，按度数开方归一
        neigh = [H[v]] + [H[u] for u in adj[v]]
        deg = np.sqrt(len(neigh))
        agg = sum(neigh) / deg          # 聚合
        newH[v] = np.tanh(agg @ W)      # 更新（线性+激活）
    return newH

W = np.array([[0.5, 0.3], [0.2, 0.4]])
H2 = gcn_layer(H, adj, W)
print("节点 3 的新表示（吸收了节点 2 的信息）:", np.round(H2[3], 3))
print("各节点表示是否都有限:", all(np.isfinite(v).all() for v in H2.values()))
```

节点 3 原本是零向量，经过一层就「从邻居 2 那里」获得了非零表示——这就是消息传递让拓扑信息流入特征的过程。

## 易错点

- **忽略节点顺序/对称性**：图没有天然顺序，聚合必须是对邻居的**排列不变**操作（求和/均值/最大），不能用依赖顺序的 RNN 式聚合。
- **深层 GNN 过平滑（over-smoothing）**：层数过多后所有节点表示趋同、无法区分；通常 2~4 层即可。
- **度大的邻居淹没小度节点**：未归一化的求和会让「枢纽节点」主导，GCN 的对称归一化正是为缓解此点。
- **把图当图像送 CNN**：图的邻接不规则，卷积的局部滑动窗口不适用；必须用消息传递。

## 小结

图神经网络用消息传递让节点在邻居间交换信息，把拓扑变成表示的一部分。GCN 用归一化均值、GAT 用注意力加权、GraphSAGE 用邻居采样以扩展，支撑节点/边/图三级任务。它是社交网络、分子、知识图谱等非欧数据的标配建模工具。
