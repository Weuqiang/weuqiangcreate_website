# 开发知识库：总览

欢迎来到「开发」知识库。这里把一名现代开发者需要的知识，按**先打地基、再学语言、后做系统**的顺序，组织成六条彼此衔接的线。无论你是转行入门、复习补课，还是查漏补缺，都能从这里找到清晰的学习路径。

> 使用建议：每条线都配有「学习路线图」首页（点进分类即可看到），文章统一采用「学习目标 → 核心直觉 → 最小示例 → 易错点 → 练习 → 小结 → 延伸阅读」的教程模板，力求**一看就懂、一学就会**。
