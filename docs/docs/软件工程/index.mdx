# 软件工程：学习路线图

「软件工程」回答的是：**怎么把写好的代码，变成真正能跑、能上线、能长期维护的系统**。它分四条线：

- **后端通识**——与具体语言无关的服务端通用能力：Web 服务器、接口设计、数据库、接口测试、数据分析与网页自动化。无论你用 Python、Java 还是 Go，这些主题都会出现。
- **Web 前端**——用户直接接触的那一层：HTML 负责结构、CSS 负责表现、JavaScript 负责行为。它是平台技术而非单一编程语言，因此归在工程线而不是语言线。
- **工程实践**——让代码「专业地」活下去的能力：版本控制、CI/CD、自动化测试、代码规范与重构、设计模式、分布式架构、项目管理。
- **开发工具链**——每天都在用的手艺工具：Git、终端、Docker、Markdown、YAML，不必系统学，遇到即用即查。

## 推荐学习顺序

```text
后端通识（建立语言无关的服务端心智）
   → Web 前端（补齐用户可见的那一层：结构 / 表现 / 行为）
   → 工程实践（再学如何把系统做对、做稳、做可维护）
        ├─ Git 与版本控制（协作地基）
        ├─ 自动化测试与 TDD（质量保障）
        ├─ 代码规范与重构（持续整洁）
        ├─ 容器化与 Docker（环境一致）
        ├─ 持续集成与部署（自动上线）
        ├─ 设计模式（复用经验）
        ├─ 微服务与分布式架构（规模扩展）
        └─ 项目管理概论（带团队交付）

开发工具链（Git / 终端 / Docker / Markdown / YAML）不排在顺序里——它全程并行，遇到即用即查。
```
