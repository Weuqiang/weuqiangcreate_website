# Rust 语言入门

Rust 是一门**内存安全、无垃圾回收、高性能**的系统级语言，能在编译期消除数据竞争与悬垂指针。

## 1. Hello World

```rust
fn main() {
    println!("Hello, Rust!");
}
```

运行：`cargo run`（Cargo 是 Rust 的构建与包管理工具）

## 2. 所有权（Ownership）：Rust 的灵魂

Rust 不用 GC，而是靠**所有权规则**在编译期管理内存：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;              // 所有权转移（move），s1 此后失效
    // println!("{}", s1);   // ❌ 编译错误：value borrowed after move
    println!("{}", s2);      // ✓
}
```

- 每个值有唯一**所有者**。
- 离开作用域时自动释放（无需手动 `free`）。
- 赋值或传参默认是 **move**，避免浅拷贝导致的双重释放。

## 3. 借用与生命周期

```rust
fn len(s: &String) -> usize {  // & 借用，不获取所有权
    s.len()
}
```

- `&T` 不可变借用，`&mut T` 可变借用（同一时刻只能有一个可变借用）。
- 编译器用**生命周期**标注确保引用始终有效。

## 4. 为什么值得学

- **安全**：编译期杜绝空指针、数据竞争、悬垂引用。
- **性能**：零成本抽象，对标 C/C++。
- **适用广**：系统编程、Web 后端（Actix）、嵌入式（no_std）、WASM。

## 5. 学习路线

1. 所有权、借用、生命周期（最难也最关键）。
2. 类型系统：枚举（enum）、模式匹配、`Result`/`Option` 错误处理。
3. 系统编程：Trait、泛型、并发（`async`/线程）。
