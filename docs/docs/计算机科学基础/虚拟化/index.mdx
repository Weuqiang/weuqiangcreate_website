# 虚拟化

虚拟化把「物理资源」（CPU、内存、I/O 设备）抽象成可灵活分配、彼此隔离的**逻辑资源**，让一台物理机同时承载多个独立的工作负载。它是云计算、容器与云原生的共同底座：没有虚拟化，就没有按需弹性与高密度部署。
