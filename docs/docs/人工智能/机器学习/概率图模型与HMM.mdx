# 概率图模型与隐马尔可夫模型

## 核心概念

### 1. 为什么用图

$n$ 个变量的联合分布 $p(x_1,\dots,x_n)$ 直接需要 $2^n-1$ 个参数，不可行。概率图模型用「变量为节点、依赖为边」把结构先验编码进去，把联合分布分解为若干因子的乘积，既省参数又显式表达条件独立。

### 2. 贝叶斯网络（有向）

有向无环图（DAG），每个节点在其父节点给定下条件独立：

$$
p(x_1,\dots,x_n)=\prod_i p(x_i\mid \mathrm{pa}(x_i))
$$

边的方向可读作「因果」或「影响方向」。给定证据后，用信念传播/变量消元做推断。典型应用：医疗诊断（症状→疾病）、垃圾邮件（词→类别）。

### 3. 马尔可夫随机场（无向）

无向图用团上的势函数（potential）$\phi_c$ 定义分布：

$$
p(x)=\dfrac{1}{Z}\prod_c \phi_c(x_c)
$$

其中 $Z$ 是配分函数（归一化常数，往往难算）。Hammersley-Clifford 定理把它们与条件独立对应。图像去噪、条件随机场（CRF）是代表。

### 4. 隐马尔可夫模型（HMM）

HMM 是「看不见的马尔可夫链 + 每个状态生成一个观测」：
- 隐状态 $z_t$ 服从转移 $A_{ij}=p(z_t=j\mid z_{t-1}=i)$
- 观测 $x_t$ 由发射概率 $B_j(x)=p(x_t\mid z_t=j)$ 生成
- 初始分布 $\pi$

给定观测序列 $x_{1:T}$，两大问题：
- **似然（前向算法）**：用动态规划累加 $\alpha_t(j)=p(x_{1:t},z_t=j)$，避免 $O(K^T)$ 的暴力枚举。
- **解码（维特比）**：求最可能的状态序列 $\arg\max_{z_{1:T}}p(z_{1:T}\mid x_{1:T})$，同样 $O(TK^2)$。

若连参数 $A,B,\pi$ 都不知道，则用 **Baum-Welch（EM 的特例）** 从数据里学。

## 示例

用维特比在「天气(隐) → 心情(观测)」小模型上做序列解码：

```python
import numpy as np

# 隐状态：晴(Sun)/雨(Rain)；观测：开心(Happy)/低落(Low)
states = ["Sun", "Rain"]
pi = np.array([0.6, 0.4])
A  = np.array([[0.7, 0.3], [0.4, 0.6]])     # Sun->Sun .7, Rain->Rain .6
B  = np.array([[0.8, 0.2], [0.3, 0.7]])     # Sun 时 Happy .8；Rain 时 Low .7
obs_idx = [0, 1, 1]                          # 观测序列 Happy, Low, Low
K = 2; T = len(obs_idx)

delta = np.zeros((T, K)); psi = np.zeros((T, K), int)
delta[0] = pi * B[:, obs_idx[0]]
for t in range(1, T):
    for j in range(K):
        seq = delta[t-1] * A[:, j] * B[j, obs_idx[t]]
        psi[t, j] = np.argmax(seq)
        delta[t, j] = seq.max()

# 回溯
path = [int(np.argmax(delta[T-1]))]
for t in range(T-1, 0, -1):
    path.insert(0, psi[t, path[0]])
print("最可能的隐状态序列:", [states[i] for i in path])
```

观测到「开心、低落、低落」，维特比会推断隐状态大约「晴→雨→雨」——把看不见的天气从心情里反推出来，这正是 HMM 的用武之地（词性标注、语音识别同理）。

## 易错点

- **把有向图的边当确定性因果**：贝叶斯网络的边表达的是条件依赖与因式分解，不一定是物理因果；方向也影响可识别性。
- **忽略配分函数 Z**：无向图模型的 $Z$ 往往难算，直接比较势能高低不等于比较概率，推断需归一化或对比。
- **HMM 解码用「逐点最大」而非维特比**：对每时刻独立取最可能的状态会破坏时序一致性，必须用动态规划保证全局最优路径。
- **维特比/前向忘记对数空间**：概率连乘极易下溢，实战要转到 log 空间做加法。

## 小结

概率图模型用图把联合分布拆成可管理的因子：贝叶斯网络用有向边表因果/条件独立，马尔可夫随机场用无向势函数表软约束。HMM 把一条隐马尔可夫链藏在观测之下，靠前向算法算似然、维特比解码状态、Baum-Welch（EM）学参数，是序列标注与语音识别的经典工具。
