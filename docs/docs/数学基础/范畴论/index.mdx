# 范畴论

范畴论研究「对象」与对象之间「态射（箭头）」的抽象结构，不问对象内部是什么，只关心它们如何相互连接。这种「关注结构与关系而非元素」的视角，使它成为数学各分支之间的通用翻译器，也是函数式编程（Haskell、Scala、Rust 的 trait 设计）的理论底座。
