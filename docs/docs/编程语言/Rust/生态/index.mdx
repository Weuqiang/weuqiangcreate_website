会用 Rust 语法只是第一步，真正把 Rust 用顺手靠的是生态：用 **Cargo** 管理依赖与构建，用 **tokio** 写高并发异步程序，用 **serde** 做序列化，用 **rayon** 做数据并行，用 **clap** 解析命令行。本栏目聚焦这些「每天都要用到」的核心 crate 与工作流。
