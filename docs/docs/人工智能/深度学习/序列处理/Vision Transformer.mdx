2020 年之前，计算机视觉 = 卷积神经网络，这几乎是常识。ViT 用一句话推翻了它：**「一张图片值 16×16 个单词」**——把图像切成小方块，当作句子里的单词，直接喂给标准 Transformer 编码器，不用一个卷积层，照样在 ImageNet 上超越 CNN。

## 核心概念

Vision Transformer 把图片切成一排小方块（patch），每个 patch 当成一个「词」送进 Transformer，于是图像分类变成「给一串 patch token 做注意力」。它证明只要数据够多，纯注意力也能打败精心设计的卷积网络；但小数据下 CNN 的归纳偏置（局部性、平移不变）更管用，所以 ViT 强在数据大、CNN 强在数据少。

- patch 化与 token

- 与 CNN 的取舍

## 核心直觉

### 把图像变成句子

CNN 用局部卷积核逐层扩大感受野；ViT 换了个思路：**把图像切成一堆小方块（patch），每个 patch 当作一个「单词」，整张图就是一串 token 序列**。

```text
原图 224×224×3
   │  切成 16×16 的 patch → (224/16)² = 196 个 patch
   ▼
每个 patch 展平（16×16×3 = 768 维）+ 线性投影 → 196 个 768 维向量
   │  加上可学习的位置编码（告诉模型谁在左上、谁在右下）
   │  在最前面拼一个 [CLS] token（一个可学习的「摘要位」）
   ▼
Transformer Encoder × L 层（多头自注意力 + MLP，都带残差和 LayerNorm）
   │
   ▼
取 [CLS] 位置的输出 → LayerNorm → MLP 分类头 → 类别概率
```

**关键换算**：序列长度 $N = (H/P) \times (W/P)$。224 图配 16 patch 得到 196；如果改用 8×8 的 patch，序列长度变成 784，而自注意力的复杂度是 $O(N^2 d)$，计算量直接涨 16 倍。**patch size 是 ViT 最重要的「精度-算力」旋钮。**

### 归纳偏置：CNN 的天赋，ViT 的短板

CNN 自带两个「先天假设」：

- **局部性**：相邻像素相关性更强，所以用局部卷积核。
- **平移等变性**：猫出现在左上角还是右下角，用同一套卷积核就能识别。

这些假设是**免费的先验知识**，让 CNN 在小数据上也能学得不错。

ViT 几乎没有这些先验：任意两个 patch 在第一层就能互相看见，位置关系完全靠位置编码从数据里学。**这是双刃剑**：

- 数据不足时，ViT 要从零学会「相邻的 patch 更相关」这种常识，效率低下，表现不如 CNN。
- 数据充足时（论文用了 JFT-300M，3 亿张图），ViT 学到的关系比人为设定的卷积先验更灵活，**反超 CNN**。

论文中的关键曲线：在 ImageNet-1k（130 万张）上预训练，ViT 不如 ResNet；换到 ImageNet-21k（1400 万张）打平；到 JFT-300M 才明显领先。

**这条曲线是理解 ViT 的核心。** 它也解释了实践建议：**除非你有海量数据，否则请用预训练权重，不要从零训 ViT。**

### 三个组件的细节

**Patch Embedding**：数学上是「展平 + 全连接」，但工程上有个漂亮的等价实现——**用 kernel size = stride = patch size 的卷积**，一步到位完成切块和投影。

**位置编码**：ViT 用**可学习**的绝对位置编码（不同于原始 Transformer 的正弦编码）。去掉它，模型就变成了「一袋 patch」，完全不知道空间结构，ImageNet 精度会掉 3 个点以上。改变输入分辨率时，位置编码需要做二维插值。

**CLS token**：一个不对应任何图像区域的可学习向量。它通过注意力从所有 patch 收集信息，最终成为整图的「摘要」。也可以直接对所有 patch 输出做平均池化（GAP），效果相当，Swin 等后续工作就用了 GAP。

### 注意力开销的量化

| patch size | 序列长度（224 图） | 注意力矩阵元素数 | 相对计算量 |
| --- | --- | --- | --- |
| 32 | 49 + 1 | 2500 | 1× |
| 16 | 196 + 1 | 38809 | 约 15× |
| 8 | 784 + 1 | 616225 | 约 246× |

**这张表解释了为什么 ViT 难以直接用于检测和分割**——那些任务需要高分辨率输入，序列长度会失控。Swin Transformer 用「窗口内注意力 + 移位窗口」把复杂度降回线性，才让 Transformer 进入密集预测任务。

## 最小示例

### 从零实现完整 ViT

```python showLineNumbers
import torch
import torch.nn as nn

class PatchEmbed(nn.Module):
    """切块 + 线性投影：用 kernel=stride=patch_size 的卷积一步完成"""
    def __init__(self, img_size=224, patch_size=16, in_ch=3, embed_dim=768):
        super().__init__()
        assert img_size % patch_size == 0, "图像尺寸必须能被 patch 整除"
        self.num_patches = (img_size // patch_size) ** 2
        self.proj = nn.Conv2d(in_ch, embed_dim, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        # (B,3,224,224) -> (B,768,14,14) -> (B,768,196) -> (B,196,768)
        return self.proj(x).flatten(2).transpose(1, 2)

class MultiHeadSelfAttention(nn.Module):
    """手写多头自注意力，便于看清 QKV 的形状变换"""
    def __init__(self, dim, heads=12, attn_drop=0.0, proj_drop=0.0):
        super().__init__()
        assert dim % heads == 0
        self.heads = heads
        self.head_dim = dim // heads
        self.scale = self.head_dim ** -0.5      # 1/sqrt(d_k)，防止 softmax 饱和
        self.qkv = nn.Linear(dim, dim * 3, bias=True)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)

    def forward(self, x):
        B, N, C = x.shape
        qkv = self.qkv(x).reshape(B, N, 3, self.heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]        # 各为 (B, heads, N, head_dim)
        attn = (q @ k.transpose(-2, -1)) * self.scale    # (B, heads, N, N)
        attn = self.attn_drop(attn.softmax(dim=-1))
        out = (attn @ v).transpose(1, 2).reshape(B, N, C)
        return self.proj_drop(self.proj(out)), attn

class Block(nn.Module):
    """Pre-LN 结构：LayerNorm 放在子层之前，训练更稳定"""
    def __init__(self, dim=768, heads=12, mlp_ratio=4.0, drop=0.0):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim)
        self.attn = MultiHeadSelfAttention(dim, heads, drop, drop)
        self.norm2 = nn.LayerNorm(dim)
        hidden = int(dim * mlp_ratio)
        self.mlp = nn.Sequential(
            nn.Linear(dim, hidden), nn.GELU(), nn.Dropout(drop),
            nn.Linear(hidden, dim), nn.Dropout(drop))

    def forward(self, x):
        h, attn = self.attn(self.norm1(x))
        x = x + h                              # 残差连接
        x = x + self.mlp(self.norm2(x))        # 残差连接
        return x, attn

class ViT(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_ch=3, num_classes=1000,
                 embed_dim=768, depth=12, heads=12, mlp_ratio=4.0, drop=0.0):
        super().__init__()
        self.patch_embed = PatchEmbed(img_size, patch_size, in_ch, embed_dim)
        n = self.patch_embed.num_patches
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, n + 1, embed_dim))
        self.pos_drop = nn.Dropout(drop)
        self.blocks = nn.ModuleList([Block(embed_dim, heads, mlp_ratio, drop)
                                     for _ in range(depth)])
        self.norm = nn.LayerNorm(embed_dim)
        self.head = nn.Linear(embed_dim, num_classes)
        nn.init.trunc_normal_(self.pos_embed, std=0.02)
        nn.init.trunc_normal_(self.cls_token, std=0.02)

    def forward(self, x, return_attn=False):
        B = x.shape[0]
        x = self.patch_embed(x)                                   # (B, N, D)
        cls = self.cls_token.expand(B, -1, -1)                    # (B, 1, D)
        x = torch.cat([cls, x], dim=1) + self.pos_embed           # (B, N+1, D)
        x = self.pos_drop(x)
        attns = []
        for blk in self.blocks:
            x, a = blk(x)
            attns.append(a)
        x = self.norm(x)
        logits = self.head(x[:, 0])                               # 只取 CLS 位置
        return (logits, attns) if return_attn else logits

vit = ViT()
out = vit(torch.randn(2, 3, 224, 224))
print("输出:", out.shape)
print(f"参数量: {sum(p.numel() for p in vit.parameters())/1e6:.1f}M （ViT-Base 约 86M）")
```

### 验证 patch 数量与位置编码的必要性

```python showLineNumbers
for img, patch in [(224, 16), (224, 32), (384, 16), (32, 4)]:
    n = (img // patch) ** 2
    print(f"图 {img}×{img}, patch {patch} -> {n} 个 token, "
          f"注意力矩阵 {(n+1)**2:,} 个元素")

# 位置编码到底有没有用？打乱 patch 顺序做对照
torch.manual_seed(0)
small = ViT(img_size=32, patch_size=4, embed_dim=64, depth=2, heads=4, num_classes=10)
x = torch.randn(1, 3, 32, 32)

with torch.no_grad():
    tokens = small.patch_embed(x)
    cls = small.cls_token
    a = torch.cat([cls, tokens], 1) + small.pos_embed
    perm = torch.randperm(tokens.shape[1])
    b = torch.cat([cls, tokens[:, perm]], 1) + small.pos_embed
    print("打乱 patch 顺序后，输入表示的差异:", (a - b).abs().mean().item())

    # 去掉位置编码后再打乱，差异应为 0（模型完全看不出区别）
    a0 = torch.cat([cls, tokens], 1)
    b0 = torch.cat([cls, tokens[:, perm]], 1)
    print("无位置编码时，打乱后差异（排序后）:",
          (a0.sort(dim=1).values - b0.sort(dim=1).values).abs().max().item())
```

第二个输出接近 0，说明**没有位置编码时，ViT 眼里的图像只是一袋无序的 patch**——上下左右的概念完全消失。

### 在 CIFAR-10 上训练小 ViT

```python showLineNumbers
import torch, torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

device = "cuda" if torch.cuda.is_available() else "cpu"

# ViT 数据饥渴，增强必须给足
train_tf = transforms.Compose([
    transforms.RandomCrop(32, padding=4),
    transforms.RandomHorizontalFlip(),
    transforms.RandAugment(num_ops=2, magnitude=9),
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)),
    transforms.RandomErasing(p=0.25),
])
test_tf = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)),
])

tr = datasets.CIFAR10("./data", train=True, download=True, transform=train_tf)
te = datasets.CIFAR10("./data", train=False, download=True, transform=test_tf)
tr_loader = DataLoader(tr, batch_size=128, shuffle=True, num_workers=2, drop_last=True)
te_loader = DataLoader(te, batch_size=256, num_workers=2)

# 小图用小 patch、浅网络，否则严重过拟合
model = ViT(img_size=32, patch_size=4, num_classes=10,
            embed_dim=192, depth=6, heads=3, drop=0.1).to(device)

opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.05)
epochs = 30
sched = torch.optim.lr_scheduler.OneCycleLR(
    opt, max_lr=1e-3, epochs=epochs, steps_per_epoch=len(tr_loader), pct_start=0.1)
crit = nn.CrossEntropyLoss(label_smoothing=0.1)

for ep in range(epochs):
    model.train()
    for x, y in tr_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()
        loss = crit(model(x), y)
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)   # ViT 需要梯度裁剪
        opt.step()
        sched.step()

    model.eval()
    correct = total = 0
    with torch.no_grad():
        for x, y in te_loader:
            x, y = x.to(device), y.to(device)
            correct += (model(x).argmax(1) == y).sum().item()
            total += y.size(0)
    print(f"epoch {ep+1:>2}  loss={loss.item():.4f}  test_acc={correct/total:.4f}")
```

30 个 epoch 后准确率大约在 **0.80~0.85**。同等规模的 [ResNet](/docs/人工智能/深度学习/网格数据/ResNet)-18 通常能到 0.93 以上——**这个差距就是「归纳偏置」的价值，也是 ViT 数据饥渴的实证**。想缩小差距，要么加数据增强，要么用预训练权重。

### 可视化注意力：模型在看哪里

```python showLineNumbers
model.eval()
with torch.no_grad():
    x = torch.randn(1, 3, 32, 32).to(device)
    _, attns = model(x, return_attn=True)

last = attns[-1][0]                       # 最后一层 (heads, N+1, N+1)
cls_attn = last[:, 0, 1:].mean(0)         # CLS 对各 patch 的平均注意力
side = int(cls_attn.numel() ** 0.5)
heat = cls_attn.reshape(side, side)
print("注意力热力图形状:", tuple(heat.shape))
print("最受关注的 patch 索引:", int(cls_attn.argmax()))
print("注意力熵（越低越集中）:",
      float(-(cls_attn * cls_attn.clamp_min(1e-9).log()).sum()))
# 用 matplotlib 的 imshow(heat.cpu()) 即可看到模型关注的区域
```

在训练好的模型上，这张热力图通常会聚焦在物体主体上——**这是 ViT 最迷人的可解释性优势**，CNN 需要额外的 Grad-CAM 才能得到类似效果。

## 易错点

- **在小数据集上从零训 ViT**：这是最常见的失败原因。**先试预训练权重（`timm` 库一行加载），或者用 DeiT 的蒸馏方案。**
- **patch size 选得太小**：序列长度按平方增长，显存和时间同步爆炸。32×32 的小图用 patch 4 已经产生 64 个 token，够用了。
- **去掉位置编码**：模型立刻退化成「一袋 patch」，精度大幅下降。
- **改变输入分辨率却不插值位置编码**：预训练在 224 上、推理用 384 时，`pos_embed` 长度对不上，必须做二维插值（`timm` 提供了 `resize_pos_embed`）。
- **用 SGD 训 ViT**：ViT 对优化器敏感，几乎都用 **AdamW + 大 weight decay（0.05）+ warmup + 余弦退火**，还常需要梯度裁剪。
- **忘记 Pre-LN 与 Post-LN 的差别**：原始 Transformer 是 Post-LN（需要 warmup 才能稳），ViT 用 Pre-LN，训练稳定性好很多。抄代码时别混用。
- **增强给太少**：ViT 缺少归纳偏置，强依赖 RandAugment、Mixup、CutMix、RandomErasing 这些「人造先验」。
- **以为 ViT 在所有任务上都强于 CNN**：在小数据、低算力、密集预测任务上，CNN 或 Swin 这类混合架构往往更实用。

## 练习

1. 把 CIFAR 训练里的 `patch_size` 从 4 改成 8 和 2，记录序列长度、显存占用、单 epoch 耗时和最终准确率，画出三者的权衡曲线。
2. 注释掉 `+ self.pos_embed`，重新训练 10 个 epoch，量化位置编码带来的精度贡献。
3. 把 CLS token 换成对所有 patch 输出做平均池化（GAP），对比准确率与收敛速度。
4. 把 `RandAugment` 和 `RandomErasing` 全部关掉，观察训练准确率与测试准确率的裂口如何扩大。
5. 手算：384×384 输入、patch 16 时的序列长度，以及注意力矩阵相对 224 输入增大了多少倍。
6. 用 `timm` 加载 `vit_base_patch16_224` 的预训练权重，在 CIFAR-10 上微调 3 个 epoch，与你从零训练 30 个 epoch 的结果对比。
7. 提取不同层的注意力图，观察浅层与深层关注范围的差异，验证「ViT 浅层也有全局感受野」这一说法。

## 小结

ViT 的核心贡献不是某个精巧的模块，而是**证明了「架构统一」的可能性**：只要数据足够，通用的注意力机制可以取代为视觉专门设计的卷积先验。它的代价是数据饥渴，后续工作分别从不同角度打补丁——**DeiT** 用蒸馏和强增强让 ImageNet-1k 就能训好，**Swin** 用窗口注意力恢复了局部性和多尺度，**MAE** 用自监督预训练摆脱了对标注数据的依赖。

而对今天的多模态大模型来说，ViT 的意义更加直接：**它是几乎所有 VLM 的视觉编码器**，让图像和文本终于能在同一个 Transformer 里被处理。
