# 雅可比矩阵与海森矩阵

## 学习目标

- 对向量值函数 $f:\mathbb{R}^n\to\mathbb{R}^m$，写出其雅可比矩阵 $J\in\mathbb{R}^{m\times n}$，理解每一项的含义
- 对标量函数 $f:\mathbb{R}^n\to\mathbb{R}$，写出海森矩阵 $H=\nabla^2 f$，理解其对称性、半正定性与「曲率」含义
- 用链式法则把多层网络的雅可比串起来，看懂反向传播就是雅可比的连乘
- 理解海森如何区分极小值、极大值与鞍点，以及为什么高维里鞍点比局部极小更常见

## 核心概念

### 1. 雅可比：向量值函数的「逐输出对逐输入」偏导

设 $f:\mathbb{R}^n\to\mathbb{R}^m$，$x=(x_1,\dots,x_n)^\top$，输出 $f(x)=(f_1,\dots,f_m)^\top$。雅可比矩阵是第 $i$ 个输出对第 $j$ 个输入的偏导排成的 $m\times n$ 矩阵：

$$
J_f(x)=\begin{bmatrix}
\frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n}\\
\vdots & \ddots & \vdots\\
\frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n}
\end{bmatrix}
$$

当 $m=1$ 时雅可比退化成梯度（行向量）；当 $n=1$ 时退化成导数（列向量）。它是「一阶线性近似」的系数：$f(x+\Delta x)\approx f(x)+J_f(x)\Delta x$。

### 2. 海森：梯度的梯度，函数的局部曲率

对 $f:\mathbb{R}^n\to\mathbb{R}$，海森是梯度的雅可比，即二阶偏导矩阵：

$$
H_f(x)=\nabla^2 f(x)=\begin{bmatrix}
\frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1\partial x_2} & \cdots\\
\frac{\partial^2 f}{\partial x_2\partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots\\
\vdots & \vdots & \ddots
\end{bmatrix}
$$

由克莱罗定理（混合偏导连续时相等），海森对称。它的特征值告诉我们沿各主方向的**曲率**：特征值全正 ⇒ 局部严格凸（极小值）；全负 ⇒ 局部凹（极大值）；有正有负 ⇒ **鞍点**。

### 3. 反向传播 = 雅可比连乘

一个 $L$ 层网络 $f = f_L\circ f_{L-1}\circ\cdots\circ f_1$，由链式法则，整体对输入（或对某层参数）的雅可比是各层雅可比的连乘：

$$
J_f = J_{f_L}\cdot J_{f_{L-1}}\cdots J_{f_1}
$$

这正是反向传播的本质：前向存激活，反向从输出层往回逐层乘雅可比（并乘损失对输出的梯度），得到损失对任意参数的梯度。连乘里大量小于 1 的奇异值 ⇒ 梯度消失；大量大于 1 ⇒ 梯度爆炸。

### 4. 牛顿法：用海森做二阶更新

梯度下降只看一阶（最陡方向），牛顿法还用海森：

$$
x_{k+1}=x_k - H_f(x_k)^{-1}\nabla f(x_k)
$$

它在二次近似下「一步到位」，收敛快（二次收敛）；代价是每步求海森逆，且海森不正定时方向可能上坡。深度学习中常用**对角近似**（如 RMSProp/Adam 的二阶动量）或拟牛顿（L-BFGS）来折中。

### 5. 高维的鞍点诅咒

在百万维空间里，一个驻点几乎不可能所有方向都「上坡」（那需要海森全负定，概率极低），更常见的是「某些方向下坡、某些上坡」的**鞍点**。所以高维优化的难点往往不是跳出局部极小，而是逃离鞍点——这解释了为什么随机梯度噪声反而有助于训练。

## 示例

用数值扰动手算一个小网络的雅可比，感受链式法则：

```python
import numpy as np

# 两层 f(x) = W2 @ tanh(W1 @ x + b1) + b2，输入 x 是 2 维，输出 1 维
np.random.seed(0)
W1 = np.random.randn(3, 2)
b1 = np.random.randn(3)
W2 = np.random.randn(1, 3)
b2 = np.random.randn(1)
x = np.array([0.5, -0.3])

def forward(x):
    z1 = W1 @ x + b1
    a1 = np.tanh(z1)
    z2 = W2 @ a1 + b2
    return z2

# 数值雅可比：逐输出逐输入扰动
def numerical_jacobian(f, x, eps=1e-5):
    out = f(x)
    m = out.shape[0]; n = x.shape[0]
    J = np.zeros((m, n))
    for j in range(n):
        xp = x.copy(); xp[j] += eps
        xm = x.copy(); xm[j] -= eps
        J[:, j] = (f(xp) - f(xm)) / (2 * eps)
    return J

J = numerical_jacobian(forward, x)
print("输出对输入的雅可比（1x2）：\n", J)
print("是否有限（确认不是 NaN）：", np.isfinite(J).all())
```

若把网络加深，解析的 $J=J_{f_2}J_{f_1}$ 与数值结果会一致——这就是反向传播的保证。

## 易错点

- **维度搞反**：雅可比是 $m\times n$（输出数 × 输入数），不是 $n\times m$。记住「行对应输出、列对应输入」。
- **把海森当不对称**：混合偏导连续时必对称；若你算出海森不对称，多半是求导写错或函数不可二阶导。
- **牛顿法直接用满海森**：维度高时 $H^{-1}$ 又贵又可能在鞍点处不定，实际多用对角/低秩近似。
- **「梯度为零」不等于「最优」**：零梯度只是驻点，还要看海森才能区分极小/极大/鞍点。

## 小结

雅可比把「梯度」推广到向量值函数，是链式法则与反向传播的载体；海森把「梯度」再求导一次，刻画局部曲率并区分极小与鞍点。二者是深度学习优化（梯度消失/爆炸、二阶方法、鞍点逃逸）的数学语言。
