集合、逻辑与证明

离散数学研究「可数、分离」的结构：集合、逻辑、图、组合。它是算法、数据库、编译器和密码学的理论底座。

1. 集合​

集合是无序、互异的元素总体。基本运算：

  • 并 A∪BA\cup BA∪B、交 A∩BA\cap BA∩B、差 A∖BA\setminus BA∖B
  • 幂集：所有子集的集合，大小为 2∣A∣2^{|A|}2∣A∣
A = {1, 2, 3}
B = {2, 3, 4}
print(A | B)   # {1,2,3,4} 并
print(A & B)   # {2,3}     交
print(A - B)   # {1}       差

2. 命题逻辑​

命题非真即假。常用连接词：

符号含义
¬p\neg p¬p非
p∧qp\land qp∧q且
p∨qp\lor qp∨q或
p→qp\to qp→q若…则…

德·摩根定律：

¬(p∧q)=¬p∨¬q,¬(p∨q)=¬p∧¬q\neg(p\land q)=\neg p\lor\neg q,\qquad \neg(p\lor q)=\neg p\land\neg q¬(p∧q)=¬p∨¬q,¬(p∨q)=¬p∧¬q

3. 证明方法​

  • 直接证明：由前提逐步推导结论。
  • 反证法：假设结论不成立，推出矛盾。
  • 数学归纳法：证明 P(1)P(1)P(1) 成立，且 P(k)⇒P(k+1)P(k)\Rightarrow P(k+1)P(k)⇒P(k+1)，则对所有 nnn 成立。
归纳法示例：证明 1+2+...+n = n(n+1)/2
基础：n=1，左=1，右=1 ✓
归纳：假设对 k 成立，则 k+1 时
  1+...+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k+2)/2 ✓

4. 与编程的关系​

  • 集合运算对应 SQL 的 UNION/INTERSECT/EXCEPT。
  • 逻辑表达式是 if 条件的数学形式。
  • 归纳法是递归正确性的证明依据。
