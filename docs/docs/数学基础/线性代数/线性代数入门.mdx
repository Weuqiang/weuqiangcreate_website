# 线性代数入门

线性代数是人工智能、计算机图形学、数据科学的数学基石。它研究**向量、矩阵以及它们之间的线性变换**。

## 学习目标

学完本章，你应该能够：

- 说清向量既是「箭头」也是「坐标列表」。
- 理解矩阵是「对空间的线性变换」。
- 区分矩阵乘法与逐元素乘法（为何要按行乘列）。
- 知道线性代数在图形、数据、ML 中的无处不在。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 高中坐标系与基础的代数运算即可。
- 能想象二维/三维空间中的点。
- 了解 [编程语言数组](/docs/编程语言/Python/0基础语法) 有助于理解矩阵存储。

## 核心概念

线性代数把几何变成算术：向量可以看成带方向的箭头，也可以看成一串数字坐标；矩阵则是一个「变换器」——它把空间里的每个点（向量）按固定规则映射到其他点，而且这种映射保持直线仍是直线、原点不动，这就是「线性」。矩阵乘法之所以「行乘列」，正是因为一次乘法要同时完成「取哪个输入、按什么权重组合」两件事。从图像旋转到神经网络层，背后全是这种线性变换。

## 1. 向量（Vector）

向量是一组有序数的集合，可理解为空间中的一个点（或带方向的箭头）。

$$
\vec{v} = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}
$$

在编程中，向量通常表示为一维数组：

```python
import numpy as np
v = np.array([1, 2, 3])
print(v + v)        # [2 4 6]  向量加法
print(v * 2)        # [2 4 6]  数乘
print(np.dot(v, v)) # 14       点积（内积）
```

## 2. 矩阵（Matrix）

矩阵是二维的数表，代表一个线性变换。

$$
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}
$$

```python
A = np.array([[1, 2], [3, 4]])
x = np.array([1, 1])
print(A @ x)        # [3 7]   矩阵乘向量
print(A.T)          # 转置
print(np.linalg.inv(A))  # 逆矩阵
```

## 3. 为什么重要

- **机器学习**：模型参数、特征、梯度的本质都是向量/矩阵，训练即大量矩阵运算。
- **降维**：PCA 通过特征值分解把高维数据压缩到低维。
- **图形学**：3D 变换（旋转、缩放、平移）用矩阵表示。

## 示例

**矩阵乘向量是"逐行点积"**：对 $A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\ \vec{x}=\begin{bmatrix}1\\1\end{bmatrix}$，结果每个分量 = $A$ 的对应行与 $\vec{x}$ 的点积：

$$
A\vec{x}=
\begin{bmatrix}
1\cdot1+2\cdot1 \\
3\cdot1+4\cdot1
\end{bmatrix}
=
\begin{bmatrix}3\\7\end{bmatrix}
$$

这也正是"线性变换把输入 $(1,1)$ 映射到输出 $(3,7)$"。

```python
import numpy as np
A = np.array([[1,2],[3,4]]); x = np.array([1,1])
# 手算每个分量，看清"行乘列"
row0 = A[0,0]*x[0] + A[0,1]*x[1]   # 3
row1 = A[1,0]*x[0] + A[1,1]*x[1]   # 7
print(row0, row1)                   # 3 7
print(A @ x)                        # [3 7]  与 matmul 一致
```

> 注意 `A @ x`（矩阵乘）与 `A * x`（逐元素乘）完全不同，后者会得到 `[1 2; 3 4]` 而非 `[3 7]`。

## 小结

向量是带方向的量（也是坐标），矩阵是对空间的线性变换，矩阵乘法按行乘列完成「取输入、加权组合」。它是 [矩阵与方程组](/docs/数学基础/线性代数/矩阵与线性方程组) 与 [向量空间](/docs/数学基础/线性代数/向量空间与基) 的入口，也是 [人工智能](/docs/人工智能/深度学习/计算机视觉/AlexNet) 与计算机图形的数学语言。

## 易错点

- 矩阵乘法**不满足交换律**：$AB$ 通常不等于 $BA$，甚至维度都可能不匹配。
- 点积 $\vec{a}\cdot\vec{b}$ 得到标量，叉积（三维）得到向量，别混用。
- `@`（matmul）与 `*`（逐元素乘）在 NumPy 里完全不同；`A*A` 不是平方，是逐元素乘积。
