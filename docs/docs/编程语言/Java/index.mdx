# Java

Java 是一门**面向对象、跨平台**的语言，依托 JVM 实现"一次编写，到处运行"，长期占据企业级后端与安卓生态的主导地位。

## 本栏目结构

- **语言基础**：语法、类型、流程控制与面向对象（类、接口、继承、多态）。
- **JVM**：内存模型、垃圾回收（GC）与类加载机制——理解性能与调优的底层。
- **并发**：线程、线程池、`synchronized` 与 `java.util.concurrent` 并发工具。
- **生态**：集合框架、Spring Boot 与主流 Java 工程实践。

## 推荐学习路线

1. 先打牢语法与面向对象基础；
2. 再深入 JVM 内存与 GC，理解为什么"卡顿"与"内存溢出"；
3. 并发是 Java 的难点与重点，配合 `java.util.concurrent` 实战；
4. 最后用 Spring Boot 串起 Web 开发全栈。
