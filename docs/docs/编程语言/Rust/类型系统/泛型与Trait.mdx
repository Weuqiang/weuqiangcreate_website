# 泛型与 Trait

Rust 用**泛型**实现零成本抽象，用 **Trait** 定义共享行为（类似接口）。两者是代码复用的基石。

## 学习目标
- 用泛型写出对多种类型复用的函数 / 结构体；
- 用 Trait 定义行为并 `impl` 给具体类型；
- 理解 Trait bound 与 `impl Trait` 简写；
- 区分静态分发（泛型）与动态分发（`dyn Trait`）。

## 前置知识
- 先读 [枚举与模式匹配](../枚举与模式匹配) 理解 `enum` 与模式。

## 核心概念

### 1. 泛型

```rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {   // T 为任意可比较类型
    let mut max = &list[0];
    for item in list {
        if item > max { max = item; }
    }
    max
}
```

- 单态化（monomorphization）：编译期为每种具体类型生成专用代码，**无运行时开销**。

### 2. Trait：定义行为

```rust
trait Summary {
    fn summarize(&self) -> String;     // 必须实现
    fn author(&self) -> String {       // 默认实现
        String::from("(匿名)")
    }
}

struct Article { title: String }
impl Summary for Article {
    fn summarize(&self) -> String {
        format!("文章: {}", self.title)
    }
}
```

### 3. Trait Bound 与泛型结合

```rust
fn notify<T: Summary>(item: &T) {
    println!("提醒: {}", item.summarize());
}
```

简写：`fn notify(item: &impl Summary)`。

### 4. 常用标准 Trait

| Trait | 作用 |
|-------|------|
| `Debug` | `{:?}` 格式化输出 |
| `Clone` / `Copy` | 复制语义 |
| `PartialEq` / `Eq` | 相等比较 |
| `Ord` | 排序 |
| `Default` | 默认值 |
| `From` / `Into` | 类型转换 |

可用派生宏自动实现：

```rust
#[derive(Debug, Clone, PartialEq)]
struct Point { x: i32, y: i32 }
```

### 5. Trait 对象（动态分发）

```rust
fn report(items: &[&dyn Summary]) {   // dyn 动态分发，运行时决定
    for i in items { println!("{}", i.summarize()); }
}
```

- `dyn Trait` 用于异构集合，牺牲一点性能换灵活。
- 默认泛型是静态分发（快），按需用 `dyn`。

## 常见误区 / 易错点
- **泛型默认静态分发（单态化）**：`fn f<T: Summary>` 会为每种类型生成一份代码，性能好但二进制体积会增大（code bloat），别在超多类型场景滥用。
- **`dyn Trait` 有运行时开销**：动态分发通过虚表调用，灵活但慢一点；只在需要异构集合时用。
- **Trait bound 写错位置**：`fn f<T: Clone>(x: T)` 约束的是"类型 T 能 Clone"，不是返回值；多约束用 `+`，如 `T: Clone + Debug`。

## 练习
1. 定义 `trait Area { fn area(&self) -> f64; }`，为 `struct Circle { r: f64 }` 与 `struct Rect { w: f64, h: f64 }` 实现它，再写一个 `fn print_area<T: Area>(s: &T)`。
2. 用 `#[derive(Debug, PartialEq, Clone)]` 给一个结构体自动实现常用 trait，体会零样板。

## 小结
泛型负责"对多种类型复用"，Trait 负责"约束类型能做什么"。二者结合既灵活又零成本，是 Rust 抽象的核心工具。
