Python 内置类型之外，标准库补充了一批「表达意图」的类型工具：把散落的魔法数字收敛成枚举，把嵌套结构打印得可读。它们不增加能力，但显著降低代码的理解成本。

## 本章模块

- [enum](./enum) — 枚举类型：给常量集合命名，避免魔法值满天飞
- [pprint](./pprint) — 美化打印：让嵌套字典与列表变得可读
- [collections](./collections) — 高性能容器数据类型：defaultdict / Counter / deque / namedtuple / ChainMap
- [dataclasses](./dataclasses) — 数据类：用 `@dataclass` 自动生成构造/打印/比较，告别样板代码
