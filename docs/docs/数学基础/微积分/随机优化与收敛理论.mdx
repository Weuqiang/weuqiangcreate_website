# 随机优化与收敛理论

## 学习目标

- 理解 SGD 为何在有限样本/有限步下仍收敛，及其与全批量 GD 的区别
- 掌握动量（momentum）、Adam 等方法的改进与理论直觉
- 理解方差缩减（SVRG）及其收敛速率
- 认识非凸优化的难点（鞍点、尖锐极小值）与实证现象

## 核心概念

### 1. 随机梯度：用噪声换速度

目标 $\min_x f(x)=\mathbb{E}_\xi[\ell(x;\xi)]$。全批量梯度 $\nabla f$ 需遍历全部数据，代价高；SGD 用单样本或小批量估计 $g_t\approx \nabla f(x_t)$，虽带噪声但每步极廉。在适当的步长衰减下，SGD 收敛到驻点（凸情形下收敛到最优的邻域）。

### 2. 收敛速率（凸情形）

- **GD（确定性）**：光滑凸下 $O(1/T)$，强凸下 $O(1/T^2)$（加速）
- **SGD**：因梯度方差，到 $O(1/\sqrt{T})$（或带衰减到 $O(1/T)$ 但常数更差）
- **方差缩减**（SVRG/SAGA）：把 SGD 的方差降到零，恢复 $O(1/T)$ 甚至线性收敛，又不失每步的廉价

### 3. 动量法

$$
v_{t+1}=\beta v_t + g_t,\qquad x_{t+1}=x_t-\eta\,v_{t+1}
$$

累积历史梯度方向，加速穿越峡谷、抑制震荡。Heavy Ball 对应物理惯性；Nesterov 加速（NAG）先「看一眼」再修正，理论更优。

### 4. Adam 与自适应步长

Adam 维护梯度一阶矩（动量）与二阶矩（梯度幅度）的指数滑动平均，用 $\hat m/\sqrt{\hat v}$ 做逐坐标自适应步长。实践中快且稳，但理论收敛保证弱于 SGD（非凸下仍有收敛性结论，泛化性争议较大）。

### 5. 非凸现实的难点

深度学习目标非凸：存在大量**鞍点**（高维下比局部极小更常见，参见雅可比/海森篇），以及尖锐 vs 平坦极小值的泛化差异。SGD 的噪声反而帮助逃离鞍点；batch norm、学习率预热等工程技巧影响巨大。

## 示例

用 numpy 复现 SVRG 的核心思路——周期性计算全梯度、用「梯度差」做低方差更新，并对比 SGD 的震荡收敛：

```python
import numpy as np

np.random.seed(0)
d = 50
A = np.random.randn(200, d)
b = A @ np.random.randn(d) + 0.01 * np.random.randn(200)
x, x_svrg = np.zeros(d), np.zeros(d)

def grad(x, i):
    return A[i] * (A[i] @ x - b[i])      # 单样本最小二乘梯度

# 朴素 SGD
for _ in range(2000):
    i = np.random.randint(200)
    x = x - 0.005 * grad(x, i)

# SVRG：每轮重算全梯度，用 (g(x)-g(x0)+μ) 做低方差更新
for _ in range(40):
    mu = A.T @ (A @ x_svrg - b) / 200.0
    x0 = x_svrg.copy()
    for _ in range(50):
        i = np.random.randint(200)
        x_svrg = x_svrg - 0.01 * (grad(x_svrg, i) - grad(x0, i) + mu)

print("SGD 残差:", round(np.linalg.norm(A @ x - b), 4),
      " SVRG 残差:", round(np.linalg.norm(A @ x_svrg - b), 4))
```

## 易错点

- **把 SGD 的 $O(1/\sqrt{T})$ 当成「不收敛」**：它是收敛到最优的邻域，步长衰减才能继续逼近。
- **动量系数 $\beta$ 过大**：导致超调、震荡甚至发散。
- **误以为 Adam 一定优于 SGD**：很多任务上 SGD+momentum 泛化更好，Adam 只是更快收敛到训练解。
- **忽略学习率调度**：固定大步长在非凸下易困在鞍点或持续震荡。

## 练习

1. 解释为何方差缩减（SVRG）能在保持每步廉价的同时，把 SGD 的 $O(1/\sqrt{T})$ 提升到 $O(1/T)$。
2. Nesterov 动量相对 Heavy Ball 的「先展望再修正」如何减小超调？画出一维势阱的直觉。
3. 非凸优化里为何「鞍点」比「局部极小」更值得担心？结合高维海森谱说明。

## 小结

随机优化用带噪声的梯度换取每步极低的代价：SGD 在凸情形下收敛到最优邻域，方差缩减恢复快速收敛，动量与 Adam 改善实际路径与稳定性。非凸现实（深度学习）里鞍点与泛化差异使理论与工程仍有落差——它是现代机器学习的引擎。
