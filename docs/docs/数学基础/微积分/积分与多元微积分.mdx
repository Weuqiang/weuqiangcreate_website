# 积分与多元微积分

积分是导数的逆运算：导数给「变化率」，积分还给「总量」。本篇覆盖定积分、不定积分与多元微积分的梯度概念。

## 1. 定积分：求面积

函数 $f(x)$ 在 $[a,b]$ 上的定积分表示曲线下的面积：

$$
\int_a^b f(x)\,dx
$$

几何意义：把区间切成无数小条，每条约 $f(x)\cdot dx$，求和取极限。

## 2. 微积分基本定理

导数与积分互为逆运算：

$$
\frac{d}{dx}\int_a^x f(t)\,dt = f(x)
$$

常见积分：

| 函数 | 不定积分 |
|------|----------|
| $x^n$ | $\frac{x^{n+1}}{n+1}+C$ |
| $e^x$ | $e^x+C$ |
| $1/x$ | $\ln|x|+C$ |

## 3. 数值积分（梯形法）

解析积分困难时，用数值逼近：

```python
import numpy as np
def f(x): return x**2
a, b, n = 0, 1, 1000
xs = np.linspace(a, b, n+1)
ys = f(xs)
area = (b-a)/n * (0.5*ys[0] + 0.5*ys[-1] + ys[1:-1].sum())
print(area)   # ≈ 0.3333 = 1/3
```

## 4. 偏导与梯度

多元函数 $f(x,y)$ 对某一变量的偏导，是「只让该变量变化」时的变化率：

$$
\frac{\partial f}{\partial x},\quad \frac{\partial f}{\partial y}
$$

梯度把所有偏导收进一个向量，指向函数上升最快的方向：

$$
\nabla f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}\right)
$$

```python
import numpy as np
def f(xy):
    x, y = xy
    return x**2 + y**2
# 数值梯度
eps = 1e-5
p = np.array([1.0, 2.0])
grad = np.array([(f(p+np.array([eps,0]))-f(p))/eps,
                 (f(p+np.array([0,eps]))-f(p))/eps])
print(grad)   # ≈ [2. 4.]
```

理解梯度，就理解了为什么模型能「沿着 downhill 方向」收敛到更优解。

## 易错点

- 定积分的上下限顺序影响符号：$\int_a^b = -\int_b^a$；面积公式里要确保 $b>a$。
- 不定积分别忘了加常数 $C$：它是「一族」原函数，不是单个。
- 偏导数只对「当前那一个变量」求导，其余变量当常数；混合偏导在连续条件下与次序无关。

## 练习

1. 用梯形法估算 $\int_0^1 e^{-x^2}\,dx$（取 $n=1000$）。
2. 对 $f(x,y)=x^2y+3y$，分别求 $\partial f/\partial x$ 与 $\partial f/\partial y$。
