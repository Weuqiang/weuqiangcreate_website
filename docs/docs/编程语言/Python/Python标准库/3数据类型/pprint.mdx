## 核心概念

`pprint` 美化打印嵌套结构：`pprint.pp` 自动换行缩进，`pformat` 返回字符串，`pp` 是更紧凑的快捷方式。关键参数 `width`（行宽）、`indent`（缩进）、`depth`（截断深度）、`sort_dicts`（是否排序键）。它是调试/日志工具，生产环境别打印超大结构（性能与可读性都差）。

## pprint 模块

`pprint` 模块用于美化打印复杂的 Python 数据结构，让嵌套的字典、列表等以层次清晰的格式输出。

### 基本使用

```python showLineNumbers
import pprint

data = {
    'name': 'Python项目',
    'config': {
        'debug': True,
        'database': {
            'host': 'localhost',
            'credentials': {'user': 'admin', 'password': '***'}
        }
    },
    'users': [
        {'id': 1, 'name': '张三', 'email': 'zhangsan@example.com'},
        {'id': 2, 'name': '李四', 'email': 'lisi@example.com'},
    ]
}

# print输出：单行显示，难以阅读
print(data)

# pprint.pp输出：结构化显示，层次清晰
pprint.pp(data)
```

### 核心函数

```python showLineNumbers
import pprint

data = {'z': 1, 'a': 2, 'b': [1, 2, 3], 'c': {'d': 4}}

# pp() - 推荐使用，默认不排序字典
pprint.pp(data, 
    width=40,        # 每行最多40字符
    indent=4,        # 缩进4个空格
    depth=2,         # 只显示2层
    compact=True,    # 紧凑模式
    sort_dicts=False # 保持字典插入顺序
)

# pformat() - 返回字符串而不是打印
formatted = pprint.pformat(data, indent=4)
with open('output.txt', 'w') as f:
    f.write(formatted)

# pprint() - 自动排序字典键
pprint.pprint(data)  # 输出: {'a': 2, 'b': [...], 'c': {...}, 'z': 1}
```

### 处理递归引用

```python showLineNumbers
import pprint

# 自引用列表
recursive_list = [1, 2, 3]
recursive_list.append(recursive_list)

pprint.pp(recursive_list)
# 输出: [1, 2, 3, <Recursion on list with id=...>]

# 检查是否可读/递归
print(pprint.isreadable(recursive_list))  # False
print(pprint.isrecursive(recursive_list))  # True
```

import requests
import pprint

response = requests.get('https://api.github.com/repos/python/cpython')

#### 日志记录

```python showLineNumbers
import logging
import pprint

logging.basicConfig(level=logging.DEBUG)

def process_order(order):
    logging.debug(f"订单:\n{pprint.pformat(order, indent=4)}")
    
order = {
    'id': '12345',
    'items': [{'name': '商品A', 'price': 99.9, 'qty': 2}],
    'customer': {'name': '张三', 'address': '北京市'}
}
process_order(order)
```

#### 配置可视化

```python showLineNumbers
import json
import pprint

with open('config.json') as f:
    config = json.load(f)

# 显示并保存格式化配置
pprint.pp(config, indent=4, sort_dicts=True)
with open('config_formatted.txt', 'w') as f:
    f.write(pprint.pformat(config, indent=4))
```

### PrettyPrinter类

重复使用相同配置时创建实例：

```python showLineNumbers
import pprint

pp = pprint.PrettyPrinter(indent=4, width=60, depth=3, compact=True)

data1 = {'name': 'Alice', 'scores': [95, 87, 92]}
data2 = {'name': 'Bob', 'scores': [88, 90, 85]}

pp.pprint(data1)
pp.pprint(data2)
```

### 性能与最佳实践

:::warning 性能考虑
- 适合：调试、开发环境、日志记录
- 避免：生产环境高频打印、超大数据结构
:::

```python showLineNumbers
import os
import pprint

# 仅开发环境使用pprint
if os.getenv('ENV') == 'development':
    pprint.pp(data)
else:
    logging.info(str(data))
```

## 易错点

- **`pp` 与 `pprint` 默认行为不同**：`pprint.pp()` 默认 `sort_dicts=False`（保持插入顺序），`pprint.pprint()` 默认 `sort_dicts=True`（按字母排序键）。需要稳定顺序时显式传参。
- **`pformat` 返回字符串**：要落盘或拼接日志用 `pformat`，不要 `pp` 之后再 `str()`。
- **超大结构用 `depth` 限制**：不设 `depth` 时深层嵌套会输出成"瀑布"，既慢又难读。
- **生产环境有成本**：pprint 要递归遍历并格式化，高频调用（如每条日志）会有性能开销；生产建议用 `str` 或采样。
- **它只美化、不改变数据**：`pp` 的返回值是 `None`，拿返回值当数据用会得到 `None`。

## 练习

1. 构造一个三层嵌套的 dict，分别用 `pprint.pp`（默认）和 `pprint.pprint` 打印，对比字典键顺序差异。
2. 用 `pformat` 把一个配置 dict 格式化后写入 `out.txt`，再读回来验证内容。
3. 故意制造一个自引用列表，用 `pprint.pp` 打印，观察递归标记；再用 `isrecursive` 判断。

## 示例

```python
import pprint

data = {"users": [{"id": 1, "name": "张三"}, {"id": 2, "name": "李四"}]}

pprint.pp(data, sort_dicts=False, width=40)
# 层次化、换行缩进显示，比 print 清晰得多

# 只拿字符串
text = pprint.pformat(data, depth=1)
```

## 小结

`pprint` 把嵌套结构层次化打印，是调试与日志的好帮手：`pp` 最常用，`pformat` 拿字符串，`width`/`indent`/`depth`/`sort_dicts` 控制形态。记住它是开发期工具，生产环境别打印超大结构。
