# CSS：学习路线图

如果说 HTML 是网页的**骨架**、JavaScript 是网页的**神经**，那 CSS 就是网页的**皮肤与体态**——它决定了同样一份 HTML，是长成一张 1995 年的纯文本文档，还是长成一个能用、好看、在手机上也不崩的现代界面。

CSS 的全称是 Cascading Style Sheets（层叠样式表）。名字里最重要的词是 **Cascading（层叠）**：CSS 不是"一条规则决定一个样式"，而是"许多来源的许多条规则，按一套确定的算法层层叠加、互相覆盖，最终算出一个值"。绝大多数"我明明写了样式却不生效"的困惑，根源都在没搞懂这个"层叠"。

## 学习目标（你会收获什么）

- 能**准确选中**页面上任意一个元素，而不是靠加 `class` 硬凑。
- 能解释"为什么我的样式没生效"——理解层叠、优先级与继承的计算规则。
- 能用 **Flexbox 和 Grid** 独立完成常见页面布局，不再依赖 `float` 和魔法数字。
- 能写出**响应式**页面：一套代码在手机、平板、桌面上都成立。
- 知道 CSS 在工程里怎么组织：变量、命名规范、预处理器与原子化方案各自解决什么问题。

## 前置知识

- 必须先掌握 [HTML](/docs/软件工程/Web前端/HTML/)：CSS 的作用对象是 HTML 元素，不懂结构就无法谈样式。
- **不需要** JavaScript 基础。CSS 是声明式语言，你描述"要什么样子"，浏览器负责"怎么做到"。
- 强烈建议边学边开浏览器开发者工具（F12），实时改样式看效果，比读十遍文档都有用。

## 推荐学习顺序

```text
intro（是什么、怎么引入）
   → selector（怎么选中元素）
   → cascade（为什么这条生效、那条不生效）
   → box-model（每个元素占多大地方）
   → 布局线：display-flow → position → flexbox → grid → responsive
   → 表现线：text → color-background → transition-animation
   → 工程线：variables → engineering
```

前四篇是**地基**，必须按顺序读完，否则后面的布局会变成"背口诀"。布局线与表现线相对独立，可以按需要跳读。

## 心智模型：CSS 是一台"计算样式"的机器

初学者常把 CSS 想成"我写一句，浏览器执行一句"。真实过程是一条流水线：

```text
① 收集所有规则（浏览器默认样式 + 你的样式表 + 行内样式）
② 对每个元素、每个属性，找出所有能命中它的声明
③ 按「层叠算法」排序（来源 → !important → 优先级 → 书写顺序），选出赢家
④ 没有任何声明命中的属性，走「继承」或「初始值」
⑤ 把相对值（em、%、auto）解析成绝对值 → 得到「计算值」
⑥ 按盒模型和布局算法，算出每个盒子的位置与尺寸 → 绘制
```

记住这条流水线，你会发现绝大多数 CSS 疑难杂症都能定位到某一步：选不中是 ②，被覆盖是 ③，值不对是 ⑤，位置不对是 ⑥。

## 学习建议

CSS 的难点不在语法——它的语法半小时就能学完。难点在于**它是一个约束求解系统**：你给出一堆约束（这个宽 50%、那个居中、总宽不能超过屏幕），浏览器求解出一个布局。当结果不符合预期时，你要能反推是哪条约束在起作用。

所以最有效的学法是：**在开发者工具里改**。选中元素，看 Computed 面板里每个属性的最终值和它来自哪条规则，看 Layout 面板里盒模型的实际尺寸。看十遍不如改一遍。
