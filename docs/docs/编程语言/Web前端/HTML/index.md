# HTML：学习路线图

HTML 是网页的"结构层"，也是所有前端技术的起点。本目录覆盖从**文档骨架**到**语义标签**、**文本与多媒体**、**表单与链接**、**编码与移动适配**的完整内容。

> 本目录内容翻译整理自 [wangdoc.com HTML 教程](https://wangdoc.com/html/)，向原作者致谢。

## 学习目标（你会收获什么）

- 能独立写出**语义正确、可访问**的网页骨架，而不是一堆 `<div>`。
- 会用**表单**收集数据、用**链接**串联页面，理解前后端交互的入口。
- 理解**字符编码**与**移动端适配**的基础，避免中文乱码和手机上"字很小"的问题。
- 知道下一步该学什么：样式交给 CSS，交互交给 [JavaScript](../JavaScript/)。

## 前置知识

- 一台装了浏览器的电脑；**无需任何编程基础**即可开始。
- 建议边学边用浏览器"查看网页源代码"，对照理解标签的嵌套关系。

## 推荐学习顺序

```text
intro（是什么） → 结构 / 语义 → 文本与多媒体 → 表单与链接 → 编码 / 移动 / 进阶
```

## 学习建议

HTML 不难，难在"写语义正确的结构"。拿到一个页面，先想清楚 `<header>` / `<main>` / `<article>` / `<footer>` 怎么摆，再填内容；表单是前后端交互的入口，务必搞懂 `name`、`method`、`action` 三件套。多对照浏览器"查看网页源代码"理解标签的嵌套关系。
