# 张量基础

## 学习目标

- 用「轴（维度）的个数」而非「维度大小」来理解张量的阶（阶 = 轴数）
- 看清常见数据的张量形状：向量(1 阶)、矩阵(2 阶)、彩色图(3 阶)、图像批(4 阶)
- 掌握爱因斯坦求和约定 `einsum`，用一套记号表达转置、点积、卷积、张量缩并
- 理解广播（broadcasting）与轴变换（转置/reshape）在框架里如何运作

## 前置知识

- [向量空间与基](/docs/数学基础/线性代数/向量空间与基) —— 向量/矩阵是 1/2 阶张量
- [矩阵与线性方程组](/docs/数学基础/线性代数/矩阵与线性方程组) —— 张量运算是矩阵运算的推广

## 核心概念

### 1. 张量 = 多维数组，阶 = 轴数

标量（0 阶）、向量（1 阶，$(n,)$）、矩阵（2 阶，$(m,n)$）、三维数组（3 阶，$(c,h,w)$）都是张量。**张量的「阶/阶数」指的是轴（axis）的个数**，不是某个轴的长度。深度学习里说「4 维张量」通常指形状 $(B,C,H,W)$ 的批图像，有 4 个轴。

### 2. 形状与轴的语义

以一张 $224\times224$ 的 RGB 图为例：
- 若不批处理：`(3, 224, 224)` —— 轴 0 是通道、轴 1 是高、轴 2 是宽
- 若批 32 张：`(32, 3, 224, 224)` —— 轴 0 是 batch

轴顺序约定很重要：PyTorch 用 `NCHW`，TensorFlow 常用 `NHWC`。同一数据不同排布，做卷积时轴向索引完全不同，**这是框架间迁移最常见的 bug 来源**。

### 3. 爱因斯坦求和 einsum

爱因斯坦求和约定：重复的下标表示在该轴上求和。几个例子（用 `numpy.einsum` 记号）：

- 矩阵乘法 $C_{ik}=A_{ij}B_{jk}$：`'ij,jk->ik'`
- 点积 $c=\sum_i a_i b_i$：`'i,i->'`
- 转置 $B_{ji}=A_{ij}$：`'ij->ji'`
- 批量矩阵乘：`'bij,bjk->bik'`
- 双线性/张量缩并：`'ijk,jkl->il'`

一套 `einsum` 记号覆盖了绝大多数线性代数与神经网络里的缩并操作，可读性高且不易写错轴。

### 4. 广播与轴变换

**广播**：形状不同的数组按「从右对齐、长度为 1 的轴可拉伸」规则自动扩展，例如 $(3,)$ 与 $(4,3)$ 相加会把向量沿轴 0 复制 4 次。误用广播（轴没对齐）会产生「悄悄算错、不报错」的 bug。

**轴变换**：`transpose`/`reshape`/`squeeze` 改变轴的排列或合并/拆分轴，但不改元素总数。`reshape` 要求新形状元素数守恒；`transpose` 只换轴序、内存未必连续（框架会惰性处理）。

### 5. 张量在深度学习里的角色

- 权重：全连接层 $W\in\mathbb{R}^{out\times in}$（2 阶），卷积核 $(C_{out},C_{in},k_h,k_w)$（4 阶）
- 激活/特征图：$(B,C,H,W)$（4 阶）
- 注意力：$Q,K,V\in\mathbb{R}^{B,H,S,D}$，注意力分数 $(B,H,S,S)$（4 阶）
- 批次归一化统计：每通道的均值/方差 $(C,)$（1 阶）

理解张量形状，是读懂任何模型「数据怎么流」的前提。

## 示例

用 `einsum` 重写几个常见操作，体会一套记号的通吃：

```python
import numpy as np

A = np.random.randn(3, 4)
B = np.random.randn(4, 5)
x = np.random.randn(4)
img = np.random.randn(2, 3, 8, 8)   # 2 张 3 通道 8x8 图

# 1) 矩阵乘
C = np.einsum('ij,jk->ik', A, B)
assert np.allclose(C, A @ B)

# 2) 点积
d = np.einsum('i,i->', x, x)
assert np.allclose(d, x @ x)

# 3) 沿通道求平均：(b,c,h,w) -> (b,h,w)
mean_ch = np.einsum('bchw->bhw', img)

# 4) 批量矩阵乘：(b,i,j),(b,j,k) -> (b,i,k)
X = np.random.randn(2, 3, 4)
Y = np.random.randn(2, 4, 5)
Z = np.einsum('bij,bjk->bik', X, Y)

print("C shape", C.shape, "dot", round(d, 3),
      "mean_ch shape", mean_ch.shape, "Z shape", Z.shape)
```

## 易错点

- **混淆「阶」与「维度」**：说「3 维张量」要分清是指 3 个轴，还是轴长恰为 3。
- **轴顺序假设错误**：NCHW 与 NHWC 混用会让卷积/池化作用在错误轴上，结果数值不对但不报错。
- **reshape 破坏语义**：把 $(B,C,H,W)$ 直接 `reshape(B, C*H*W)` 会按内存序拼接，若后续要恢复空间结构必须记清原轴序；`view`/`reshape` 前后语义不一致是常见隐患。
- **广播 silently 出错**：长度不同的非 1 轴不能广播，但 `(1,n)` 与 `(m,1)` 相加会得到 $(m,n)$，若本意是逐行/逐列操作却写反，结果形状对、数值错。

## 练习

1. 用 `einsum` 写出「矩阵 $A$ 的迹 $\mathrm{tr}(A)$」与「Frobenius 范数平方 $\|A\|_F^2$」。
2. 一张灰度图（无通道）批 16 张、尺寸 $28\times28$，它的张量形状是什么？若错误地按 `(B,H,W,C)` 排布并送进期望 `NCHW` 的层，会发生什么？
3. 卷积核形状 $(64,3,3,3)$ 中每个数字分别代表什么轴？

## 小结

张量是多维数组，阶数即轴数；轴顺序约定（NCHW/NHWC）与广播规则是框架实战的两大陷阱。爱因斯坦求和用一套下标记号统一了转置、点积、批乘与缩并，是读懂深度学习数据流的利器。
