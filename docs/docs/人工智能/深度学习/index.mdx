title: 深度学习
---

深度学习是一类以多层神经网络为核心、靠大量数据自动学习层次化表示的机器学习方法。它在视觉、语音、自然语言等感知与序列任务上取得了突破性进展。

本分类涵盖从基础网络结构到典型应用的主线：

- **经典神经网络**：感知机、全连接网络、激活函数、反向传播与训练技巧。
- **网格数据**：面向图像等规则网格的卷积神经网络（CNN）及其演进。
- **序列处理**：面向时序与文本的 RNN/LSTM、Transformer、Vision Transformer 与多模态模型。
