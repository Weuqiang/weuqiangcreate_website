## 核心概念

### 1. 为什么给网络加先验

标准 NN 只给点估计 $w^*$，无法表达「我不确定」。贝叶斯视角下对权重设先验 $p(w)$，用训练数据得后验 $p(w\mid D)$，预测时对权重积分：

$$
p(y^*\mid x^*)=\int p(y^*\mid x^*,w)\,p(w\mid D)\,dw
$$

输出天然带不确定性，对分布外输入更保守——安全关键应用必需。

### 2. 实用近似

- **MC Dropout**：训练时 dropout，推理时多次 dropout 前向取统计，近似贝叶斯集成（几乎是「免费」的）；
- **深度集成（Deep Ensemble）**：训多个随机初始化网络，预测聚合；强但贵；
- 这两者在很多基准上胜过更复杂的 BNN。

### 3. 贝叶斯神经网络（BNN）与变分推断

显式对每层权重设分布 $q_\theta(w)\approx p(w\mid D)$，用 ELBO 训练：

$$
\text{ELBO}=\mathbb{E}_{q_\theta}[\log p(D\mid w)]-\mathrm{KL}\big(q_\theta(w)\,\|\,p(w)\big)
$$

把权重用对角 / 低秩高斯近似，可微训练。代价是近似误差与额外参数。

### 4. Laplace 近似与模型选择

训练后在 $w^*$ 对对数后验做二阶泰勒（海森），用高斯近似后验；可用于快速不确定性估计与边际似然近似（模型选择）。

## 示例

MC Dropout 推理的不确定性估计（示意）：

```python
import numpy as np
np.random.seed(0)
T = 20
# 同一输入做 T 次带 dropout 的前向，不同输出维的不确定性不一
samples = np.random.randn(T, 5) * np.array([0.2, 1.5, 0.4, 2.0, 0.3])
mean, std = samples.mean(0), samples.std(0)
print("预测均值:", np.round(mean, 3))
print("预测不确定性(σ):", np.round(std, 3))
```

## 易错点

- **以为「单点预测 + dropout」就是贝叶斯**：需多次前向取分布。
- **忽视深度集成的强基线地位**：复杂 BNN 未必更优。
- **在 BNN 里用过于简单的权重先验**（如各向同性），忽略尺度。
- **把 epistemic（模型）与 aleatoric（数据）不确定性混为一谈**。

## 小结

贝叶斯深度学习把神经网络的「点估计权重」升级为「权重分布」：MC Dropout 与深度集成是性价比极高的实用近似，BNN + 变分推断给出端到端贝叶斯基元，Laplace 近似便于快速不确定性估计。它是安全关键 AI 与主动学习的不确定性基础。
