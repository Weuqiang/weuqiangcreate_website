# 开发知识库：总览

欢迎来到「开发」知识库。这里把一名现代开发者需要的知识，按**先打地基、再学语言、后做系统**的顺序，组织成六条彼此衔接的线。无论你是转行入门、复习补课，还是查漏补缺，都能从这里找到清晰的学习路径。

> 使用建议：每条线都配有「学习路线图」首页（点进分类即可看到），文章统一采用「学习目标 → 核心直觉 → 最小示例 → 易错点 → 练习 → 小结 → 延伸阅读」的教程模板，力求**一看就懂、一学就会**。

## 六大方向

| 方向 | 解决什么问题 | 路线图 |
|---|---|---|
| 编程外的基础 | 语言之外的通用底盘：计算机科学导论、数据结构与算法、开发工具链 | [进入](./编程外的基础/) |
| 数学基础 | AI 与算法的底层语言：线性代数、微积分、概率统计、离散数学 | [进入](./数学基础/) |
| 编程语言 | 多语言横向对比与选型：Python / C / Web 前端 / Java / Go / Rust | [进入](./编程语言/) |
| 人工智能 | 从机器学习、深度学习到大模型（LLM）与应用 | [进入](./人工智能/) |
| 软件工程与后端 | 后端通识与工程实践：网络、数据库、API、架构、CI/CD、测试 | [进入](./软件工程与后端/) |
| 嵌入式开发 | 硬件电路、单片机、RTOS 与嵌入式固件 | [进入](./嵌入式开发/) |

## 推荐阅读顺序

```text
编程外的基础（全局地图）
   ├─ 数学基础（底层语言）
   ├─ 编程语言（动手工具）
   ├─ 软件工程与后端（做系统）
   ├─ 嵌入式开发（软硬结合，可选）
   └─ 人工智能（建立在上述之上）
```

想直接开始？从 [编程外的基础](./编程外的基础/) 建立全局心智模型，再挑一门主力语言深入。每条线的首页都列出了「已建内容」与「待补充清单」，方便你对照查漏。
