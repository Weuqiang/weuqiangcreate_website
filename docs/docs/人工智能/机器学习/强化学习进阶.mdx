## 核心概念

### 1. 函数逼近：从表格到网络

状态 / 动作空间巨大时，$Q(s,a)$ 无法用表存。DQN 用神经网络 $Q_\theta(s,a)$ 近似，关键技巧：

- **经验回放（replay buffer）**：打破时序相关、提升样本效率；
- **目标网络（target net）**：缓慢更新的 $Q$ 目标，稳定自举（bootstrapping）训练。

### 2. 策略梯度定理

直接优化策略 $\pi_\theta(a\mid s)$，目标是期望回报 $J(\theta)=\mathbb{E}[R]$。策略梯度定理给出：

$$
\nabla_\theta J = \mathbb{E}\big[\nabla_\theta\log\pi_\theta(a\mid s)\cdot A(s,a)\big]
$$

其中 $A$ 是优势函数（动作价值减基线）。REINFORCE 用蒙特卡洛回报做 $A$ 的无偏估计，但方差大。

### 3. Actor-Critic

用 critic（值函数 $V$ 或 $Q$）估计 $A$ 代替蒙特卡洛，降低方差；actor 沿策略梯度更新。它是众多深度 RL 算法的骨架。

### 4. PPO

TRPO 用信赖域约束策略更新幅度；PPO 用裁剪代理目标简化实现：

$$
L^{\text{CLIP}}=\mathbb{E}\big[\min(r_t A_t,\;\text{clip}(r_t,1-\varepsilon,1+\varepsilon)A_t)\big],\quad r_t=\frac{\pi_\theta}{\pi_{\text{old}}}
$$

约束新策略不偏离旧策略太远，兼顾稳定与样本效率，是 RLHF 的主力优化器。

### 5. 离线 RL 与分布偏移

离线 RL 只用固定数据集训练，面临「分布外动作」高估（extrapolation error）。方法如 CQL 约束 $Q$ 值、BCQ 限制动作选择接近数据分布。

## 示例

用 numpy 实现策略梯度的核心（REINFORCE 思路，带基线）：

```python
import numpy as np

# 假设在轨迹里采样到：每步回报 r，策略对数概率 logp
np.random.seed(0)
returns = np.array([1.0, 0.5, -0.5, 2.0, 0.0])      # 折扣后回报（示意）
logp = np.array([-0.3, -0.2, -0.5, -0.1, -0.4])    # 各步策略对数概率
baseline = returns.mean()                           # 简单基线降低方差
adv = returns - baseline
policy_grad = -(logp * adv).mean()                   # 梯度上升取负
print("策略梯度（示意）:", round(float(policy_grad), 4))
print("优势项:", np.round(adv, 3))
```

## 易错点

- **策略梯度里漏掉基线**：方差大、收敛慢。
- **把 on-policy 数据用于多轮更新**：PPO/REINFORCE 的旧数据会失效。
- **DQN 不用目标网络 / 回放**：训练震荡发散。
- **离线 RL 不做分布约束**：OOD 动作价值被高估，策略崩坏。

## 小结

深度强化学习把「表格方法」升级为函数逼近：DQN 用网络 + 回放 + 目标网络处理离散动作，策略梯度 / Actor-Critic / PPO 直接优化参数化策略并兼顾稳定，离线 RL 解决固定数据集的分布偏移。它是游戏 AI、机器人、以及大模型对齐（RLHF）的核心引擎。
