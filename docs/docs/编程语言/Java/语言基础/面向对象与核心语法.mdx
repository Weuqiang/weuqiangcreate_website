# 面向对象与核心语法

在 [Java 语言入门](../Java语言入门) 之后，本篇梳理 Java 面向对象（OOP）的核心语法：类、接口、继承、多态、泛型与异常。它们是你读懂 90% 业务代码的基础。

## 学习目标

- 用 `private`/构造器/getter 实现封装；
- 用 `extends`/`implements` 与 `@Override` 实现继承与多态；
- 用泛型获得编译期类型安全，用 `try/catch` 处理异常。

## 前置知识

- 已完成 [Java 语言入门](../Java语言入门)；
- 想对比"所有权 vs 引用"可看 [Rust 语言入门](../../../Rust/所有权/Rust语言入门)。

## 1. 类与对象

```java
public class User {
    private String name;          // 封装：私有字段
    public User(String name) { this.name = name; }
    public String getName() { return name; }
}
User u = new User("Ada");         // 实例化，u 持有堆上对象的引用
```

- `private` 隐藏内部细节，`getter/setter` 暴露受控访问。
- `new` 在堆上创建对象，变量持有的是**引用**（类似指针，但 JVM 管理生命周期）。

## 2. 继承与多态

```java
abstract class Shape {
    abstract double area();       // 抽象方法，无实现
}
class Circle extends Shape {
    double r;
    Circle(double r) { this.r = r; }
    @Override double area() { return Math.PI * r * r; }
}
```

- 单继承：`extends` 复用父类；`implements` 可实现多个接口。
- 多态：父类引用指向子类对象，运行时调用实际类型的方法（动态绑定）。

## 3. 接口与默认方法

```java
interface Comparable<T> {
    int compareTo(T o);
    default boolean eq(T o) { return compareTo(o) == 0; }  // Java 8+ 默认方法
}
```

接口只定义契约；`default` 方法让接口演进时不用破坏已有实现。

## 4. 泛型

泛型提供编译期类型安全，避免强制转换：

```java
List<String> list = new ArrayList<>();
list.add("hi");
String s = list.get(0);           // 无需 (String) 强转
```

## 5. 异常处理

```java
try {
    int x = 1 / 0;
} catch (ArithmeticException e) {
    System.out.println("除零：" + e.getMessage());
} finally {
    System.out.println("总是执行");
}
```

- 受检异常（`IOException`）必须 `try/catch` 或声明 `throws`；运行时异常（`RuntimeException`）可不捕获，但最好处理。

## 易错点

- `Integer` 等包装类型用 `==` 比引用、`equals` 比值；集合中判等务必用 `equals`。
- 重写（`@Override`）方法时，访问修饰符不能比父类更严格（否则编译报错）。
- 泛型不支持基本类型：`List<int>` 非法，要用 `List<Integer>`。
