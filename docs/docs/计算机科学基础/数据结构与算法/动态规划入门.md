# 动态规划入门

动态规划（DP）是把「分治」推到极致：当子问题**大量重复**且整体有**最优子结构**时，用一张表把每个子问题的答案存起来，避免重复计算。它把指数级暴力压成多项式级。

## 学习目标

- 判断一个问题是否适合 DP（重叠子问题 + 最优子结构）。
- 用「状态定义 + 转移方程 + 边界」三步建模。
- 写出自顶向下（备忘录）与自底向上（DP 表）两种实现。

## 前置知识

- [递归与分治](../递归与分治) — DP 是带记忆的分治。
- [哈希表](../哈希表) — 备忘录本质是个缓存。
- [数组与链表](../数组与链表) — DP 表常用数组存。

## 核心概念

### 1. 两大特征

- **重叠子问题**：递归时会反复计算同一个子问题（如斐波那契）。
- **最优子结构**：大问题的最优解由小问题的最优解组成。

两者都满足，才适合 DP。

### 2. 建模三步

1. **定义状态** `dp[i]` 表示「什么到 i 为止的最优值」。
2. **写转移方程**：`dp[i]` 如何用更小的 `dp` 推出。
3. **定边界**：最小子问题的值。

### 3. 两种写法

- **自顶向下（备忘录）**：从原问题递归，用哈希/数组缓存已算结果。代码直观。
- **自底向上（DP 表）**：从最小子问题递推到原问题，通常更省栈、更快。

## 最小可运行示例

0-1 背包（n 件物品，背包容量 W，求最大价值）：

```python
def knapsack(W, weights, values):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(W + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w],
                               dp[i-1][w-weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]
```

最长递增子序列（LIS，经典一维 DP）：

```python
def lis(a):
    if not a: return 0
    dp = [1] * len(a)                 # dp[i]: 以 a[i] 结尾的 LIS 长度
    for i in range(len(a)):
        for j in range(i):
            if a[j] < a[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

## 易错点

1. **状态定义不清**：先能用一句话说清 `dp[i]` 的含义，再写转移。
2. **边界漏设**：最小子问题（如 `dp[0]`）必须初始化，否则全错。
3. **维度数错**：二维 DP 注意 `i/j` 与「选/不选」的对应，别写反索引。
4. **空间可优化却写复杂**：很多一维 DP 只需滚动数组（如背包压到 `O(W)`），初学先写完整表再优化。

## 练习

1. 爬楼梯（每次 1 或 2 步）用 DP 而非递归备忘录。
2. 最长公共子序列（LCS，二维 DP 经典）。
3. 零钱兑换：用最少硬币凑出 amount（完全背包变形）。

## 小结

DP = 分治 + 记忆 + 状态建模。口诀：「定义状态 → 写转移 → 定边界」。新手从备忘录写法入手最稳，熟练后改自底向上省栈。它是算法面试的高频考点，也是 [图与遍历](../图与遍历)、[哈希表](../哈希表) 之外必须掌握的武器。
