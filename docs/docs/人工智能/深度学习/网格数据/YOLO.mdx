YOLO（You Only Look Once）把**目标检测**变成一次前向推理：给定一张图，直接输出所有物体的框和类别。它利用 CNN 的特征提取能力识别图像中的物体，是应用最广泛的实时检测框架。

:::info
YOLO 与 PyTorch 的区别
- **PyTorch 是工具箱**：提供张量、自动求导、网络层、优化器等“零件”，让你自己搭模型。
- **YOLO 是成品**：一个已经设计好、训练好的检测模型，用 PyTorch 的零件组合而成，专门做“目标检测”。
:::

## 核心思想

把图像划分成 S×S 网格，每个格子负责预测落在其内的物体：

- 每个格子预测 **B 个边界框**（x, y, w, h, 置信度）；
- 同时预测 **C 个类别概率**；
- 一次前向就得到全图所有检测结果 → 极快（视频实时）。

```text
输入图 ──► CNN 主干(Backbone, 如 ResNet) ──► 特征图
        ──► 每个格子预测 (框 + 置信度 + 类别) ──► NMS 去重 ──► 最终结果
```

## 与两阶段检测对比

- **两阶段（R-CNN / Fast R-CNN / Faster R-CNN）**：先提候选框，再分类。精度高但慢。
- **YOLO（单阶段）**：一步到位。速度快、易部署，对小物体和密集场景稍弱。
- **演进**：v1→v8 / v10 / v11（Ultralytics），从 anchor-based 走向 anchor-free，越来越小又快。

## 最小可运行示例（推理）

```python
from ultralytics import YOLO

model = YOLO("yolov8n.pt")                 # 加载预训练模型
results = model("street.jpg")              # 一次前向出结果
for r in results:
    print(r.boxes.xyxy, r.boxes.cls, r.boxes.conf)  # 框坐标 / 类别 / 置信度
```

## 常见误区

- **框太多要 NMS**：同一物体会被多个格子预测，需用非极大值抑制（NMS）去重。
- **小物体难检**：一个格子只负责有限框，密集小目标容易漏；可用更高分辨率或专门的小目标模型。
- **直接拿训练集指标当真实精度**：检测要用 mAP，且要在验证集 / 测试集上评估。
