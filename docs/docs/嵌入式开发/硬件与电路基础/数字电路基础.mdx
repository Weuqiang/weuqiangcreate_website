# 数字电路基础

单片机只认「0 和 1」。理解数字电路，才能看懂 MCU 为什么能控制现实世界。

## 1. 电平与逻辑

数字电路用**电压区间**表示逻辑：

- TTL 电平：`0V~0.8V` 为逻辑 0，`2.0V~5V` 为逻辑 1（5V 系统）。
- 3.3V 系统：高电平约 3.3V。

> 注意电平匹配：用 5V 单片机直接驱动 3.3V 器件可能烧毁后者，需要电平转换。

## 2. 基本逻辑门

| 门 | 功能 | 真值（A,B→Y） |
|----|------|---------------|
| 与 AND | 全 1 才 1 | 0,0→0；1,1→1 |
| 或 OR | 有 1 则 1 | 0,0→0；1,0→1 |
| 非 NOT | 取反 | 0→1；1→0 |
| 异或 XOR | 不同为 1 | 1,0→1；1,1→0 |

## 3. 组合逻辑 vs 时序逻辑

- **组合逻辑**：输出只取决于当前输入（如加法器、译码器）。
- **时序逻辑**：输出还依赖「历史状态」，靠**触发器（Flip-Flop）**记忆（如寄存器、计数器）。

`D 触发器`：时钟上升沿把输入 D 锁存到输出 Q，是寄存器的基本单元。

## 4. 用软件感知「数字逻辑」

GPIO 读到的就是逻辑 0/1：

```cpp
// Arduino：读按键（按下为 LOW，因内部上拉）
pinMode(2, INPUT_PULLUP);
int pressed = digitalRead(2) == LOW;
```

理解门电路，有助于看懂数据手册里的「真值表」与「时序图」。

## 易错点

- **电平不匹配会烧芯片**：5V 输出直连 3.3V 输入可能超限，需要电平转换或分压。
- **"逻辑 1"是区间不是定值**：TTL 与 CMOS 阈值不同，混用时看数据手册的 $V_{IH}/V_{IL}$。
- **组合与时序别混淆**：组合逻辑无记忆、时序逻辑靠时钟锁存；代码里的状态机正对应时序逻辑。

## 练习

1. 用与门、或门、非门搭一个"异或"电路（写出表达式并验证逻辑）。
2. Arduino 读按键用 `INPUT_PULLUP`：为什么松开时是 HIGH、按下是 LOW？画一下电路。
