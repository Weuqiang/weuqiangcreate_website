极限与导数

微积分研究「变化」：导数描述瞬时变化率，积分描述累积量。本篇先建立极限与导数的直观，下一篇再讲积分。

1. 极限：逼近的思想​

极限描述「当 xxx 无限接近 aaa 时，f(x)f(x)f(x) 趋向的值」。

3. 为什么重要：梯度下降​

机器学习的核心优化算法梯度下降，就是对损失函数 L(θ)L(\theta)L(θ) 求梯度 ∇L\nabla L∇L，沿反方向更新参数：

θ←θ−η∇L(θ)\theta \leftarrow \theta - \eta \nabla L(\theta)θ←θ−η∇L(θ)

其中 η\etaη 是学习率。导数告诉我们「往哪走能让损失下降最快」。

import numpy as np
# 最小化 f(x) = x^2，解析梯度为 2x
x = 5.0
lr = 0.1
for _ in range(50):
    x = x - lr * 2 * x
print(x)   # 趋近于 0

4. 链式法则​
