# 集合框架

Java 集合框架（Java Collections Framework）统一了容器操作，几乎所有业务代码都在用它。本篇从整体结构讲到 `HashMap` 原理与并发集合。

## 学习目标

- 说清 `List`/`Set`/`Queue`/`Map` 的分工与常见实现；
- 理解 `ArrayList` vs `LinkedList`、`HashMap` 的取舍；
- 知道单线程与多线程下分别该用什么容器。

## 前置知识

- 已掌握 [面向对象与核心语法](../../语言基础/面向对象与核心语法) 的泛型；
- 下文涉及的内存回收背景见 [JVM 内存模型与 GC](../../JVM/JVM内存模型与GC)。

## 核心概念

集合框架以接口分层：`Collection` 下分 `List`（有序可重复）、`Set`（无序唯一）、`Queue`（队列）；`Map` 独立存放键值对。实现选择：随机访问多用 `ArrayList`、头尾频繁增删用 `LinkedList`、哈希查找用 `HashMap`、需要有序键用 `TreeMap`。迭代时结构被修改会抛 `ConcurrentModificationException`（fail-fast）。

本章主线：
- 集合体系：Collection 与 Map
- List：ArrayList vs LinkedList
- Set：HashSet / TreeSet
- Map：HashMap / TreeMap / ConcurrentHashMap
- fail-fast 与并发修改

## 1. 整体结构

```text
Collection                Map
├─ List (有序可重复)       ├─ HashMap (键值, 快)
│   ├─ ArrayList           ├─ LinkedHashMap (保序)
│   └─ LinkedList          ├─ TreeMap (按 key 排序)
├─ Set (不可重复)          └─ Hashtable (线程安全, 老旧)
│   ├─ HashSet
│   └─ TreeSet
└─ Queue
    └─ PriorityQueue
```

## 2. List：ArrayList vs LinkedList

```java
List<String> a = new ArrayList<>();   // 底层数组，随机访问 O(1)，尾部增删快
List<String> l = new LinkedList<>();  // 双向链表，头尾增删 O(1)，随机访问慢
```

| 操作 | ArrayList | LinkedList |
|------|-----------|------------|
| `get(i)` | O(1) | O(n) |
| 头插 | O(n) | O(1) |
| 尾插 | O(1)* | O(1) |

\* ArrayList 扩容时偶发 O(n)。

## 3. Map：HashMap 原理

```java
Map<String, Integer> m = new HashMap<>();
m.put("a", 1);
Integer v = m.get("a");     // O(1) 平均
```

- JDK 8 的 `HashMap`：数组 + 链表/红黑树；冲突超阈值（8）链表转红黑树。
- key 的 `hashCode()` 决定桶位置，`equals()` 判断相等。

## 4. Set 与 Queue

```java
Set<Integer> s = new HashSet<>();   // 基于 HashMap，自动去重
s.add(1); s.add(1);                  // 只有一个 1

Queue<Integer> q = new LinkedList<>();
q.offer(1); int x = q.poll();        // 入队/出队（FIFO）
```

## 5. 工具类 Collections / Arrays

```java
Collections.sort(list);              // 排序
Collections.unmodifiableList(list);  // 不可变视图
Arrays.asList("a", "b");             // 数组转 List
```

## 6. 线程安全与并发集合

单线程用 `HashMap`/`ArrayList` 即可；多线程共享时它们**非线程安全**，需换并发容器或加锁：

```java
import java.util.concurrent.*;

// 高并发 Map：桶级锁 / CAS，读多写少场景远快于 synchronizedMap
ConcurrentHashMap<String, Integer> cmap = new ConcurrentHashMap<>();
cmap.put("a", 1);
cmap.compute("a", (k, v) -> v + 1);   // 原子更新

// 线程安全 List / Queue
List<String> safe = new CopyOnWriteArrayList<>();
Queue<Integer> q2 = new ConcurrentLinkedQueue<>();
```

`Collections.synchronizedList/Map/Set` 也能加锁，但粒度粗、并发度低，一般让位给 `java.util.concurrent` 容器。

## 7. 不可变集合（Java 9+）

`List.of` / `Set.of` / `Map.of` 创建不可变集合，写操作会抛 `UnsupportedOperationException`，适合配置、常量：

```java
List<String> consts = List.of("a", "b", "c");
Map<String, Integer> m2 = Map.of("x", 1, "y", 2);
```

## 小结

集合框架按“接口—实现”分层；选型看访问模式（随机/顺序/查找/有序）。并发场景优先选并发容器，避免边遍历边修改触发 fail-fast。

## 易错点

- `HashMap` 的 key 必须正确覆写 `hashCode()` 与 `equals()`；用可变对象做 key 会导致后续查不到。
- 遍历集合时**不能直接增删**原集合（抛 `ConcurrentModificationException`）；要删除请用 `Iterator.remove()` 或 `removeIf`。
- `Integer` 等包装类型做 `==` 比较的是引用而非值，集合里判等要用 `equals`。
- `TreeMap`/`TreeSet` 要求元素可比较（实现 `Comparable` 或提供 `Comparator`），否则插入即抛 `ClassCastException`。
