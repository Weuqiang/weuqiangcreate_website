# 数据结构与算法

数据结构是**数据的组织方式**，算法是**操作数据的步骤**。两者共同决定程序"快不快、省不省"。

## 复杂度：衡量好坏的尺子

用大 O 表示法描述随数据规模 $n$ 增长的趋势：

| 复杂度 | 含义 | 例子 |
|--------|------|------|
| $O(1)$ | 常数 | 数组按下标访问 |
| $O(\log n)$ | 对数 | 二分查找 |
| $O(n)$ | 线性 | 遍历数组 |
| $O(n \log n)$ | 线性对数 | 归并/快速排序 |
| $O(n^2)$ | 平方 | 冒泡排序 |

## 本栏目结构

- **线性结构**：数组、链表、栈、队列。
- **树与图**：二叉树、堆、BST 与图的遍历。
- **排序与查找**：快排/归并、二分与哈希查找。
- **高级算法**：递归、回溯、贪心与动态规划。

> 一个例子：用哈希表去重 `set()` 平均 $O(1)$，比双重循环 $O(n^2)$ 高效得多。
