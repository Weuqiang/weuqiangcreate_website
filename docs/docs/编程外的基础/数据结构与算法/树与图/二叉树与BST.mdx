# 二叉树与二叉搜索树

树是非线性结构，二叉树每个节点最多两个子节点。本篇讲遍历与二叉搜索树（BST）。

## 1. 二叉树

```python
class TreeNode:
    def __init__(self, v):
        self.v = v
        self.left = None
        self.right = None
```

## 2. 遍历

| 遍历 | 顺序 | 应用 |
|------|------|------|
| 前序 | 根→左→右 | 复制树、表达式树 |
| 中序 | 左→根→右 | BST 得有序序列 |
| 后序 | 左→右→根 | 释放节点、求树高 |
| 层序 | 逐层 | BFS，用队列 |

```python
def inorder(n):
    if n:
        inorder(n.left)
        print(n.v)
        inorder(n.right)
```

## 3. 二叉搜索树（BST）

- 左子树所有值小于根，右子树所有值大于根；
- 中序遍历得到升序序列；
- 查找/插入/删除平均 $O(\log n)$（树高）。

```python
def search(n, key):
    while n:
        if key == n.v: return n
        n = n.left if key < n.v else n.right
    return None
```

## 4. 退化问题与平衡

若插入有序数据，BST 退化成链表，查找退化为 $O(n)$。解决：

- **AVL 树**：严格平衡（左右子树高差 ≤ 1），查找稳定 $O(\log n)$；
- **红黑树**：近似平衡，插入删除代价更低，C++ `map`、Java `TreeMap` 用；
- **替罪羊树 / B 树**：数据库索引常用 B+ 树（多路平衡）。

## 5. 与哈希表的取舍

| | BST | 哈希表 |
|---|------|--------|
| 查找 | $O(\log n)$ | $O(1)$ 平均 |
| 有序遍历 | 支持 | 不支持 |
| 范围查询 | 支持 | 不支持 |

需要"有序/范围"用 BST 系，纯点查用哈希。
