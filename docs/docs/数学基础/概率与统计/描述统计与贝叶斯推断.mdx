# 描述统计与贝叶斯推断

上篇建立了概率与分布的基础。本篇落到工程常用两手：**描述统计**（汇总数据）与**贝叶斯推断**（用数据更新信念）。

## 学习目标

学完本章，你应该能够：

- 说清均值、中位数、方差分别刻画分布的什么。
- 区分相关与因果，警惕辛普森悖论。
- 用贝叶斯公式把先验与似然合成后验。
- 理解共轭先验为何让计算变简单。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [概率基础与随机变量](/docs/数学基础/概率与统计/概率基础与随机变量) 中的分布与期望。
- 知道均值、方差的直观。
- 能接受「先验 + 数据 = 后验」的更新框架。

## 核心概念

描述统计先把一堆杂乱数据压缩成几个有意义的数字——均值说中心、方差说散布、相关系数说两件事是否一起变（但不等于因果）。贝叶斯推断更进一步：你先有一个「先验信念」，每来一条新数据就按贝叶斯公式更新成「后验信念」，数据越多信念越稳。这种「边看边改主意」的框架，特别适合在线学习与不确定性建模。

本章主线：
- 先用统计量压缩数据、识别相关
- 再用贝叶斯公式持续更新信念
- 最后看共轭先验如何简化计算

## 1. 描述统计

面对一批样本，先看集中趋势与离散程度：

- 均值 $\bar{x}=\frac{1}{n}\sum x_i$
- 中位数：排序后居中者，抗异常值
- 标准差 $s=\sqrt{\frac{1}{n-1}\sum(x_i-\bar{x})^2}$

```python
import numpy as np
data = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(data.mean(), np.median(data), data.std(ddof=1))
```

> 均值被极端值拉偏时，中位数更可靠。

## 2. 相关性

皮尔逊相关系数衡量两变量的线性关联：

$$
r=\frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2}\sqrt{\sum(y_i-\bar{y})^2}}
$$

$r\in[-1,1]$，$r=0$ 仅表示「无线性相关」，不代表独立。

## 3. 贝叶斯推断：用数据更新先验

把「参数 $\theta$ 的信念」写成分布：先验 $P(\theta)$ → 观测数据 $D$ → 后验

$$
P(\theta\mid D)=\frac{P(D\mid\theta)\,P(\theta)}{P(D)}
$$

直觉：先有一个猜测（先验），每来一条新证据就修正一次（后验），后验又成为下一条证据的先验。

```python
# 抛硬币：先验 Beta(1,1)（均匀），观测 7 正 3 反
# 后验 Beta(1+7, 1+3) = Beta(8,4)
a, b = 8, 4
posterior_mean = a / (a + b)
print(posterior_mean)   # ≈ 0.667，比朴素 0.7 更保守
```

## 4. 假设检验（简述）

用 $p$ 值判断「观察到的差异是否可能只是随机波动」。注意：$p$ 小不代表效应大，只是「不太像纯巧合」。

> 在 A/B 测试中，务必同时看**效应量**与**置信区间**，别被显著但不重要的 $p$ 值误导。

## 小结

描述统计用均值/方差/相关概括数据，贝叶斯推断用「先验+似然=后验」持续更新信念。它上承 [概率基础](/docs/数学基础/概率与统计/概率基础与随机变量)，下接 [假设检验](/docs/数学基础/概率与统计/假设检验) 与 [信息论](/docs/数学基础/概率与统计/信息论基础)，是数据科学与 [检索增强](/docs/人工智能/大模型与应用/检索增强) 等方法论的底色。

## 易错点

- 相关系数 $r=0$ 只说明「无线性相关」，变量仍可能高度非线性相关（如 $y=x^2$ 在对称区间 $r\approx0$）。
- $p$ 值小 ≠ 效应大：大样本下微小的差异也能「显著」；要看效应量与置信区间。
- 贝叶斯「先验」不是随便选的：不恰当的强先验会扭曲后验；实践中常用无信息先验或做敏感性分析。
