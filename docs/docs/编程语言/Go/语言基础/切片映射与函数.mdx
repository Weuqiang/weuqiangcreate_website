# 切片、映射与函数

在 [Go 语言入门](../Go语言入门) 之后，本篇深入 Go 最常用的三种类型：切片（slice）、映射（map）与函数式特性。

## 学习目标

学完本章，你应该能够：

- 区分数组与切片，理解切片底层（指针/长度/容量）与扩容
- 掌握 map 的增删查与零值、并发安全注意事项
- 理解函数作为一等公民、闭包捕获与 defer 执行顺序

## 核心概念

切片是对底层数组的“视图”：它由指针、长度、容量三部分组成，切片赋值是引用共享，修改会相互影响；`append` 超过容量会分配新底层数组。map 是哈希表，零值为 `nil`（不能直接写入），必须用 `make` 创建。函数是值，可作为参数/返回值；闭包捕获的是变量本身而非取值。

## 1. 切片 slice

切片是对底层数组的**动态视图**，含指针、长度、容量：

```go
s := []int{1, 2, 3}
s = append(s, 4)            // 追加，容量不足时重新分配
fmt.Println(s[1:3])         // [2 3]，左闭右开
fmt.Println(len(s), cap(s)) // 4 4
```

- `make([]T, len, cap)` 预分配，减少扩容开销。
- 切片共享底层数组，注意`append`导致的"意外修改"。

```go
a := make([]int, 3, 5)
b := a[:2]
b[0] = 99
fmt.Println(a[0])   // 99 —— a 也被改了
```

## 2. 映射 map

```go
m := map[string]int{"a": 1}
m["b"] = 2
v, ok := m["c"]     // ok=false 表示不存在，避免零值歧义
if !ok { fmt.Println("未找到") }
delete(m, "a")
```

- map **无序**，遍历顺序随机（有意防依赖）。
- 并发读写 map 会 panic，需用 `sync.Map` 或加锁。

## 3. 函数与多返回值

Go 函数支持多返回值，惯用 `(结果, error)`：

```go
func div(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("除零")
    }
    return a / b, nil
}
r, err := div(4, 2)
if err != nil { log.Fatal(err) }
```

## 4. 匿名函数与闭包

```go
func counter() func() int {
    n := 0
    return func() int { n++; return n }   // 闭包捕获 n
}
c := counter()
fmt.Println(c(), c())   // 1 2
```

## 5. 方法与接口

```go
type Dog struct{ name string }
func (d Dog) Speak() string { return d.name + ": wang" }  // 值接收者
```

Go 的接口是**隐式实现**：类型只要拥有接口要求的方法集，就自动满足接口，无需 `implements`。

## 易错点

- 切片共享底层数组：`append` 触发扩容后会指向**新数组**，不扩容则仍共享，导致"改 b 误伤 a"。
- `nil` slice 可 `append`、可 `range`；但向 `nil` map 写入会 **panic**。
- map 遍历顺序随机（语言有意），切勿依赖顺序。
- `for k, v := range` 中 `v` 是值拷贝（struct 尤甚），改 `v` 不影响原元素，要改请用索引 `&s[i]`。
