# 电源与稳压

「电源 → 时钟 → 复位 → 引脚复用」这套排查四件套里，**电源永远排第一**。板子不启动、串口乱码、ADC 读数飘、模块随机重启——超过一半的"玄学问题"最终都能追到电源上。

## 学习目标

- 能画出一块典型板子的**电源树**，算清每一级的电流预算与压降。
- 分清 LDO 与 DC-DC（Buck/Boost）的适用场景，会算 LDO 的功耗与散热。
- 理解去耦电容为什么必须"贴着芯片放"，会做电容取值组合。
- 掌握上电时序、软启动与欠压检测（BOR/POR）的意义。
- 会用万用表和示波器诊断电源问题：纹波、跌落、启动失败。

## 核心直觉

### 电源树是第一张要画的图

```text
DC 12V 输入
   │
   ├─ 保险丝 + TVS + 防反接 MOS       （保护）
   │
   ├─ Buck 12V→5V  (效率 90%, 2A)     （给电机/继电器/USB）
   │        │
   │        └─ LDO 5V→3.3V (500mA)    （给 MCU 与数字外设）
   │                 │
   │                 └─ LDO/π型滤波 →  VDDA 3.3V 模拟域（给 ADC/传感器）
   │
   └─ 备用电池 3V → VBAT （RTC 与备份域）
```

画这张图时必须标注三件事：**每一级的输出电压、最大电流、下游负载清单**。很多"跑一会儿就重启"的板子，就是因为 3.3V LDO 只有 300mA，而 WiFi 模块发射瞬间要 400mA。

### LDO vs DC-DC 的选择

| 维度 | LDO（线性稳压） | DC-DC（开关稳压） |
|------|----------------|-------------------|
| 原理 | 多余电压变成热 | 开关 + 电感储能转换 |
| 效率 | Vout/Vin（压差大就烂） | 85%~95% |
| 噪声 | 极低，适合模拟/射频 | 有开关纹波（几十 mV） |
| 压差 | 需要最小压差（0.1~1V） | 可升可降 |
| 成本/体积 | 便宜、外围少 | 贵、要电感和布局功夫 |

**LDO 功耗的心算**：`P = (Vin − Vout) × Iout`。12V 降 3.3V 带 500mA，就是 `8.7 × 0.5 = 4.35W`——SOT-23 封装直接冒烟。所以经验规则是：**压差大或电流大，一律先用 Buck 降到 5V，再用 LDO 精修到 3.3V**。

### 去耦电容：给芯片配一个"本地水塔"

MCU 一个时钟周期内瞬间抽取电流，而 LDO 的响应速度是微秒级，走线还有寄生电感。去耦电容就是紧挨着芯片的小型储能罐：

```text
LDO ──[ 走线电感 ]──┬── VDD 引脚
                     │
              100nF ─┴─ 就近放（离引脚 2mm 内），滤高频
               10µF ─── 放在电源入口附近，滤中低频
```

取值组合的常规做法：**每个 VDD 引脚配一个 100nF（0402/0603），每个电源域再配一个 10µF 钽电容或 MLCC**。100nF 必须放在**同一面、走线最短、直接打过孔到地平面**——放到板子另一头等于没放。

## 最小可运行例程

一个典型的 12V 输入 / 3.3V MCU 板的电源设计清单与验算（可直接照抄进设计文档）：

```text
=== 电流预算表 ===
负载                     典型     峰值
STM32F103 @72MHz         36mA     50mA
外部 Flash               5mA      20mA
ESP8266 WiFi             80mA     380mA   ← 峰值决定选型！
传感器 ×3                15mA     20mA
LED 指示 ×2              10mA     10mA
--------------------------------------
3.3V 总计                146mA    480mA
选型：3.3V 轨至少留 2 倍余量 → 需要 1A 能力

=== LDO 方案验算（12V 直降 3.3V）===
P_loss = (12 − 3.3) × 0.48 = 4.18W        → 不可接受，需巨大散热
=== 两级方案 ===
Buck 12→5V @ 90%: P_in = 5 × 0.5 / 0.9 = 2.78W，损耗 0.28W
LDO  5→3.3V     : P_loss = (5 − 3.3) × 0.48 = 0.82W  → SOT-223 可控
```

固件侧配合欠压检测与上电稳定等待：

```c
/* 1. 开启 BOR/PVD：电压跌到阈值以下先告警，避免脏数据写入 Flash */
void pvd_init(void)
{
    PWR_PVDTypeDef pvd = {0};

    __HAL_RCC_PWR_CLK_ENABLE();
    pvd.PVDLevel = PWR_PVDLEVEL_5;          /* 约 2.8V 阈值 */
    pvd.Mode     = PWR_PVD_MODE_IT_RISING_FALLING;
    HAL_PWR_ConfigPVD(&pvd);
    HAL_PWR_EnablePVD();

    HAL_NVIC_SetPriority(PVD_IRQn, 0, 0);   /* 最高优先级，掉电抢救 */
    HAL_NVIC_EnableIRQ(PVD_IRQn);
}

/* 电压异常回调：抢在彻底掉电前保存关键数据 */
void HAL_PWR_PVDCallback(void)
{
    if (__HAL_PWR_GET_FLAG(PWR_FLAG_PVDO)) {   /* 低于阈值 */
        save_critical_state_to_backup_reg();   /* 只做最快的动作 */
        disable_heavy_loads();                 /* 关掉电机/无线，延长撑持时间 */
    }
}

/* 2. 上电时序：外设电源稳定后再初始化，避免"读不到芯片 ID" */
void power_up_sequence(void)
{
    HAL_GPIO_WritePin(SENSOR_PWR_GPIO_Port, SENSOR_PWR_Pin, GPIO_PIN_SET);
    HAL_Delay(10);                 /* 等待外设 LDO 建立 + 芯片内部复位完成 */

    if (sensor_probe() != HAL_OK) {
        /* 探测失败先怀疑供电，而不是急着改 I2C 代码 */
        printf("[ERR] sensor no ACK, check 3V3_SENSOR rail\r\n");
    }
}
```

## 易错点

- **只看典型电流，不看峰值**：WiFi/GSM 模块发射瞬间的电流是平均值的 5~10 倍，电源撑不住就是"一联网就重启"。这类模块务必在其供电脚附近并 100~470µF 大电容。
- **LDO 压差算错导致失稳**：`Vin` 必须大于 `Vout + Vdropout`。用 3.6V 锂电池给 3.3V LDO 供电，电池放到 3.4V 时普通 LDO 就退出稳压了，要选 LDO(low dropout) 参数在 100mV 级的型号。
- **去耦电容离芯片太远**：走线一长，寄生电感让电容形同虚设。布局时去耦电容优先级高于一切美观考量。
- **MLCC 的直流偏压效应**：标称 10µF 的 0603 X5R 电容，加到 3.3V 实际容量可能只剩 4µF，加到 5V 只剩 2µF。设计裕量要按实际容量算，或选更大封装。
- **模拟电源不做隔离**：VDDA 直接和 VDD 短接，数字开关噪声全灌进 ADC。正确做法是串一颗磁珠 + 并 100nF/10µF 组成 π 型滤波。
- **地线当成"理想 0V"**：大电流回路在地线上产生的压降（地弹）会让不同芯片看到不同的"地"，这是很多通信错误的根源。
- **忘了防反接与浪涌保护**：现场接反电源一次就烧一批板子。串一个 P-MOS 做理想二极管，成本几毛钱。
- **测纹波时探头地线太长**：几厘米的地线环路会拾取空间噪声，测出来的"纹波"其实是探头自己的。要用弹簧地针贴测。

## 练习

1. 为一块含 STM32 + OLED + ESP32 + 三个传感器的板子画出完整电源树，列电流预算表，并给出 LDO/DC-DC 选型与功耗验算。
2. 用示波器 AC 耦合、20MHz 带宽限制，分别测 LDO 与 Buck 输出的纹波，对比峰峰值。
3. 做对照实验：把某芯片的 100nF 去耦电容拆掉，观察其电源脚上的瞬态跌落幅度变化。
4. 用可调电源缓慢降低输入电压，记录板子在什么电压下开始异常、什么电压下彻底停止工作，验证 BOR 阈值是否合理。

## 小结

电源设计的三条铁律：**先画电源树算峰值电流、按压差和电流选 LDO 还是 DC-DC、去耦电容贴着芯片放**。再加上防反接、欠压检测和干净的模拟电源分区，你就消灭了嵌入式里最大的一类"玄学 bug"。遇到任何不稳定现象，第一步永远是把示波器接到芯片电源脚上看一眼。
