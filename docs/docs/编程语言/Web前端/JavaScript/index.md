# JavaScript：学习路线图

JavaScript 是网页的"行为层"，也是 Node.js 等服务端运行时的语言。本目录按**由内到外**的顺序组织：先打牢语言本身的语法与类型，再学标准库与面向对象，最后进入浏览器相关的异步、DOM、事件与 BOM。

> 本目录内容翻译整理自 [wangdoc.com JavaScript 教程](https://wangdoc.com/javascript/)，向原作者对开源文档的贡献致谢。

## 推荐学习顺序

```text
1. 语法基础  →  2. 类型系统  →  3. 运算符  →  4. 语言特性
      ↓
5. 标准库  →  6. 面向对象  →  7. 异步编程
      ↓
8. DOM  →  9. 事件  →  10. BOM  →  11. 常用元素
```

## 模块导航

下面 11 个模块按推荐顺序排列，每个模块都包含若干篇详解（见本页底部卡片或左侧侧边栏）：

1. **语法基础**（`1. basic`）— 语句、变量、标识符、注释、区块、条件与循环。从"基本语法"读起，先建立对 JS 执行模型的直觉。
2. **类型系统**（`2. types`）— 数字、字符串、对象、数组、函数、空值（`null` / `undefined`）。JS 的坑大半在类型上，这章要细读。
3. **运算符**（`3. operators`）— 算术、位运算、布尔、比较与优先级。重点搞懂 `==` 与 `===`、隐式转换。
4. **语言特性**（`4. features`）— 控制台、类型转换、错误处理、编码风格。
5. **标准库**（`5. stdlib`）— 内置对象与方法：数组、JSON、正则、日期、数学等。
6. **面向对象**（`6. oop`）— `this` 绑定、原型链、`new`、严格模式。理解原型是理解 JS 的关键。
7. **异步编程**（`7. async`）— 回调、Promise、定时器。现代 JS 的重心。
8. **DOM**（`8. dom`）— 文档树操作：document、element、node、属性与样式。
9. **事件**（`9. events`）— 事件模型、事件对象，以及鼠标 / 键盘 / 触摸等交互。
10. **BOM**（`10. bom`）— 浏览器对象模型：window、location、fetch / XHR、跨域（CORS）。
11. **常用元素**（`11. elements`）— 表单与媒体标签：input、form、a、button、video 等。

## 学习建议

JavaScript 最容易踩的坑都在**类型隐式转换**和**异步时序**上。每学一个特性，先问"它什么时候会悄悄改变类型"，以及"它到底是同步还是异步返回"。建议边读边在浏览器控制台（F12）里敲一遍例子，肉眼看到结果比看十遍描述都管用。
