# 信息论

香农在 1948 年用「信息 = 意外程度」统一了通信、压缩与推断。入门篇 [信息论基础（熵与 KL 散度）](/docs/数学基础/概率与统计/信息论基础) 已讲清离散熵、交叉熵与互信息；本主题把视野推向**连续量、有损压缩、以及通信的理论极限**。

## 本主题内容

- [熵率与微分熵](/docs/数学基础/信息论/熵率与微分熵) —— 随机过程的熵率、连续变量的微分熵、联合/条件互信息与 Fisher 信息
- [率失真与信息瓶颈](/docs/数学基础/信息论/率失真与信息瓶颈) —— 有损压缩的极限（率失真函数），以及信息瓶颈这一表征学习框架
- [信道容量与香农定理](/docs/数学基础/信息论/信道容量与香农定理) —— 信道容量、香农源编码与信道编码三大定理、高斯/BSC 信道容量
