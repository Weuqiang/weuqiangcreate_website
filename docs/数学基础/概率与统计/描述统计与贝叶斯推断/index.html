描述统计与贝叶斯推断

上篇建立了概率与分布的基础。本篇落到工程常用两手：描述统计（汇总数据）与贝叶斯推断（用数据更新信念）。

1. 描述统计​

面对一批样本，先看集中趋势与离散程度：

  • 均值 xˉ=1n∑xi\bar{x}=\frac{1}{n}\sum x_ixˉ=n1​∑xi​
  • 中位数：排序后居中者，抗异常值
  • 标准差 s=1n−1∑(xi−xˉ)2s=\sqrt{\frac{1}{n-1}\sum(x_i-\bar{x})^2}s=n−11​∑(xi​−xˉ)2​
import numpy as np
data = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(data.mean(), np.median(data), data.std(ddof=1))

均值被极端值拉偏时，中位数更可靠。

2. 相关性​

皮尔逊相关系数衡量两变量的线性关联：

r=∑(xi−xˉ)(yi−yˉ)∑(xi−xˉ)2∑(yi−yˉ)2r=\frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2}\sqrt{\sum(y_i-\bar{y})^2}}r=∑(xi​−xˉ)2​∑(yi​−yˉ​)2​∑(xi​−xˉ)(yi​−yˉ​)​

r∈[−1,1]r\in[-1,1]r∈[−1,1]，r=0r=0r=0 仅表示「无线性相关」，不代表独立。

3. 贝叶斯推断：用数据更新先验​

把「参数 θ\thetaθ 的信念」写成分布：先验 P(θ)P(\theta)P(θ) → 观测数据 DDD → 后验

P(θ∣D)=P(D∣θ) P(θ)P(D)P(\theta\mid D)=\frac{P(D\mid\theta)\,P(\theta)}{P(D)}P(θ∣D)=P(D)P(D∣θ)P(θ)​

直觉：先有一个猜测（先验），每来一条新证据就修正一次（后验），后验又成为下一条证据的先验。

# 抛硬币：先验 Beta(1,1)（均匀），观测 7 正 3 反
# 后验 Beta(1+7, 1+3) = Beta(8,4)
a, b = 8, 4
posterior_mean = a / (a + b)
print(posterior_mean)   # ≈ 0.667，比朴素 0.7 更保守

4. 假设检验（简述）​

用 ppp 值判断「观察到的差异是否可能只是随机波动」。注意：ppp 小不代表效应大，只是「不太像纯巧合」。

在 A/B 测试中，务必同时看效应量与置信区间，别被显著但不重要的 ppp 值误导。
