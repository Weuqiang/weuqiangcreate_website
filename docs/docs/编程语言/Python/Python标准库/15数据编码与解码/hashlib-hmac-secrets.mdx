## 学习目标

- 用 `hashlib` 计算 SHA-256 等摘要，理解「摘要不可逆」
- 用 `hmac` 在共享密钥下验证消息未被篡改
- 用 `secrets` 生成令牌、密钥等不可预测随机值

- 字节与编码（见 [base64 与 struct](../base64-struct)）

## 核心概念

`hashlib` 实现密码学哈希（SHA-2/SHA-3/blake2 等）：输入任意长度，输出固定长度「摘要」，具备**单向性**（无法反推原文）与**抗碰撞性**（难找两个输入同摘要）。常用于校验文件完整性、存储密码（加盐后哈希，绝不明文）。注意：单纯 `sha256(password)` 仍易被彩虹表攻击，密码存储应使用 `bcrypt`/`argon2` 等慢哈希。

`hmac` 在哈希之上引入**密钥**：`hmac.new(key, msg, hashlib.sha256)` 生成消息认证码（MAC）。通信双方共享 key，既能验证消息完整，又能验证来源——没有 key 的人无法伪造。这是 API 签名、Webhook 校验的常见做法。

`secrets` 是**密码学安全**的随机源（基于系统熵），区别于可预测的 `random`：用于生成令牌、API key、验证码、盐值。永远不要用 `random` 生成安全敏感的值。

## 示例

```python
import hashlib
import hmac
import secrets

# hashlib：文件/数据摘要
digest = hashlib.sha256(b"hello").hexdigest()
print(digest[:16], "...")     # 2cf24dba6ff...

# hmac：带密钥的消息认证
key = secrets.token_bytes(32)
msg = b"transfer:100->alice"
mac = hmac.new(key, msg, hashlib.sha256).hexdigest()
# 接收方用同样的 key 重算并比较（用 hmac.compare_digest 防时序攻击）
expected = hmac.new(key, msg, hashlib.sha256).digest()
print(hmac.compare_digest(expected, hmac.new(key, msg, hashlib.sha256).digest()))

# secrets：安全随机
print(secrets.token_hex(16))   # 32 字符十六进制令牌
print(secrets.randbelow(100))  # [0,100) 安全整数
print(secrets.choice("abcdef"))  # 安全随机选择
```

## 易错点

- **密码别只用 `sha256`**：需用慢哈希（bcrypt/argon2）+ 每用户盐；`hashlib` 适合完整性校验，不适合直接存密码。
- **比较 MAC 用 `compare_digest`**：`==` 会因「短电路」产生时序侧信道，攻击者可用响应时间推断正确前缀。
- **`hmac` 的 key/msg 必须是 `bytes`**：传 `str` 报错，记得 `.encode()`。
- **`secrets` 不是 `random` 的替代品用于普通随机**：它更慢，仅在安全敏感场景使用；普通洗牌/抽样仍用 `random`。
- **SHA-1/MD5 已不安全**：新代码禁用，用 SHA-256 起。

## 小结

- 完整性校验用 `hashlib` 摘要；
- 来源+完整性认证用 `hmac`（共享密钥）；
- 安全随机用 `secrets`，慢哈希存密码用专用库。
