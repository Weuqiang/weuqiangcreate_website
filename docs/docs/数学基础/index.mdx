# 数学基础

数学是编程的底层语言。无论你做人工智能、图形学、后端还是嵌入式，**扎实的数学直觉都能让你更快看懂公式背后的含义，而不是只会调库**。

本栏目按四条主线组织，覆盖绝大多数工程场景所需的数学：

- **线性代数**：向量、矩阵、线性变换、特征值。AI 与图形学的基石。
- **微积分**：极限、导数、积分、梯度。理解优化与训练过程的关键。
- **概率与统计**：随机变量、分布、贝叶斯、假设检验。处理不确定性的工具。
- **离散数学**：集合、逻辑、图论、组合。算法、数据库与编译器的理论底座。

> 建议路径：先建立线性代数与微积分的直观，再用概率统计描述数据，最后以离散数学收口算法与结构。

## 为什么工程上要学数学

- **读得懂论文与文档**：损失函数、梯度下降、注意力机制背后都是数学。
- **调得动模型**：学习率、正则化、归一化的选择依赖于对优化的理解。
- **写得对算法**：复杂度分析、图遍历、动态规划都建立在离散数学之上。
