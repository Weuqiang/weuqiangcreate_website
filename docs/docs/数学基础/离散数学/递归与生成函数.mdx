# 递归与生成函数

「第 $n$ 项由前几项决定」是描述离散过程最自然的方式，但递推式无法直接告诉你第 100 万项是多少。**把递推关系转成闭式公式**——这就是特征方程与生成函数要解决的问题。

## 学习目标

- 写出常见问题的递推关系（斐波那契、汉诺塔、爬楼梯）。
- 用特征方程法求解线性齐次递推，得到通项闭式。
- 理解生成函数「把数列装进幂级数」的思想，并用它求解递推。
- 用 numpy 验证闭式解与递推计算结果一致。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [集合逻辑与证明](/docs/数学基础/离散数学/集合逻辑与证明) 中的归纳法。
- 写过递归函数——可参考 [Python](/docs/编程语言/Python/0基础语法)。
- 基本的级数求和直觉。

## 核心概念
**递推关系**是「用小问题的答案拼出大问题的答案」：

$$
a_n=c_1a_{n-1}+c_2a_{n-2}+\cdots+c_ka_{n-k}
$$

它必须配上足够的**初始条件**才能唯一确定数列——就像多米诺骨牌，既要有「一张倒了会推倒下一张」的规则，也要有「推倒第一张」的起点。

**特征方程法的直觉**：既然递推是线性的，不妨大胆猜测解的形式是 $a_n=r^n$（指数增长是线性递推最自然的形态）。代入 $a_n=a_{n-1}+a_{n-2}$：

$$
r^{n}=r^{n-1}+r^{n-2}\ \Longrightarrow\ r^{2}=r+1\ \Longrightarrow\ r^{2}-r-1=0
$$

解得 $r_{1,2}=\frac{1\pm\sqrt5}{2}$。其中 $\varphi=\frac{1+\sqrt5}{2}\approx1.618$ 正是**黄金比例**。由线性性，通解是各根的线性组合：

$$
a_n=A\varphi^{n}+B\psi^{n},\qquad \psi=\frac{1-\sqrt5}{2}
$$

代入 $F_0=0,F_1=1$ 解出 $A=1/\sqrt5,\ B=-1/\sqrt5$，得到著名的 **Binet 公式**：

$$
F_n=\frac{1}{\sqrt5}\left[\left(\frac{1+\sqrt5}{2}\right)^{n}-\left(\frac{1-\sqrt5}{2}\right)^{n}\right]
$$

因为 $|\psi|\approx0.618<1$，第二项迅速趋于零，所以 $F_n\approx\varphi^{n}/\sqrt5$——**斐波那契数列本质上是指数增长的**，增长率就是黄金比例。

**生成函数的直觉**：把整个数列 $a_0,a_1,a_2,\dots$ 打包成一个幂级数

$$
G(x)=\sum_{n\ge0}a_nx^{n}
$$

$x^n$ 在这里只是「第 $n$ 号抽屉的标签」，不需要关心它收不收敛。这样做的好处是：**数列的递推关系变成了 $G(x)$ 的代数方程**，而解代数方程比解递推容易得多。

以斐波那契为例，由 $F_n=F_{n-1}+F_{n-2}$ 可推出

$$
G(x)=\frac{x}{1-x-x^{2}}
$$

再用部分分式拆开并展开，就重新得到 Binet 公式。生成函数的更大威力在**组合计数**：几何级数 $\frac{1}{1-x}=1+x+x^2+\cdots$ 表示「某物品可取任意个」，$(1+x)$ 表示「取 0 个或 1 个」。把各部分**相乘**，$x^n$ 的系数就自动是方案总数——**乘法自动完成了卷积式的枚举**。

## 最小示例

```python
import numpy as np
from functools import lru_cache

# ============ 1. 递推 vs 闭式：斐波那契 ============
@lru_cache(maxsize=None)
def fib_rec(n):
    return n if n < 2 else fib_rec(n-1) + fib_rec(n-2)

def fib_binet(n):
    s5 = np.sqrt(5)
    phi, psi = (1 + s5) / 2, (1 - s5) / 2
    return (phi**n - psi**n) / s5

for n in [10, 20, 30, 50]:
    print(f"F_{n}: 递推={fib_rec(n):>12}  Binet={fib_binet(n):>16.1f}")
# 完全吻合 ✔（n 很大时浮点精度会开始丢失，需改用整数矩阵幂）

# ---- 增长率验证：相邻项之比 -> 黄金比例 ----
print("\n相邻项之比:")
for n in [5, 10, 20, 30]:
    print(f"  F_{n+1}/F_{n} = {fib_rec(n+1)/fib_rec(n):.10f}")
print(f"  黄金比例 φ  = {(1+np.sqrt(5))/2:.10f}")   # 收敛 ✔

# ============ 2. 生成函数：多项式系数即方案数 ============
# 问题：用 1元、2元、5元硬币凑出 n 元，有多少种组合（不计顺序）？
# 生成函数 G(x) = 1/((1-x)(1-x²)(1-x⁵))
N = 20
coef = np.zeros(N + 1); coef[0] = 1          # 初始：凑 0 元有 1 种方式
for coin in [1, 2, 5]:
    for amount in range(coin, N + 1):
        coef[amount] += coef[amount - coin]  # 等价于乘上 1/(1-x^coin)
print("\n凑钱方案数:")
for n in [5, 10, 20]:
    print(f"  {n:>2} 元: {int(coef[n])} 种")
# 5 元: 4 种 -> {5}, {2,2,1}, {2,1,1,1}, {1×5} ✔ 可手工枚举核对

# ============ 3. 汉诺塔：a_n = 2a_{n-1} + 1 ============
# 特征方程法 + 特解，闭式为 a_n = 2^n - 1
a = 0
for n in range(1, 11):
    a = 2 * a + 1
    assert a == 2**n - 1
print(f"\n汉诺塔 10 层需要 {a} 步 = 2^10 - 1 ✔")

# ============ 4. 矩阵幂法：O(log n) 求斐波那契（大数精确）============
M = np.array([[1, 1], [1, 0]], dtype=object)   # object 类型避免溢出
def fib_matrix(n):
    return np.linalg.matrix_power(M, n)[0, 1] if n > 0 else 0
print("F_100 =", fib_matrix(100))    # 354224848179261915075（精确大整数）
```

## 易错点

- **初始条件数量不足**。$k$ 阶递推需要 $k$ 个初值。只给 $F_0=0$ 无法确定数列，还必须给 $F_1$。
- **特征根重根时形式不同**。若 $r$ 是二重根，通解是 $(A+Bn)r^{n}$ 而非 $Ar^n+Br^n$（后者会退化成一个常数乘 $r^n$，自由度不够）。
- **忘记非齐次项的特解**。$a_n=2a_{n-1}+1$ 的通解 = 齐次通解 $C\cdot2^n$ + 特解 $-1$，得 $a_n=C2^n-1$，再代初值。漏掉特解结果必错。
- **朴素递归实现的指数爆炸**。不加记忆化的 `fib_rec` 是 $O(2^n)$，$n=50$ 就跑不动了。加 `lru_cache` 后降到 $O(n)$。
- **用 Binet 公式算大 $n$ 会失精**。$n>70$ 左右浮点误差就超过 1，得不到正确整数，此时应用整数矩阵快速幂。
- **纠结生成函数的收敛性**。作为**形式幂级数**，它只是系数的容器，代数运算合法即可，无需讨论收敛域。

## 练习

1. 求解 $a_n=5a_{n-1}-6a_{n-2}$，$a_0=1,a_1=4$。
   *提示：特征方程 $r^2-5r+6=0$ 得 $r=2,3$；由 $A+B=1,\ 2A+3B=4$ 解得 $A=-1,B=2$，故 $a_n=2\cdot3^{n}-2^{n}$。*
2. 爬 $n$ 级台阶，每次可迈 1 级或 2 级，共有多少走法？
   *答案：$a_n=a_{n-1}+a_{n-2}$，即斐波那契数（$a_1=1,a_2=2$）。*
3. 写出「用 1、2、5 元硬币凑钱」的生成函数，并说明 $x^{10}$ 的系数含义。
   *答案：$G(x)=\frac{1}{(1-x)(1-x^2)(1-x^5)}$；$x^{10}$ 的系数即凑出 10 元的方案总数（上面程序给出 10 种）。*

## 小结

递推关系用「小问题拼大问题」定义数列，必须配足初始条件。线性齐次递推可用特征方程法求闭式：猜测 $a_n=r^n$ 代入得到代数方程，通解是各特征根幂次的线性组合，重根时需额外乘上 $n$ 的幂。生成函数把整个数列装进形式幂级数，将递推关系转化为代数方程，在组合计数中尤其强大——因子相乘即自动完成枚举。实现时注意朴素递归的指数复杂度与浮点闭式的精度限制。
