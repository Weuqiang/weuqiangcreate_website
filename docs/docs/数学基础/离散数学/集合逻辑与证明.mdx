# 集合、逻辑与证明

离散数学研究「可数、分离」的结构：集合、逻辑、图、组合。它是算法、数据库、编译器和密码学的理论底座。

## 学习目标

学完本章，你应该能够：

- 说清并集、交集、补集与笛卡尔积。
- 用真值表判断命题逻辑等价。
- 掌握直接证明、反证法、数学归纳法。
- 理解集合与逻辑是计算机科学的语言基础。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 高中数学的集合与逻辑直观即可。
- 愿意用「严格定义」代替「大概意思」。
- 了解 [编程语言](/docs/编程语言/Python/0基础语法) 中的布尔表达式有助于理解逻辑。

## 核心概念

离散数学是计算机科学的语法课：集合把「一堆东西」形式化，逻辑把「真假推理」形式化。证明方法则是把这些形式化工具串起来——直接证明顺推，反证法先假设反面再导出矛盾，数学归纳法处理「对所有自然数成立」的命题。几乎所有算法正确性、数据库约束、程序验证，最终都落在集合与逻辑这块地基上。

本章主线：
- 从集合与逻辑的形式化语言切入
- 再看三种基本证明方法
- 最后理解它们对计算机科学的奠基作用

## 1. 集合

集合是无序、互异的元素总体。基本运算：

- 并 $A\cup B$、交 $A\cap B$、差 $A\setminus B$
- 幂集：所有子集的集合，大小为 $2^{|A|}$

```python
A = {1, 2, 3}
B = {2, 3, 4}
print(A | B)   # {1,2,3,4} 并
print(A & B)   # {2,3}     交
print(A - B)   # {1}       差
```

## 2. 命题逻辑

命题非真即假。常用连接词：

| 符号 | 含义 |
|------|------|
| $\neg p$ | 非 |
| $p\land q$ | 且 |
| $p\lor q$ | 或 |
| $p\to q$ | 若…则… |

德·摩根定律：

$$
\neg(p\land q)=\neg p\lor\neg q,\qquad \neg(p\lor q)=\neg p\land\neg q
$$

## 3. 证明方法

- **直接证明**：由前提逐步推导结论。
- **反证法**：假设结论不成立，推出矛盾。
- **数学归纳法**：证明 $P(1)$ 成立，且 $P(k)\Rightarrow P(k+1)$，则对所有 $n$ 成立。

```text
归纳法示例：证明 1+2+...+n = n(n+1)/2
基础：n=1，左=1，右=1 ✓
归纳：假设对 k 成立，则 k+1 时
  1+...+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k+2)/2 ✓
```

## 4. 与编程的关系

- 集合运算对应 SQL 的 `UNION`/`INTERSECT`/`EXCEPT`。
- 逻辑表达式是 `if` 条件的数学形式。
- 归纳法是递归正确性的证明依据。

## 示例

**德·摩根定律用代码验证**（逻辑等式不止"看起来对"，还能枚举真值表）：

```python
for p in (True, False):
    for q in (True, False):
        left  = not (p and q)
        right = (not p) or (not q)
        assert left == right          # ¬(p∧q) ≡ ¬p∨¬q 对所有真值成立
print("德·摩根定律验证通过")
```

**数学归纳法代码化**（验证 $1+2+\cdots+n=\frac{n(n+1)}{2}$）：

```python
def sum_formula(n): return n*(n+1)//2
def sum_loop(n):    return sum(range(1, n+1))
for n in range(1, 1001):
    assert sum_loop(n) == sum_formula(n)   # 对 n=1..1000 全部成立
```

## 小结

集合与命题逻辑把「对象」和「推理」形式化，证明方法（直接、反证、归纳）把它们变成可靠结论。它是一切 [算法分析](/docs/数学基础/离散数学/复杂度初步) 与 [布尔代数](/docs/数学基础/离散数学/布尔代数) 的前提，也是 [自动机与形式语言](/docs/数学基础/离散数学/自动机与形式语言) 的底层词汇。

## 易错点

- 幂集大小是 $2^{|A|}$，不是 $|A|^2$：每个元素独立地「选 / 不选」，$n$ 个元素共 $2^n$ 个子集。
- $\to$ 不是对称关系：$p\to q$ 不等价于 $q\to p$；只有 $p\leftrightarrow q$ 才双向。
- 归纳法必须同时证明「基础」和「归纳步骤」，只证后者不算完成。
