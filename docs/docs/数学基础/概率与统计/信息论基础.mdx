# 信息论基础（熵与 KL 散度）

「明天太阳从东边升起」几乎不含信息，「明天下冰雹」则信息量很大。香农把这种直觉变成了可计算的量——**信息 = 意外程度**。由此衍生的熵、交叉熵、KL 散度，是压缩算法、决策树、以及几乎所有分类模型损失函数的共同基础。

## 学习目标

- 用自信息与熵量化不确定性，并解释对数的必然性。
- 计算交叉熵与 KL 散度，说清两者的关系与非负性含义。
- 解释为什么分类模型的标准损失函数就是交叉熵。
- 用互信息与信息增益衡量两个变量的依赖程度，理解决策树的分裂准则。

## 核心概念
**信息量 = 意外程度。** 一个概率为 $p$ 的事件发生时，带来的**自信息**是

$$
I(x)=-\log_2 p(x)\quad(\text{单位：比特})
$$

为什么必须是对数？因为信息要满足**可加性**：两个独立事件同时发生的信息量，应等于各自信息量之和。而概率是相乘的（$p_1p_2$），要把乘法变加法，只有对数能做到。此外 $p=1$ 时 $-\log 1=0$，「必然发生的事没有信息」也自动成立。

**熵**是自信息的期望，即平均意外程度：

$$
H(X)=-\sum_x p(x)\log_2 p(x)
$$

它衡量一个分布的**不确定性**，也等于最优编码下的**平均码长下界**（香农源编码定理）。均匀分布熵最大（最难猜），确定性分布熵为 0（毫无悬念）。公平硬币的熵是 1 比特，$p=0.9$ 的偏心硬币只有 0.469 比特——**越确定，越容易压缩**。

**交叉熵**：用「猜测的分布 $q$」去编码「真实分布 $p$」产生的数据，平均需要的码长

$$
H(p,q)=-\sum_x p(x)\log q(x)
$$

**KL 散度**：因为猜错分布而**多付出**的代价

$$
D_{KL}(p\parallel q)=\sum_x p(x)\log\frac{p(x)}{q(x)}=H(p,q)-H(p)
$$

这个分解极其重要：

$$
\underbrace{H(p,q)}_{\text{实付}}=\underbrace{H(p)}_{\text{不可避免}}+\underbrace{D_{KL}(p\parallel q)}_{\text{因猜错而浪费}}
$$

**吉布斯不等式**保证 $D_{KL}\ge0$，且等号仅在 $p=q$ 时成立。在机器学习中，$H(p)$ 由数据决定、是常数，所以**最小化交叉熵损失完全等价于最小化 KL 散度，即让模型分布逼近真实分布**——这就是交叉熵损失函数的理论依据，而不是某个凭经验挑出来的公式。

**互信息**衡量两个变量共享多少信息：

$$
I(X;Y)=H(X)-H(X\mid Y)=D_{KL}\big(p(x,y)\parallel p(x)p(y)\big)
$$

即「知道 $Y$ 之后，$X$ 的不确定性减少了多少」。独立时为 0。决策树的**信息增益**正是特征与标签之间的互信息——每次选择让标签熵下降最多的特征来分裂。

## 最小示例

```python
import numpy as np

def entropy(p, base=2):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                       # 约定 0*log0 = 0，直接过滤
    return -np.sum(p * np.log(p) / np.log(base)) + 0.0

def cross_entropy(p, q, base=2):
    p, q = np.asarray(p, float), np.asarray(q, float)
    m = p > 0
    return -np.sum(p[m] * np.log(q[m]) / np.log(base))

def kl(p, q, base=2):
    return cross_entropy(p, q, base) - entropy(p, base)

# ---- 1. 熵：越均匀越大 ----
print("公平硬币 H =", entropy([0.5, 0.5]))            # 1.0 比特
print("偏心硬币 H =", round(entropy([0.9, 0.1]), 4))  # 0.469 比特
print("确定事件 H =", entropy([1.0, 0.0]))            # 0.0 比特
print("均匀四选一 H =", entropy([0.25]*4))            # 2.0 比特（= log2(4)）

# ---- 2. KL 散度：非负 + 不对称 ----
p = np.array([0.5, 0.3, 0.2])
q = np.array([0.4, 0.4, 0.2])
print(f"\nD(p||q) = {kl(p, q):.6f}")     # 0.036453
print(f"D(q||p) = {kl(q, p):.6f}")       # 0.037244  -> 数值不同，不对称！
print(f"D(p||p) = {kl(p, p):.6f}")       # 0.0 ✔
print("交叉熵分解校验:",
      np.isclose(cross_entropy(p, q), entropy(p) + kl(p, q)))   # True ✔

# ---- 3. 分类模型的交叉熵损失 ----
# 真实标签 one-hot: 类别 1；模型两种预测
y_true = np.array([0., 1., 0.])
for name, y_pred in [("好模型", [0.1, 0.8, 0.1]),
                     ("差模型", [0.4, 0.3, 0.3])]:
    loss = -np.sum(y_true * np.log(y_pred))          # 自然对数，单位 nat
    print(f"{name}: 交叉熵损失 = {loss:.4f}")
# 好模型 0.2231，差模型 1.2040 -> 预测越接近真实，损失越小 ✔

# ---- 4. 互信息 / 信息增益：决策树选特征 ----
# 14 个样本，标签 9 正 5 负
H_label = entropy([9/14, 5/14])
print(f"\n分裂前熵 = {H_label:.4f}")

# 特征"天气"分三支: (2正3负), (4正0负), (3正2负)
branches = [(5, [2/5, 3/5]), (4, [1.0, 0.0]), (5, [3/5, 2/5])]
H_cond = sum(n/14 * entropy(dist) for n, dist in branches)
print(f"分裂后条件熵 = {H_cond:.4f}")
print(f"信息增益 I(X;Y) = {H_label - H_cond:.4f}")   # ≈ 0.2467
# 决策树会挑信息增益最大的特征作为分裂点
```

## 易错点

- **以为 KL 散度是「距离」**。它**不对称**（$D(p\|q)\neq D(q\|p)$）且不满足三角不等式，所以叫「散度」不叫「距离」。需要对称版本时用 JS 散度。
- **忽略 $q(x)=0$ 而 $p(x)>0$ 的情形**。此时 $D_{KL}=\infty$。工程上必须做平滑（加 $\epsilon$ 或拉普拉斯平滑），否则会出现 `inf`／`nan`。
- **搞反 $D(p\|q)$ 的参数顺序**。第一个参数是**真实/目标**分布，第二个是**近似/模型**分布。$D(p\|q)$ 惩罚「$p$ 有而 $q$ 没有」（求全，倾向覆盖），反向 KL 则倾向锁定单个模式，两者在变分推断中行为差异巨大。
- **对数底数不统一**。以 2 为底单位是比特，以 e 为底是 nat。深度学习框架默认用自然对数，跨来源对比数值前先确认底数。
- **把熵大等同于「信息多」**。熵度量的是**不确定性**，即「平均而言你还需要多少信息才能确定结果」，不是「已经拥有的信息量」。

## 练习

1. 计算 $p=(0.25,0.25,0.25,0.25)$ 与 $p=(0.7,0.1,0.1,0.1)$ 的熵，说明哪个更容易压缩。
   *答案：分别为 2.0 与约 1.357 比特；后者更容易压缩，因为它更可预测。*
2. 验证当 $p=q$ 时 $D_{KL}=0$，并说明为什么 $D_{KL}$ 永远非负。
   *提示：$\log$ 是凹函数，由 Jensen 不等式得 $-D_{KL}=\sum p\log\frac{q}{p}\le\log\sum q=0$。*
3. 二分类模型对真实标签为 1 的样本预测概率 0.9，交叉熵损失是多少（自然对数）？
   *答案：$-\ln 0.9\approx0.1054$。若预测 0.5 则为 $0.693$，若预测 0.01 则高达 $4.605$——错得越自信，惩罚越重。*

## 小结

信息量定义为 $-\log p$，对数形式来自「独立事件信息可加」的要求。熵是信息量的期望，衡量分布的不确定性，也是最优编码的平均码长下界。交叉熵是用错误分布编码的实际代价，它恰好分解为「真实熵 + KL 散度」，因此最小化交叉熵损失等价于让模型分布逼近真实分布。KL 散度非负但不对称，使用时要注意参数顺序与零概率平滑。互信息量化两变量的依赖，正是决策树信息增益的本体。
