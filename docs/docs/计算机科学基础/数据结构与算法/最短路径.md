# 最短路径

导航软件算「从家到公司最快怎么走」，网络路由算「数据包走哪条链路延迟最低」——这些都是**最短路径问题**：在带权图中找出两点间权重和最小的路径。不同的图有不同的最优解法，选错算法要么慢十倍，要么算错。

## 学习目标

- 说清四种最短路算法各自的**适用条件**，尤其是负权边这条分水岭。
- 手写 Dijkstra（堆优化版）与 Bellman-Ford，并解释它们的核心循环在做什么。
- 理解「松弛（relaxation）」这个所有最短路算法的共同原语。
- 面对具体问题时，能在 30 秒内选对算法。

## 核心直觉

### 共同原语：松弛

所有最短路算法都在反复做同一件事——**松弛**：

```text
if dist[u] + weight(u, v) < dist[v]:
    dist[v] = dist[u] + weight(u, v)
```

翻译成人话：「如果先到 u 再走一步到 v，比我现在记录的到 v 的距离更短，那就更新记录。」四种算法的区别，只在于**用什么顺序、松弛多少轮**。

### 四种算法的分工

| 算法 | 适用图 | 求什么 | 时间复杂度 | 核心思想 |
|---|---|---|---|---|
| **BFS** | 无权图（或边权全相等） | 单源到所有点 | $O(V + E)$ | 按层扩散，先到即最短 |
| **Dijkstra** | 非负权边 | 单源到所有点 | $O((V+E)\log V)$ 堆优化 | 贪心：每次确定当前最近的未访问点 |
| **Bellman-Ford** | **允许负权边** | 单源到所有点 | $O(V \cdot E)$ | 松弛 $V-1$ 轮，可检测负环 |
| **Floyd-Warshall** | 任意（可负权，无负环） | **所有点对**之间 | $O(V^3)$ | DP：逐个引入中转点 |

**选型决策树**（记住这个就够了）：

```text
边权全相等 / 无权？        → BFS
有负权边？                 → Bellman-Ford（或 SPFA）
要所有点对且 V 不大（<500）？→ Floyd
其余（非负权、单源）        → Dijkstra
```

### Dijkstra 为什么要求非负权

Dijkstra 的贪心策略是：**每次从「未确定」的点中挑出 `dist` 最小的那个，宣布它的距离已经是最终答案，不再更改。**

这个「不再更改」的承诺，依赖一个前提：**从它出发再往外走，路径只会更长，不会更短**。这在边权非负时显然成立。但如果存在负权边，走出去反而可能变短，之前的承诺就被推翻了。

看一个具体反例：

```text
    A --(2)--> B --(1)--> D
    A --(3)--> C --(-2)-> B
```

真实最短路是 `A → C → B = 3 + (-2) = 1`，进而 `A → C → B → D = 2`。

但 Dijkstra 的执行顺序是：弹出 A(0)，得 B=2、C=3 → 弹出 **B(2) 并锁定** → 由 B 松弛出 D=3 → 弹出 C(3)，此时才发现 B 可以改进到 1。可 B 已经锁定，它传播给 D 的那个错误的 3 再也没机会回滚，最终 `dist[D] = 3`，而正确答案是 2。

**问题的根源是「过早锁定」**：负权边让「已确定的点还能变得更近」，直接推翻了贪心的前提。所以只要图里可能有负权边，就必须换 Bellman-Ford。

### Bellman-Ford 为什么松弛 $V-1$ 轮

任何一条**不含环**的最短路径最多经过 $V$ 个点，也就是最多 $V-1$ 条边。第 $k$ 轮松弛后，所有「最多 $k$ 条边」的最短路都已正确。所以 $V-1$ 轮之后一定收敛。

推论：**如果第 $V$ 轮还能松弛成功，说明图里有负环**（因为绕负环转圈可以无限变短）。这是 Bellman-Ford 的独有能力，常用于套利检测、货币兑换环路检查。

## 最小示例

```python
import heapq
from collections import deque

# 带权有向图：graph[u] = [(v, weight), ...]
graph = {
    'A': [('B', 4), ('C', 2)],
    'B': [('C', 5), ('D', 10)],
    'C': [('E', 3)],
    'D': [('F', 11)],
    'E': [('D', 4)],
    'F': [],
}


def dijkstra(graph, src):
    """堆优化 Dijkstra，要求边权非负。"""
    dist = {u: float('inf') for u in graph}
    dist[src] = 0
    prev = {}
    pq = [(0, src)]                      # (当前距离, 节点)
    visited = set()

    while pq:
        d, u = heapq.heappop(pq)
        if u in visited:                 # 懒删除：跳过过期条目
            continue
        visited.add(u)
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:             # 松弛
                dist[v] = nd
                prev[v] = u
                heapq.heappush(pq, (nd, v))
    return dist, prev


def rebuild_path(prev, src, dst):
    path, cur = [], dst
    while cur != src:
        path.append(cur)
        if cur not in prev:
            return None                  # 不可达
        cur = prev[cur]
    path.append(src)
    return path[::-1]


dist, prev = dijkstra(graph, 'A')
print(dist)
# {'A': 0, 'B': 4, 'C': 2, 'D': 9, 'E': 5, 'F': 20}
print(rebuild_path(prev, 'A', 'F'))
# ['A', 'C', 'E', 'D', 'F']
```

**手算推演** Dijkstra 从 A 出发的每一步：

| 轮次 | 弹出（锁定）| 本轮松弛的边 | 松弛后 dist 表 |
|---|---|---|---|
| 0 | — | — | A=0，其余 = ∞ |
| 1 | A(0) | A→B=4，A→C=2 | B=4, C=2 |
| 2 | C(2) | C→E=2+3 | B=4, C=2, E=5 |
| 3 | B(4) | B→C=9（比 2 大，不更新）；B→D=4+10 | D=14, E=5 |
| 4 | E(5) | E→D=5+4=9，**改进 14 → 9** | D=9 |
| 5 | D(9) | D→F=9+11 | F=20 |
| 6 | F(20) | 无出边 | 全部确定 |

第 4 轮是松弛的经典体现：D 一度被记为 14（走 `A→B→D`），但当 E 被锁定后发现 `A→C→E→D = 2+3+4 = 9` 更短，于是改进。这也说明**只有节点被弹出堆的那一刻，它的距离才最终确定**，在此之前随时可能变小。

### Bellman-Ford（支持负权 + 负环检测）

```python
def bellman_ford(graph, src):
    dist = {u: float('inf') for u in graph}
    dist[src] = 0
    edges = [(u, v, w) for u in graph for v, w in graph[u]]

    for _ in range(len(graph) - 1):      # 松弛 V-1 轮
        changed = False
        for u, v, w in edges:
            if dist[u] != float('inf') and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                changed = True
        if not changed:                  # 提前收敛，优化
            break

    for u, v, w in edges:                # 第 V 轮还能松弛 → 有负环
        if dist[u] != float('inf') and dist[u] + w < dist[v]:
            raise ValueError("图中存在负权环")
    return dist


neg_graph = {
    'A': [('B', 1)],
    'B': [('C', -2)],
    'C': [('D', 2)],
    'D': [],
}
print(bellman_ford(neg_graph, 'A'))     # {'A': 0, 'B': 1, 'C': -1, 'D': 1}
```

### Floyd-Warshall（所有点对）

```python
def floyd(nodes, edges):
    """edges: [(u, v, w), ...]；返回所有点对最短距离矩阵。"""
    INF = float('inf')
    d = {u: {v: (0 if u == v else INF) for v in nodes} for u in nodes}
    for u, v, w in edges:
        d[u][v] = min(d[u][v], w)

    for k in nodes:                      # k 是「允许的中转点」
        for i in nodes:
            for j in nodes:
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d


nodes = ['A', 'B', 'C']
edges = [('A', 'B', 3), ('B', 'C', 1), ('A', 'C', 7)]
res = floyd(nodes, edges)
print(res['A']['C'])                     # 4  ← 经 B 中转比直连的 7 更短
```

Floyd 的三重循环里，**`k` 必须在最外层**——它表示「已经考虑了前 $k$ 个中转点」的 DP 状态维度。这是这个算法唯一但致命的坑。

| 算法 | 时间 | 空间 | 负权 | 负环检测 | 输出 |
|---|---|---|---|---|---|
| BFS | $O(V+E)$ | $O(V)$ | 不适用 | 否 | 单源 |
| Dijkstra（堆） | $O((V+E)\log V)$ | $O(V)$ | ❌ 不支持 | 否 | 单源 |
| Dijkstra（朴素） | $O(V^2)$ | $O(V)$ | ❌ | 否 | 单源，稠密图更优 |
| Bellman-Ford | $O(V \cdot E)$ | $O(V)$ | ✅ 支持 | ✅ 支持 | 单源 |
| Floyd-Warshall | $O(V^3)$ | $O(V^2)$ | ✅ 支持 | ✅（对角线为负）| 所有点对 |

## 易错点

1. **在有负权边的图上用 Dijkstra。** 不会报错，只会**默默给出错误答案**——这是最危险的一类 bug。凡是权重可能为负（成本抵扣、汇率差、收益模型）的场景，先确认算法选对。

2. **忘记「懒删除」判重。** 堆优化 Dijkstra 中，同一个节点可能被多次 push 进堆（每次松弛都 push）。弹出时必须用 `if u in visited: continue` 跳过过期条目，否则会重复处理，复杂度退化。

3. **Floyd 的循环顺序写错。** 把 `k` 写在内层就变成了错误算法。记住语义：`k` 是 DP 的**阶段**，`i`、`j` 是状态，阶段必须在最外层。

4. **BFS 用在带权图上。** 边权不全相等时，BFS 求出的是「边数最少」而不是「权重和最小」。这两者完全不同——高速绕远路可能比市区直行更快。

5. **无穷大参与运算溢出。** 用 `float('inf')` 时 `inf + w` 仍是 `inf`，安全；但如果用整型的 `INT_MAX`（C++/Java），`INT_MAX + w` 会溢出成负数，导致错误松弛。必须先判断 `dist[u] != INF` 再松弛（上面 Bellman-Ford 代码就做了这个判断）。

6. **只求单点却算了全图。** Dijkstra 求「A 到 F」时，一旦 F 被弹出堆就可以直接 `break`，不必跑完所有点。大图上这能省很多时间。

## 练习

1. 给 Dijkstra 加上提前终止：找到目标点就返回，验证在上面的示例图中求 `A→C` 时只弹出了 2 个节点。
2. 实现 **A\* 算法**：在 Dijkstra 的基础上，把优先队列的键从 `dist[v]` 改成 `dist[v] + h(v)`（`h` 为到终点的估价函数）。用网格地图 + 曼哈顿距离作为 `h` 来测试，对比它比 Dijkstra 少扩展了多少节点。
3. 用 Bellman-Ford 做**套利检测**：给定若干货币兑换汇率，把权重取 $-\log(\text{rate})$，判断是否存在负环（存在即有套利机会）。
4. 手算：在示例图上跑 Bellman-Ford，写出每一轮松弛后的 `dist` 表，验证第几轮开始不再变化。
5. 实现 **0-1 BFS**：当边权只有 0 和 1 时，用双端队列（权 0 从队首入、权 1 从队尾入）可以做到 $O(V+E)$，比 Dijkstra 更快。

## 小结

最短路径的四种算法本质上是**同一个松弛操作在不同约束下的四种调度策略**：BFS 按层调度、Dijkstra 按当前最小值贪心调度、Bellman-Ford 无脑轮询 $V-1$ 遍、Floyd 按中转点做 DP。选型的第一个分水岭永远是「有没有负权边」，第二个是「单源还是全源」。掌握了这两个判断，加上 Dijkstra 的堆优化实现，你已经能应对 95% 的实际最短路需求了。
