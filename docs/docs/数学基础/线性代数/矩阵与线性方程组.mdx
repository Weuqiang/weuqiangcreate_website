# 矩阵与线性方程组

在「线性代数入门」中我们认识了向量与矩阵的基本运算。本篇聚焦**如何用矩阵表示并求解线性方程组**——这是科学计算与机器学习中最常见的操作之一。

## 学习目标

学完本章，你应该能够：

- 把线性方程组写成 `Ax=b` 的矩阵形式。
- 理解行变换（高斯消元）不改变解集。
- 区分唯一解、无解、无穷多解三种情形。
- 知道行列式为零意味着矩阵「压扁了空间」。

## 前置知识

在阅读下面的内容前，建议先掌握：

- 已掌握 [线性代数入门](/docs/数学基础/线性代数/线性代数入门) 中的向量与矩阵。
- 会解二元一次方程组。
- 了解 [编程语言数组](/docs/编程语言/Python/0基础语法) 的二维结构。

## 核心概念

线性方程组本质上是一组「用矩阵 A 把未知向量 x 变到 b」的关系，写成 `Ax=b` 后，求解就是「反着把空间变回去」。高斯消元通过行变换把系数矩阵化简成阶梯型，过程中只做「等价变形」，所以解不变。当 A 把空间压扁（行列式为零）时，反变换不存在，于是可能无解或有无穷多解——这正是线性系统解的结构三态。

本章主线：
- 从 `Ax=b` 建立矩阵视角的方程组
- 用高斯消元等价化简
- 再看解的唯一/无/无穷三态

## 1. 用矩阵表示方程组

方程组

$$
\begin{cases}
x + 2y = 5 \\
3x + 4y = 11
\end{cases}
$$

可写成矩阵形式 $A\vec{x}=\vec{b}$：

$$
\begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}
\begin{bmatrix} x \\ y \end{bmatrix}
=
\begin{bmatrix} 5 \\ 11 \end{bmatrix}
$$

其中 $A$ 是系数矩阵，$\vec{x}$ 是未知数向量，$\vec{b}$ 是常数向量。

## 2. 求解：逆矩阵法

若 $A$ 可逆，则 $\vec{x}=A^{-1}\vec{b}$。

```python
import numpy as np
A = np.array([[1., 2.], [3., 4.]])
b = np.array([5., 11.])
x = np.linalg.solve(A, b)   # 比直接求逆更稳定
print(x)                    # [1. 2.]
```

> 工程上优先用 `np.linalg.solve` 而非先求 `inv(A)`：数值更稳定、速度更快。

## 3. 无解与无穷多解

并非所有方程组都有唯一解：

- **满秩（$rank(A)=n$）**：唯一解。
- **欠定（$rank<n$）**：无穷多解。
- **矛盾**：无解（最小二乘求近似解）。

```python
A = np.array([[1., 2.], [2., 4.]])   # 第二行是第一行的 2 倍，秩为 1
b = np.array([3., 7.])
print(np.linalg.matrix_rank(A))       # 1 -> 无唯一解
```

## 4. 最小二乘

当方程数多于未知数（超定）时，常用最小二乘求「最优近似」：

$$
\vec{x}^* = \arg\min_{\vec{x}} \|A\vec{x}-\vec{b}\|^2 = (A^TA)^{-1}A^T\vec{b}
$$

```python
A = np.array([[1., 1.], [1., 2.], [1., 3.]])  # 3 行 2 列（超定）
b = np.array([2., 2.5, 4.])
x, *_ = np.linalg.lstsq(A, b, rcond=None)
print(x)   # 拟合直线的斜率与截距
```

线性回归的本质，就是求这个最小二乘解。

## 小结

线性方程组写成 `Ax=b`，高斯消元用等价行变换求解，行列式为零意味着空间被压扁、解不唯一。它承接 [矩阵入门](/docs/数学基础/线性代数/线性代数入门)，并通向 [向量空间与基](/docs/数学基础/线性代数/向量空间与基) 与 [LU 分解](/docs/数学基础/线性代数/QR与LU分解)。

## 易错点

- `np.linalg.inv` 在矩阵接近奇异时会数值爆炸；实际求解优先用 `solve` 或 `lstsq`。
- 秩不足时「解」不唯一（无穷多解）或无解；别假设一定有唯一解。
- 最小二乘的 $A^TA$ 可能奇异（特征线性相关），`lstsq` 会自动走 SVD 路径保稳定。
