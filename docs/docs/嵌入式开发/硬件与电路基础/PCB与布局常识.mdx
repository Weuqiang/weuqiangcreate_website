# PCB 与布局常识

原理图对了，板子照样可能不工作——因为**PCB 是一张"看不见的电路图"**：每根走线都是电阻加电感，每两根相邻走线之间都是电容。学会布局布线，才算真正从"会连线"进阶到"会做板"。

## 学习目标

- 理解 PCB 叠层的意义，知道为什么四层板比双层板好做太多。
- 掌握**完整地平面**与**回流路径**这两个最核心的概念。
- 会算走线宽度（载流）与过孔数量，避免电源线发热。
- 掌握模块化布局顺序：先分区、再摆关键器件、最后布线。
- 会看常见的制造参数（线宽/间距/孔径/阻焊），能把板子顺利送去打样。

## 核心概念
### 直觉一：电流一定要回家，而且走阻抗最低的路

初学者只画"去"的路径，忘了电流必须**形成回路**。高频信号的回流电流不走"最短直线"，而是**紧贴着信号线正下方的地平面回流**（因为那条路径的电感最小）。

```text
信号线 ────────────────────►
地平面 ◄══════════════════      ← 回流紧贴信号线下方，环路面积最小

如果地平面被割裂：
信号线 ────────────────────►
地平面 ═══╣ 割缝 ╠═════════      ← 回流被迫绕远路
                                    环路面积暴增 → 天线效应 → EMI + 串扰
```

**这是 PCB 设计的第一原则：永远不要割裂高速信号下方的地平面。**

### 直觉二：布局决定 80% 的成败，布线只是执行

正确的顺序是：

```text
1. 分区   ── 电源区 / 数字区 / 模拟区 / 射频区，物理上分开
2. 定位   ── 接插件、按键、指示灯先按结构要求固定
3. 关键器件 ── 晶振紧贴 MCU、去耦电容紧贴电源脚、Buck 环路最小
4. 一般器件 ── 按信号流向依次排开，减少交叉
5. 布线   ── 先电源与地，再关键信号，最后一般信号
6. 铺铜   ── 大面积地铜，检查孤岛与细颈
```

### 直觉三：叠层选择

| 叠层 | 结构 | 适用 |
|------|------|------|
| 双层 | 顶层信号 + 底层"尽量完整"的地 | 低速、成本敏感（Arduino 类） |
| 四层 | 信号 / GND / PWR / 信号 | **强烈推荐的起步选择**，有完整地平面 |
| 六层及以上 | 多组信号 + 多个平面 | 高速、BGA、多电源域 |

四层板比双层板贵不了多少，但把"回流路径"这个最大难题一次性解决掉，对新手是**性价比最高的投资**。

### 排查四件套的 PCB 版本

- **电源**：去耦电容是否贴着引脚？电源走线是否够宽？大电流路径有没有绕远？
- **时钟**：晶振与负载电容是否紧邻 MCU（走线小于 10mm）？晶振下方是否有完整地、且**不要走任何其他信号**？
- **复位**：复位线是否有 100nF 到地、走线是否远离干扰源？长复位线是天然的噪声接收天线。
- **引脚复用**：为了布线方便随意换脚前，务必确认该脚是否支持目标外设功能。

## 最小可运行例程

一份可直接套用的 **PCB 布局检查清单（Checklist）**，配合 KiCad 的设计规则设置：

```text
=== 布局阶段 ===
[ ] 电源区（Buck 电感、二极管、大电容）与模拟区物理分离 ≥ 10mm
[ ] 每个 IC 的每个 VDD 脚：100nF 去耦电容距引脚 ≤ 2mm，同层放置
[ ] 晶振与两颗负载电容紧贴 MCU，走线 ≤ 10mm，下方地平面完整
[ ] Buck 的"开关环路"（IC → 电感 → 输出电容 → 地 → IC）面积最小化
[ ] 接插件、按键、指示灯位置与结构图核对无误
[ ] 发热器件（LDO、MOS、电阻）远离温度传感器与晶振

=== 布线阶段 ===
[ ] 电源走线按载流计算加宽，必要时铺铜带
[ ] 地平面完整，无因走线导致的长条形割裂
[ ] 差分对（USB / CAN / 以太网）等长、等距、全程平行
[ ] 高速线不跨越平面分割，不走板边
[ ] 模拟地与数字地单点连接（或用四层板同一地平面 + 分区布局）
[ ] 走线换层处附近加地过孔，给回流提供通路
[ ] 无 90° 直角走线（改 45° 或圆弧）

=== 出图阶段 ===
[ ] DRC 全过，无未布线网络
[ ] 丝印不压焊盘，极性标识（二极管、电解电容、IC 第一脚）清晰
[ ] 加板名、版本号、日期丝印，方便日后区分打样批次
[ ] 泪滴、阻焊开窗、拼板工艺边按厂家要求处理
```

走线宽度的估算（依据 IPC-2221，1oz 铜、外层、温升 10℃）：

```text
载流粗略口诀（外层 1oz 铜、允许 10℃ 温升）：
  0.25mm (10mil) ≈ 0.9A
  0.5mm  (20mil) ≈ 1.5A
  1.0mm  (40mil) ≈ 2.5A
  2.0mm  (80mil) ≈ 4.0A
内层散热差，按外层的 50%~60% 折算。
过孔：0.3mm 孔径的过孔约可过 0.5~1A，大电流处并多个过孔。
```

固件侧也能反过来验证布局质量——用一段"最坏情况压力测试"来暴露布线问题：

```c
/* 让所有大电流负载同时动作，观察 MCU 是否死机、ADC 是否跳变
   这是验证电源完整性与地弹最有效的固件手段 */
void pcb_stress_test(void)
{
    for (int i = 0; i < 1000; i++) {
        motor_pwm_set(100);                     /* 电机全速 */
        relay_toggle();                         /* 继电器反复吸合，制造浪涌 */
        wifi_send_burst(1024);                  /* 无线满功率发射 */

        uint16_t adc = adc_read_blocking();     /* 同时采样 */
        if (adc > ADC_EXPECT_MAX || adc < ADC_EXPECT_MIN) {
            printf("[FAIL] i=%d adc=%u 采样被干扰，检查模拟区隔离\r\n", i, adc);
        }
        HAL_Delay(5);
    }
}
```

## 易错点

- **地平面被走线切成长条**：这是双层板最致命的错误。底层地平面上横穿一根长走线，就把回流路径拦腰截断了。改法：把那根线挪到顶层，或加地过孔跨接。
- **去耦电容"放在了图上好看的位置"**：布局阶段被挪到芯片外围一圈，实际相当于没放。
- **晶振走线过长或下方走了别的信号**：现象是时钟不起振、频率偏移、通信误码率高。
- **大电流与小信号共用回流路径**：电机地电流经过 ADC 参考地，地弹直接叠加成采样误差。
- **USB / 差分对没做等长等距**：低速下也许能用，但一遇到长线或高温就出问题。
- **过孔太少导致电源发热**：一个 0.3mm 过孔过 3A 会明显发热，大电流换层必须并联多孔。
- **丝印压焊盘**：工厂会自动裁掉，导致极性看不清、贴片方向贴反。
- **忘了工艺边和定位孔**：贴片厂无法上机，只能返工加拼板。
- **首板不留测试点**：调试时找不到地方接探头，只能刮阻焊。关键网络（电源、复位、串口、SWD）都应留 1mm 测试焊盘。

## 练习

1. 用 KiCad 画一块最小 STM32 系统板（MCU + LDO + 晶振 + SWD + 串口），严格按上文清单自检一遍。
2. 故意做两版布局：一版去耦电容贴脚放、一版放到 20mm 外，打样后用示波器对比电源脚的瞬态跌落。
3. 在双层板上找出所有"地平面被割裂"的位置，用地过孔和跨接方式修复，记录修改前后的数量。
4. 为一个 3A 的电机驱动回路计算走线宽度与过孔数量，并在板上实测满载 10 分钟后的温升。

## 小结

PCB 设计的核心不是"把线连上"，而是**管理回流路径与环路面积**。记住三句话：优先上四层板保住完整地平面；布局阶段就把去耦电容、晶振、开关环路安排好；关键信号绝不跨越平面分割。剩下的靠 Checklist 逐条过——这份清单比任何理论都更能救你的第一版板子。
