## 核心概念

### 语音合成的三段式

传统 TTS（Text-to-Speech）流水线：

```
文本 → 文本前端(归一化/分词/韵律) → 声学模型(文本→频谱) → 声码器(频谱→波形)
```

- **文本前端**：把「2026年」读成「二零二六年」、处理多音字与停顿。
- **声学模型**：预测中间表征（梅尔频谱或离散 token）。
- **声码器**：把频谱还原成可播放的波形。现代声码器多为神经网络（WaveNet、HiFi-GAN、或扩散声码器）。

代表高质量端到端模型：VITS、NaturalSpeech 系列——把对齐、声学、声码器合一训练，自然度接近真人。

### 神经音频 codec：让音频进入「token 世界」

要让大模型直接「说」和「听」，需要把连续波形变成离散 token，就像文本 token 一样可被 Transformer 处理。方法是**神经音频 codec**：

- **SoundStream / EnCodec**：用编码器-量化器-解码器结构，把 24kHz 波形压缩成每秒几十到上百个离散 token，且能近乎无损重建。
- 量化常用 **残差向量量化（RVQ）**：多层码本逐级修正，兼顾压缩率与保真度。

有了 codec，音频就变成了「另一种语言的 token 序列」，可以和文本 token 拼在一起训练。

### 音频大语言模型（原生语音对话）

代表：Whisper（语音识别）、以及 GPT-4o 风格的**端到端语音对话模型**。关键进化是**不再「先转文字再对话」**，而是：

- 输入：用户语音 → codec 编码为音频 token；
- 模型在统一 token 空间里「理解」并「生成」回复的音频 token；
- 输出：音频 token → codec 解码 → 语音。

好处是能保留**语气、情感、停顿、笑声**等副语言信息，这是纯文本中转会丢失的。挑战是音频 token 序列很长，需要 [长上下文](/docs/人工智能/大模型与应用/长上下文与位置编码扩展) 与流式处理。

### 音乐生成

音乐比语音多一层**结构约束**（节拍、调性、段落重复）。代表：

- **MusicGen / AudioCraft**：基于语言模型在音频 token 上自回归生成，支持文本/旋律条件。
- **Suno / Udio 类**：产品级「文本→完整歌曲」，内含人声合成与编曲。
- 常用 **扩散模型** 生成高保真片段，再用 LLM 做长时序拼接。

音乐生成的难点在**长程一致性**（副歌要重复、不能中途跑调），与 [视频生成](/docs/人工智能/深度学习/视频生成) 的时序一致性是同一类问题。

## 示例

一个最小「文本→音频 token→波形」的生成骨架（伪代码）：

```python
codec = EnCodec()                       # 预训练神经 codec
lm    = AudioLLM()                      # 在音频 token 上训练的语言模型

text_tokens  = text_tok("用温和的语气读这段话")
audio_prompt = codec.encode(reference_voice_wav)   # 参考音色 → token

# 自回归生成回复的音频 token
gen_tokens = lm.generate(text_tokens, prefix=audio_prompt, max_len=1500)
# 解码回波形
wav = codec.decode(gen_tokens)
play(wav)
```

要点：参考音色以「音频 token 前缀」注入，使合成声音带特定人声特征——这是 zero-shot 声音克隆的常见做法。

## 易错点

- **把 Whisper 当成语音合成**：Whisper 是 ASR（语音→文本），不做合成；合成要看 VITS/NaturalSpeech 类。
- **忽视流式与首包延迟**：实时对话对「说出第一个字」的延迟极敏感，非流式 TTS 不可用在对讲场景。
- **codec 码本过大**：码本越大越保真但 token 越长、越难训；需在压缩率与质量间权衡。
- **音乐生成跑调/结构崩**：纯自回归容易长程失稳，需要显式节拍/段落条件或扩散式长时序建模。

## 小结

语音与音频生成已从「拼接式 TTS」演进到「**神经 codec + 音频 LLM**」的统一范式：SoundStream/EnCodec 把声音变成 token，使语音能直接接入大模型生态，催生了原生语音对话与音乐生成。它与 [多模态统一生成模型](/docs/人工智能/大模型与应用/多模态统一生成模型) 共享「万物 token 化」的思路，也共享其长序列与一致性的工程难题。
