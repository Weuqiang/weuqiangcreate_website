# 栈与队列

栈和队列是「加了进出规则」的线性结构：数组/链表能任意位置增删，而栈和队列**只允许在特定的端**操作。规则越简单，越能解决特定问题。

## 学习目标

- 区分栈（LIFO）与队列（FIFO）的进出规则。
- 用 Python 的 `list` / `collections.deque` 实现二者。
- 识别栈/队列的典型应用场景（括号匹配、BFS 等）。

## 前置知识

- [数组与链表](../数组与链表) — 栈和队列通常基于它们实现。

## 核心概念

### 1. 栈（Stack）：后进先出（LIFO）

只在**同一端**（栈顶）压入（push）和弹出（pop）。像一摞盘子：最后放上去的先拿。

核心操作：$O(1)$ 的 `push` / `pop` / `peek`（看栈顶但不弹出）。

### 2. 队列（Queue）：先进先出（FIFO）

从**一端**（队尾）入队（enqueue），从**另一端**（队头）出队（dequeue）。像排队买票：先来的先走。

普通队列用数组实现时，出队后前面空位会浪费；所以用**循环队列**或双端队列（`deque`）更优。

### 3. 什么时候用哪个

- 需要「回头处理最近的东西」→ 栈（撤销、函数调用、括号匹配）。
- 需要「按到达顺序依次处理」→ 队列（BFS、任务调度、缓冲）。

## 最小可运行示例

栈（直接用 `list`，但 `pop(0)` 是 $O(n)$，所以栈用 `append`/`pop()` 在尾部操作）：

```python
stack = []
stack.append(1)      # push
stack.append(2)
print(stack.pop())   # pop -> 2（最后进的先出）
print(stack[-1])     # peek -> 1
```

队列（用 `collections.deque`，两端都是 $O(1)$）：

```python
from collections import deque
q = deque()
q.append(1)          # 入队（右端）
q.append(2)
print(q.popleft())   # 出队（左端）-> 1（最先进的先出）
print(q[0])          # 看队头 -> 2
```

应用：用栈做括号匹配

```python
def is_valid(s: str) -> bool:
    st, pair = [], {')':'(', ']':'[', '}':'{'}
    for ch in s:
        if ch in '([{':
            st.append(ch)
        elif ch in ')]}':
            if not st or st.pop() != pair[ch]:
                return False
    return not st

print(is_valid("({[]})"))   # True
print(is_valid("([)]"))     # False
```

## 易错点

1. **栈别用 `pop(0)`**：`list.pop(0)` 是 $O(n)$。栈务必在尾部 `append`/`pop()`。
2. **队列别用 `list.pop(0)`**：同样 $O(n)$；改用 `deque.popleft()`。
3. **空时弹出**：栈/队为空时 `pop`/`popleft` 会抛异常，操作前先判断 `if stack:` / `if q:`。
4. **混淆两端**：队列一定要「一头进、另一头出」，否则退化成栈。

## 练习

1. 用栈实现一个「最小栈」：在 $O(1)$ 内返回栈中最小值。
2. 用两个栈实现一个队列；用两个队列实现一个栈。
3. 用队列（BFS）求二叉树某层节点数（提示：见 [树与二叉树](../树与二叉树)）。

## 小结

栈管「最近」，队管「顺序」。它们把数组/链表的能力收窄，反而让特定问题变得清晰。下一步看 [排序算法](../排序算法)，那里会用到递归与分治思想。
