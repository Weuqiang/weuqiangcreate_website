# 特征值与特征向量

矩阵是空间变换。大多数向量在被矩阵作用后既转向又伸缩，但总有一些「幸运方向」只被拉长或压短、方向不变——它们就是特征向量，拉伸倍数就是特征值。

## 学习目标

- 用几何语言解释 $A\vec{v}=\lambda\vec{v}$，并判断一个给定向量是否为特征向量。
- 手算 $2\times2$ 矩阵的特征值与特征向量，并用 numpy 校验。
- 用对角化 $A=PDP^{-1}$ 把矩阵幂 $A^k$ 的计算变成标量幂。
- 说明特征值在稳态分析、PCA、迭代收敛判断中的作用。

## 核心概念
想象一块被均匀拉伸的橡皮膜。你在膜上画满从原点出发的箭头，拉伸后绝大多数箭头都会歪掉；但沿着「主拉伸方向」的箭头只会变长，指向纹丝不动。这些方向就是**特征向量**，变长的倍数就是**特征值**。

形式化地：

$$
A\vec{v}=\lambda\vec{v},\qquad \vec{v}\neq\vec{0}
$$

移项得 $(A-\lambda I)\vec{v}=\vec{0}$。要有非零解，$A-\lambda I$ 必须**不可逆**，即

$$
\det(A-\lambda I)=0
$$

这就是**特征多项式**，它的根就是全部特征值。

特征值的三个直观含义值得牢记：

- **$|\lambda|>1$ 是放大方向，$|\lambda|<1$ 是收缩方向**。反复施加 $A$ 时，最大 $|\lambda|$ 对应的方向会主导一切——这正是幂法、PageRank、马尔可夫链稳态收敛的原理。
- **$\lambda=0$ 意味着这个方向被压扁**，此时 $A$ 不可逆，$\det A=\prod\lambda_i=0$。
- **迹与行列式是特征值的摘要**：$\mathrm{tr}(A)=\sum\lambda_i$，$\det(A)=\prod\lambda_i$。这两条是手算后最快的自检方式。

如果 $n\times n$ 矩阵有 $n$ 个线性无关的特征向量，把它们按列拼成 $P$，特征值放在对角阵 $D$ 上，就得到**对角化**：

$$
A=PDP^{-1}\quad\Longrightarrow\quad A^k=PD^kP^{-1}
$$

意义非常大：在特征向量这组基下，复杂的矩阵作用退化成「每个坐标各自乘一个数」。所有耦合都被解开了。

## 最小示例

先手算 $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$。

$$
\det(A-\lambda I)=(2-\lambda)^2-1=\lambda^2-4\lambda+3=(\lambda-1)(\lambda-3)
$$

得 $\lambda_1=3,\ \lambda_2=1$。代入 $\lambda=3$：$(A-3I)\vec v=\begin{bmatrix}-1&1\\1&-1\end{bmatrix}\vec v=\vec0$，得 $\vec v_1=(1,1)$；代入 $\lambda=1$ 得 $\vec v_2=(1,-1)$。自检：$\mathrm{tr}=4=3+1$ ✔，$\det=3=3\times1$ ✔。

```python
import numpy as np

A = np.array([[2., 1.],
              [1., 2.]])

vals, vecs = np.linalg.eig(A)
print(vals)            # [3. 1.]
print(vecs)            # 每一列是一个单位化的特征向量

# 验证定义 A v = λ v（取第 0 个）
v0 = vecs[:, 0]
print(A @ v0, vals[0] * v0)   # 两者相同 ✔

# ---- 对角化算矩阵幂：A^10 ----
P = vecs
D = np.diag(vals)
A10_diag = P @ np.diag(vals**10) @ np.linalg.inv(P)
A10_direct = np.linalg.matrix_power(A, 10)
print(np.allclose(A10_diag, A10_direct))   # True ✔

# ---- 幂法：反复作用后方向收敛到最大特征值对应的特征向量 ----
x = np.array([1., 0.])
for _ in range(30):
    x = A @ x
    x = x / np.linalg.norm(x)     # 每步归一化，防止数值溢出
print(x)          # ≈ [0.707 0.707]，即 (1,1) 方向 ✔
print(x @ A @ x)  # ≈ 3.0，瑞利商给出对应特征值 ✔
```

## 易错点

- **特征向量不唯一**。$\vec v$ 是特征向量，$c\vec v\ (c\neq0)$ 也是。numpy 返回的是单位化结果，符号可能与你手算相反，这不是错误。
- **不是所有实矩阵都有实特征值**。旋转矩阵 $\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ 的特征值是 $\pm i$——纯旋转确实没有方向不变的实轴。
- **重根不等于可对角化**。$\begin{bmatrix}1&1\\0&1\end{bmatrix}$ 的 $\lambda=1$ 是二重根，却只有一个线性无关特征向量，无法对角化（需要 Jordan 型）。
- **别把特征值和奇异值搞混**。特征值要求方阵、可能为负或复数；奇异值对任意矩阵都有、恒为非负实数。对称正定矩阵下两者才一致。

## 练习

1. 求 $\begin{bmatrix}4&1\\2&3\end{bmatrix}$ 的特征值。
   *提示：$\lambda^2-7\lambda+10=0$，得 $\lambda=5,2$；用 $\mathrm{tr}=7,\det=10$ 自检。*
2. 已知 $A$ 的特征值为 $0.9$ 和 $0.5$，问 $A^{k}\vec x$ 当 $k\to\infty$ 会趋于什么？
   *答案：趋于零向量，因为两个 $|\lambda|$ 都小于 1；衰减速度由较大的 $0.9$ 主导。*
3. 证明：若 $\lambda$ 是 $A$ 的特征值且 $A$ 可逆，则 $1/\lambda$ 是 $A^{-1}$ 的特征值。
   *提示：在 $A\vec v=\lambda\vec v$ 两边左乘 $A^{-1}$ 并除以 $\lambda$（$\lambda\neq0$ 因为 $A$ 可逆）。*

## 小结

特征向量是矩阵作用下方向不变的轴，特征值是该轴上的缩放倍数。它们由 $\det(A-\lambda I)=0$ 求得，且满足 $\sum\lambda_i=\mathrm{tr}(A)$、$\prod\lambda_i=\det(A)$ 两条便捷自检。当特征向量足够多时可对角化，把矩阵幂化为标量幂，这是分析长期演化（马尔可夫稳态、迭代法收敛）的核心武器。但特征值只对方阵有定义、也不总是实数，遇到一般矩阵时应改用奇异值分解。
