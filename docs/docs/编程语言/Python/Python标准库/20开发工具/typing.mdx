## typing 模块

`typing` 模块提供高级类型支持，**注意：类型提示只在静态检查阶段有意义，运行时不做任何强制**。

```python
from typing import List, Dict, Tuple, Optional, Union

# 容器类型
names: List[str] = ["Alice", "Bob"]
person: Dict[str, Union[str, int]] = {"name": "Alice", "age": 30}

# 可选类型
def get_age(name: str) -> Optional[int]:
    if name == "Alice":
        return 30
    return None

# 类型别名
UserId = int
user_id: UserId = 1001
```

### 泛型 (Generic)

创建可复用的类型安全容器：

```python
from typing import TypeVar, Generic, List

T = TypeVar('T')

class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: List[T] = []
    
    def push(self, item: T) -> None:
        self._items.append(item)
    
    def pop(self) -> T:
        return self._items.pop()

# 使用
int_stack: Stack[int] = Stack()
int_stack.push(42)
```

### Literal 字面量类型

限制值只能是特定的字面量：

```python
from typing import Literal

def set_mode(mode: Literal["read", "write", "append"]) -> None:
    print(f"Mode set to: {mode}")

set_mode("read")    # 正确
set_mode("delete")  # 类型检查器会报错

# 多种类型的字面量
def process_flag(flag: Literal[True, False, 0, 1]) -> None:
    pass
```

## 易错点

- **Python 3.9+ 推荐内置写法**：`list[str]` / `dict[str, int]` 已经可用，`typing.List` 仍兼容但偏旧；新项目优先用内置泛型。
- **类型提示不检查运行时**：`x: int = "abc"` 运行时不会报错，只有 `mypy` / `pyright` 才会提示；它不改变程序行为。
- **`Optional[X]` ≠ "可省略的参数"**：它等价于 `Union[X, None]`，表示"可能是 X 也可能是 None"，通常用于返回值或允许为空的变量。
- **嵌套泛型要写全**：`list[dict[str, int]]` 不要漏内层，否则检查器推断不出真实类型。
- **循环引用/前向引用**：标注尚未定义的类时，用字符串 `"ClassName"` 作前向引用，或在文件顶部 `from __future__ import annotations`。
- **`TypedDict` 描述固定结构的 dict**：键固定、值有类型，比裸 `Dict[str, Any]` 表达力更强。
