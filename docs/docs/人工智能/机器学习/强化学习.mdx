## 核心概念

### 1. 与另两大范式的根本区别

| 范式 | 数据 | 信号 | 典型目标 |
|---|---|---|---|
| 监督 | 带标签 | 每个样本有正确答案 | 拟合输入→输出映射 |
| 无监督 | 无标签 | 数据结构本身 | 聚类/降维 |
| 强化 | 与环境交互 | 延迟、稀疏的奖励 | 最大化长期回报 |

RL 的独特难点：**信用分配**（某步动作导致许多步后的奖励，如何归因）与**探索-利用权衡**（试新动作还是用已知好动作）。

### 2. MDP：序列决策的骨架

马尔可夫决策过程用五元组 $(S,A,P,R,\gamma)$：
- $S$ 状态集，$A$ 动作集
- $P(s'\mid s,a)$ 转移概率（满足马尔可夫性：下一状态只依赖当前状态与动作）
- $R(s,a)$ 即时奖励
- $\gamma\in[0,1)$ 折扣因子，越远的奖励权重越低

智能体的「策略」$\pi(a\mid s)$ 给出在状态 $s$ 下选动作的概率。

### 3. 价值函数与贝尔曼方程

- 状态价值 $V^\pi(s)=\mathbb{E}_\pi[\sum_{t=0}^\infty \gamma^t r_t\mid s_0=s]$
- 动作价值 $Q^\pi(s,a)=\mathbb{E}_\pi[\sum_{t=0}^\infty \gamma^t r_t\mid s_0=s,a_0=a]$

最优价值满足**贝尔曼最优方程**：

$$
Q^\star(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\max_{a'}Q^\star(s',a')
$$

它把「长期最优」拆成「即时奖励 + 折扣后的未来最优」，是几乎所有 RL 算法的递归基础。

### 4. 基于价值：Q-learning

Q-learning 用一张表（或网络）估计 $Q(s,a)$，通过与环境交互的转移 $(s,a,r,s')$ 做**时序差分（TD）更新**：

$$
Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]
$$

括号里是 **TD 误差**：「实际得到的（r+未来最优）」与「预期 Q」的差。离轨（off-policy）特性让它可以从旧经验学。Deep Q-Network（DQN）用神经网络代替 Q 表，并加经验回放与目标网络稳定训练。

### 5. 基于策略：策略梯度

当动作空间连续或大，直接参数化策略 $\pi_\theta(a\mid s)$ 并用梯度上升最大化期望回报：

$$
\nabla_\theta J(\theta)=\mathbb{E}\big[\nabla_\theta\log\pi_\theta(a\mid s)\,G_t\big]
$$

其中 $G_t$ 是从时刻 $t$ 起的回报（可用基线减偏）。REINFORCE 是最朴素的实现；Actor-Critic 同时学一个价值网络（Critic）来降低方差。

## 示例

用 Q-learning 在一个小网格世界里学「走到终点拿奖励」（表格版，直观）：

```python
import numpy as np

# 4x4 网格，终点 (3,3) 奖励 +1，其余每步 -0.01；撞墙不动
n = 4
Q = np.zeros((n*n, 4))            # 状态×动作(上右下左)
goal = (3, 3)
alpha, gamma = 0.1, 0.95

def step(s, a):
    r, c = s
    if a == 0: r = max(0, r-1)
    elif a == 1: c = min(n-1, c+1)
    elif a == 2: r = min(n-1, r+1)
    elif a == 3: c = max(0, c-1)
    ns = (r, c)
    reward = 1.0 if ns == goal else -0.01
    return ns, reward

np.random.seed(0)
for ep in range(2000):
    s = (0, 0)
    for _ in range(50):
        si = s[0]*n + s[1]
        if np.random.rand() < 0.2:               # ε-探索
            a = np.random.randint(4)
        else:
            a = Q[si].argmax()
        ns, r = step(s, a)
        ni = ns[0]*n + ns[1]
        td = r + gamma * Q[ni].max() - Q[si, a]
        Q[si, a] += alpha * td
        s = ns
        if s == goal:
            break

# 沿学到的 Q 走一遍，看是否直达终点
s = (0, 0); path = [s]
for _ in range(20):
    si = s[0]*n + s[1]
    a = Q[si].argmax()
    s, _ = step(s, a); path.append(s)
    if s == goal: break
print("学到的路径长度:", len(path)-1, "是否到达终点:", s == goal)
```

跑完智能体学会了绕过无效方向、直奔终点——这正是从奖励而非标签中学出的策略。

## 易错点

- **把 RL 当监督学习用**：没有每步的「正确动作」标签，只有奖励；强行打标签会丢掉 RL 处理延迟奖励的精髓。
- **折扣因子 γ 设 1**：无折扣时 episodic 任务可能不收敛、回报可能无穷；通常用 0.9~0.99。
- **探索不足导致次优**：纯贪心很快停在不佳策略；ε-探索或熵正则保探索。
- **奖励塑形（reward shaping）误导**：加错中间奖励可能让智能体学会「刷分」而非真目标（如机器人原地打转拿小奖）。

## 练习

1. 写出贝尔曼最优方程，并说明为什么它是递归而非直接可解的。
2. Q-learning 的 TD 误差项 $r+\gamma\max_{a'}Q(s',a')-Q(s,a)$ 各部分的含义？
3. 策略梯度里为什么乘 $\log\pi_\theta(a\mid s)$ 而不是 $a$ 本身？基线（baseline）起什么作用？

## 小结

强化学习是「从奖励中学决策」的第三范式：用 MDP 建模、用价值函数与贝尔曼方程刻画长期回报，再用 Q-learning（基于价值）或策略梯度（基于策略）优化。它是游戏 AI、机器人控制、以及大模型 RLHF 的数学基础。
