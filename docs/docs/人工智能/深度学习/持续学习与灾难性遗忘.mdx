## 核心概念

### 什么是灾难性遗忘

标准神经网络在**顺序学习多个任务**时，学完任务 B 会剧烈损害在任务 A 上的表现——这叫**灾难性遗忘（Catastrophic Forgetting）**。根源是：网络权重是任务 A、B 共享的，优化 B 的梯度会无差别地改写对 A 关键的权重，而「没有机制保护旧知识」。

这与人类「学了法语不忘英语」相反。持续学习（Continual Learning, CL）的目标就是**在不重放全部旧数据的前提下，缓解遗忘**。

### 三大范式

| 范式 | 思路 | 代表方法 |
|------|------|---------|
| **经验回放（Replay）** | 保留/生成旧任务的少量样本，训练时混进新批次 | ER、生成式回放（GA）、Gradient Episodic Memory |
| **正则化（Regularization）** | 对「对旧任务重要的权重」加约束，限制其变动 | EWC（ Fisher 信息）、LwF（知识蒸馏）、SI |
| **参数隔离（Parameter Isolation）** | 为新任务分配专属参数/子网络，旧参数不动 | PackNet、Adapter、Progressice Neural Networks |

- **EWC（弹性权重固化）**：用旧任务上的 Fisher 信息矩阵估计每个权重的重要性 $\Omega_i$，在损失里加罚项 $\frac{\lambda}{2}\Omega_i(\theta_i-\theta_i^*)^2$，重要权重「焊死」、不重要权重自由调。
- **LwF（学习而不遗忘）**：用旧模型对旧任务输入的输出作软标签，新模型需同时拟合新标签与「别偏离旧软标签」，本质是蒸馏。

### 评估协议

持续学习不能只看最终准确率，要看**记忆与迁移**：

- **准确率矩阵 $R_{i,j}$**：学完第 $j$ 个任务后在任务 $i$ 上的表现。
- **向后迁移（BWT）**：学后续任务后，前期任务准确率的平均变化（负值即遗忘）。
- **向前迁移（FWT）**：前期任务是否帮后续任务学得更快。

### 与大模型的关系

LLM 的**持续预训练（CPT）**与**微调**都会触发遗忘：

- 在领域语料上继续预训练，可能让通用能力（如推理、代码）下降——「学了新的，忘了旧的」。
- 缓解：回放一小部分通用数据（replay mix）、用 LoRA/Adapter 等新参数隔离方式（见 [模型微调](/docs/人工智能/大模型与应用/模型微调) 的 LoRA）、或对关键权重加正则。
- 这与 [AI 安全对齐](/docs/人工智能/大模型与应用/AI安全对齐) 中「更新模型不能破坏既有安全行为」是同一类约束。

## 示例

一个最小的 EWC 罚项（伪代码）：

```python
# 在旧任务结束后，估计权重重要性 Omega（Fisher 信息的对角近似）
fisher = estimate_fisher(model, old_task_data)      # 对每个权重：梯度平方的期望值
old_params = {n: p.detach().clone() for n, p in model.named_parameters()}

def ewc_loss(new_batch, lambda_=1000):
    ce = cross_entropy(model(new_batch.x), new_batch.y)        # 新任务损失
    reg = 0.0
    for n, p in model.named_parameters():
        reg += (fisher[n] * (p - old_params[n]) ** 2).sum()    # 重要权重不许大幅变动
    return ce + lambda_ * reg / 2
```

要点：`fisher[n]` 大的权重是「旧任务命门」，被罚项保护；小的权重才允许为新任务调整。

## 易错点

- **只报最终平均准确率**：掩盖了「前期任务已崩」的事实，必须看 BWT/记忆矩阵。
- **回放数据泄漏隐私**：真实回放要保存旧样本，医疗/金融场景可能不允许；此时用生成式回放（用旧模型造伪样本）替代。
- **正则项系数难调**：$\lambda$ 太大模型僵化学不动新任务，太小则遗忘照旧，需按任务难度搜索。
- **混淆 CL 与多任务学习**：多任务是同时看所有任务数据，CL 是顺序且不可回看全部旧数据——约束根本不同。

## 小结

持续学习要解决「顺序学新任务不忘旧任务」。灾难性遗忘源于共享权重被无差别改写；三大范式——**回放**（保旧样本）、**正则**（护重要权重，如 EWC/LwF）、**参数隔离**（分槽位）——分别从数据、约束、结构上缓解。它直接关乎 [大模型持续预训练](/docs/人工智能/大模型与应用/模型微调) 与 [安全对齐](/docs/人工智能/大模型与应用/AI安全对齐) 中「更新不破坏旧能力」的实际工程约束。
