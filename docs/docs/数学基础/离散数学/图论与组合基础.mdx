图是「点 + 边」的结构，几乎能建模一切关系：社交网络、依赖图、路由、任务调度。组合数学则回答「有多少种可能」。

## 核心概念

图论把「事物及其关系」抽象成点和边：社交网络是图，路线图是图，依赖关系也是图。遍历算法（BFS 按层扩散、DFS 一条路走到底）是几乎所有图处理的基础；最短路径则在加权图上找代价最小的连接。组合数学则回答「有多少种安排方式」，排列组合与容斥原理是计数问题的通用工具，也是概率与算法分析的常客。

本章主线：
- 从「点边模型」建立图的世界观
- 用 BFS/DFS 与最短路径处理图
- 再用组合计数量化「可能性数量」

## 1. 图的基本概念

- **无向图 / 有向图**：边是否区分方向。
- **度（degree）**：与某点相连的边数。
- **路径 / 环**：顶点序列；首尾相连即成环。

```python
from collections import defaultdict
# 邻接表表示图
graph = defaultdict(list)
edges = [("A","B"), ("B","C"), ("A","C"), ("C","D")]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)
print(graph["C"])   # ['B', 'A', 'D']
```

## 2. 遍历：BFS 与 DFS

- **广度优先（BFS）**：逐层扩展，求无权图最短路径。
- **深度优先（DFS）**：一路到底再回溯，用于连通性、拓扑排序。

```python
from collections import deque
def bfs(start):
    seen, q = {start}, deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in seen:
                seen.add(v); q.append(v)
    return seen
print(bfs("A"))   # {'A','B','C','D'}
```

## 3. 最短路径

带权图常用 Dijkstra：每次松弛「当前最近且未确定」的节点。

```python
import heapq
# 简例：{(u, v): 权重}
def dijkstra(adj, src):
    dist = {src: 0}
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float("inf")): continue
        for v, w in adj[u]:
            if d + w < dist.get(v, float("inf")):
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

## 4. 组合计数

- 排列 $P(n,k)=\frac{n!}{(n-k)!}$
- 组合 $C(n,k)=\binom{n}{k}=\frac{n!}{k!(n-k)!}$
- 鸽巢原理：把 $n+1$ 个物体放入 $n$ 个盒子，必有一盒 ≥2。

组合数是概率分母、哈希冲突分析、信息论熵的基础。

## 示例

**组合数计数**：从 10 人中选 3 人组队，不考虑顺序：

$$
C_{10}^{3}=\binom{10}{3}=\frac{10\times9\times8}{3\times2\times1}=120
$$

**Dijkstra 逐步松弛**（权图 `A-(1)->B-(2)->C, A-(4)->C`，求 A 到各点最短距离）：

```
初始: dist={A:0, B:∞, C:∞}
取 A(0): 松弛 B→1, C→4        dist={A:0,B:1,C:4}
取 B(1): 经 B 到 C: 1+2=3 < 4  → 更新 C=3
取 C(3): 无更优
结果: A→B=1, A→C=3
```

```python
adj = {"A":[("B",1),("C",4)], "B":[("C",2)], "C":[]}
print(dijkstra(adj, "A"))   # {'A':0,'B':1,'C':3}
```

## 小结

图用点边抽象关系，BFS/DFS 与最短路径是处理图的主干算法，组合计数则量化可能性。它承接 [集合逻辑](/docs/数学基础/离散数学/集合逻辑与证明)，并与 [数据结构与算法](/docs/计算机科学基础/数据结构与算法/图与遍历) 紧密耦合，也支撑 [马尔可夫链](/docs/数学基础/概率与统计/马尔可夫链) 的图模型。

## 易错点

- 无向图的「度之和 = 2 × 边数」：每条边贡献两个端点，奇度顶点必有偶数个。
- BFS 用队列、DFS 用栈（或递归），混用会导致遍历顺序错误。
- 排列 $P(n,k)$ 与组合 $C(n,k)$ 的区别只在「是否关心顺序」：发奖牌是排列，组队是组合。
