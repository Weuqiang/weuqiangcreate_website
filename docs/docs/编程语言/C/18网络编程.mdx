# C 网络编程（socket）

C 做网络编程直接调用 **BSD socket** API（`<sys/socket.h>`、`<netinet/in.h>`、`<arpa/inet.h>`），这是 TCP/IP 协议栈在应用层的接口，几乎所有语言的高层网络库都建立在它之上。

## 学习目标

学完本章，你应该能够：

- 理解 socket 模型与客户端/服务器分工
- 掌握 TCP 的 `socket`/`bind`/`listen`/`accept`/`connect` 流程
- 能写一个最小可用的回显服务器与客户端

## 前置知识

在阅读下面的内容前，建议先掌握：

- [并发执行（pthread）](../17并发执行)

## 核心概念

网络编程本质是「用文件描述符做跨机器的字节流」：socket 把网络连接抽象成可 read/write 的句柄。TCP 用「三次握手 + 可靠字节流」保证有序到达，服务器端 listen/accept、客户端 connect 完成握手。

本章主线：
- socket 抽象与 C/S 模型
- TCP 流程：`socket`→`bind`→`listen`→`accept`
- 客户端：`connect` 与收发
- 阻塞 I/O 与并发服务器雏形

## 1. TCP 通信模型

```text
服务端：socket → bind → listen → accept → recv/send → close
客户端：socket → connect → send/recv → close
```

## 2. 最小 TCP 服务端

```c
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <stdio.h>
#include <unistd.h>
#include <string.h>

int main(void) {
    int srv = socket(AF_INET, SOCK_STREAM, 0);
    struct sockaddr_in addr = {0};
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(8080);            // 端口要转网络字节序

    bind(srv, (struct sockaddr *)&addr, sizeof(addr));
    listen(srv, 5);
    printf("listening on 8080...\n");

    int cli = accept(srv, NULL, NULL);      // 阻塞等客户端
    char buf[128];
    int n = read(cli, buf, sizeof(buf) - 1);
    buf[n] = '\0';
    printf("recv: %s\n", buf);
    write(cli, "ok", 2);
    close(cli);
    close(srv);
    return 0;
}
```

## 3. 最小 TCP 客户端

```c
int sock = socket(AF_INET, SOCK_STREAM, 0);
struct sockaddr_in srv = {0};
srv.sin_family = AF_INET;
srv.sin_port = htons(8080);
inet_pton(AF_INET, "127.0.0.1", &srv.sin_addr);

connect(sock, (struct sockaddr *)&srv, sizeof(srv));
write(sock, "hi", 2);
char buf[128];
int n = read(sock, buf, sizeof(buf) - 1);
buf[n] = '\0';
printf("reply: %s\n", buf);
close(sock);
```

## 4. 必须注意的字节序

网络协议统一用**大端（网络字节序）**，而 x86 是小端。所以：

- 端口、IP 等要用 `htons` / `htonl` 转成网络序；
- 多字节数据（如自定义协议的长度字段），收发双方要约定一致，否则跨机乱码。

## 易错点

- **`htons` 漏写**：端口没转网络字节序，`bind` 到错误端口，`connect` 连不上。
- **`read`/`recv` 可能只收一部分**：TCP 是字节流，一次 `read` 不一定收全；循环读取 + 缓冲才是正确姿势。
- **忘了 `close` 套接字**：文件描述符泄漏，高并发下很快耗尽。
- **`INADDR_ANY` vs 具体 IP**：服务端监听 `INADDR_ANY` 才能接受任意网卡连接；客户端必须填对端 IP。

## 练习

1. 把服务端改成"回显"：收到什么就原样发回，用循环 `read` 处理多次收发。
2. 写个客户端连续发 5 条消息，观察 TCP 字节流如何被服务端分多次 `read` 收齐。

## 小结

本章把网络变成「可 read/write 的 socket」：TCP 服务器 listen/accept、客户端 connect，握手后就是熟悉的字节流收发。结合多线程即可支撑并发连接。

## 示例

下面是一个完整可运行的回显服务器，在最小示例的基础上补齐了工程里真正必要的部分：每一步都检查返回值、用 `SO_REUSEADDR` 避免重启时端口被占、用 `inet_ntop` 打印客户端地址，以及最关键的「循环 read、循环 write」来正确处理 TCP 字节流的分包与短写。

```c
/* 回显服务器：gcc echo.c -o echo && ./echo，另开终端用 nc 127.0.0.1 8080 测试 */
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

int main(void) {
    int srv = socket(AF_INET, SOCK_STREAM, 0);
    if (srv < 0) { perror("socket"); return 1; }

    int on = 1;
    setsockopt(srv, SOL_SOCKET, SO_REUSEADDR, &on, sizeof(on));  /* 重启时不必等 TIME_WAIT */

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family      = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    addr.sin_port        = htons(8080);        /* 端口必须转成网络字节序 */

    if (bind(srv, (struct sockaddr *)&addr, sizeof(addr)) < 0) { perror("bind");   return 1; }
    if (listen(srv, 16) < 0)                                    { perror("listen"); return 1; }
    printf("echo server on 8080\n");

    for (;;) {
        struct sockaddr_in cli_addr;
        socklen_t len = sizeof(cli_addr);
        int cli = accept(srv, (struct sockaddr *)&cli_addr, &len);
        if (cli < 0) { perror("accept"); continue; }

        char ip[INET_ADDRSTRLEN];
        inet_ntop(AF_INET, &cli_addr.sin_addr, ip, sizeof(ip));
        printf("client %s:%d connected\n", ip, ntohs(cli_addr.sin_port));

        char buf[256];
        ssize_t n;
        while ((n = read(cli, buf, sizeof(buf))) > 0) {   /* 循环读：一次不一定收全 */
            ssize_t sent = 0;
            while (sent < n) {                            /* 循环写：一次不一定写完 */
                ssize_t w = write(cli, buf + sent, (size_t)(n - sent));
                if (w <= 0) break;
                sent += w;
            }
        }
        close(cli);        /* read 返回 0 表示对端已关闭连接 */
    }

    close(srv);
    return 0;
}
```
