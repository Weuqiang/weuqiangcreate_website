# 高斯过程与贝叶斯优化

## 学习目标

- 理解高斯过程（GP）作为「函数的分布」：由均值函数与核函数定义的无限维高斯先验
- 掌握 GP 回归的预测均值/方差公式与核的作用
- 理解贝叶斯优化如何用 GP 做黑箱全局优化（采集函数 EI / UCB）
- 认识 GP 的计算瓶颈（$O(n^3)$）与稀疏近似

## 核心概念

### 1. 高斯过程是函数的先验

高斯过程定义为：对任意有限个输入点，对应的函数值服从联合高斯分布。它由均值函数 $m(x)$ 与核（协方差）函数 $k(x,x')$ 完全确定，记作 $f\sim\mathcal{GP}(m,k)$。核编码了我们对函数形状的先验信念：RBF（平方指数）核对应光滑函数，Matérn 核允许一定粗糙，周期核对应周期性。

### 2. GP 回归

观测 $y=f(x)+\varepsilon$，$\varepsilon\sim\mathcal{N}(0,\sigma_n^2)$。给定训练集 $(X,y)$ 与测试点 $X_*$，预测分布仍是高斯：

$$
\mu_* = K(X_*,X)\,[K(X,X)+\sigma_n^2 I]^{-1}y
$$

$$
\Sigma_* = K(X_*,X_*) - K(X_*,X)\,[K(X,X)+\sigma_n^2 I]^{-1}K(X,X,*)
$$

GP 最大的优势是**给出预测的不确定性（方差）**，而不只是点估计——这对安全关键与主动决策极其重要。

### 3. 贝叶斯优化

目标：最小化黑箱函数 $f(x)$，但每次评估昂贵（调超参数、材料实验、训练大模型）。流程：

1. 用 GP 对 $f$ 建立代理模型；
2. 用**采集函数**平衡探索（高不确定性）与利用（高均值）：
   - **期望改进（EI）**：超过当前最佳的可改进量的期望；
   - **上置信界（UCB）**：$\mu+\kappa\sigma$，鼓励高均值或高不确定；
3. 选采集函数最大处评估，更新 GP，迭代。

样本效率极高：往往几十次评估就能逼近近最优，远胜网格/随机搜索。

### 4. 计算与近似

朴素 GP 需 $O(n^3)$ 求逆、$O(n^2)$ 内存。大规模数据用稀疏 GP（inducing points）、局部近似，或把核换成可扩展的 Deep Kernel / 神经过程。

## 示例

用 scikit-learn 的 GP 回归拟合带噪声数据，并输出 95% 置信带：

```python
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, WhiteKernel

np.random.seed(0)
X = np.linspace(0, 5, 12)[:, None]
y = np.sin(X.ravel()) + 0.1 * np.random.randn(12)
kernel = RBF(length_scale=1.0) + WhiteKernel(noise_level=0.1)
gp = GaussianProcessRegressor(kernel=kernel, normalize_y=True).fit(X, y)

Xs = np.linspace(0, 5, 100)[:, None]
mu, std = gp.predict(Xs, return_std=True)
print("预测均值范围", round(mu.min(), 3), round(mu.max(), 3))
print("末点 95% 区间半宽", round(1.96 * std[-1], 3))
```

## 易错点

- **把 GP 当普通高斯分布**：它是函数的分布，只有任意有限子集才联合高斯。
- **忽略核选择**：错误核（如过短 length_scale）会过拟合或欠拟合。
- **忘记噪声项 $\sigma_n^2$**：观测有噪时必须加入，否则置信带过窄、过拟合。
- **高估可扩展性**：朴素 GP 是 $O(n^3)$，大数据必须上稀疏近似。

## 练习

1. 由联合高斯的块矩阵公式推导 GP 回归的预测均值与方差。
2. 为什么贝叶斯优化比网格/随机搜索更适合昂贵黑箱？给出 EI 的直觉表达式。
3. 若核函数 $k(x,x')=x^\top x'$（线性核），GP 回归会退化成什么经典模型？

## 小结

高斯过程把「高斯分布」提升到函数空间，提供带不确定性的非参数回归；贝叶斯优化借 GP 与采集函数，在极少评估内优化昂贵黑箱。它们是自动化调参、实验设计与安全强化学习的关键工具。
