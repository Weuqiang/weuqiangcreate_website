首次成功将 Transformer 架构（原用于 NLP）应用于图像分类任务，挑战了 CNN 在计算机视觉领域的主导地位。

ViT 的成功是深度学习领域方法论的一次重大转变，标志着“大一统”架构（即 Transformer）开始统治 NLP 和 CV 两个领域。

:::info
《An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale》在 2020 年及之后发表的论文中，谷歌学术总引用次数排名第 1。
:::

## 核心思想

CNN 用局部卷积核逐层提取特征；ViT 换了个思路：**把图像切成一堆小方块（patch），每个 patch 当作一个“单词”，把整张图当成一串 token 序列，直接喂给标准 Transformer 编码器**。最后用一个特殊的 `[CLS]` token 的输出做分类。

```
原图 224×224
   │  切成 16×16 的 patch → 196 个 patch
   ▼
每个 patch 展平 + 线性投影 → 196 个向量（维度 768）
   │  加上可学习的位置编码（patch 也有先后）
   │  在最前面拼一个 [CLS] token
   ▼
Transformer Encoder × L 层（自注意力 + MLP）
   │
   ▼
取 [CLS] 的输出 → MLP 分类头 → 类别概率
```

## 为什么能取代 CNN

- **全局感受野**：自注意力一眼看全图，第 1 层就能建立任意两个 patch 的联系；CNN 要堆很多层才能做到。
- **可扩展性强**：模型和数据越大，ViT 增益越明显（在 JFT-300M 这类超大语料上预训练后，ImageNet 精度反超 CNN）。
- **更像一个“通用架构”**：和 NLP 的 Transformer 同构，为后续多模态（图文统一）铺路。

> 代价：ViT 对数据量极其饥渴。数据不足时不如 CNN。后续 **DeiT** 用知识蒸馏，仅用 ImageNet 就能训出好 ViT。

## 最小可运行示例（PyTorch 草图）

```python
import torch
import torch.nn as nn

class PatchEmbed(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_ch=3, embed_dim=768):
        super().__init__()
        # 用卷积把每个 patch 投影成 embed_dim 维向量
        self.proj = nn.Conv2d(in_ch, embed_dim, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        # (B,3,224,224) -> (B,768,14,14) -> (B,196,768)
        return self.proj(x).flatten(2).transpose(1, 2)

class ViTBlock(nn.Module):
    def __init__(self, dim=768, heads=12, mlp_ratio=4):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim)
        self.attn = nn.MultiheadAttention(dim, heads, batch_first=True)
        self.norm2 = nn.LayerNorm(dim)
        self.mlp = nn.Sequential(
            nn.Linear(dim, dim * mlp_ratio), nn.GELU(),
            nn.Linear(dim * mlp_ratio, dim))

    def forward(self, x):
        h = self.norm1(x)
        a, _ = self.attn(h, h, h)          # 自注意力
        x = x + a                          # 残差连接
        x = x + self.mlp(self.norm2(x))    # 残差连接
        return x

x = torch.randn(1, 3, 224, 224)
tokens = PatchEmbed()(x)                       # (1,196,768)
cls = torch.zeros(1, 1, 768)                   # 前置 CLS token
tokens = torch.cat([cls, tokens], dim=1)       # (1,197,768)
out = ViTBlock()(tokens)
print(out[:, 0].shape)                         # (1,768) → 送分类头
```

## 常见误区

- **patch size 不是越小越好**：patch 越小，序列越长，计算和显存暴涨（注意力复杂度是序列长度的平方）。
- **位置编码不能省**：去掉后 patch 变成“一袋单词”，模型不知道上下左右。
- **别在 small 数据集上硬训 ViT**：先用 CNN 或预训练权重，否则容易欠拟合。
